| Comportement | Outils « Cercle » (prototype conservé) et « Arc » (palette, synonymes « circle », « arc », « C », « A ») → mode de saisie (centre-rayon, 2 points, 3 points) dans l'inspecteur → **aperçu** avec rayon (m), diamètre, longueur d'arc, angle balayé (°) → contrôle → validation. Commandes (annexe B) : `{ type: "esquisse.cercle", params: { niveauId, centre, rayon, calqueId } }` et `{ type: "esquisse.arc", params: { niveauId, centre, rayon, angleDebut, angleFin, sens, calqueId } }`, labels « Tracer un cercle » / « Tracer un arc ». Préconditions : niveau existant ; calque non verrouillé ; repère `local`, unités `m` / `°` ; rayon ≥ `longueurMin` ; arc : angle balayé > `tolAngle` et < 360° (un arc de 360° est refusé : utiliser un cercle). Inverse : `esquisse.supprimer`. Modification : `esquisse.modifier` (centre, rayon, angles), inverse = anciens paramètres. **Exigence** (cahier §5.2, D1 / R15) : la géométrie canonique est analytique ; la facettisation pour l'affichage est dérivée et n'est jamais stockée comme canonique. |
| Données et dépendances | Classes `esquisse.cercle`, `esquisse.arc` (ontologie `drawing`) ; `atelier_objects` (`params` : centre, rayon, angles, sens) ; représentation `plan-2d` d'autorité `parametrique`. Facettisation d'affichage dans `core-geometry` avec flèche maximale `flecheAffichage` = 0,001 m (**proposée, à confirmer**). Caractéristiques proposées pour le lot 5 : `esquisse:centre`, `esquisse:debut`, `esquisse:fin`, `esquisse:quadrant[i]` (**recommandation**, à ajouter à §5.2 par L1.1). Points d'accrochage fournis à DA-02-15 : centre, quadrants, extrémités, milieu d'arc. Événement `atelier.commande.validee` → vues du niveau « à recalculer ». |
| Résultats | Cercle ou arc visible au plan, listé dans le navigateur (« Esquisse ») ; inspecteur : centre, rayon, diamètre, périmètre / longueur d'arc, aire (cercle), angles (arc) ; journal ; révision + 1. |
| Cas limites | Rayon ≤ 0 ou < `longueurMin` → 400 `{ chemin: "commands[0].params.rayon", message }`. Niveau supprimé entre-temps → 409. 403 / 423 selon droits et réservation. Hors ligne : file Dexie, rejeu idempotent (T06). |
