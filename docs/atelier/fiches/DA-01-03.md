# DA-01-03 — Arcs and circles / Arcs et cercles — module M01 → Atelier — lot 3a

Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-01-03 (M01, étape cible P1). Sous-exigences : -a cercle (`esquisse.cercle`) ; -b arc (`esquisse.arc`). Référence de comportement : prototype, outil « Cercle » (centre et point de rayon), qui stocke un polygone de 48 côtés ; le prototype n'avait pas d'arc. |
| Situation utilisateur | Esquisser des courbes circulaires exactes (cercle de giration, arrondi, trémie circulaire) dont le rayon reste une valeur et non une liste de sommets. |
| Entrées et unités | `esquisse.cercle` : `centre`, `rayon` (m, au-dessus de la tolérance de longueur). `esquisse.arc` : `centre`, `rayon`, `angleDebut`, `angleFin` (°, sens trigonométrique de début à fin, balayage strictement compris entre 0° et 360°). Communs : `niveauId`, `calqueId`. |
| | Modes de saisie : cercle = centre + rayon (ou diamètre saisi) ; arc = trois points (début, point de passage, fin) ou centre + début + angle. Le mode trois points calcule `centre`, `rayon` et angles ; seuls ces paramètres sont stockés. |
| Comportement | **Cycle.** Outil → points ou valeurs (clic, toucher, saisie DA-02-16) → aperçu avec rayon et angle affichés → contrôle → validation par lot unique ; Échap annule sans commande. Accrochages DA-02-15, dont le centre d'un cercle ou d'un arc. |
| | **Commandes.** `esquisse.cercle`, `esquisse.arc` ; `esquisse.modifier` pour rayon, centre ou angles ; `esquisse.supprimer`. Poignées : DA-02-14 (centre et point de rayon ; début, fin et milieu de l'arc). |
| | **Contrôles.** Rayon sous la tolérance de longueur refusé ; trois points alignés refusés (« Arc — les trois points sont alignés. Écartez le point de passage. ») ; balayage de 0° ou de 360° refusé pour un arc (utiliser `esquisse.cercle`) ; centre ou rayon hors borne du réducteur refusés. |
| | **Clavier et toucher (T16).** Au clavier : centre en coordonnées puis rayon (ou diamètre) ; arc par centre, rayon, angles saisis (DA-02-16). Au toucher : appuis successifs ; deux doigts déplacent ou zooment la vue sans poser de point. |
| | **Palette (UX2) et aide (UX4).** « cercle », « arc » ; synonymes « rond », « courbe », « circle » ; exemple court : cercle de rayon 0,75 m centré sur un point accroché. |
| Données et dépendances | Géométrie canonique paramétrique (R15). Représentation `plan-2d` dérivée : tessellation à une tolérance de flèche d'affichage (R10), autorité `derivee`, moteur `fadi-geometry` versionné ; la tessellation n'est jamais la géométrie stockée. Un cercle est une occurrence indépendante, pas un polygone. |
| | Références : le centre d'un cercle ou d'un arc est accrochable (DA-02-15) mais aucune caractéristique nommée d'esquisse n'existe avant le lot 5 : pas de cotation rattachée, donc pas de référence à réparer (R12) au lot 3a. |
| Résultats | Un cercle ou un arc exact, rayon et angles lisibles dans l'inspecteur avec unités, entrée de journal avec inverse ; vues du niveau « à recalculer ». |
| Cas limites | **Géométrie.** Rayon nul ou négatif ; arc dégénéré (balayage hors ]0°, 360°[) ; trois points alignés ou confondus ; centre hors borne ; calque verrouillé : lot refusé en entier. Grand rayon (trois points presque alignés) : refusé si le centre sort de la borne. |
| | **Concurrence et réseau.** `baseRevision` dépassée → 409 détaillé ; même `requestId` → une seule révision (T06) ; hors ligne : réducteur local puis file Dexie rejouée dans l'ordre ; 403 / 404 / 423 selon R13. |
| Compatibilité | Import P.118 : des tracés à 48 à 96 sommets approchent des cercles (ex. « Rotation Ø 1,50 m · gabarit », 96 sommets, rôle `clearance`) ; l'importeur les garde en polygones (`solide`) : aucune reconnaissance de cercle, un cercle n'est jamais déduit (R3, R7). |
| | DXF : `CIRCLE` et `ARC` à l'export des vues (lot 5) ; l'export actuel n'écrit que `LINE` (un cercle serait aplati en segments : tout aplatissement est signalé au rapport d'export). IFC : omis au rapport (annexe C) ; `IfcCircle` / `IfcTrimmedCurve` en annotation envisageables au lot 6. |
| Validation | **Unité** (`esquisse.test.ts` et `packages/core-geometry`) : rayon 0 refusé ; arc par trois points d'un triangle rectangle : centre au milieu de l'hypoténuse, rayon égal à sa moitié (cas vérifiable à la main) ; trois points alignés refusés ; balayage 360° refusé ; flèche de la tessellation inférieure à la tolérance ; inverse restitue l'état. |
| | **API** (`atelier-commands.test.ts`) : `esquisse.cercle` et `esquisse.arc` → 200 ; `rayon` en « ° » ou négatif → 400 avec `chemin` ; même `requestId` → une seule révision ; `baseRevision` périmée → 409. |
| | **e2e** (`05-atelier.mjs`, bloc « 2D · cercles et arcs ») : cercle de rayon saisi puis arc par trois points sur la mezzanine de la copie de travail P.118 ; rayon relu dans l'inspecteur ; poignée de rayon déplacée ; annuler, rétablir, second navigateur. |
| Règles métier | Aucune règle réglementaire. Gabarits de manœuvre ou de giration : donnée de projet quand P.118 en fournit (rôle `clearance`), jamais valeur par défaut d'un autre bâtiment (R3). |
| Extensions à spécifier | Cercle par deux ou trois points ; arc tangent à un objet ; ellipse ; arc comme segment de polyligne ; rayon piloté par contrainte (DA-01-07 / 08). |
