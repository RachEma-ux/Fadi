Preuve prévue : —

| Champ | Contenu |
| --- | --- |
| Identité | DA-12-11 (M08, P2). Un équipement se pose et se déplace comme tout objet (`transformer.deplacer` / `tourner`) ; ses ports suivent ; après chaque commande, `controlerReseau` rejuge ses connexions : un port qui s'éloigne de plus de 5 mm produit un problème « reseau », effacé quand il revient. |
| Situation utilisateur | Déplacer une pompe sans casser silencieusement le réseau. |
| Entrées et unités | `transformer.deplacer { dx, dy }`, `transformer.tourner`, cibles ; `equipementReseau.modifier`. |
| Comportement | Échelle refusée (ports et sections typés) ; miroir refusé (ports orientés). Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `mep` activable par projet (registre `ontologies/mep/`, T01) ; classes `segment-reseau`, `raccord-reseau`, `vanne`, `equipement-reseau`, `support-reseau` ; définitions `specification` et `catalogue` ; relation `connecte` ; géométrie 3D partagée `geometrie-3d.ts` ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; contrôle `controlerReseau` après chaque commande (T07). |
| Résultats | Problèmes « reseau » (message avec la distance), effacés à la réparation. |
| Cas limites | Échelle, miroir : refus nommés. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC : placement local de l'équipement et de ses ports. |
| Validation | Tests : déplacement de 20 mm → problème, retour → plus rien, suppression → connexions retirées ; recette : même scénario depuis l'API et la fiche. |
| Règles métier | Aucune valeur de réseau dans le code (test : pas de table de DN, pas de débit ni de pression) : sections saisies ou tirées d'un catalogue CSV sourcé (`tubes-raccords.csv`, D-180), fluides et matériaux déclarés, spécifications du projet ; une grandeur absente est « non évaluée » (R3) ; aucun dimensionnement, aucune vérification hydraulique ou aéraulique. |
| Extensions à spécifier | Accrochage des ports au tracé pendant la pose ; alignement automatique sur un port cible. |
