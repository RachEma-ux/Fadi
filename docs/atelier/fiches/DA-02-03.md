# DA-02-03 — Rotate / Tourner — module M02 → Atelier — lot 3a

**État : spécifiée (lot 0)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : —.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-03 (M02, étape cible P1). `transformer.tourner`. Référence de comportement : prototype, outil « Tourner objet » (angle demandé en degrés, rotation autour du premier point de l'objet ; poteau : angle propre seulement) ; le centre est ici choisi explicitement. |
| Situation utilisateur | Faire pivoter des objets d'un niveau autour d'un point choisi, d'un angle exact ou d'un angle de référence, sans casser leurs attachements. |
| Entrées et unités | `niveauId` ; `cibles` ; `centre` (point local, m) ; `angle` `{ value, unit: "°" }` (positif = sens trigonométrique ; non nul modulo 360°). Mode de référence : angle actuel puis angle voulu, seul l'angle résultant est stocké. |
| | Classes admises : celles de DA-02-01 (hors `ouverture` seule). |
| Comportement | **Cycle.** Sélection → centre (accroché, DA-02-15) → angle au pointeur (pas angulaire réglable, accrochage de direction) ou saisie (DA-02-16) → aperçu fantôme avec l'angle affiché → contrôle → validation ; Échap annule sans commande. |
| | **Commandes.** `transformer.tourner`. Mur : axe tourné, `alignement`, `epaisseur` et `hauteur` inchangés, ouvertures hébergées suivent (`t` inchangé). Poteau : `point` tourné et `angle` augmenté de l'angle de rotation. Rectangle : `angle` augmenté. Hachure : contour et motif tournent. Texte et étiquette : position tournée, orientation du texte non modélisée au lot 3a. |
| | **Références (R12).** Rotation d'un même objet : références et caractéristiques nommées conservées (`mur:face-gauche` reste la face gauche), cotations recalculées ; une cotation libre sélectionnée voit `a`, `b` et `decalage` tournés. |
| | **Précision.** `sin` et `cos` peuvent différer au dernier bit entre navigateur et serveur : le résultat validé par le serveur fait autorité, l'écart d'aperçu est borné par la tolérance de comparaison déclarée (test) ; l'inverse restitue les valeurs enregistrées, il ne recalcule pas une rotation opposée. |
| | **Contrôles.** Angle nul modulo 360° refusé (aucun effet) ; angle non fini ou unité autre que ° refusés (T03) ; cible d'un autre niveau, supprimée ou sur un calque verrouillé : lot refusé en entier. |
| | **Palette (UX2) et aide (UX4).** « tourner » ; synonymes « rotate », « pivoter », « rotation » ; actif si au moins un objet d'une classe admise est sélectionné ; exemple court : tourner un mur de 90° autour de son extrémité ; clavier complet par la saisie de précision (DA-02-16). |
| Données et dépendances | Paramètres de position et d'orientation des cibles ; relations `heberge`, `joint-a`, `delimite` recalculées ; jonctions avec des voisins non sélectionnés rompues et listées (rien d'autre ne bouge) ; événement de commande validée : vues, quantités et bilan Harmonie « à recalculer ». |
| Résultats | Objets pivotés, effets listés (objets modifiés, jonctions rompues, problèmes), inverse = valeurs précédentes enregistrées. |
| Cas limites | **Géométrie.** Angle 0° ou 360° ; centre sur un objet de la sélection (admis) ; rotation d'un escalier d'un `groupe` : autres occurrences listées, jamais tournées en silence ; pièce dont la délimitation ne correspond plus à ses murs : problème listé. |
| | **Concurrence.** `baseRevision` dépassée et cible modifiée ou supprimée depuis → 409 détaillé, résolution explicite côté client ; même `requestId` → réponse enregistrée, aucune seconde révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie rejouée dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |

| | IFC : placements exportés après rotation, `IfcRelVoidsElement` conservé. DXF : aucune sortie propre. Objets « représentation importée » (lot 6) : classes admises à préciser. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts`) : rotation de 90° d'un mur autour de son extrémité `a` : `b` tournée à la tolérance près (valeurs vérifiables à la main) ; porte : `t` inchangé ; poteau : `angle` + 90° ; 0° et 360° refusés ; inverse = valeurs précédentes bit à bit ; écart aperçu / validé inférieur à la tolérance déclarée. |
