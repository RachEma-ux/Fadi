# DA-07-01 — Walls / Murs — module M05 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-07-01 (M05, étape cible P1). Un mur est un objet de classe `mur` (building.architecture) défini par un axe, une épaisseur, une hauteur ou un niveau haut, un alignement et un type (`cloison`, `mur`, `non-type`). Sous-exigences : -a tracer (`mur.tracer`) ; -b modifier (`mur.modifier`) ; -c scinder (`mur.scinder`) ; -d joindre et jonctions (`mur.joindre`) ; -e supprimer (`mur.supprimer`). Référence de comportement : prototype, les 220 murs de P.118 et leurs ouvertures hébergées. |
| Situation utilisateur | Tracer et modifier les murs d'un niveau, les voir se joindre à leurs voisins et les scinder sans perdre les portes, fenêtres et cotes qui leur sont liées, ni rien rattacher en silence. |
| Entrées et unités | `niveauId` ; `a`, `b` `{ x, y, frame: "local", unit: "m" }` (longueur de l'axe supérieure à la tolérance de longueur, DA-01-01) ; `epaisseur` `{ value, unit: "m" }` (> 0) ; `hauteur` `{ value, unit: "m" }` (> 0) ou `niveauHaut` (niveau existant, d'élévation supérieure à celle du niveau du mur) ; `alignement` (gauche, axe, droite) ; `typeId` (`cloison`, `mur`, `non-type`) ; `calqueId` ; `nom` ; `exterieur` (booléen). Points accrochés (DA-02-15) ou longueur et angle saisis (DA-02-16). |
| | Unité autre que m refusée (T03). Aucune épaisseur, hauteur ni type par défaut (R3) : `non-type` est une valeur explicite, jamais attribuée en silence ; une `hauteur` absente reste « non évaluée » (mur tracé en plan, exclu des volumes, aucune valeur déduite du niveau) ; `exterieur` non déclaré reste « non évalué ». |
| Comportement | **Cycle.** Outil « Mur » → paramètres (type, épaisseur, hauteur ou niveau haut, alignement, calque) → points successifs accrochés ou saisis → aperçu (polygone du mur, longueur, angle, jonctions créées avec les murs voisins) → contrôle → validation ; Entrée valide le chaînage, Échap l'annule sans commande. Un chaînage de N segments est un seul lot (libellé « Tracer N murs »). |
| | **Commandes.** `mur.tracer` ; `mur.modifier` (épaisseur, hauteur ou niveau haut, alignement, type, calque, nom, `exterieur` ; déplacer une extrémité relève de `transformer.etirer`, DA-02-06) ; `mur.scinder` ; `mur.joindre` ; `mur.supprimer`. Chaque commande déclare préconditions, effets et inverse (section 5.3). |
| | **Jonctions.** Deux murs dont une extrémité coïncide, à la tolérance de longueur (DA-01-01), avec une extrémité ou l'axe d'un autre sont joints (`joint-a`, relation dérivée, jamais saisie) ; le traitement d'angle (L, T) est un calcul de `core-geometry` sur axes et épaisseurs, sans seconde géométrie (R15). `mur.joindre` prolonge ou raccourcit les axes jusqu'à leur intersection, valeurs avant et après dans l'aperçu ; axes parallèles refusés. |
| | **Scission et références (R12).** `mur.scinder` en un point de l'axe (accroché ou à distance saisie) remplace le mur par deux nouveaux murs (identifiants nouveaux) de mêmes paramètres typés, joints au point de scission. Chaque ouverture hébergée est réaffectée au mur qui contient son emprise : `t` recalculé, position dans le plan et dimensions inchangées. Un point de scission dans l'emprise d'une ouverture est refusé avec la plage interdite. Cotations et étiquettes rattachées au mur d'origine (`mur:face-gauche`, `mur:arete-fin`…) passent « à réparer » avec propositions ; `reference.reparer` choisit ou détache. |
| | **Contrôles et palette.** Longueur nulle ; `epaisseur` ou `hauteur` ≤ 0 ; `niveauHaut` absent ou non supérieur ; `niveauId`, `typeId` ou `calqueId` inconnu ; calque verrouillé : lot refusé en entier. Mur superposé à un mur existant : signalé, jamais fusionné. Palette (UX2) : « mur » ; synonymes « wall », « cloison » ; exemple court : tracer un mur de 4,50 m (exemple, jamais valeur par défaut) ; aide (UX4) ; clavier complet par la saisie de précision. |
| Données et dépendances | Classes `mur`, `porte`, `fenetre`, `ouverture`, `cotation`, `etiquette`, `piece` ; relations `heberge` (mur → ouvertures), `joint-a` et `delimite` (dérivées, recalculées) ; `niveauHaut` vers `niveau` ; définitions `cloison`, `mur`, `non-type` ; caractéristiques nommées `mur:face-gauche`, `mur:face-droite`, `mur:arete-debut`, `mur:arete-fin`, `mur:axe`. |
| | `core-geometry` (polygones, jonctions) ; événement `atelier.commande.validee` : vues, quantités et bilan Harmonie « à recalculer » (R11, T07) ; microversion +1. Pièces dont la délimitation ne correspond plus aux murs : problème listé, `piece.detecter` propose (DA-07-15). |
| Résultats | Mur tracé, modifié, scindé, joint ou supprimé (état « local » puis « synchronisé ») ; effets dans le panneau des modifications (ouvertures réaffectées, références à réparer, pièces à revoir) ; inverse = objets et valeurs précédents, références comprises. |
| Cas limites | **Géométrie.** Longueur nulle ; hôte raccourci (`mur.joindre`, `transformer.etirer`) : une ouverture dont l'emprise sort du mur passe « à réparer » (déplacer dans l'emprise, supprimer, détacher), listée dans l'aperçu avant validation ; `mur.supprimer` refusé tant que des ouvertures sont hébergées, sauf option explicite de les supprimer avec lui (listées) ; `niveauHaut` supprimé par autrui : refus au rejeu. |
| | **Concurrence.** `baseRevision` dépassée et mur ou ouverture modifié ou supprimé depuis → 409 avec `conflits[].objetId` et état serveur ; résolution explicite côté client ; un objet supprimé par autrui ne réapparaît pas. Même `requestId` → réponse enregistrée, aucune seconde révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie (une entrée par lot), rejeu dans l'ordre à la reconnexion, brouillon si incompatible. Rôle `write` exigé : 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 (section 6) : 220 `mur` (types `cloison`, `mur` ou absent → `non-type` ; `exterieur` d'après `exteriorWallIds` ; `layer` → `calqueId` ; `lineRef` et `color` en propriétés de provenance `import`) ; coordonnées et épaisseurs conservées bit à bit ; 210 ouvertures hébergées (84 portes, 126 fenêtres). |
| | IFC (annexe C, lot 6) : `IfcWall` (+ `IfcWallType`), `IfcExtrudedAreaSolid`, `IfcMaterialLayerSet` seulement si la composition est connue (aucun matériau inventé) ; deux murs issus d'une scission = deux `IfcWall`, `IfcRelVoidsElement` rattachés au bon mur. DXF : aucune sortie propre, vues de plan au lot 5. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/mur.test.ts`) : tracé (coordonnées exactes, paramètres typés conservés) ; longueur nulle, épaisseur ≤ 0, unité ≠ m, `niveauHaut` invalide refusés ; jonctions L et T détectées sans déplacer d'axe ; `mur.joindre` : axes prolongés à l'intersection, axes parallèles refusés ; `mur.scinder` : deux murs, ouvertures réaffectées (`t` recalculé, position inchangée à la tolérance), scission dans une emprise refusée, cotation sur `mur:face-gauche` « à réparer » avec propositions ; inverse restitue le mur, ses ouvertures et ses références. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `mur.tracer` → 200, révision +1, `applique[].objetIds`, `effets` ; même `requestId` → même réponse ; `baseRevision` périmée et mur modifié → 409 avec `conflits[].objetId` ; épaisseur nulle → 400 avec `chemin` ; `mur.scinder` → `effets.problemes` (cotations à réparer) ; rôle lecture → 403 ; réservation d'autrui → 423 ; `/commands/essai` : mêmes effets, aucune révision. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · murs ») : copie de travail de P.118 : 220 murs, 84 portes et 126 fenêtres comptés d'après le rapport d'import ; tracer un mur, annuler, rétablir ; scinder `EX118-mezz-W-009` en un point hors de l'emprise de la porte `EX118-mezz-D-001` (t = 0,5) : porte réaffectée, position inchangée ; annuler : mur d'origine, porte à t = 0,5 ; second navigateur à la même révision. |
| Règles métier | Aucune règle réglementaire (épaisseur minimale, hauteur, résistance au feu, isolation : non fournies ; règles selon pays, usage et version identifiés, à fournir avec leur source). R3 : aucune dimension ni type par défaut, valeurs absentes « non évaluées ». R9 : tout passe par une commande typée et inversible. R10 : niveau actif et sélection hors révision. R12 : jamais de rattachement silencieux. |
| Extensions à spécifier | Murs courbes ; composition en couches et matériaux ; murs inclinés ou à profil ; jonctions à priorité et traitement d'angle sur mesure ; scission en plusieurs points ; murs-rideaux (DA-07-14, P2) ; suppression logique (lot 7). |
