# DA-06-01 — Constraints / Contraintes d'esquisse — module M03 → Atelier — lot 5

Preuve liée : `packages/atelier-model/src/commandes/contrainte.test.ts`, `contrainte-plus.test.ts`, `contrainte-murs.test.ts`, `contraintes-cercles.test.ts`, recette `apps/web/e2e/atelier-documents.mjs` ; `lots/lot-5.md`, D-018, D-051.

| Champ | Contenu |
| --- | --- |
| Identité | DA-06-01 (M03, P1). Jeu **borné** de contraintes d'esquisse 2D : coïncidence, horizontal, vertical, parallèle, perpendiculaire, distance (pilotante ou de contrôle) [D-018] ; puis longueurs égales, au milieu, sur la ligne, fixe, symétriques, angle, tangence [D-051]. Pas de solveur général (D.3, cahier §2.2). |
| Situation utilisateur | Tenir une esquisse cohérente quand on déplace un sommet : garder deux segments parallèles, une longueur, un alignement. |
| Entrées et unités | `contrainte.ajouter` { type, cibles (sommets ou segments d'esquisse du même niveau), valeur (m ou °) } ; `contrainte.supprimer` ; `contrainte.modifier` (valeur). Tolérance de respect `TOLERANCE_CONTRAINTE` = 5 µm (D-051). |
| Comportement | La contrainte s'ajoute depuis l'inspecteur sur la sélection ; à chaque commande qui déplace un sommet contraint, le solveur de Gauss-Newton au plus petit déplacement résout l'ensemble des contraintes du groupe ; un système incompatible refuse la commande en nommant la contrainte ; une contrainte de contrôle n'impose rien et affiche l'écart. |
| Données et dépendances | Relation `contrainte` entre occurrences d'esquisse ; `atelier-model/src/contraintes.ts` (solveur), `commandes/contrainte.ts` ; une contrainte dont une cible disparaît passe « à réparer » (R12). |
| Résultats | Esquisse résolue à 5 µm ; état de chaque contrainte (respectée, à réparer, contrôle avec écart) dans l'inspecteur et le panneau des problèmes. |
| Cas limites | Système sur-contraint : commande refusée (409 côté serveur, même solveur) ; cible supprimée : « à réparer » avec propositions ; déplacement rigide d'un groupe entièrement contraint : accepté (tolérance 5 µm, D-051) ; cercles et arcs : centre / rayon pilotés (`contraintes-cercles`). |
| Compatibilité | Archive v2 : contraintes revalidées à l'import ; IFC / DXF : non exportées (données de conception) ; P.118 : aucune contrainte importée. |
| Validation | Tests cités : résolution, refus incompatible, « à réparer », tolérance ; recette : contrainte posée dans le navigateur et respectée après déplacement. |
| Règles métier | Aucune règle réglementaire ; R3 : une valeur pilotante est saisie, jamais devinée. |
| Extensions à spécifier | Solveur d'assemblage 3D (P2-2, D-178) ; proposition automatique de coïncidence à l'accrochage (non fait, déclaré lot 5). |
