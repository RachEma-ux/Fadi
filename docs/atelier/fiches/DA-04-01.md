# DA-04-01 — Extrusion / Extrusion d'esquisse — module M02 → Atelier — lot 3b

**État : prototype (lot 3b)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs` (partie 3D), tests `packages/atelier-model/src/projection/maillage.test.ts` ; compte rendu `lots/lot-3b.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-04-01 (M02, étape cible P1). Sous-exigences : -a extruder un profil polygonal fermé ; -b profil avec trous ; -c extruder vers le haut ou vers le bas ; -d conserver ou consommer l'esquisse. Contrôle commun de la section : résultat géométrique valide, erreurs et références ambiguës signalées. Référence de comportement : prototype, polygones extrudés en `solide` (hauteur et décalage de base). |
| Situation utilisateur | Transformer un contour tracé dans le plan d'un niveau en volume plein d'une hauteur donnée. |
| Entrées et unités | `solide.extruder` : `niveauId` ; `profil` : un ou plusieurs contours fermés (`esquisse.polygone` ou `esquisse.rectangle` du niveau, ou points `{ x, y, frame: "local", unit: "m" }`) ; `hauteur` `{ value, unit: "m" }` (> 0, saisie obligatoire, aucune valeur par défaut, R3) ; `direction` (`haut` ou `bas`) ; `decalageBase` `{ value, unit: "m" }` (0 m si non précisé : base à l'élévation du niveau, valeur affichée) ; `calqueId` ; `nom` et `couleur` facultatifs ; `consommerEsquisse` (booléen, faux par défaut). |
| Comportement | **Cycle.** Sélection d'un ou plusieurs profils fermés (clic, lasso) → hauteur (saisie, clavier ou glisser d'une poignée, DA-02-16) → aperçu 3D du volume fantôme avec hauteur, aire et volume dérivés → contrôle → validation ; Échap annule sans commande. Un polygone fermé sélectionné avec l'outil Pousser / tirer (DA-04-07) émet la même commande. |
| | **Commande.** `solide.extruder` (annexe B), libellé « Extruder N profils » ; un lot, un `solide` par contour extérieur avec ses trous. Direction `bas` : `decalageBase` diminue de la hauteur et `hauteur` reste positive (une seule convention canonique). Le `solide` copie le contour : aucune dépendance ensuite entre l'esquisse et le solide (pas d'historique, R15, R16) ; l'esquisse est conservée sauf `consommerEsquisse`, qui la supprime dans le même lot. |
| | **Contrôles.** Profil ouvert, auto-sécant, d'aire nulle ou à sommets confondus (tolérance de DA-01-01) refusé ; trou hors du contour extérieur ou en recoupant un autre refusé, avec le trou nommé ; profil intérieur à un autre : ambiguïté signalée à l'aperçu (trou ou solide séparé), choix explicite, jamais deviné ; profil courbe (`esquisse.cercle`, `.arc`, `.spline`) refusé (message : noyau exact ou polygonisation explicite, extension) ; `hauteur` ≤ 0 ou unité ≠ m refusée (T03) ; calque ou niveau verrouillé : lot refusé en entier ; coordonnée résultante hors borne refusée. |
| | **Rôle, palette (UX2) et aide (UX4).** `role` = `solid`, seul rôle créé par l'interface au lot 3b (les autres rôles du prototype sont conservés à l'import et ne se choisissent pas ici). « extruder » ; synonymes « extrusion », « extrude » ; actif si au moins un profil fermé est sélectionné ; exemple court : extruder un polygone sur 3,00 m (jamais une valeur par défaut). |
| Données et dépendances | Crée un `solide` (`contour`, `trous`, `ferme` = vrai, `hauteur`, `decalageBase`, `role`, `calqueId`) ; supprime éventuellement l'esquisse source ; représentation `solide-3d` dérivée (DA-03-01). `core-geometry` : simplicité, inclusion, aire, triangulation, maillage. Événement de commande validée : vues et quantités « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Un ou plusieurs `solide` sélectionnables, modifiables (DA-04-07, `solide.modifier`) et annulables ; volume dérivé ; effets listés (esquisses consommées) ; inverse supprime les solides et restitue les esquisses. |
| Cas limites | **Géométrie.** Deux profils disjoints : deux solides ; esquisse supprimée par autrui entre l'aperçu et la validation : 409, aucun solide créé ; maillage non triangulable : refusé avant écriture ; profil ouvert d'un export du prototype (« Ligne », `closed: false`) : non extrudable (solide à contour ouvert, voir DA-03-01). |
| | **Concurrence et réseau.** `baseRevision` dépassée et profil modifié ou supprimé depuis → 409 avec `conflits[].objetId` ; un profil supprimé par autrui ne réapparaît pas ; même `requestId` → un seul solide (T06). Hors ligne : réducteur local (aperçu 3D inclus), file Dexie, rejeu dans l'ordre, brouillon si l'esquisse a changé. 403 / 404 / 423 selon R13. |
| Compatibilité | Import P.118 : les 967 tracés fermés deviennent des `solide` (cahier §6) avec contours, trous, hauteurs et décalages repris sans arrondi ; aucune extrusion n'est recalculée à l'import. IFC : `IfcExtrudedAreaSolid` à l'export (annexe C, lot 6) ; à l'import, une extrusion IFC devient un `solide` seulement si profil et direction le permettent, sinon représentation importée (R16). DXF : aucune sortie 3D ; emprise 2D dans les vues (lot 5). |
| Validation | **Unité** (`packages/atelier-model/src/commandes/solide.test.ts`) : polygone de 4 sommets extrudé : `hauteur` et `decalageBase` exacts, volume = aire × hauteur ; rectangle avec trou : volume = (aire − aire du trou) × hauteur ; direction `bas` : base abaissée, hauteur positive ; profil ouvert, auto-sécant, hauteur ≤ 0, unité ≠ m, cercle refusés ; consommation de l'esquisse : supprimée dans le lot ; inverse restitue l'état initial. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `solide.extruder` → 200, révision +1, `effets` ; profil auto-sécant → 400 avec `chemin` du sommet ; même `requestId` → même réponse ; `baseRevision` périmée et esquisse supprimée → 409 ; rôle lecture → 403 ; réservation d'autrui → 423. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 3D · extrusion ») : copie de travail de P.118 : le polygone de 4 sommets de la mezzanine (DA-01-02) extrudé à une hauteur saisie : volume affiché = aire × hauteur ; annuler, rétablir, révisions persistées, second navigateur ; ligne `⏱ extrusion d'un profil (aperçu 3D)` imprimée (R14), sans seuil. |
| Règles métier | Aucune règle réglementaire. R3 : hauteur saisie, jamais par défaut ; les valeurs d'exemple de la palette ne sont jamais des valeurs par défaut. R14 : aucune performance annoncée avant mesure. R15 : maillage dérivé, géométrie canonique paramétrique. |
| Extensions à spécifier | Profils courbes (polygonisation avec tolérance déclarée, ou noyau exact : lot optionnel OCCT) ; extrusion d'un profil ouvert avec épaisseur ; extrusion oblique, avec dépouille ou le long d'un trajet (DA-04-03) ; lien paramétrique esquisse → solide (lot 5, contraintes). |
