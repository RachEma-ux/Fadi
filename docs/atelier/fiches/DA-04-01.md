# DA-04-01 — Extrusion / Extrusion — module M02 → module Fadi Atelier — lot 3b

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : — (à lier au lot 3b).

Attention : l'outil « Extruder » du prototype (`v14-tools.js`, `fdExtrude`) ne fait **pas** d'extrusion : il
creuse une « coque » (trou décalé d'une épaisseur dans un polygone fermé) ou « perce » un mur / un volume. Cette
fiche couvre l'extrusion d'un contour d'esquisse en solide (`solide.extruder`). La coque relève de DA-04-10 et le
percement de DA-04-09 (lot optionnel) ou de `ouverture.poser` (DA-07-02 / 03 / 04, fiches B) ; leur sort est une
question (voir Extensions).
