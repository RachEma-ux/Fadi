Sous-exigences : **DA-07-02-a** poser une porte dans un mur hôte ; **-b** la déplacer le long du mur ; **-c** modifier ses paramètres (largeur, hauteur, allège, repère, type) ; **-d** la supprimer ; **-e** contrôle d'emprise dans le mur hôte ; **-f** symbole de plan dérivé ; **-g** importer les portes de P.118. | Situation utilisateur | L'architecte place une porte dans un mur existant (clic sur le mur, position ajustée par saisie de distance), règle sa largeur et sa hauteur, la fait glisser le long du mur, la change de type ; il voit immédiatement si elle sort du mur ou chevauche une autre baie, et la porte suit le mur quand celui-ci est modifié ou scindé. |
| Entrées et unités | `classe = "porte"` ; `murHoteId` (mur existant, même niveau) ; `position` : `t` ∈ [0, 1] le long de l'axe du mur, **et** `distance` `{ value, unit: "m" }` dérivée (= `t` × longueur de l'axe, mesurée depuis `mur:arete-debut` jusqu'au **centre** de la porte — lecture confirmée sur P.118 : avec elle, aucune des 210 baies n'est hors emprise ; à figer par L1.1 avec un test) ; `largeur` `{ value, unit: "m" }` > 0 (largeur de baie) ; `hauteur` `{ value, unit: "m" }` > 0 ; `allege` `{ value, unit: "m" }` ≥ 0 ; `repere` (texte, facultatif) ; `typeId` (définition de porte du catalogue versionné ; `non-type` si aucune). Saisie à la souris (accrochage sur l'axe du mur, milieu du mur, distance à l'extrémité) ou au clavier (distance en m). Aucune valeur par défaut tirée de P.118 : dernières valeurs saisies dans la session ou champ vide (R3). Le sens d'ouverture et la main ne sont pas des paramètres de l'occurrence au lot 3 : ils appartiennent à la définition de type (proposition §4.2 « type de porte (dimensions, sens) ») ; absents, ils restent « non renseignés ». |
| Comportement | **Poser** : outil Porte → survol d'un mur (aperçu de la baie et de son symbole, cotes de position) → contrôle d'emprise → validation = `ouverture.poser` (`classe: "porte"`). **Déplacer** = `ouverture.deplacer` (nouveau `t` sur le même mur ; le changement de mur hôte est un déplacement vers un autre `murHoteId` du même niveau, contrôlé de même). **Modifier** = `ouverture.modifier`. **Supprimer** = `ouverture.supprimer` (le mur hôte n'est pas modifié ; les références qui visent `ouverture:centre` passent « à réparer », R12). **Contrôle d'emprise** (précondition de chaque commande) : `[distance − largeur/2, distance + largeur/2]` inclus dans `[0, longueur de l'axe]`, aucun recouvrement avec une autre baie du même mur, `allege + hauteur` ≤ hauteur du mur (ou hauteur dérivée de `niveauHaut`) ; tolérance 0,001 m **proposée** (déléguée au chef de projet, §10.2). Sur `mur.modifier` ou `mur.scinder` du mur hôte, la porte suit (`t` recalculé, `distance` conservée) ou la commande du mur est refusée avec la liste des portes touchées (DA-07-01). **Symbole de plan dérivé** (représentation `plan-2d`, R15) : selon la propriété `openingType` si elle existe (`hinged` battant, `sliding` coulissante, `sectional` sectionnelle) ; sinon symbole neutre de baie et mention « type d'ouverture non renseigné » — jamais un battant deviné. |

Modules : `atelier-model` (réducteur, contrôle d'emprise), `core-geometry`, service de commandes, Documents (tableau des portes au lot 5). | Résultats | Porte hébergée dans son mur, découpe du mur dans les vues 2D et 3D, symbole de plan ; effectifs de portes par niveau ; entrée du journal, révision `n + 1`. |
| Cas limites | Mur hôte inexistant, supprimé ou sur un autre niveau → refus 400 / 409. Porte hors emprise ou chevauchant une autre baie → refus avec la baie en cause. Largeur supérieure à la longueur du mur → refus. `allege + hauteur` > hauteur du mur → refus. Largeur ou hauteur ≤ 0, unité non métrique → 400 `{ chemin, message }` (T03). `t` hors [0, 1] → refus. Import d'une porte dont l'hôte est introuvable → porte créée **et** problème « hôte introuvable » (cahier §6, jamais supprimée ; aucun cas dans P.118). Deux comptes déplacent la même porte → 409 ; l'un supprime le mur pendant que l'autre déplace la porte → 409, pas de réapparition (Architecture V4 §7). Requête répétée → une seule révision (T06). Hors ligne → file Dexie, brouillon si incompatible au retour. |
