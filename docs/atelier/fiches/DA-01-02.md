| Comportement | Cycle UX3 (cahier §5.8) : outil « Ligne » ou « Polyligne » (palette `Ctrl/⌘ K`, synonymes « line », « polyline », « pline », « trait ») → paramètres dans l'inspecteur (calque, fermeture) → **aperçu** du segment courant (longueur en m, angle en °) par le même réducteur pur que le serveur → contrôle à chaque point → validation : clic sur le premier point (ferme), double-clic ou `Entrée` (termine ouverte), `Retour arrière` (retire le dernier point de l'aperçu), `Échap` (abandonne sans commande).<br>Commandes émises (annexe B, noms tels quels) : `{ type: "esquisse.ligne", params: { niveauId, a, b, calqueId, nom? } }` ou `{ type: "esquisse.polyligne", params: { niveauId, points, ferme, calqueId, nom? } }`, `label` « Tracer une ligne » / « Tracer une polyligne ». Préconditions : niveau existant ; calque existant non verrouillé (**hypothèse** : le drapeau `verrouille` interdit la création, à confirmer avec DA-05-01) ; points en repère `local`, unité `m`, coordonnées finies ; chaque segment ≥ `longueurMin`. Effet : un objet créé ; inverse = `esquisse.supprimer`.<br>Modifier les sommets : `esquisse.modifier` (`cibles: [id]`, `params: { points, ferme }`), inverse = `esquisse.modifier` avec les anciens paramètres. Supprimer : `esquisse.supprimer`, inverse = recréation à l'identique (même identifiant). **Exigence** (R9) : aucun tracé n'atteint le modèle hors de ces commandes ; le serveur refuse, il ne corrige jamais. |

| Résultats | Un objet d'esquisse `${projectId}_${id}` visible dans le plan 2D du niveau, listé dans le navigateur du projet (classe « Esquisse ») ; inspecteur : longueur totale (dérivée), nombre de sommets, fermé, aire si fermée (dérivée), calque ; entrée de journal ; vues du niveau marquées « à recalculer ». |
| Cas limites | Segment < `longueurMin` (0,001 m, proposée, à confirmer) : point refusé dans l'aperçu ; côté serveur 400 `details: [{ chemin: "commands[0].params.points[2]", message: "segment de longueur nulle" }]`.
