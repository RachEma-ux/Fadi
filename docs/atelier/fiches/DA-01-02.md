| Champ | Contenu |
| --- | --- |
| Identité | DA-01-02 (M01, étape cible P1). Sous-exigences : -a ligne (`esquisse.ligne`) ; -b polyligne ouverte (`esquisse.polyligne`) ; -c polygone fermé (`esquisse.polygone`). Contrat de précision : DA-01-01. Référence de comportement : prototype, outils « Ligne » (deux points) et « Polygone » (sommets successifs, « Terminer pour fermer »). |
| Situation utilisateur | Tracer des segments et des chaînes de segments droits dans le plan d'un niveau pour esquisser un contour, un axe d'implantation ou un profil, puis les modifier sans perdre leur identité. |
| Entrées et unités | `esquisse.ligne` : `a`, `b` (points locaux, m). `esquisse.polyligne` : `sommets` (au moins 2 points, segments droits, chaîne ouverte). `esquisse.polygone` : `sommets` (au moins 3, contour fermé simple). Communs : `niveauId`, `calqueId`, `nom` et `couleur` facultatifs (couleur du calque par défaut). |
| | Pendant le tracé : longueur (m) et angle (°) du segment en cours, ou x, y absolus (DA-02-16) ; accrochages DA-02-15 (extrémité, milieu, perpendiculaire, intersection, orthogonal, grille 0,50 m). |
| Comportement | **Cycle.** Outil Ligne : premier point, second point (clic, toucher ou saisie), validation immédiate. Outil Polyligne : points successifs ; Entrée ou double clic termine ; Retour arrière retire le dernier sommet ; Échap annule sans commande. Fermer (retour sur le premier sommet) émet `esquisse.polygone` au lieu de `esquisse.polyligne`. Aperçu : segment élastique avec longueur et angle affichés. |
| | **Commandes.** `esquisse.ligne`, `esquisse.polyligne`, `esquisse.polygone` (libellé du lot : « Tracer une polyligne ») ; valeur modifiée dans l'inspecteur : `esquisse.modifier` ; suppression : `esquisse.supprimer` (aucun effet sur d'autres objets). Poignées de sommet : DA-02-14. |
| | **Contrôles.** Sommets consécutifs confondus (tolérance de longueur, DA-01-01) refusés, jamais fusionnés en silence ; polygone d'aire nulle (sommets alignés) ou auto-sécant refusé (« Polygone — le côté 3 coupe le côté 1. Déplacez un sommet. ») ; polyligne ouverte : auto-intersection admise, signalée à l'aperçu ; nombre de sommets borné par la limite d'enveloppe (1 Mo). |
| | **Clavier et toucher (T16).** Tracé complet au clavier : premier point en coordonnées, puis longueur et angle, Entrée, Échap (DA-02-16). Au toucher, un appui pose un point (`pointer events` unifiés) ; deux doigts déplacent ou zooment la vue sans poser de point. |
| | **Palette (UX2) et aide (UX4).** « ligne » ; synonymes « segment », « polyligne », « polygone » ; actif si un niveau modifiable et un calque libre sont choisis ; exemple court : tracer un segment de 4,5 m à 30°. |
| Données et dépendances | Occurrences `esquisse.ligne`, `.polyligne`, `.polygone` (`drawing`), sans relation. Un polygone simple est un profil candidat pour `solide.extruder` (DA-04-01, lot 3b) et pour `esquisse.hachure` (DA-01-11). `core-geometry` : intersections et contrôle de simplicité. Événement de commande validée : vues du niveau « à recalculer ». |
| | Références : aucune caractéristique nommée d'esquisse n'existe avant le lot 5 (cotations et contraintes, DA-01-07) ; au lot 3a aucune cotation ne se rattache à une esquisse, donc aucune référence à réparer (R12) n'est créée par ces objets. |
| Résultats | Une ligne, une polyligne ou un polygone par lot, dans le calque choisi, sélectionnable, modifiable, annulable ; entrée de journal avec inverse. |
| Cas limites | **Géométrie.** Ligne de deux points confondus ; sommet répété ; polygone dégénéré ou auto-sécant ; `niveauId` inconnu ; calque verrouillé : lot refusé en entier, rien n'est écrit. Un tracé interrompu (perte de focus, `pointercancel`) est annulé sans commande. |
| | **Concurrence et réseau.** `baseRevision` dépassée → 409 détaillé, résolution explicite côté client ; même `requestId` → une seule révision (T06). Hors ligne : réducteur local puis file Dexie rejouée dans l'ordre, brouillon si incompatible. 403 / 404 / 423 selon R13. |
| Compatibilité | Import P.118 : aucun tracé ouvert (967 tracés fermés) ; les polygones du prototype deviennent des `solide` (cahier §6), pas des `esquisse.polygone`. Un tracé ouvert d'un export du prototype (« Ligne », 2 points, `closed: false`) devient un `solide` à contour ouvert. |
| | DXF : `LINE` et `LWPOLYLINE` à l'export des vues (lot 5 ; l'export actuel n'écrit que `LINE`) ; import DXF 2D en `reference-plan` (lot 6). IFC : omis au rapport d'échange (annexe C sans correspondance). |
| Validation | **Unité** (`esquisse.test.ts`) : ligne a = b refusée ; polyligne à 1 sommet refusée ; polygone en 8 refusé avec les deux côtés nommés ; polygone aligné refusé ; sommets consécutifs confondus refusés ; inverse restitue l'état initial. |
| | **API** (`atelier-commands.test.ts`) : `esquisse.polyligne` valide → 200 et `effets` ; polygone auto-sécant → 400 avec `chemin` du sommet ; même `requestId` → même réponse ; `baseRevision` périmée → 409. |
| | **e2e** (`05-atelier.mjs`, bloc « 2D · lignes ») : polyligne de 4 sommets sur la mezzanine de la copie de travail P.118, fermée en `esquisse.polygone` ; annuler, rétablir, révisions persistées, second navigateur ; ligne de 4,5 m à 30° saisie au clavier, valeurs exactes. |
| Règles métier | Aucune règle réglementaire. Types de trait normalisés : non fournis (R3). |
| Extensions à spécifier | Segments en arc dans une polyligne ; polygone régulier (centre, rayon, nombre de côtés) ; jonction de lignes en polyligne (inverse de DA-02-13) ; détection de contours fermés depuis des lignes jointives (proposition, jamais imposée). |
