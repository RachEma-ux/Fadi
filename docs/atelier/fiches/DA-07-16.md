# DA-07-16 — Spaces / Espaces — module M05 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-07-16 (M05, étape cible P1). Un espace est un objet de classe `espace` (building.architecture) : région nommée d'un niveau, délimitée par un ou plusieurs polygones, qui n'est pas une pièce programmée. Il se distingue de la `piece` (DA-07-15) : pas de code, pas d'aire déclarée, pas de liaison `programme`. Sous-exigences : -a créer ; -b modifier ; -c supprimer (famille `espace.*` de l'annexe B) ; -d convertir en pièce. Référence de comportement : prototype, tracés `role = room` de P.118 sans pièce de même code. |
| Situation utilisateur | Délimiter sur un niveau une région du plan qui n'est pas (ou pas encore) une pièce du programme, la nommer, la classer et en connaître l'aire géométrique. |
| Entrées et unités | `niveauId` ; `polygones` (un ou plusieurs contours fermés `{ x, y, frame: "local", unit: "m" }`) ; `nom` ; `categorie` (texte du projet, aucune liste imposée). L'aire calculée est dérivée des `polygones` (m²), jamais saisie. Contour tracé (polygone, rectangle), pris sur une région fermée par les murs proposée par la détection (DA-07-15), ou copié d'un tracé fermé sélectionné (copie, sans lien caché). |
| | Unité autre que m refusée (T03). Aucun nom ni aucune catégorie par défaut (R3) : absents, ils restent « non évalués ». |
| Comportement | **Cycle.** Outil « Espace » → contour (tracé, région détectée, tracé fermé existant) → paramètres (nom, catégorie) → aperçu (polygone, aire calculée, recouvrements avec les pièces et espaces du niveau) → contrôle → validation ; Échap annule sans commande. |
| | **Commandes.** Création, modification (polygones, nom, catégorie) et suppression d'espace (famille `espace.*`). Une région détectée par `piece.detecter` (proposition, jamais imposée) peut être acceptée comme espace au lieu d'une pièce : l'utilisateur choisit la classe. Conversion espace → pièce : un seul lot (`piece.creer` puis suppression de l'espace, identifiant nouveau), jamais un changement de classe silencieux ; l'inverse du lot restitue l'espace. |
| | **Sans correction silencieuse.** Un espace qui recouvre une pièce ou un autre espace du même niveau est signalé dans l'aperçu (recouvrements listés, aire commune) sans refus ni fusion ; murs modifiés : l'espace ne bouge pas, l'écart éventuel est listé. Supprimer un espace le retire de chaque zone qui le contient dans le même lot (effets listés, inverse restitue l'appartenance). Palette (UX2) : « espace » ; synonymes « space », « région » ; exemple court : délimiter un espace sur le niveau actif (exemple, jamais valeur par défaut) ; aide (UX4). |
| Données et dépendances | Classe `espace` ; relation `contient` portée par une `zone` (DA-07-17) ; ni `delimitee-par` ni `programme` (propres à la `piece`) ; `niveauId`. `core-geometry` (aires, recouvrements) ; événement `atelier.commande.validee` : vues, quantités et bilan Harmonie « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Espace créé, modifié, converti ou supprimé ; aire calculée dérivée ; recouvrements et appartenances de zone listés dans le panneau des modifications ; inverse = valeurs précédentes. |
| Cas limites | **Géométrie.** Polygone non fermé, auto-intersecté, de moins de 3 sommets ou d'aire sous la tolérance : refusé (400 avec `chemin`) ; niveau absent ; calque verrouillé : lot refusé en entier ; espace identique à une pièce existante : signalé, jamais fusionné. |
| | **Concurrence, réseau, droits.** `baseRevision` dépassée et espace ou zone modifié ou supprimé depuis → 409 avec `conflits[].objetId` et état serveur ; même `requestId` → réponse enregistrée, aucune seconde révision (T06) ; hors ligne : réducteur local, file Dexie, rejeu dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 (section 6) : tracés `role = room` dont le code ne correspond à aucune `piece` → `espace` ; jamais une pièce en double ; le rapport d'import nomme chaque espace créé (effectif donné par le rapport). |
| | IFC (annexe C, lot 6) : `IfcSpace`, aires en `Qto_SpaceBaseQuantities` (aire calculée) ; la règle de reconnaissance pièce / espace au retour d'IFC est à spécifier au lot 6, sans reclassement silencieux. DXF : aucune sortie propre. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/espace.test.ts`) : création ; aire calculée d'un rectangle de test (4 m sur 5 m : 20 m², entrées de test sans valeur normative) à la tolérance ; polygone auto-intersecté refusé ; recouvrement avec une pièce signalé, rien fusionné ; conversion en pièce en un lot, inverse restitue l'espace ; suppression d'un espace membre d'une zone : appartenance retirée, puis restituée par l'inverse. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : création d'espace → 200, révision +1, `effets` ; polygone invalide → 400 avec `chemin` ; même `requestId` → même réponse ; `baseRevision` périmée et espace modifié → 409 avec `conflits[].objetId` ; rôle lecture → 403 ; réservation d'autrui → 423. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · pièces, espaces, zones ») : copie de travail de P.118 : espaces issus des tracés `role = room` listés comme le rapport d'import, aucune pièce en double ; créer un espace, le convertir en pièce, annuler, rétablir ; second navigateur à la même révision. |
| Règles métier | Aucune règle réglementaire (surfaces, hauteurs, usages : non fournis ; règles selon pays, usage et version identifiés, à fournir avec leur source). R3 : aucune catégorie ni aire par défaut ; l'aire calculée est géométrique, pas une surface réglementaire. R9 : tout par commande ; R10 : niveau actif et sélection hors révision. |
| Extensions à spécifier | Espaces tridimensionnels (volume, hauteur propre) ; espaces à plusieurs niveaux (vides, gaines) ; règle de mesure des surfaces, à fournir avec sa source ; reconnaissance pièce / espace à l'import IFC (lot 6). |
