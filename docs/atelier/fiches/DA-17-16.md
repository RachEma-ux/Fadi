| Champ | Contenu |
| --- | --- |
| Identité | DA-17-16 (M12, étape cible P1). Revue de la maquette numérique de l'Atelier en 3D : naviguer, sélectionner un objet, en lire les propriétés, y rattacher les commentaires existants de Collaboration. Sous-exigences : -a navigation 3D ; -b sélection et lecture des propriétés ; -c commentaires de Collaboration rattachés à un objet ; -d révision affichée. Référence de comportement : prototype (vue 3D et sélection) ; commentaires : module Collaboration existant. |
| Situation utilisateur | Parcourir la maquette avec d'autres personnes, désigner un objet précis et en discuter dans les commentaires existants de Collaboration, sans modifier le modèle. |
| Entrées et unités | Caméra (orbite, panoramique, zoom ; gestes tactiles sur mobile) ; sélection par clic ou toucher (rayon contre les représentations 3D dérivées, résolu en `objetId`), par la liste des objets (niveau, classe) ou par filtre de classe ; `objetId` et, s'il y a lieu, caractéristique nommée (`mur:face-gauche`, `ouverture:centre`, `escalier:depart`…) ; révision affichée ; texte du commentaire (Collaboration). |
| Comportement | **Revue en lecture seule.** La revue n'émet aucune commande de modèle : caméra, sélection, niveaux visibles, filtres de classe, isolation et mode sont des paramètres d'affichage qui ne touchent jamais la révision (R10). Une personne `write` quitte la revue pour éditer par les outils habituels. |
| | **Navigation et sélection.** Rendu WebGL2 (three.js) par défaut ; WebGPU seulement derrière un réglage avec repli automatique (R14). Objet sélectionné surligné ; panneau de propriétés : classe, nom, paramètres canoniques avec unités, provenance et statut ; valeur absente « non évaluée » (R3). Tout ce qui se fait à la souris ou au toucher se fait aussi depuis la liste des objets, au clavier et au lecteur d'écran (accessibilité, lot 3b). |
| | **Commentaires.** Un commentaire de Collaboration peut porter une référence `{ objetId, caracteristique }` (caractéristique facultative) et la révision affichée au moment du commentaire ; il reste un commentaire de Collaboration (même stockage, mêmes droits : `comment` suffit, `read` est refusé en 403) ; l'Atelier n'en crée pas un second. Un repère 3D signale l'objet commenté : sélectionner l'objet ouvre le fil, sélectionner le commentaire cadre l'objet. Commenter n'est pas une commande du modèle : aucune révision. |
| | **Objet disparu ou remplacé (R12).** Objet supprimé : le commentaire reste lisible, marqué « objet supprimé » ; objet remplacé par une scission (`mur.scinder`) : commentaire « à réparer » avec propositions (rattacher à l'un des nouveaux objets, détacher), jamais rattaché en silence. |
| Données et dépendances | Aucune classe ni aucun paramètre du modèle modifiés ; lecture de `GET /model` et `GET /model/niveaux/:niveauId` (niveau chargé à la demande) ; commentaires de Collaboration (référence `objetId`) ; représentations `solide-3d` dérivées (autorité `derivee`, `moteur`, `versionMoteur`, R15) ; après un lot validé par autrui, resynchronisation par `GET /journal?apres=n`. |
| Résultats | Objet sélectionné et ses propriétés ; commentaires rattachés visibles en 3D et en liste ; indication de la révision affichée ; aucune écriture dans le modèle. |
| Cas limites | **Rendu.** WebGL2 indisponible : repli sur la liste d'objets et le plan 2D avec message (état d'erreur, R20) ; modèle volumineux : chargement par niveau, état de chargement affiché ; objet sans représentation 3D (hauteur « non évaluée ») : listé, non dessiné, signalé. |
| | **Concurrence, réseau, droits.** La revue n'émet aucune commande : ni `requestId` ni 409 pour elle-même. Objet sélectionné modifié ou supprimé par autrui pendant la revue : bandeau « modèle mis à jour (révision n) », sélection conservée si l'objet existe, sinon libérée avec message ; hors ligne : modèle déjà chargé consultable (Dexie), commentaires selon le comportement existant de Collaboration (inchangé) ; `read` : navigation et sélection seulement ; 404 sans accès. |
| Compatibilité | Import P.118 (section 6) : tous les objets de la copie de travail sélectionnables (220 murs, 120 poteaux, 84 portes, 126 fenêtres, 32 escaliers, 45 pièces…) ; WebGL2 requis par défaut (R14). |
| | IFC : aucun commentaire exporté ; la correspondance entre `objetId` et l'identité IFC d'un objet commenté est à spécifier au lot 6 ; échange de commentaires au format BCF : non couvert. DXF : sans objet. |
| Validation | **Unité** (fonctions pures de sélection, de filtre et de cadrage, `packages/core-geometry/src/revue.test.ts`, nom provisoire) : rayon résolu en `objetId` (objet le plus proche, égalité départagée de façon déterministe) ; filtre de classe ; objet sans représentation ignoré ; empreinte du modèle identique avant et après navigation et sélection. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`, groupe « revue ») : `GET /model` et `GET /model/niveaux/:niveauId` → 200 pour `read`, 404 sans accès ; une session de navigation scriptée n'émet aucune commande, révision inchangée ; commentaire avec `objetId` : créé avec `comment`, 403 avec `read` (route de Collaboration, test dans sa suite, nom à relever au lot 3b) ; objet supprimé : commentaire toujours lisible. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 3D · revue ») : copie de travail de P.118 : orbite, panoramique, zoom ; sélection de `EX118-mezz-W-009` en 3D puis depuis la liste : mêmes propriétés ; commentaire rattaché par un compte `comment`, visible depuis un second navigateur à la même révision ; modification par autrui : bandeau, révision de la revue inchangée jusqu'à l'actualisation ; compte `read` : pas de champ de commentaire ; temps de première image imprimé, sans seuil (R14). Traçabilité (critère de la section 17) : révision et empreinte du modèle, moteur et version des représentations affichés ; résultats comparés à P.118. |
| Règles métier | Aucune règle réglementaire. R9 : le modèle ne change que par commande, jamais depuis la revue. R10 : caméra, sélection, filtres et mode ne touchent pas la révision. R11 : représentations dérivées et captures portent la révision et l'empreinte dont elles sont issues. R13 : droits relus par le serveur à chaque requête. R14 : aucun chiffre de performance annoncé avant mesure ; WebGL2 par défaut. R12 : commentaire rattaché à un objet remplacé « à réparer ». R3 : valeurs absentes « non évaluées ». |
