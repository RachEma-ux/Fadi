# DA-02-15 — Snapping / Accrochage — module M01 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-15 (M01, étape cible P1). Aide à la saisie du plan, sans commande propre. Sous-exigences : -a accrochage aux objets (extrémité, milieu, centre, intersection, perpendiculaire) ; -b grille ; -c orthogonal. Référence de comportement : prototype (bouton « Accrochage » ; pas 0,10 / 0,25 / 0,50 par défaut / 1,00 m ; accroche le sommet le plus proche dans un rayon de 12 px d'écran, sinon la grille). |
| Situation utilisateur | Poser un point exactement sur un point remarquable d'un objet ou sur la grille, voir ce qui est accroché avant de valider, et pouvoir l'inhiber. |
| Entrées et unités | Position du pointeur (px), convertie en mètres par `apps/web` ; rayon d'accrochage (m) passé à la fonction pure (R6) ; types actifs ; pas de grille (m) ; point précédent du geste (pour perpendiculaire et orthogonal) ; objets visibles du niveau actif et des niveaux affichés en fond. |
| | Types : extrémité (sommets, extrémités ; pour un mur : extrémités de l'axe et coins des faces), milieu, centre (cercle, arc), intersection, perpendiculaire (depuis le point précédent), orthogonal (direction multiple de 90° du repère de saisie, DA-02-16), grille. Le centre ne figure pas dans la liste du cahier §5.8 : il est ajouté, car requis par DA-01-03 et DA-02-03. |
| Comportement | **Cycle.** Le pointeur survole → le meilleur candidat est affiché (marqueur et libellé textuel « Extrémité », « Milieu », « Intersection », jamais la couleur seule) → le clic ou l'appui pose le point exact → il alimente la commande en cours. Tab passe au candidat suivant dans le rayon. |
| | **Priorité.** Extrémité, intersection, milieu, centre, perpendiculaire, orthogonal, grille en dernier recours ; sans candidat ni grille : point libre (coordonnée exacte du pointeur). À égalité de distance : ordre déterministe (priorité, puis identifiant). |
| | **Exactitude.** Le point est calculé sur la géométrie (double précision), jamais sur les pixels ; il garde la caractéristique nommée visée (`objetId` et, par exemple, `mur:arete-fin` ou `ouverture:centre`) pour qu'une cotation ou une contrainte créée ensuite s'y rattache (lot 5, R12). |
| | **Calques et niveaux.** Calque masqué : objets ni visibles ni accrochables ; calque verrouillé : accrochable, non modifiable ; objets d'autres niveaux affichés en fond : accrochables (repère local commun), en lecture seule. |
| | **Réglages.** Types actifs, pas de grille et rayon : préférence d'affichage par utilisateur, conservée dans le navigateur (échec de stockage toléré : valeurs par défaut), jamais dans le modèle (R10) ; inhibition temporaire par un raccourci à fixer avec la maquette (L0.3). |
| | **Accessibilité.** L'accrochage actif est annoncé dans une région `aria-live` (« Accroché : extrémité du mur … ») ; au clavier seul, la saisie de précision (DA-02-16) remplace le pointeur. |
| | **Palette (UX2) et aide (UX4).** « accrochage » ; synonymes « snap », « magnétisme », « grille » ; actif pendant tout geste de dessin ou de transformation ; exemple court : accrocher un mur à l'extrémité d'un autre. |
| Données et dépendances | Aucune donnée écrite, aucune révision ; lit les paramètres de géométrie des objets visibles (`core-geometry`, fonction pure sans DOM, R6) ; préférences locales. |
| Résultats | Un point exact (ou libre) et son libellé de candidat ; la commande qui le reçoit porte la coordonnée exacte. |
| Cas limites | **Géométrie.** Plusieurs candidats à égale distance (ordre déterministe) ; objet plus petit que le rayon (le candidat le plus prioritaire gagne) ; zoom éloigné : rayon constant en pixels donc grand en mètres, nombreux candidats : même ordre déterministe ; coordonnée hors borne : refusée par le réducteur à la validation. |
| | **Concurrence.** Un objet accroché supprimé par autrui entre l'aperçu et la validation : refus à la validation (cible inexistante, 400 ou 409 selon la commande) ; l'accrochage lui-même n'émet aucune requête. |
| | **Réseau et droits.** Hors ligne : accrochage complet (géométrie locale) ; rôle lecture : accrochage actif pour mesurer, aucune commande possible (403 motivé si forcée) ; stockage des préférences indisponible : valeurs par défaut. |
| Compatibilité | Import P.118 : toutes les classes visibles sont accrochables (220 murs, 120 poteaux, 967 tracés importés, cotations, textes). DXF : les `reference-plan` importés (lot 6) seront accrochables (extrémités, intersections). IFC : sans objet. |
| Validation | **Unité** (`packages/core-geometry`, fonction pure d'accrochage) : extrémité prioritaire sur milieu à rayon égal ; perpendiculaire depuis le point précédent : pied de la perpendiculaire (valeur vérifiable à la main) ; intersection de deux segments ; centre d'un cercle ; grille 0,50 m en l'absence d'objet ; calque masqué ignoré, calque verrouillé accroché ; ordre déterministe ; rayon exprimé en mètres. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : sans objet, l'accrochage n'émet aucune commande ; une coordonnée accrochée (valeur exacte d'un sommet de l'import) est stockée telle quelle : `GET /model` renvoie la valeur sans arrondi (R7). |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · accrochage ») : curseur près de l'extrémité d'un mur de la mezzanine de la copie de travail P.118 : libellé « Extrémité » annoncé, point posé = coordonnées exactes de l'import ; sans objet : point sur la grille 0,50 m ; aucun `POST /commands` pendant le survol ; clavier : saisie de précision. |
| Règles métier | Aucune règle réglementaire. Repère : un point accroché reste `local` (R5). |
| Extensions à spécifier | Accrochage au toucher (loupe de précision, rayon adapté) ; quadrants et tangentes ; point le plus proche sur une face de mur ; pistage polaire à pas d'angle réglable (DA-02-16) ; accrochage 3D (lot 3b). |
