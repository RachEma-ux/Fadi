| Champ | Contenu |

| Identité | **DA-02-12** « Arrays and patterns » (Exigences V4.1, annexe B.3, module M02, étape cible P1 ; critère de recette commun B.3 : « Transformations réversibles ; sélection, copie et dépendances conservées »). Retenue (proposition §5.1, lot 3) ; tâche **L3a.2**. Sous-exigences : **DA-02-12-a** réseau rectangulaire (lignes × colonnes, pas, orientation) ; **-b** réseau polaire (centre, nombre, angle total, rotation des copies) ; **-c** regroupement facultatif des copies (`groupe.creer`, DA-05-05). Fiches liées : DA-02-02 (copier, dont la règle de recopie des ouvertures d'un mur), DA-05-05 (groupes), DA-02-15 / 16. Lien de recette : le lot 8 exige « un script qui pose une trame de poteaux » par les mêmes commandes (T19). |
| Situation utilisateur | L'architecte pose une trame de poteaux, répète un poste de travail ou des sièges, dispose des éléments autour d'un centre. Résultat : des copies indépendantes, exactement espacées, éventuellement réunies en un groupe. |
| Entrées et unités | `cibles` : sélection typée (classes admises : `esquisse.*`, `solide`, `poteau`, `mur`, `texte` ; refusées au lot 3a : `porte`, `fenetre`, `ouverture` seules — hébergées, elles ne se répètent pas hors de leur mur —, `piece`, `espace`, `zone`, `niveau`, `cotation`). Rectangulaire : `colonnes` (entier ≥ 1), `lignes` (entier ≥ 1), `pasX`, `pasY` `{ value, unit: "m" }` (signés), `orientation` `{ value, unit: "°" }` (direction des colonnes par rapport à l'axe x local). Polaire : `centre` `{ x, y, frame: "local", unit: "m" }`, `nombre` (entier ≥ 2, original compris), `angleTotal` `{ value, unit: "°" }` ∈ ]0 ; 360], `tournerCopies` (booléen). `grouper` (booléen). Aucune valeur par défaut de projet (R3). |
| Comportement | Cycle UX3 : outil « Répéter » (synonymes « array », « réseau », « trame », « pattern ») → sélection → mode et paramètres → **aperçu** de toutes les copies (contours fantômes) et de leur nombre → contrôle → validation.<br>Commande émise (annexe B) : `{ type: "transformer.repeter", cibles: [id…], params: { mode: "rectangulaire", colonnes, lignes, pasX, pasY, orientation } }` ou `{ mode: "polaire", centre, nombre, angleTotal, tournerCopies }`, suivie dans le **même lot** de `groupe.creer` si `grouper` (annexe B). Effets : (colonnes × lignes − 1) ou (nombre − 1) copies par cible ; chaque copie est un objet neuf (identifiant neuf), de même classe, mêmes paramètres hors placement, même niveau et même calque ; un mur répété emporte ses ouvertures hébergées selon la règle de `transformer.copier` (fiche DA-02-02) ; jonctions de murs proposées comme pour `mur.tracer`. Pour un réseau polaire avec `angleTotal` = 360°, pas = 360° / nombre ; sinon pas = angleTotal / (nombre − 1). Inverse : suppression de toutes les copies (et du groupe). Les copies **ne sont pas associatives** au lot 3a (modifier le pas ensuite = annuler et refaire). |
| Données et dépendances | Calcul pur des placements dans `packages/core-geometry` (translations, rotations exactes ; angles multiples de 90° calculés sans erreur d'arrondi trigonométrique — **Recommandation**) ; réducteur `transformer.repeter` (`packages/atelier-model`) qui réutilise celui de `transformer.copier`. Écritures `atelier_objects` (N créations), `atelier_relations` (`heberge` pour les ouvertures recopiées), groupe éventuel, journal, événement → vues, quantités (effectifs de poteaux, longueurs de murs) et bilan Harmonie « à recalculer ». Propriété de provenance `copieDe` (`provenance: calcul`) — **Recommandation**. |
| Résultats | Copies visibles dans le plan 2D et le navigateur (effectif par classe mis à jour) ; groupe éventuel ; journal « Répéter (n copies) » ; révision `n + 1` (un seul lot, une seule microversion). |
| Cas limites | `colonnes` ou `lignes` non entiers ou < 1, `nombre` < 2 → 400. Réseau qui ne produit aucune copie (1 × 1) → refus. Pas nul sur un axe où il y a plus d'une copie, ou copies confondues (polaire 360° avec un centre sur l'objet et `tournerCopies` = faux…) → refus « copies confondues ». Nombre total de copies supérieur à `copiesMax` = 500 par commande (**proposée, à confirmer**, §10.2) ou enveloppe > 1 Mo (cahier §8) → refus motivé, jamais de troncature. Unité ou repère invalides → 400 (T03, R5). Classe refusée dans la sélection → refus de tout le lot listant les objets concernés. Calque de destination verrouillé → refus. Copies de murs qui se superposent à des murs existants → jonctions ambiguës listées comme problèmes (règle DA-07-01), pas de fusion. Copie hors de la parcelle : autorisée (pas de règle d'implantation activée, R3). Lecteur 403 ; réservation 423 ; 409 ; `requestId` répété → une seule série de copies (T06) ; hors ligne : local, rejoué. |
| Compatibilité | Copies exportées comme objets indépendants (IFC : une entité par copie, lot 6 ; pas d'`IfcRelAggregates` sauf groupe). Import P.118 : les 120 poteaux sont des objets indépendants ; aucune répétition n'est enregistrée et l'importeur n'en reconstitue pas (pas d'inférence de trame, R3). Prototype : pas d'outil de répétition. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts`) : poteau en (0 ; 0), réseau 3 colonnes × 2 lignes, pas 5 m × 6 m, orientation 0° → 5 copies en (5 ; 0), (10 ; 0), (0 ; 6), (5 ; 6), (10 ; 6) exactement ; même réseau avec orientation 90° → (0 ; 5)… ; polaire : ligne (1 ; 0)–(2 ; 0), centre (0 ; 0), nombre 4, 360°, `tournerCopies` → copies (0 ; 1)–(0 ; 2), (−1 ; 0)–(−2 ; 0), (0 ; −1)–(0 ; −2) exactes ; mur avec une porte répété 2 × 1 → 2 portes hébergées ; `grouper` → un groupe de 6 ; refus `copiesMax` ; inverse → empreinte identique. **API** : un seul `model_revision + 1` pour 5 copies ; idempotence ; 400 détaillé. **Scénario** `05-atelier.mjs` : sur P.118 importé, sélection d'un poteau, trame 3 × 2 au clavier, effectif de poteaux du niveau + 5 dans le navigateur, annuler → effectif d'origine. |
| Règles métier | Aucune règle réglementaire ni structurelle : une trame de poteaux répétée n'est **pas** une descente de charges ni une validation structurelle (P.118 : « structure non calculée », hypothèse « à confirmer », R4). Non évaluée. |
| Extensions à spécifier | Réseau le long d'un chemin ; réseau sur plusieurs niveaux (copies verticales) ; réseau associatif (paramètres modifiables après coup, DA-06, lot 5) ; répétition d'ouvertures le long de leur mur hôte ; bloc / composant répété (DA-05-06 / 09, lot 5). **Question au chef de projet** : valeur de `copiesMax`. |
