# DA-01-11 — Hatching / Hachures — module M01 → module Fadi Atelier — lot 3a

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `creer.hachure` (`apps/web/src/modules/atelier/plan2d/outils/esquisse.ts`) : contour fermé et trous copiés par clic intérieur ou depuis la sélection, espacement et angle saisis ; traits découpés par le dessinateur (`plan2d/dessinateurs.ts`) ; tests `apps/web/src/modules/atelier/plan2d/outils.test.ts` « hachure : paramètres exigés, contour et trou copiés par clic intérieur », `apps/web/src/modules/atelier/plan2d/fondations.test.ts` « traits de hachure découpés par le contour et ses trous » ; PR #57. Reste : -b choix du motif (l'outil écrit toujours `motifId: "lignes"`, `MOTIFS_HACHURE` n'est pas proposé) ; -d couleur de trait / de fond ; -e suppression (aucun outil de suppression dans le nouvel Atelier (`plan2d/controleur.ts` ne transmet Retour arrière / Suppr qu'à l'outil actif)) ; -f hachure des coupes (lot 5) ; étapes « 05-atelier.mjs » du champ Validation (ancien Atelier) non reprises dans `apps/web/e2e/scenarios/14-nouvel-atelier.mjs`.

| Champ | Contenu |
| --- | --- |
| Identité | **DA-01-11** « Hatching » (Exigences V4.1, annexe B.2, module M01, étape cible P1 ; critère de recette commun B.2 : « Primitives et contraintes mesurables ; accrochages et unités cohérents »). Sous-exigences : **DA-01-11-a** hachure d'un contour fermé avec trous ; **-b** motif choisi dans un catalogue versionné (lignes parallèles, lignes croisées, remplissage plein, points) ; **-c** angle et espacement (échelle) du motif ; **-d** couleur de trait / de fond (ou couleur du calque) ; **-e** modification et suppression ; **-f** hachure des coupes d'objets dans les vues (**lot 5**, non couverte ici). Tâche **L3a.2**. Fiches liées : DA-01-02 / 03 / 04 / 05 (contours), DA-01-09 (analyse de profil), DA-05-01 (calques), DA-14 (vues, lot 5), DA-05-14 (catalogue de types, pour une éventuelle hachure par matériau). |
| Situation utilisateur | L'architecte distingue une surface au plan (zone à démolir, revêtement, réservation, espace extérieur) par un motif ; il choisit motif, angle et espacement, voit l'aire hachurée et peut modifier le contour ou le motif sans redessiner. |
| Entrées et unités | `niveauId` ; `contour` (polygone `{ x, y, frame: "local", unit: "m" }[]`, fermé) et `trous` (polygones) ; à la création, contour et trous sont **copiés** depuis des esquisses fermées sélectionnées (ou un clic intérieur à des contours fermés), avec `sourceIds` conservés en propriété de provenance `saisie` (**hypothèse** : pas d'association vivante au lot 3a) ; `motifId` (catalogue `motifs-hachure` versionné, **recommandation** : contenu initial neutre — `lignes`, `croisees`, `plein`, `points` — sans prétention normative) ; `angle` `{ value, unit: "°" }` ; `espacement` `{ value, unit: "m" }` > 0 (espacement en mètres modèle au lot 3a ; espacement « papier » lié à l'échelle de vue : lot 5) ; `couleur`, `fond` (`#rrggbb` ou « du calque ») ; `calqueId`. Aucune valeur par défaut tirée de P.118 ; l'outil reprend les derniers paramètres saisis par l'utilisateur ou un champ vide. |
| Comportement | Outil « Hachure » (synonymes « hatch », « motif », « remplissage », « H ») → sélection de contours fermés ou clic intérieur → analyse de profil (DA-01-09 : extérieur + trous) → paramètres dans l'inspecteur → **aperçu** du motif découpé et de l'aire nette (m²) → validation. Commande (annexe B) : `{ type: "esquisse.hachure", params: { niveauId, contour, trous, motifId, versionCatalogue, angle, espacement, couleur, fond, calqueId } }`, label « Hachurer ». Préconditions : contour fermé, non auto-intersectant, aire ≥ `aireMin` ; trous strictement inclus, non sécants entre eux ; `motifId` présent dans la version de catalogue citée ; `espacement` ≥ `longueurMin` ; nombre de traits générés ≤ 100 000 (**proposée, à confirmer** — protège le rendu). Inverse : `esquisse.supprimer`. Modification : `esquisse.modifier` (motif, angle, espacement, couleurs, contour, trous). Les traits du motif ne sont **pas** stockés : ils sont dérivés à l'affichage par `core-geometry` (D1 / R15). |
| Données et dépendances | Classe `esquisse.hachure` (ontologie `drawing`) ; catalogue `motifs-hachure` (définitions versionnées, `atelier_definitions`, T15) ; représentation `plan-2d` `parametrique` ; découpe du motif par `core-geometry` (fonction pure `hachurer(contour, trous, motif, angle, espacement)`, nom proposé). Événement `atelier.commande.validee` → vues « à recalculer ». Au lot 5, les vues exportent les hachures (SVG / PDF / DXF). |
| Résultats | Surface hachurée au plan ; inspecteur : motif (nom + version de catalogue), angle, espacement, aire brute, aire des trous, aire nette ; journal ; révision + 1. |
| Cas limites | Contour ouvert ou auto-intersectant → refus « contour non fermé » / « auto-intersection » (aperçu et 400). Trou hors du contour ou sécant → refus nominatif. Espacement trop petit (traits > limite) → refus « espacement trop fin pour la surface », proposition d'un espacement minimal. `motifId` inconnu ou version de catalogue absente → 400. Esquisse source modifiée ensuite : la hachure ne suit pas (copie) — signalé dans l'inspecteur (« contour copié depuis … ») ; l'association est une extension. Calque verrouillé, niveau supprimé, droits, hors ligne : comme DA-01-02. |
| Compatibilité | IFC 4.3 : esquisse omise et listée (T13) ; `IfcFillAreaStyleHatching` non prévu dans l'annexe C. DXF (lot 5) : `HATCH` avec motif prédéfini ou défini par l'utilisateur (à confirmer par DA-22-03). Import P.118 : pas d'entité hachure ; les remplissages `fill` des calques et `color` des tracés sont des couleurs de calque / d'objet (DA-05-01), pas des hachures — aucune conversion. |
| Validation | **core-geometry** (`packages/core-geometry/src/hachure.test.ts`, nom proposé) : carré (0;0)–(4;4), motif `lignes`, angle 0°, espacement 0,5 m → 7 segments de 4 m (y = 0,5 … 3,5) ; même carré avec un trou (1,25;1,25)–(2,75;2,75) → 10 segments, longueur totale 23,5 m ; angle 90° → 7 segments verticaux ; même entrée → même sortie. **Unité** (`packages/atelier-model/src/commandes/esquisse.test.ts`) : aire nette 16 − 2,25 = 13,75 m² ; refus : contour ouvert, trou sécant, motif inconnu, espacement 0 ; modifier angle puis inverse → empreinte identique. **Scénario** `05-atelier.mjs` : rectangle 4 × 3 hachuré (`croisees`, 45°, 0,20 m) → inspecteur 12,00 m² ; angle changé à 0° ; annuler / rétablir ; second navigateur identique. |
| Règles métier | Aucune règle réglementaire. Les conventions normalisées de hachures par matériau (ISO 128-50, SIA 400, NF) ne sont ni imposées ni présentées comme appliquées : **non évaluées** ; le catalogue initial est neutre (motifs géométriques sans signification normative). |
| Extensions à spécifier | Hachure associative au contour source (références, lot 5) ; espacement en unités papier selon l'échelle de la vue (lot 5) ; hachure automatique des parties coupées des murs, dalles et poteaux dans les vues (DA-14, lot 5) ; motifs par matériau liés aux types (DA-05-14 / 15) ; import de motifs `.pat`. **Question au maître d'ouvrage** (si souhaité) : un jeu de motifs conforme à une norme précise (SIA 400 ou ISO 128-50) doit-il être fourni — avec sa source — ou le catalogue neutre suffit-il ? |
