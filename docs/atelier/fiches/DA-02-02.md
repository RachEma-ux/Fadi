# DA-02-02 — Copy / Copier — module M02 → module Fadi Atelier — lot 3a

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `modifier.copier` (`apps/web/src/modules/atelier/plan2d/outils/transformations.ts`) → `transformer.copier`, nouveaux identifiants tirés au geste, ouvertures copiées avec leur mur ; tests `apps/web/src/modules/atelier/plan2d/outils.test.ts` « copier un mur : ses ouvertures sont copiées avec lui (nouveaux identifiants, un par objet) », « déplacer : fantôme pendant le survol, vecteur exact ; Ctrl au second point : copie » ; PR #57. Reste : -b copier vers un autre niveau ; -c copier-coller (presse-papiers de l'Atelier) ; étapes « 05-atelier.mjs » du champ Validation (ancien Atelier) non reprises dans `apps/web/e2e/scenarios/14-nouvel-atelier.mjs`.

| Champ | Contenu |
| --- | --- |
| Identité | **DA-02-02** « Copy » (Exigences V4.1, annexe B.3, M02, P1). Critère commun B.3 : « Transformations réversibles ; sélection, copie et dépendances conservées ». Tâche **L3a.2**. Sous-exigences : **DA-02-02-a** copier une sélection par un vecteur (une copie) ; **-b** copier vers un autre niveau ; **-c** copier-coller dans le même projet (presse-papiers de l'Atelier). Règles communes des transformations : fiche **DA-02-01** (classes admises, objets hébergés, références, calques, niveaux). Fiches liées : DA-02-12 (répétition, copies multiples), DA-05-05 (groupes), DA-05-14 / 15 (types partagés). |
| Situation utilisateur | L'architecte duplique un bureau type, une cloison avec ses portes ou un poteau à une distance précise ou sur un autre niveau ; il obtient de nouveaux objets indépendants, avec de nouveaux identifiants, sur les mêmes calques et types que l'original. |
| Entrées et unités | `cibles` (≥ 1) ; `vecteur` `{ dx, dy, frame: "local", unit: "m" }` et / ou `niveauCibleId` ; saisie comme DA-02-01 (point de base / arrivée, longueur m + angle °, Δx / Δy). Aucun décalage par défaut (le prototype copiait à +0,5 m : **non repris**, R3 ; un collage sans point d'arrivée colle à la même position et le signale). |
| Comportement | Cycle UX3 : sélection → outil « Copier » (synonymes « copy », « dupliquer », `Ctrl/⌘ C` puis `Ctrl/⌘ V` pour -c) → point de base → **aperçu** des copies, des objets entraînés → validation.<br>Commande (annexe B) : `{ type: "transformer.copier", cibles, params: { vecteur?, niveauCibleId? } }`. Effet : objets **créés** ; le réducteur attribue les identifiants `${projectId}_${id}` de façon déterministe à partir du `requestId` (même identifiants à l'aperçu et sur le serveur, idempotence T06). Inverse : suppression des objets créés (`<classe>.supprimer` / `esquisse.supprimer` dans un lot).<br>Règles propres : **ouvertures hébergées** d'un mur copié → copiées avec lui, `heberge-par` vers le nouveau mur, mêmes `t` ; une ouverture seule n'est pas copiable par `transformer.copier` (elle se pose par `ouverture.poser`) ; **définition de type** partagée (la copie référence le même `typeId`, pas de duplication du type) ; **calque** conservé ; copie *vers* un calque verrouillé → refus ; copie *depuis* un calque verrouillé → **admise** (la source n'est pas modifiée — **Recommandation**, à confirmer) ; **cotations** : copiées si toutes leurs caractéristiques référencées sont copiées, et alors re-référencées vers les copies ; sinon non copiées et listées ; **pièces** : une pièce copiée garde `nom` et `code` suivis de « (copie) », jamais de code identique en double sans signalement ; liaison `programme` **non** copiée (une copie n'est pas l'espace programmé). Propriétés de provenance `import` (P.118 : `lineRef`, `designRevision`, `sourceMarker`…) : **non** recopiées ; la copie porte `provenance: saisie` et une propriété `copieDe` (nom proposé, à figer par L1.1). |
| Données et dépendances | Nouvelles occurrences `atelier_objects`, relations `heberge` / `heberge-par` dupliquées, références de cotation re-ciblées ; représentations dérivées calculées pour les copies. Modules : `atelier-model` (réducteur, génération d'identifiants déterministe), `core-geometry`, API ; événement → vues, quantités (effectifs d'ouvertures, longueurs de murs) « à recalculer ». Révision `n + 1`. |
| Résultats | Copies sélectionnées après validation ; journal « Copier n objets » ; quantités périmées. |
| Cas limites | Copie à vecteur nul sur le même niveau → **avertissement** « objets superposés » dans l'aperçu, autorisée seulement après confirmation explicite (**Recommandation**). Code de pièce dupliqué → problème listé. Niveau cible inexistant → 400. Copie d'une ouverture seule → refus motivé. Classe exclue (parcelle, niveau…) → 400. Rôle `read` → 403 ; 409 ; 423. Requête répétée (même `requestId`) → mêmes identifiants, une seule création (T06). Hors ligne : exécutable localement, rejouée. Presse-papiers (-c) : contenu local, jamais une commande tant qu'on n'a pas collé (R10) ; collage dans un autre projet : hors périmètre (extension). |
| Compatibilité | Aucun format concerné ; IFC (lot 6) exporte les copies comme objets distincts, `IfcWallType` partagé. Prototype : outil « Copier » (glisser) — fonction conservée. |
| Validation | **Unité** `transformer.test.ts` : copier un mur 4 m portant une porte et une fenêtre de (0 ; 3) → 2 murs, 2 portes, 2 fenêtres, relations hôte correctes, `typeId` partagé ; identifiants identiques sur deux exécutions du réducteur avec le même `requestId` ; inverse → empreinte identique ; cotation dont une seule extrémité est copiée → non copiée et listée ; copie vers calque verrouillé → refus. **API** : idempotence (T06), 403, 409. **Scénario** `05-atelier.mjs` : copier un poteau de P.118 importé de 6,00 m à 0° ; révision + 1 ; effectif « poteaux » du métré passe de 120 à 121 ; annuler → 120. |
| Règles métier | Aucune règle réglementaire. Une copie d'objet portant une hypothèse structurelle (`structural`, P.118) recopie l'hypothèse avec son statut « à confirmer », jamais promue (R4). |
| Extensions à spécifier | Copier-coller entre projets (identités, types, calques absents de la cible) ; « copier les propriétés » d'un objet à l'autre ; copies multiples (DA-02-12). **Question au chef de projet** : nom de la propriété de traçabilité `copieDe` (L1.1). |
