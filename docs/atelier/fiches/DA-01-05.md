| Champ | Contenu |
| --- | --- |
| Identité | DA-01-05 (M01, étape cible P1). Objet : `esquisse.spline`, courbe cubique qui passe par des points de passage. Pas de référence dans le prototype (qui ne connaît que des polygones). |
| Situation utilisateur | Esquisser une courbe libre et régulière (rampe, bord de terrain, mobilier courbe) passant par des points choisis, et la retoucher en déplaçant ses points. |
| Entrées et unités | `esquisse.spline` : `points` (points de passage, au moins 2, repère local, m), `ferme` (booléen), `niveauId`, `calqueId`. |
| | Type de courbe : cubique interpolante. La variante exacte (B-spline d'interpolation ou Catmull-Rom centripète) est à fixer et à consigner dans `decisions.md` avant le code : elle conditionne l'export DXF `SPLINE` (cahier 10.2). |
| Comportement | **Cycle.** Points successifs (clic ou toucher avec accrochages DA-02-15, ou saisie DA-02-16) ; aperçu de la courbe à chaque point ; Entrée termine ; option « fermer » ; Retour arrière retire le dernier point ; Échap annule sans commande. |
| | **Commandes.** `esquisse.spline` ; retouche par points de passage : `transformer.pointsDeControle` (déplacer, insérer, supprimer : DA-02-14) ; `esquisse.modifier` (`ferme`, calque) ; `esquisse.supprimer`. |
| | **Contrôles.** Moins de 2 points, points consécutifs confondus (tolérance de longueur, DA-01-01), courbe fermée à moins de 3 points : refusés. Auto-intersection de la courbe : signalée à l'aperçu, admise pour un tracé, à refuser comme profil. |
| | **Clavier et toucher (T16).** Au clavier : points en coordonnées (x, y), Entrée pour terminer. Au toucher : appuis successifs ; deux doigts déplacent ou zooment la vue sans poser de point. |
| | **Palette (UX2) et aide (UX4).** « spline » ; synonymes « courbe », « courbe libre » ; exemple court : courbe passant par cinq points accrochés. |
| Données et dépendances | Géométrie canonique = points de passage + type + `ferme` (R15). Tessellation dérivée à une tolérance de flèche d'affichage (R10) par la même fonction de `core-geometry` dans le navigateur et sur le serveur : mêmes entrées, mêmes échantillons. |
| | Références : aucune caractéristique nommée d'esquisse avant le lot 5 ; pas de cotation rattachée, donc pas de référence à réparer (R12) au lot 3a. Événement de commande validée : vues du niveau « à recalculer ». |
| Résultats | Une spline par lot ; points de passage listés dans l'inspecteur avec unités ; entrée de journal avec inverse. |
| Cas limites | **Géométrie.** Un seul point ; points confondus ; ordre des points significatif (autre ordre, autre courbe) ; boucle parasite quand des points sont très proches (signalée à l'aperçu) ; niveau inconnu ; calque verrouillé : lot refusé en entier. |
| | **Concurrence.** `baseRevision` dépassée → 409 détaillé, résolution explicite côté client ; même `requestId` → une seule révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local puis file Dexie rejouée dans l'ordre, brouillon si incompatible ; 403 / 404 / 423 selon R13. |
| Compatibilité | Import P.118 : aucune courbe ; les polygones de 48 à 96 sommets restent des polygones, sans ajustement de spline (R3, R7). |
| | DXF : `SPLINE` à l'export des vues (lot 5) ; si le type retenu n'est pas exportable à l'identique, la courbe est échantillonnée en `LWPOLYLINE` et le rapport d'export le dit. IFC : omis au rapport (annexe C sans correspondance). |
| Validation | **Unité** (`esquisse.test.ts` et `packages/core-geometry`) : la courbe échantillonnée passe par chaque point de passage (tolérance de longueur) ; spline fermée : jonction continue au point de fermeture ; deux points : segment ; points confondus refusés ; mêmes entrées, mêmes échantillons ; inverse restitue l'état. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `esquisse.spline` à 1 point → 400 avec `chemin` ; spline valide → 200 ; même `requestId` → une seule révision ; `baseRevision` périmée → 409. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · spline ») : spline de cinq points sur la mezzanine de la copie de travail P.118 ; un point de passage déplacé par poignée (DA-02-14) ; annuler, rétablir, second navigateur. |
| Règles métier | Aucune règle réglementaire. |
| Extensions à spécifier | Poignées de tangente ; NURBS (DA-03-04, hors périmètre) ; ajustement d'une spline sur une polyligne existante ; trajet pour balayage (DA-04-03). |
