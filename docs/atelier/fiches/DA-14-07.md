| Champ | Contenu |

| Identité | DA-14-07 (M11, P1, limité par le cahier aux détails d'assemblage d'escalier). Détail d'un escalier droit ou balancé : marches, contremarches, limon, cotes de giron et de hauteur. |
| Situation utilisateur | Documenter l'escalier pour l'exécution. |
| Entrées et unités | Escalier cible, échelle, type (plan ou coupe de volée). |
| Comportement | Vue `detail` cadrée sur l'escalier avec cotes automatiques de giron et hauteur de marche (valeurs calculées, non réglementaires). Cycle : `vue.creer` → paramètres → aperçu calculé dans le navigateur (hors du rendu) → `vue.modifier` ; le dessin est **dérivé** du modèle à la révision courante et porte son empreinte (`objetsVue`, `empreinteVue`). |
| Données et dépendances | Définition `vue` (D-017) ; `documents/vues.ts`, `dessin.ts`, `visibilite.ts` ; dépend des objets du niveau ou de la coupe ; fraîcheur par révision et empreinte (T07). |
| Résultats | Dessin vectoriel (SVG), PDF, DXF au catalogue ; placement sur feuille (DA-16). |
| Cas limites | Objet supprimé après génération : document périmé, régénération sans l'objet ; niveau sans objet : dessin vide déclaré ; même révision et même empreinte → octets identiques (reproductibilité testée) ; `baseRevision` périmée à la création de la vue → 409 ; hors ligne : la définition est mise en file, le dessin attend la reprise. |
| Compatibilité | IFC : non concerné (les vues ne s'exportent pas en IFC) ; export SVG / PDF (vectoriel, sans dépendance, Helvetica WinAnsi) / DXF R12 (calques par nature de trait) au catalogue ; import P.118 : les documents se régénèrent depuis le modèle importé. |
| Validation | `documents.test.ts` : dessin reproductible, fraîcheur, objets dépendants ; recette documents : vue créée, PDF au catalogue à jour puis périmé après une commande. |
| Règles métier | Aucune règle réglementaire : un document dérivé porte révision et empreinte (R11), périmé il reste consultable sans être présenté comme actuel (T07) ; les surfaces sont calculées, jamais qualifiées de conformes ; hauteur absente = « non évaluée » (R3). |
| Extensions à spécifier | Détails d'assemblage mécaniques et structure (P2-3, P2-7). |
