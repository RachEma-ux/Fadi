| Champ | Contenu |
| --- | --- |
| Identité | DA-03-06 (M02, P2). Surfaces libres (maillage subdivisé) et opérations exactes `surface` / `patch` couvrent la forme libre ; les objets paramétriques du bâtiment restent canoniques (R15) et se convertissent **explicitement** (DA-07-20). |
| Situation utilisateur | Étudier un volume libre à côté d'un bâtiment paramétrique sans le dénaturer. |
| Entrées et unités | Outils Surface libre et Solide exact (surface, patch, congé). |
| Comportement | Formes libres dessinées ou converties ; jamais de conversion implicite d'un mur, d'une dalle ou d'un poteau. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'outil vit dans l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Classe `surface-libre` (`ParamsSurfaceLibre` : sommets 3D relatifs au niveau, faces à 3 ou 4 indices, `niveaux` 0–4, `origine`, `ferme`) ; `geometrie-3d.ts` (`triangulerFaces`, `subdiviserLoop`, `proprietesMasse`) ; `batiment-p2.ts` (`maillageSurfaceLibre`, `controleDepuisMaillage`) ; réducteurs `surfaceLibre.creer / modifier / supprimer / depuisObjet / deplacerSommet / subdiviser`. `packages/geometry-exact` (occt-wasm, D-177) : `validerOperation` puis `MoteurExact.executer` ; le serveur recalcule et compare l'empreinte (`apps/api/src/lib/atelier-exact.ts`, R9) ; classe `solide-exact`. Commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9). |
| Résultats | Occurrences `surface-libre` et `solide-exact`. |
| Cas limites | Conversion d'un objet sans maillage (esquisse, cotation) : refus nommé. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC proxy tessellé. |
| Validation | Tests du modèle et du noyau ; recette P2-6. |
| Règles métier | Le paramétrique reste canonique : une forme libre est une classe à part, nommée, avec son origine. Une grandeur absente est « non évaluée » (R3) ; géométrie seulement, aucune vérification réglementaire. |
| Extensions à spécifier | Sculpture directe en 3D (glisser des sommets dans la vue 3D), symétrie. |
