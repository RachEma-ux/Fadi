| Champ | Contenu |
| --- | --- |
| Identité | DA-02-16 (M01, étape cible P1). Interprétation de l'inventaire : saisie de précision et repères de construction, équivalent fonctionnel ; pas reprise du produit AccuDraw. Sous-exigences : -a barre de saisie (longueur, angle, x, y) ; -b repère de précision temporaire ; -c guides de pistage. Aucune commande propre : les valeurs saisies renseignent les paramètres des commandes `esquisse.*` et `transformer.*`. |
| Situation utilisateur | Poser, mesurer et transformer avec des valeurs exactes saisies au clavier (ou au pavé tactile) pendant le geste, dans un repère aligné sur ce que l'on dessine, sans passer par la souris. |
| Entrées et unités | Champs selon l'outil : ligne et polyligne (longueur m, angle °) ; rectangle (longueur, largeur) ; cercle (rayon ou diamètre) ; arc (rayon, angle) ; déplacer (dx, dy, ou distance et angle) ; tourner (angle) ; échelle (facteur) ; décaler (distance) ; raccord (rayon) ; chanfrein (distances) ; réseau (compte, pas). Premier point : x, y absolus (repère local, m). |
| | Valeur saisie : nombre à virgule ou à point décimal, unité facultative (m, cm, mm pour une longueur ; ° pour un angle ; aucune pour un facteur) ; sans unité, l'unité d'affichage courante s'applique. |
| Comportement | **Cycle.** Pendant un geste, la barre de saisie (près du curseur ; dans l'inspecteur sur téléphone) montre les champs de l'outil ; Tab et Maj + Tab changent de champ ; saisir une valeur la verrouille (le pointeur ne la modifie plus) ; Entrée valide l'étape, Échap annule le geste, Retour arrière sur un champ vide retire le dernier point. L'aperçu se met à jour à chaque frappe. |
| | **Clavier (T16).** Le geste « tracer un mur » (puis ligne, rectangle, cercle) est réalisable sans pointeur : premier point en coordonnées, puis longueur et angle, Entrée. Sur téléphone : clavier numérique (`inputmode="decimal"`), cibles d'au moins 44 px. |
| | **Contrôles.** Grandeur incompatible (« 30° » dans un champ de longueur, « 2 m » dans un angle), valeur non finie ou hors borne : refusée sur place (message « objet, cause, action »), sans quitter le geste ; valeur négative refusée là où une valeur positive est exigée (rayon, distance) ; la même validation est refaite par le réducteur et par le serveur (T03). |
| | **Repère de précision.** Repère de saisie temporaire (origine et orientation des axes) posé en cliquant un point et une direction, ou en s'alignant sur un segment sélectionné ; dx et dy se lisent alors dans ce repère ; il disparaît à la fin de l'outil. Il reste exprimé dans le repère `local` : aucune conversion vers `cadastral` ou `geographic`, jamais de mélange (R5) ; affichage et saisie, pas modèle (R10). |
| | **Guides de pistage.** Guides temporaires affichés pendant le geste (alignement horizontal ou vertical avec un point remarquable, prolongement d'un segment, direction polaire à pas d'angle réglable), sans écriture. Un repère à conserver devient une `esquisse.construction` explicite (DA-01-10). |
| | **Palette (UX2) et aide (UX4).** « saisie de précision » ; synonymes « coordonnées », « longueur angle », « dynamic input » ; actif pendant tout geste de dessin ou de transformation ; exemple court : saisir 4,5, Tab, 30 pour un segment de 4,5 m à 30°. |
| Données et dépendances | Aucune donnée écrite : état de la barre, repère de précision et guides sont de l'affichage (R10) ; la fonction de lecture d'une grandeur saisie est pure (`packages/atelier-model`, ontologie des unités, R6) ; les commandes reçoivent des valeurs `{ value, unit }` exactes, sans arrondi. |
| Résultats | Des paramètres exacts (longueur, angle, coordonnées, facteur) transmis à la commande en cours ; messages d'erreur sur place ; aucune révision tant que le lot n'est pas validé. |
| Cas limites | **Saisie.** Champ vide ; plusieurs séparateurs (« 1,2,3 ») ; exposant ou valeur non finie (« 1e400 ») ; unité inconnue ; angle supérieur à 360° (admis, valeur conservée telle que saisie) ; valeur qui conduit à une longueur nulle (refusée par le contrôle de l'outil). |
| | **Concurrence.** La saisie n'émet rien ; la validation suit les cas limites de la commande (409 détaillé, `requestId` unique par lot, même `requestId` → une seule révision). |
| | **Réseau et droits.** Hors ligne : saisie et aperçu complets, file Dexie rejouée dans l'ordre ; rôle lecture : saisie possible pour mesurer, aucune commande (403 motivé si forcée) ; 404 sans accès ; 423 pendant une réservation d'autrui. |
| Compatibilité | Import P.118 : les coordonnées de projet restent `local` et ne sont jamais ressaisies ; une valeur lue dans l'inspecteur se retape à l'identique (m). DXF et IFC : sans objet. |
| Validation | **Unité** (`packages/atelier-model`, lecture d'une grandeur saisie, nom provisoire) : « 3,5 » → 3,5 m ; « 35 cm » → 0,35 m ; « 120 mm » → 0,12 m ; « 30° » pour une longueur refusé ; « −2 » pour un rayon refusé ; virgule et point décimaux acceptés ; « 1e400 » refusé ; repère de précision tourné de 90° : dx, dy convertis en repère `local` (valeurs vérifiables à la main). |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `esquisse.ligne` dont la longueur est en « ° » → 400 avec `chemin` ; valeurs saisies en cm stockées en m ; même `requestId` → une seule révision. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · saisie de précision ») : clavier seul, sans pointeur : ligne de 4,5 m à 30° par Tab et Entrée, puis polyligne ; valeurs de l'inspecteur égales aux valeurs saisies ; « 30° » saisi dans un champ de longueur : message affiché, geste maintenu ; axe-core sur la barre de saisie à 1536 px et 390 px. |
| Règles métier | Aucune règle réglementaire. Repères : saisie en `local` seulement (R5). |
| Extensions à spécifier | Expressions arithmétiques dans les champs (DA-06-02) ; saisie de coordonnées cadastrales avec conversion explicite (hors outil de dessin) ; verrouillages multiples ; saisie vocale. |
