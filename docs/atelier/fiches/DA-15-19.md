| Champ | Contenu |
| --- | --- |
| Identité | DA-15-19 (M11, P1). Feuilles A0–A4 paysage / portrait, cadre avec marge de reliure, cartouche (projet, titre, numéro, jeu, indice, auteur, date saisie, échelles, révision du modèle, empreinte). |
| Situation utilisateur | Mettre un dessin au format et l'identifier. |
| Entrées et unités | `feuille.creer` { format, orientation, titre, numero, jeu, indice, auteur, date }. |
| Comportement | Le cartouche est rempli depuis la feuille et la révision ; un seul gabarit de cartouche (déclaré lot 5). |
| Données et dépendances | Annotation rattachée à une vue (définition `vue`) ou au modèle (texte, étiquette) ; références aux caractéristiques d'objets ; documents « à recalculer ». |
| Résultats | Annotation dessinée dans la vue, exportée SVG / PDF / DXF. |
| Cas limites | Caractéristique disparue : « à réparer » (R12) ; texte vide refusé ; unité absente d'une valeur numérique refusée (T03) ; hors ligne : commande en file. |
| Compatibilité | SVG / PDF / DXF ; IFC : non exporté ; P.118 : les `dims` et `texts` natifs deviennent cotes libres et textes (cahier §6). |
| Validation | `documents.test.ts`, recette documents (cote rattachée puis « à réparer », textes, étiquettes). |
| Règles métier | Aucune règle réglementaire : un document dérivé porte révision et empreinte (R11), périmé il reste consultable sans être présenté comme actuel (T07) ; les surfaces sont calculées, jamais qualifiées de conformes ; hauteur absente = « non évaluée » (R3). |
| Extensions à spécifier | Cartouches personnalisés par projet. |
