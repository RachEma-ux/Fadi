| Champ | Contenu |
| --- | --- |
| Identité | DA-14-11 (M11, P2). Type de vue `isometrique` : projection isométrique (axes x, y à ±30°, z vertical, parallèle) des objets de réseau en trait unique — segments, raccords (cercle), vannes (losange), équipements (rectangle) — avec repère, désignation de section et longueur de chaque tronçon. |
| Situation utilisateur | Produire l'isométrique d'un réseau d'eau froide pour l'atelier. |
| Entrées et unités | `vue.creer { type: "isometrique", titre, echelle, niveauId? }` (null : tous les niveaux) ; mode Documents → « Isométrique de tuyauterie » ; gabarit de feuille `isometrique` (vue + nomenclature de réseau). |
| Comportement | `genererIsometrique` : coordonnées 3D (altitude du niveau + z) projetées ; textes « repère · section · longueur » ; avertissements (aucun objet de réseau ; longueurs non mesurables sur le dessin). Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'outil vit dans l'inspecteur ou dans le mode Documents, sans ruban ni écran distinct (T01). |
| Données et dépendances | `documents/vues.ts` (`TypeVue`, `TYPES_VUE`, `objetsVue`, `empreinteVue`), ontologie `mep` (P2-5) ; rendus SVG / DXF / PDF existants. Commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9). |
| Résultats | Vue dérivée, documents `atelier-vue-<id>-{svg,dxf,pdf}` ; feuille gabarit. |
| Cas limites | Ontologie réseaux inactive ou niveau sans réseau : vue vide avertie (jamais inventée). `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | SVG, DXF R12, PDF par les rendus existants ; IFC : sans objet (vue). |
| Validation | Tests : objets retenus (segments, vanne), tronçon vertical projeté verticalement (Δy = 2 m), textes ; API : SVG contient le repère ; recette : vue créée depuis Documents. |
| Règles métier | Projection géométrique seule ; aucune longueur n'est mesurable sur le dessin (dit). Une grandeur absente est « non évaluée » (R3). |
| Extensions à spécifier | Cotation automatique des longueurs, numérotation des spools, nomenclature par isométrique, éclatement par feuille. |
