# DA-07-05 — Floors / Planchers — module M05 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-07-05 (M05, étape cible P1). Un plancher est l'usage « sol d'un niveau » de la classe `dalle` : même modèle, mêmes paramètres, mêmes commandes (`dalle.creer`, `dalle.modifier`, `dalle.supprimer`) que la dalle isolée (DA-07-06, qui porte le modèle, les contrôles et les références communs). Aucune classe `plancher`, aucun paramètre ni aucune géométrie en double (R15) : la distinction est d'usage, portée par le point d'entrée « Plancher » et ses propositions. Sous-exigences : -a créer le plancher d'un niveau ; -b le reprendre quand les murs ou les escaliers changent. Référence de comportement : prototype, tracés `floor-slab` de P.118. |
| Situation utilisateur | Doter un niveau de son plancher à partir de l'emprise de ses murs, avec les trémies de ses escaliers, sans que le contour soit jamais imposé. |
| Entrées et unités | Celles de DA-07-06 : `niveauId` (niveau actif), `contour`, `trous`, `epaisseur`, `decalageBase` (m ; unité autre que m refusée, T03 ; aucune valeur par défaut, R3). |
| | Propositions calculées par `core-geometry` avec le même moteur de régions fermées que `piece.detecter`, jamais écrites dans le modèle : contour extérieur des murs fermés du niveau (ligne de rive, face extérieure ou axe : choix explicite, sans valeur par défaut) ; trous à l'emprise (axe plus ou moins la demi-largeur) des escaliers qui relient ce niveau à un niveau inférieur, une proposition par `groupe` (DA-07-10), sans marge ajoutée. |
| Comportement | **Cycle.** Outil « Plancher » (niveau actif) → choix de la ligne de rive → propositions de contour et de trous en surimpression, acceptables une à une et modifiables → paramètres (épaisseur, décalage de base) → aperçu (contour, trous, aire géométrique) → contrôle → validation ; Échap annule sans commande. Contrôles, références `dalle:contour[i]` : ceux de DA-07-06. |
| | **Commandes.** `dalle.creer` avec le contour et les trous retenus (un lot : plancher et trous) ; reprise : l'aperçu liste les écarts entre la dalle et l'emprise actuelle des murs ou des escaliers, `dalle.modifier` n'est émise que si la proposition est acceptée. Palette (UX2) : « plancher » ; synonymes « floor », « sol » ; exemple court : créer le plancher du niveau actif (exemple, jamais valeur par défaut) ; aide (UX4). |
| | **Sans correction silencieuse (R3, R12).** Mur déplacé, élévation du niveau modifiée, escalier ajouté ou déplacé : le plancher ne bouge pas ; contour désaligné, trémie absente ou obsolète sont des problèmes listés avec proposition (`GET /problemes`). Un second plancher sur le même niveau est signalé, ni refusé ni fusionné. |
| Données et dépendances | `dalle` (usage plancher) ; `niveauId` ; relation `porte` (dérivée) ; relations `delimite` des murs (emprise proposée) et `relie` des escaliers (trémies). `core-geometry` ; événement `atelier.commande.validee` : vues par niveau, quantités (la règle de mesure des surfaces n'est pas posée ici) et bilan Harmonie « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Plancher créé ou repris ; trémies et écarts listés dans le panneau des modifications ; propositions non retenues sans trace dans le modèle ; inverse = valeurs précédentes. |
| Cas limites | **Géométrie.** Murs du niveau non fermés : aucune proposition de contour pour la boucle ouverte, interstice listé (extrémités, distance) avec proposition de `mur.joindre` (DA-07-01), contour dessiné à la main toujours possible ; plusieurs boucles disjointes : une proposition par boucle ; niveau sans mur : saisie manuelle ; escalier sans niveau d'arrivée : aucune trémie proposée (DA-07-10). |
| | **Concurrence, réseau, droits.** `baseRevision` dépassée et dalle, mur ou escalier modifié depuis → 409 avec `conflits[].objetId` et état serveur ; même `requestId` → aucune seconde révision (T06) ; hors ligne : réducteur local, file Dexie, rejeu dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 (section 6) : dalles issues de `floor-slab` conservées avec `thickness`, `baseOffset`, `holes` (effectif par niveau au rapport d'import) ; la source ne distingue pas plancher et dalle, aucun usage n'est déduit. |
| | IFC (annexe C, lot 6) : `IfcSlab` de type `FLOOR` ; trous : voir DA-07-06. DXF : aucune sortie propre, vue de plan par niveau au lot 5. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/dalle.test.ts`, groupe « plancher ») : quatre murs fermés : un contour proposé (faces extérieures ou axe selon le choix) à la tolérance, modèle inchangé (empreinte identique avant et après la proposition) ; boucle ouverte : aucune proposition, interstice listé ; escalier reliant le niveau au niveau inférieur : trou proposé, un seul par `groupe` ; `dalle.creer` du contour accepté en un lot ; mur déplacé : dalle inchangée et écart listé. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `dalle.creer` (plancher avec trou) → 200, révision +1, `effets` ; contour invalide → 400 avec `chemin` ; même `requestId` → même réponse ; `baseRevision` périmée et dalle modifiée → 409 avec `conflits[].objetId` ; rôle lecture → 403 ; réservation d'autrui → 423. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · planchers ») : copie de travail de P.118 : niveau actif changé (révision inchangée, R10) ; propositions de contour et de trémies affichées sans écrire (révision inchangée) ; accepter un plancher : révision +1 ; annuler, rétablir ; second navigateur à la même révision. |
| Règles métier | Aucune règle réglementaire (épaisseur minimale, portance, trémie réglementaire : non fournies ; règles selon pays, usage et version identifiés, à fournir avec leur source). R3 : ligne de rive, épaisseur et décalage jamais par défaut ; l'aire n'est pas une surface réglementaire. R9 : tout par commande ; R10 : niveau actif et propositions affichées hors révision ; R11. |
| Extensions à spécifier | Plancher multi-niveaux (copie d'un niveau à un autre) ; pentes, retombées, rives de plancher ; composition en couches ; propriété typée d'usage pour filtrer planchers et dalles isolées (lot 5) ; surface de plancher selon une règle de mesure fournie avec sa source. |
