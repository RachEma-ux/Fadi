# DA-01-06 — Freehand drawing / Dessin à main levée — module M01 → module Fadi Atelier — lot 3a

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `creer.main-levee` (`apps/web/src/modules/atelier/plan2d/outils/esquisse.ts`) : trait au pointeur simplifié (Ramer–Douglas–Peucker) en polyligne, Alt au relâcher → spline, fermeture automatique près du départ ; geste à deux doigts = zoom (`apps/web/src/modules/atelier/plan2d/controleur.ts`) ; tests `apps/web/src/modules/atelier/plan2d/outils.test.ts` « main levée : trait simplifié en polyligne au relâcher ; Alt : spline ; trait trop court refusé », `apps/web/src/modules/atelier/plan2d/controleur.test.ts` « pointeur annulé pendant un trait à main levée : abandon sans commande », « deux doigts : pincer zoome autour du milieu, jamais de trait », `apps/web/src/modules/atelier/plan2d/fondations.test.ts` « simplification RDP : la ligne droite bruitée devient deux points » ; PR #57. Reste : étapes « 05-atelier.mjs » / « 11-accessibilite.mjs » du champ Validation (ancien Atelier) non reprises dans `apps/web/e2e/scenarios/14-nouvel-atelier.mjs` (trait au doigt à 390 px, alternative clavier déclarée).

**Recommandation de correspondance (hypothèse à valider)** : l'annexe B ne contient pas de commande
« main levée ». Le geste à main levée est un **mode de saisie** qui produit, après simplification locale, une
commande existante : `esquisse.polyligne` (par défaut) ou `esquisse.spline` (option « lisser »). Les
échantillons bruts du pointeur ne sont pas stockés dans le modèle.
