| Entrées et unités | `garde-corps.creer` { niveauId, trace (polyligne locale, m), hauteur (m, requise), type, calqueId } ; `.modifier`, `.supprimer`. |

| Résultats | Objet sélectionnable, longueur dérivée, présent en plan, 3D, IFC. |
| Cas limites | Hauteur absente : refus (R3, pas de défaut) ; tracé d'un seul point refusé ; type inconnu refusé. |
| Compatibilité | IFC `IfcRailing` tessellé ; DXF / PDF : trace en plan. |
| Validation | Tests : hauteur requise, longueur, inverse ; recette : garde-corps posé. |
| Règles métier | Aucune hauteur minimale réglementaire n'est imposée ni suggérée (R3) ; la hauteur est une donnée du projet. |
