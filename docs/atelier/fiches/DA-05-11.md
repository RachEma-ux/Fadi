## Réalisation (compléments) et écarts déclarés

- Fait : définition `reference-externe` épinglant une **publication** (révision et empreinte) — seules les
  publications, figées, sont référençables ; `refexterne.rattacher` / `.detacher` ; contrôles serveur dans la
  transaction du lot (lecture de la source sinon 404, publication, révision, empreinte et niveau source exacts,
  référence à soi-même ou par une chaîne de publications épinglées refusée 409 `reference-circulaire`) ;
  `GET /atelier/references-externes` (état « à jour » / « publication plus récente » / « inaccessible », traits
  convertis par rotation puis translation explicites) ; `GET …/:id/mise-a-jour` (différences avant épinglage) ;
  superposition grise non sélectionnable dans le plan 2D ; annulable par le journal.
- Fait ensuite (D-024) : accrochage sur les traits de la source (jamais sélectionnables) ; dessin dans les plans et
  détails des documents (traits lus avec les droits du demandeur ; sans droit, la vue le dit) et en 3D ; cache hors
  ligne persistant (cache des requêtes conservé dans le navigateur ; panneau « hors ligne », mise à jour à la
  reconnexion).
- Fait ensuite (D-029) : refus sur calque verrouillé ; état « non lisible » pour un contrat ou un modèle source plus
  récent.
- Fait ensuite (D-031) : réparation d'une référence inaccessible ou non lisible par repointage explicite vers une
  autre publication (« Réparer… » ; nom, niveau, calage et calque gardés ; jamais rattachée ailleurs en silence, R12).
- Fait (D-137) : décalage d'altitude d'une référence externe (3D) ; tests `refexterne.test.ts`, e2e `atelier-complements.mjs`.
