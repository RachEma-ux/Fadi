# DA-03-10 — Direct modeling and editing / Modélisation et édition directes — module M02 → module Fadi Atelier — lot 3a + 3b

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : — (à lier aux lots 3a et 3b).

Parts : lot 3a, édition directe en plan 2D (poignées de sommets, d'extrémités, de position, inspecteur) ; lot 3b,
édition directe en 3D (pousser / tirer, manipulateur). Toute édition directe est **traduite en commande
paramétrique** : l'utilisateur touche la forme, le modèle reçoit des paramètres (D-003, R15).

| Champ | Contenu |
| --- | --- |
| Identité | **DA-03-10** « Direct modeling and editing » (Exigences V4.1, annexe B.4, M02, P1 ; critère de recette commun B.4 : « Représentation identifiée ; géométrie valide dans les tolérances du cas »). Retenue au lot 3 (`docs/atelier-drawall.md` §5.1). Sous-exigences : **DA-03-10-a** poignées en plan (extrémités et milieu d'un mur, sommets d'un contour, position d'une ouverture le long de son mur) ; **-b** édition dans l'inspecteur (valeurs typées avec unités) ; **-c** pousser / tirer en 3D (DA-04-07) ; **-d** manipulateur déplacer / tourner / échelle (DA-02-17) ; **-e** saisie exacte au clavier pendant le geste (DA-02-16) ; **-f** aperçu des objets affectés avant validation. Fiches liées : DA-02-14 (points de contrôle), DA-02-01 / 03 / 05 (déplacer, tourner, échelle), DA-04-07, DA-03-09, DA-07-01 / 02 (murs, ouvertures, fiches B). |
| Situation utilisateur | L'architecte prend une extrémité de mur et la tire, glisse une porte le long de son mur, déplace un sommet de dalle, ou tape une nouvelle valeur dans l'inspecteur, sans passer par une boîte de dialogue ni redessiner. Résultat : la forme change immédiatement en aperçu, puis la modification est validée, persistée, annulable. |
| Entrées et unités | Objet et poignée (`cibles: [id]`, caractéristique saisie : `mur:arete-debut`, `dalle:contour[i]`, `ouverture:centre`…) ; position cible `{ x, y, frame: "local", unit: "m" }` ou valeur `{ value, unit }` ; accrochages (DA-02-15) et contraintes de geste (orthogonal, le long de l'axe) ; aucune valeur par défaut. |
| Comportement | Cycle UX3 : sélection → poignées visibles (taille de cible adaptée au toucher) → glissement : **aperçu** local par le réducteur pur, cotes dynamiques, objets affectés surlignés (ouvertures hébergées, murs joints, pièces) → contrôle (validité, emprise, calque verrouillé) → relâchement = validation (ou `Échap` = abandon sans commande). Traduction en commandes (annexe B) : extrémité de mur → `mur.modifier { axe }` (+ `mur.joindre` si une jonction proposée est acceptée) ; position d'ouverture → `ouverture.deplacer` ; sommet de contour → `dalle.modifier` / `solide.modifier` / `esquisse.modifier` (`contour` ou `points`) ou `transformer.pointsDeControle` (DA-02-14) ; inspecteur → `<classe>.modifier`. Un geste = un lot = une entrée de journal = une annulation. **Exigence** : jamais d'écriture directe de coordonnées dérivées (ex. sommet du solide 3D d'un mur) : la poignée n'existe que sur des paramètres canoniques. |
| Données et dépendances | Paramètres canoniques (cahier §5.2) ; caractéristiques nommées (§5.2) pour désigner la poignée ; représentations re-dérivées ; relations `heberge`, `joint-a` ; références des cotations (lot 5) conservées tant que la caractéristique existe (R12). Modules : `apps/web/src/modules/atelier/plan2d/**` (poignées 2D), `rendu3d/**` (poignées 3D, lot 3b), `atelier-model`, `core-geometry`. |
| Résultats | Objet(s) modifié(s), dépendants recalculés, révision `n + 1`, documents « à recalculer » ; libellé de journal explicite (« Déplacer l'extrémité du mur M-12 »). |
| Cas limites | Poignée tirée jusqu'à une géométrie invalide (mur de longueur < 0,01 m, contour qui se recoupe, ouverture hors mur) → aperçu rouge avec motif, relâchement sans commande. Ouverture glissée au-delà de l'extrémité → bornée à l'emprise dans l'aperçu (affichage), le serveur refuse s'il reçoit une position hors emprise (jamais corrigée côté serveur). Objet modifié par autrui pendant le geste → 409, état serveur proposé. Geste interrompu (perte de pointeur, changement d'onglet) → abandon sans commande. Requête répétée → T06. Hors ligne → exécutable localement. |
| Compatibilité | Objets importés de P.118 éditables directement (paramètres réels). Solides à hauteurs par sommet (`vertexOffsets` / `topOffsets`) : poignées de hauteur désactivées avec motif (voir DA-04-07). Objets importés d'IFC (lot 6, `autorite: "importee"`) : édition directe limitée au placement (**hypothèse**, à figer au lot 6). |
| Validation | **Unité** `packages/atelier-model/src/commandes/mur.test.ts`, `ouverture.test.ts`, `dalle.test.ts` : extrémité de mur déplacée de (4,5 ; 0) à (5,0 ; 0) → longueur 5,0 m, ouverture conservée à la même `distance` de l'extrémité de départ (son `t` recalculé dans le même lot, effet listé — **hypothèse** à figer avec les fiches DA-07-01 / 02, cohérente avec la règle de scission de DA-07-01) ; ouverture déplacée hors emprise refusée ; inverse exact. **Scénario** `apps/web/e2e/scenarios/05-atelier.mjs` : sur P.118, glisser une porte le long de son mur (`ouverture.deplacer`, révision + 1), tirer une extrémité de mur, annuler / rétablir ; même modification au clavier dans l'inspecteur (`11-accessibilite.mjs`) ; `⏱` du déplacement d'un élément (`12-mesures.mjs`). |
