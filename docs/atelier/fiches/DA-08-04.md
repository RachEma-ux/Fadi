| Champ | Contenu |
| --- | --- |
| Identité | DA-08-04 (M06, P1). Une trame est un objet `trame` : origine, angle, files (selon u) et rangs (selon n) nommés avec leur position en m ; ses intersections sont des caractéristiques accrochables (`sommet[i]`). |
| Situation utilisateur | Poser la trame porteuse d'un bâtiment, s'y accrocher. |
| Entrées et unités | `trame.creer` { niveauId, nom, origine, angle (°), files [{ nom, position }], rangs [{ nom, position }] } ; outil Trame : positions séparées par « ; », noms A, B, C… / 1, 2, 3…. |
| Comportement | Dessinée en plan (axes en trait mixte, bulles nommées en bout) ; accrochage aux intersections et aux axes ; transformations : déplacer, tourner, miroir (rangs retournés) ; échelle refusée (entraxes typés). Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `structure` activable par projet (registre `ontologies/structure/`, cahier P2 §4, T01) ; classes `poutre`, `trame`, `plaque`, `assemblage-structurel`, `soudure`, `armature`, `coulage` + `poteau` du socle ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; nomenclatures « à recalculer » (T07). |
| Résultats | Occurrence `trame` ; IFC `IfcGrid` (files = UAxes, rangs = VAxes). |
| Cas limites | Deux axes confondus ou deux noms identiques : refus ; plus de 200 axes : refus. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC `IfcGrid` avec `IfcGridAxis` ; réimport : non relue (déclaré) ; DXF : vues. |
| Validation | Tests : intersections, segments, IFC ; recette : trame créée depuis l'inspecteur, dessinée en plan. |
| Règles métier | Aucune valeur normative dans le code (test « aucune constante normative » de `structure.test.ts`, cahier P2 §8-3) ; sections et masses linéiques viennent du projet (saisie ou catalogue CSV sourcé, D-180) ; masse « non évaluée » sans masse linéique sourcée ; aucune vérification de résistance (R3). |
| Extensions à spécifier | Trames radiales, trames par niveau liées (copie entre niveaux). |
