| Champ | Contenu |
| --- | --- |
| Identité | DA-04-02 (M02, P1). Solide par révolution d'un profil fermé plan autour d'un axe (angle 0 < a ≤ 360°). |
| Situation utilisateur | Créer un fût, un tube, une pièce tournée. |
| Entrées et unités | Profil fermé (esquisse plane ou face), axe (point, direction, repère local), angle (°). |
| Comportement | Profil et axe dans le même plan ; axe ne traversant pas le profil. Cycle : sélection → paramètres → **aperçu** (maillage du résultat) → contrôle (`isValid`, volume) → validation ; la commande est exécutée par le serveur avec le même noyau (même `.wasm`, même version) et refusée si le résultat diffère de l'aperçu (empreinte). |
| Données et dépendances | Classe `solide-exact` : géométrie canonique **B-rep** (`brep` binaire OCCT, versionné par la version du noyau), maillage dérivé pour la 3D et les documents ; jamais une seconde géométrie canonique pour un objet paramétrique (R15, D1) ; OCCT chargé à la demande dans un Web Worker, jamais sur le chemin d'ouverture (D-013, D-177). |
| Résultats | Un `solide-exact` sélectionnable, volume et aire exacts, exportable STEP AP242 Éd.3 et IFC (tessellation, `IfcFacetedBrep` ou `IfcTriangulatedFaceSet`). |
| Cas limites | Profil ouvert ou traversé par l'axe : refus nommé ; angle 360° : solide fermé ; noyau non chargé : message « Noyau exact non chargé » et aucune commande ; dépassement du délai du Worker (borne déclarée) : refus ; `isValid` faux : refus avant écriture. |
| Compatibilité | STEP AP242 Éd.3 (export / import, D5) ; IFC 4.3 en tessellation ; Planche : opération « exacte » proposée à côté de manifold-3d, résultat déclaré « exact » ou « maillage ». |
| Validation | Tests : volume attendu à 1e-6 m³, `isValid`, reproductibilité, refus nommés ; banc `scripts/bench/occt-browser-bench.mjs` (20 cas, `p2-mesures.md`) ; recette navigateur. |
| Règles métier | Aucune ; R15 ; D-177 (composant LGPL remplaçable). |
| Extensions à spécifier | Révolution avec dépouille ; profils multiples. |
