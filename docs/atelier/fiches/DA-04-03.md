| Champ | Contenu |
| --- | --- |
| Identité | DA-04-03 (M02, P1). Solide par balayage d'un profil fermé le long d'un trajet (polyligne 3D, arcs, spline), transition arrondie ou à angle. |
| Situation utilisateur | Créer un tube coudé, une main courante, un conduit. |
| Entrées et unités | Profil fermé, trajet (fil 3D), mode de transition (arrondi | droit | angle). |
| Comportement | Le profil est maintenu perpendiculaire au trajet (Frenet) ou à orientation fixe ; auto-intersection détectée. Cycle : sélection → paramètres → **aperçu** (maillage du résultat) → contrôle (`isValid`, volume) → validation ; la commande est exécutée par le serveur avec le même noyau (même `.wasm`, même version) et refusée si le résultat diffère de l'aperçu (empreinte). |
| Données et dépendances | Classe `solide-exact` : géométrie canonique **B-rep** (`brep` binaire OCCT, versionné par la version du noyau), maillage dérivé pour la 3D et les documents ; jamais une seconde géométrie canonique pour un objet paramétrique (R15, D1) ; OCCT chargé à la demande dans un Web Worker, jamais sur le chemin d'ouverture (D-013, D-177). |
| Résultats | Un `solide-exact` sélectionnable, volume et aire exacts, exportable STEP AP242 Éd.3 et IFC (tessellation, `IfcFacetedBrep` ou `IfcTriangulatedFaceSet`). |
| Cas limites | Rayon de courbure du trajet < demi-largeur du profil : auto-intersection, refus nommé ; trajet ouvert ou fermé admis ; noyau non chargé : message « Noyau exact non chargé » et aucune commande ; dépassement du délai du Worker (borne déclarée) : refus ; `isValid` faux : refus avant écriture. |
| Compatibilité | STEP AP242 Éd.3 (export / import, D5) ; IFC 4.3 en tessellation ; Planche : opération « exacte » proposée à côté de manifold-3d, résultat déclaré « exact » ou « maillage ». |
| Validation | Tests : volume attendu à 1e-6 m³, `isValid`, reproductibilité, refus nommés ; banc `scripts/bench/occt-browser-bench.mjs` (20 cas, `p2-mesures.md`) ; recette navigateur. |
| Règles métier | Aucune ; R15 ; D-177 (composant LGPL remplaçable). |
| Extensions à spécifier | Balayage avec loi d'évolution (échelle le long du trajet). |
