# DA-07-03 — Windows / Fenêtres — module M05 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-07-03 (M05, étape cible P1). Une fenêtre est un objet de classe `fenetre` (building.architecture), ouverture hébergée par un mur : elle suit le modèle et les commandes `ouverture.*` décrits en DA-07-04, qui porte la mécanique commune (emprise, déplacement, scission de l'hôte). Sous-exigences : -a poser (`ouverture.poser`, classe `fenetre`) ; -b modifier (`ouverture.modifier`) ; -c déplacer le long de l'hôte (`ouverture.deplacer`) ; -d supprimer (`ouverture.supprimer`). Référence de comportement : prototype, les 126 fenêtres de P.118 (`hostWallId`, `t`, `width`, `height`, `sill`, `mark`). |
| Situation utilisateur | Poser une fenêtre dans un mur avec une position, une allège et des dimensions choisies, la repérer, la déplacer le long de son mur et la voir suivre son mur. |
| Entrées et unités | `murHoteId` ; `position` : `t` ∈ [0, 1] le long de l'axe, ou distance saisie en m depuis l'extrémité choisie (`distance` dérivée) ; `largeur`, `hauteur`, `allege` `{ value, unit: "m" }` (allège = hauteur de l'appui depuis la base du mur, ≥ 0) ; `repere` ; `typeId` (définition du catalogue). |
| | Unité autre que m refusée (T03). Aucune dimension, allège, repère ni type par défaut (R3) : une allège absente de la source ou de la saisie reste « non évaluée » (fenêtre posée et visible en plan, vide 3D non construit, jamais 0 supposé). Cadre, vitrage et menuiserie relèvent du type (`typeId`), non de paramètres de la fenêtre au lot 3a. |
| Comportement | **Cycle.** Outil « Fenêtre » → survol d'un mur (hôte candidat surligné) → paramètres (largeur, hauteur, allège, repère, type) → position par clic accroché ou distance saisie → aperçu avec distances aux extrémités du mur et aux ouvertures voisines → contrôle → validation ; Échap annule sans commande. |
| | **Commandes et contrôles.** `ouverture.poser` (classe `fenetre`), `ouverture.modifier`, `ouverture.deplacer`, `ouverture.supprimer` ; contrôles de DA-07-04 (emprise dans l'axe de l'hôte, recouvrement) ; en plus, le haut de la fenêtre (allège + hauteur) doit tenir sous la hauteur du mur lorsqu'elle est évaluée, sinon refus avec la valeur maximale ; hauteur du mur « non évaluée » : contrôle « non évalué ». |
| | **Sans règle appliquée (R3).** Aucun éclairement, aucune ventilation, aucune surface vitrée ni hauteur d'allège de sécurité n'est calculé ou contrôlé ; une fenêtre dans un mur intérieur n'est pas refusée ; une fenêtre d'angle (à cheval sur deux murs) n'est pas modélisée : emprise hors du mur hôte, refus. |
| | **Suivre l'hôte (R12).** Mur déplacé : la fenêtre suit, `t` inchangé. Mur scindé : fenêtre réaffectée, `t` recalculé, position inchangée ; scission dans son emprise refusée. Mur raccourci : « à réparer » (déplacer, supprimer, détacher), jamais déplacée en silence. Palette (UX2) : « fenêtre » ; synonymes « window », « châssis » ; exemple court : poser une fenêtre de 1,20 m de large dans un mur (exemple, jamais valeur par défaut) ; aide (UX4). |
| Données et dépendances | Classe `fenetre` ; relation `heberge-par` → `mur` (inverse `heberge`) ; caractéristique `ouverture:centre` ; `typeId` vers une définition. Symbole en plan et vide en 3D dérivés ; événement `atelier.commande.validee` : vues, quantités (fenêtres par type, lot 5) et bilan Harmonie « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Fenêtre posée, modifiée, déplacée ou supprimée ; `distance` dérivée affichée ; effets dans le panneau des modifications (références à réparer, quantités à recalculer) ; inverse = valeurs précédentes enregistrées. |
| Cas limites | **Hôte et géométrie.** `murHoteId` jamais existé → 400 avec `chemin` ; hôte supprimé par autrui depuis `baseRevision` → 409 avec `conflits[].objetId` ; fenêtre importée sans hôte : conservée avec le problème « hôte introuvable ». Largeur ≤ 0 ; allège < 0 ; allège + hauteur au-delà du mur ; emprise hors du mur hôte : refus avec la plage admise ; repère en double : signalé, jamais renuméroté. |
| | **Concurrence, réseau, droits.** `baseRevision` dépassée et fenêtre ou hôte modifié depuis → 409, résolution explicite ; même `requestId` → aucune seconde révision (T06) ; hors ligne : réducteur local, file Dexie, rejeu dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
