| Champ | Contenu |
| --- | --- |
| Identité | DA-06-02 (M03, P1). Une contrainte de **distance ou d'angle pilotante** porte une valeur modifiable qui pilote la géométrie ; variante « de contrôle » (lecture seule). Sous-ensemble de DA-06-01. |
| Situation utilisateur | Changer la valeur d'une cote et voir l'esquisse se recalculer. |
| Entrées et unités | `contrainte.modifier` { id, valeur } (m ou °) ; `pilotante` booléen. |
| Comportement | Modifier la valeur relance le solveur ; la cote apparaît dans les documents comme cote associative ; si la résolution échoue, la valeur précédente est gardée et la commande refusée. |
| Données et dépendances | Comme DA-06-01 ; documents marqués « à recalculer » quand la géométrie bouge (T07). |
| Résultats | Esquisse recalculée ; une révision par modification ; inverse exact. |
| Cas limites | Valeur ≤ 0 ou unité ≠ m / ° refusée (T03) ; contrainte de contrôle : la saisie est refusée (lecture seule) ; valeur hors borne géométrique (distance > somme des segments) : refus nommé. |
| Compatibilité | Comme DA-06-01. |
| Validation | `contrainte-plus.test.ts` : modification de valeur, refus, inverse ; recette documents. |
| Règles métier | Aucune ; R3. |
| Extensions à spécifier | Expressions et paramètres globaux liés entre contraintes (DA-06-03 à 06, P2-2) ; tables de familles. |
