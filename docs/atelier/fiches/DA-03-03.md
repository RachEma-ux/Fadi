Preuve prévue : —

| Champ | Contenu |
| --- | --- |
| Identité | DA-03-03 (M02, P2). Une `surface-libre` est un maillage de contrôle (sommets 3D, faces triangulaires ou quadrangulaires) subdivisé `niveaux` fois (Loop) ; le maillage dérivé sert au rendu, aux corps d'interférence, à l'IFC. |
| Situation utilisateur | Modéliser une forme libre (dôme, sculpture, volume d'étude) par ses sommets et ses faces. |
| Entrées et unités | `surfaceLibre.creer { sommets: {x,y,z}[], faces: number[][], niveaux (0–4), ferme, nom? }` (m, z depuis le niveau) ; outil Surface libre (sommets « x ; y ; z » et faces d'indices). |
| Comportement | Triangulation des quads, subdivision de Loop (4ⁿ triangles), volume signé si fermée ; emprise convexe en plan. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'outil vit dans l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Classe `surface-libre` (`ParamsSurfaceLibre` : sommets 3D relatifs au niveau, faces à 3 ou 4 indices, `niveaux` 0–4, `origine`, `ferme`) ; `geometrie-3d.ts` (`triangulerFaces`, `subdiviserLoop`, `proprietesMasse`) ; `batiment-p2.ts` (`maillageSurfaceLibre`, `controleDepuisMaillage`) ; réducteurs `surfaceLibre.creer / modifier / supprimer / depuisObjet / deplacerSommet / subdiviser`. Commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9). |
| Résultats | Occurrence ; faces subdivisées comptées (`facesSubdivisees`) ; volume dérivé du maillage fermé. |
| Cas limites | Indice de face hors des sommets, face à moins de 3 ou plus de 4 indices : 400 ; plus de 50 000 sommets ou faces : refus ; `niveaux` > 4 : refus. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC `IfcBuildingElementProxy` tessellé (maillage subdivisé), `Fadi_SurfaceLibre` (sommets, faces, subdivisions, fermée, origine). |
| Validation | Tests : pyramide à 5 sommets → 6 triangles, ×4 par niveau (24, 96), volume lissé < volume de contrôle ; recette : conversion et subdivision depuis la fiche. |
| Règles métier | Le maillage de contrôle est la donnée ; la surface lissée en est dérivée et recalculée à l'identique. Une grandeur absente est « non évaluée » (R3) ; géométrie seulement, aucune vérification réglementaire. |
| Extensions à spécifier | Arêtes vives (creases), subdivision Catmull–Clark sur quads, import OBJ / STL. |
