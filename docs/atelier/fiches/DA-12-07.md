# DA-12-07 — Specification-driven piping / Tuyauterie pilotée par spécification — module M08 → Atelier (ontologie `mep`) — lot P2-5

Preuve liée (P2-5) : `packages/atelier-model/src/ontologies/mep/mep.test.ts`, `apps/api/src/routes/atelier-reseaux.test.ts`, recette `apps/web/e2e/p2-reseaux.mjs` (en CI) ; compte rendu `lots/p2-lot-5.md`. Preuve prévue : —

| Champ | Contenu |
| --- | --- |
| Identité | DA-12-07 (M08, P2). Une spécification est une définition du projet (`specification.definir`) ; `specificationId` sur un segment, un raccord ou une vanne impose le système, fournit fluide et matériau par défaut et, si elle porte un catalogue, exige une section de ce catalogue parmi les désignations admises. |
| Situation utilisateur | Garantir qu'une classe de tuyauterie n'emploie que les tubes de son catalogue. |
| Entrées et unités | `specification.definir { id?, nom, systeme, fluide?, materiau?, catalogueId?, designations?, note? }`, `specification.supprimer { id }` ; outil Spécification de réseau ; champ « Spécification » des outils. |
| Comportement | Refus nommés : système différent, section saisie alors que la spécification a un catalogue, désignation non admise ; suppression refusée tant qu'un objet la suit. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `mep` activable par projet (registre `ontologies/mep/`, T01) ; classes `segment-reseau`, `raccord-reseau`, `vanne`, `equipement-reseau`, `support-reseau` ; définitions `specification` et `catalogue` ; relation `connecte` ; géométrie 3D partagée `geometrie-3d.ts` ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; contrôle `controlerReseau` après chaque commande (T07). |
| Résultats | Définition versionnée ; nom de la spécification dans la nomenclature et `Fadi_Reseau`. |
| Cas limites | Désignations sans catalogue : refus ; catalogue inconnu : refus. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC `Fadi_Reseau.Specification`. |
| Validation | Tests : trois refus, héritage du fluide, suppression refusée puis admise ; recette : spécification « Eau froide acier » sur le catalogue T. |
| Règles métier | Aucune valeur de réseau dans le code (test : pas de table de DN, pas de débit ni de pression) : sections saisies ou tirées d'un catalogue CSV sourcé (`tubes-raccords.csv`, D-180), fluides et matériaux déclarés, spécifications du projet ; une grandeur absente est « non évaluée » (R3) ; aucun dimensionnement, aucune vérification hydraulique ou aéraulique. |
| Extensions à spécifier | Spécifications par classe de pression, par plage de DN, substitution automatique. |
