| Champ | Contenu |

| Identité | DA-09-01 (M06, P2). Une pièce de bois est un objet `element-bois` : axe a → b (za, zb), section largeur × hauteur (`SectionBois`, provenance de catalogue facultative), rôle (montant, lisse, sablière, traverse, linteau, appui, poteau, poutre, solive, entretoise, panne, chevron, faîtière, diagonale, autre), rotation, ossature d'origine, repère. |
| Situation utilisateur | Poser une panne, une solive, un poteau bois. |
| Entrées et unités | `elementBois.creer` { niveauId, a, b, za, zb (m), section : { largeur, hauteur (m), essence?, classe? } ou { catalogueId, designation }, role, rotation (°), repere } ; outil Élément bois : deux poteaux, une ligne ou extrémités saisies ; section en mm. |
| Comportement | Balayage de la section le long de l'axe (volume = l × h × L) ; rendu plan : bande de la largeur (section en plan pour une pièce verticale) ; accrochage à l'axe ; suppression en cascade des assemblages bois qui la relient. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `timber` activable par projet (registre `ontologies/timber/`, T01) ; classes `element-bois`, `ossature`, `panneau-clt`, `assemblage-bois` ; géométrie 3D partagée `geometrie-3d.ts` ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; liste des pièces « à recalculer » (T07). |
| Résultats | Occurrence `element-bois` ; fiche (section, essence, source, longueur, volume, masse non évaluée) ; ligne de la liste des pièces. |
| Cas limites | Longueur nulle : refus ; désignation absente du catalogue : 409. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC `IfcMember` (PredefinedType par rôle : STUD, PLATE, POST, PURLIN, RAFTER, BRACE, STRUT) ou `IfcBeam` (.BEAM. / .JOIST.) ; essence en `IfcMaterial` ; `Fadi_Bois` ; réimport `objet-importe`. |
| Validation | Tests : création, refus, volume, IFC ; recette : fiche d'un montant généré (section, essence, source). |
| Règles métier | Aucune valeur normative : sections, essences et classes viennent du projet (saisie déclarée ou catalogue CSV sourcé `sections-bois.csv`, D-180) ; test « aucune constante normative » (classes C16–GL28, densités) ; masse « non évaluée » (aucune densité sourcée) ; aucune vérification de résistance (R3). |
| Extensions à spécifier | Pièces courbes ou cintrées, lamellé-collé par couches, débits optimisés (DA-09-09, P3). |
