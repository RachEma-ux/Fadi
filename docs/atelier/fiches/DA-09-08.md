| Identité | DA-09-08 (M06, P2). Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |

| Résultats | Pièces de bois (chevron, sabliere, faitiere) rattachées. |
| Cas limites | Toiture plate ou sans pente : refus ; pan non convexe : chevrons sur l'étendue traversée (déclaré). `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
