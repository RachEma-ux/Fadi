Preuve liée : `packages/atelier-model/src/commandes/commandes.test.ts` (groupes), recette `apps/web/e2e/atelier-nouveau.mjs` ; comptes rendus `lots/lot-3a.md`, `lot-3b.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-03-12 (M02, étape cible P1). Interprétation retenue (limitée) : un ensemble de plusieurs `solide` indépendants, un corps = un `solide`, rassemblés dans un `groupe` (DA-05-05) pour être sélectionnés, déplacés, affichés et comptés ensemble. Sous-exigences : -a créer plusieurs corps ; -b les rassembler ; -c lister et isoler les corps d'un ensemble. Ni booléennes ni fusion de corps : DA-04-11 et lot optionnel OCCT. |
| Situation utilisateur | Composer un volume complexe de plusieurs corps (par exemple une masse faite de plusieurs prismes) en gardant chaque corps modifiable séparément. |
| Entrées et unités | `solide.extruder` (plusieurs fois, DA-04-01) ; `groupe.creer` : `niveauId`, `membres` (au moins 2 `solide`) ; dimensions de chaque corps : `hauteur`, `decalageBase` `{ value, unit: "m" }`, contour en points locaux (m). Aucun paramètre de corps n'est partagé : chaque `solide` garde ses valeurs. |
| Comportement | **Cycle.** Extruder plusieurs profils (DA-04-01) ou sélectionner des solides existants → Grouper → liste des corps (nom, rôle, calque, volume dérivé) → isoler un corps (affichage, R10) → modifier un corps (DA-04-07, `solide.modifier`) ou l'ensemble (`transformer.*` sur le groupe) → aperçu, contrôle, validation ; Échap annule sans commande. |
| | **Commandes.** `solide.extruder`, `solide.modifier`, `solide.supprimer`, `groupe.creer`, `groupe.dissoudre`, `transformer.*` : aucune commande nouvelle. Un groupe de solides n'a pas de géométrie : volume, aire d'emprise et maillage d'un ensemble sont la somme et l'union affichée des corps, dérivés ; aucun maillage fusionné n'est stocké (R15). |
| | **Limites assumées.** Corps qui se recouvrent : admis, recouvrement signalé (« chevauchement ») sans correction, double comptage du volume signalé ; aucune union, différence ni intersection (DA-04-11) ; aucun contact ni jeu contrôlé ; ensembles limités à un niveau (DA-05-05) ; corps d'une autre nature (surface, maillage, B-rep) hors lot. |
| | **Contrôles.** Ceux de DA-05-05 (membres du même niveau, pas de cycle, calque verrouillé : lot refusé en entier) et de DA-03-01 (validité de chaque corps) ; la liste des corps n'est proposée que si tous les membres du groupe sont des `solide`. |
| Données et dépendances | Classe `solide` (un corps par occurrence), entité `groupe` (DA-05-05), relation `membre-de`. Volume et emprise d'ensemble : dérivés, non stockés. Événement de commande validée : vues et quantités « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Ensemble de corps sélectionnable, déplaçable, masquable et listé ; chaque corps modifiable séparément ; volume cumulé affiché comme dérivé ; inverse restitue corps et groupe. |
| Cas limites | **Géométrie.** Corps dégénéré dans un ensemble : refusé à sa création, rien n'est écrit ; chevauchement : signalé, pas refusé ; corps supprimé : retiré du groupe, effet listé ; dernier corps supprimé : groupe supprimé, effet listé. |
| | **Concurrence et réseau.** `baseRevision` dépassée et corps modifié ou supprimé depuis → 409 avec `conflits[].objetId` ; un corps supprimé par autrui ne réapparaît pas ; même `requestId` → une seule révision (T06). Hors ligne : réducteur local, file Dexie, rejeu dans l'ordre, brouillon si incompatible. 403 / 404 / 423 selon R13. |
| Compatibilité | Import P.118 : les 807 `solide` de rôle `solid` restent des corps indépendants, sans groupe créé à l'import (aucun ensemble inventé, R3, R7) ; l'utilisateur peut les grouper. IFC (lot 6) : un solide = un élément ou une représentation ; un ensemble de corps s'exporte comme `IfcGroup` si l'annexe C le retient ; booléennes IFC importées : représentation importée (R16). DXF : sans objet. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/groupe.test.ts`, cas solides) : 3 `solide` extrudés puis groupés ; `transformer.deplacer` sur le groupe : 3 corps déplacés, un seul lot ; volume d'ensemble = somme des volumes ; chevauchement signalé ; suppression d'un corps : effet listé ; inverse restitue. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `groupe.creer` de solides → 200 ; membre d'un autre niveau → 400 avec `chemin` ; même `requestId` → même réponse ; `baseRevision` périmée et corps supprimé → 409. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 3D · multicorps ») : copie de travail de P.118 : extruder 2 profils de la mezzanine, les grouper, déplacer l'ensemble ; isoler un corps (affichage, révision inchangée) ; annuler ; second navigateur à la même révision ; ligne `⏱ affichage d'un ensemble de corps` imprimée (R14), sans seuil. |
| Règles métier | Aucune règle réglementaire. R3 : aucun ensemble n'est créé par déduction. R14 : aucune performance annoncée avant mesure. R15 : une seule géométrie canonique par corps, aucune géométrie d'ensemble stockée. |
| Extensions à spécifier | Booléennes (DA-04-11) et corps fusionnés : lot optionnel OCCT ; contrôle d'interférence ; corps de natures différentes ; ensembles sur plusieurs niveaux ; propriétés par corps (DA-06-07 s'applique déjà à chaque `solide`). |
