# DA-03-12 — Multibody modeling / Modélisation multicorps — module M02 → module Fadi Atelier — lot 3b + optionnel

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : — (à lier au lot 3b).

Portée : au lot 3, **plusieurs corps indépendants** (solides, objets d'architecture) coexistent sur un niveau et
dans le projet, chacun avec son identité, sans opération booléenne entre eux. Les booléens et corps combinés
relèvent du lot optionnel (OCCT, licence non arbitrée, D-003) ; manifold-3d (Apache-2.0) est mesuré au lot 0 comme
alternative de maillage — **un maillage n'est pas une B-Rep** (`docs/atelier-drawall.md` §4.3).

| Champ | Contenu |
| --- | --- |
| Identité | **DA-03-12** « Multibody modeling » (Exigences V4.1, annexe B.4, M02, P1 ; critère de recette commun B.4 : « Représentation identifiée ; géométrie valide dans les tolérances du cas »). Retenue « 3 + optionnel » (`docs/atelier-drawall.md` §5.1 ; cahier §7, lot optionnel « DA-03-01 / 12 »). Sous-exigences lot 3 : **DA-03-12-a** plusieurs corps par niveau, chacun objet distinct (identité stable `${projectId}_${id}`, calque, rôle) ; **-b** sélection multiple et filtre par classe ; **-c** recouvrement de corps permis et **signalé** (pas fusionné) ; **-d** regroupement logique sans fusion (DA-05-05, groupes) ; **-e** quantités par corps, jamais sommées en volume « net » de recouvrements. Optionnel : **-f** union, différence, intersection (DA-04-11). Fiches liées : DA-03-01, DA-04-01, DA-05-05, DA-05-12. |
| Situation utilisateur | L'architecte compose un plateau de nombreux volumes (mobilier, noyaux, rampes, gabarits) qui se touchent ou se recouvrent ; il les sélectionne ensemble, les déplace, les groupe, et lit leurs quantités, sans que le logiciel les fusionne à son insu. |
| Entrées et unités | Ensemble de corps (identifiants), niveau ; aucune nouvelle grandeur. Tolérance de contact / recouvrement : `tolCoincidence` (proposée, à confirmer). |
| Comportement | Création de chaque corps par sa commande propre (`solide.extruder`, `mur.tracer`…). Opérations sur plusieurs corps : `transformer.*` sur une sélection (lot atomique, DA-02), `groupe.creer` / `groupe.dissoudre` (annexe B ; DA-05-05). Détection de recouvrement : calcul dérivé (non stocké) affiché dans l'inspecteur et, en niveau d'affichage Complet, dans le panneau des problèmes en information (**recommandation** : information, pas erreur ; les collisions d'architecture sont au lot 7, DA-17-13). Aucune commande booléenne au lot 3 ; la palette répond à « union », « soustraire », « boolean » par « disponible avec le noyau exact (lot optionnel) » (aide située, UX4). |
| Données et dépendances | `atelier_objects` (un corps = une occurrence) ; `group_id` (DA-05-05) ; représentations dérivées par corps ; aucune relation de fusion. Rendu : instanciation three.js, scène par niveau (L3b.1). Quantités (L1.3) par corps. |
| Résultats | Corps distincts, sélectionnables ensemble ; quantités par corps ; recouvrements visibles en information. |
| Cas limites | Corps identiques superposés (doublon exact) → information « doublon possible », pas de suppression automatique. Sélection de plusieurs centaines de corps → transformation en un lot unique, borné par l'enveloppe ≤ 1 Mo (cahier §8), au-delà refus motivé. Corps sur un calque verrouillé dans la sélection → tout le lot refusé avec la liste (tout ou rien). |
| Compatibilité | **Import P.118** : 870 tracés deviennent des `solide` distincts (807 `solid`, 35 `clearance`, 28 `ramp-*`), aucun regroupement ni fusion inventés (aucun `group` dans la source). **IFC 4.3** (lot 6) : un `IfcBuildingElementProxy` par corps. **Optionnel** : booléens OCCT (`brep`) ou manifold-3d (maillage, représentation `importee` / `derivee` déclarée comme maillage) selon les mesures `docs/atelier/p0-mesures.md`. |
| Validation | **Unité** `packages/atelier-model/src/commandes/transformer.test.ts` : déplacement d'une sélection de 3 solides → 3 objets modifiés, un journal, inverse exact ; recouvrement de deux prismes 2 × 2 m décalés de 1 m → information listée, volumes par corps inchangés (2 × 2 × h chacun). **Import** `src/importeur/p118.test.ts` : effectifs par niveau des solides égaux à la source. **Scénario** `apps/web/e2e/scenarios/05-atelier.mjs` : sélection lasso de plusieurs mobiliers sur le RDC de P.118, déplacement, annuler ; `⏱` sélection (`12-mesures.mjs`). |
