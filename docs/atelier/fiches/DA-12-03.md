Preuve prévue : —

| Champ | Contenu |
| --- | --- |
| Identité | DA-12-03 (M08, P2). La CVC se modélise avec les classes de l'ontologie : gaines (air), tuyaux (eau chaude, eau glacée), équipements à plusieurs ports de systèmes différents (une centrale a des ports gaine et des ports tuyau), connectivité vérifiée par port. |
| Situation utilisateur | Modéliser une centrale de traitement d'air avec ses gaines et ses tuyaux de batterie. |
| Entrées et unités | Classes de DA-12-02, 04, 10 ; `equipementReseau.creer` avec des ports `systeme: "gaine"` et `systeme: "tuyau"`. |
| Comportement | Un équipement relie des systèmes différents sans les mélanger : chaque port porte son système et son fluide ; `reseauxConnexes` nomme chaque composante avec ses systèmes et fluides. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `mep` activable par projet (registre `ontologies/mep/`, T01) ; classes `segment-reseau`, `raccord-reseau`, `vanne`, `equipement-reseau`, `support-reseau` ; définitions `specification` et `catalogue` ; relation `connecte` ; géométrie 3D partagée `geometrie-3d.ts` ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; contrôle `controlerReseau` après chaque commande (T07). |
| Résultats | Réseaux connexes, P&ID, nomenclature. |
| Cas limites | Port d'équipement sans section : refus. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC : équipements par catégorie, `IfcDistributionSystem` par réseau connexe (ObjectType systèmes:fluides). |
| Validation | Tests : réseau tuyau + gaine + chemin de câbles, trois composantes ; recette : pompe et gaine dans P.118-R. |
| Règles métier | Aucune valeur de réseau dans le code (test : pas de table de DN, pas de débit ni de pression) : sections saisies ou tirées d'un catalogue CSV sourcé (`tubes-raccords.csv`, D-180), fluides et matériaux déclarés, spécifications du projet ; une grandeur absente est « non évaluée » (R3) ; aucun dimensionnement, aucune vérification hydraulique ou aéraulique. |
| Extensions à spécifier | Bilans aérauliques et thermiques (P3 : calcul) ; schémas de régulation (DA-13, P3). |
