| Identité | DA-18-03 (M14, étape cible P1). Mode « Éclaté » de la vue 3D de l'Atelier : les niveaux sont écartés verticalement pour lire l'empilement du bâtiment. Sous-exigences : -a activer, régler et désactiver l'éclaté ; -b objets multi-niveaux ; -c image ou vue éclatée enregistrée, rattachée à la bonne révision (lot 5, extension). | Situation utilisateur | Lire l'empilement des niveaux d'un bâtiment en les écartant, puis revenir à l'assemblé, sans rien modifier dans le modèle. |
| Entrées et unités | Mode (assemblé, éclaté) ; écart entre niveaux `{ value, unit: "m" }` (≥ 0, 0 = assemblé), réglé par l'utilisateur et jamais enregistré dans le modèle ; niveaux visibles (R10) ; sélection et caméra conservées. Aucune valeur d'écart n'est une donnée de projet (R3). |
| Comportement | **Cycle.** Bouton « Éclaté » de la barre de la vue 3D → réglage de l'écart (curseur, flèches du clavier, saisie numérique) → aperçu immédiat : chaque niveau et les objets qui lui sont rattachés (`contient`) sont translatés verticalement ; désactiver rend l'assemblé. Aucune commande ni validation : le mode est un paramètre d'affichage (R10). |
| | **Calcul.** Décalage vertical d'un niveau = rang du niveau (selon `ordre`) × écart, le niveau de plus bas rang n'étant pas déplacé ; fonction pure sans `three` ni DOM (R6). Les coordonnées x, y et les altitudes du modèle ne changent pas : l'éclaté n'est qu'une transformation de rendu. Niveaux de même élévation, ou `ordre` incohérent avec les élévations (DA-05-04) : l'éclaté suit `ordre` et le signale, sans rien corriger. |
| | **Objets multi-niveaux.** Un escalier (`relie` deux niveaux) suit son niveau de départ, un mur à `niveauHaut` son niveau de base ; la relation avec l'autre niveau reste lisible (trait de rappel ou surbrillance, présentation à valider sur la maquette du lot 0). Aucun objet n'est coupé ni dupliqué. |
| | **Palette (UX2) et aide (UX4).** « éclaté » ; synonymes « explode », « vue éclatée » ; actif si le modèle compte au moins deux niveaux ; exemple court : écarter les niveaux de 1 m (exemple, jamais valeur par défaut). |
| Données et dépendances | Lecture seule : `niveau` (`ordre`, `elevation`), relations `contient` et `relie`, `niveauHaut` des murs ; aucune commande émise, aucun paramètre du modèle modifié, aucune révision créée (R10) ; réglage d'écart conservé localement (session ou Dexie), jamais dans le modèle ; fonction de décalage dans `packages/core-geometry` (R6). |
| Résultats | Vue 3D éclatée ; niveaux et objets rattachés écartés ; assemblé restauré sans résidu (écart 0 : coordonnées de rendu identiques) ; aucune écriture. |
| Cas limites | **Valeurs.** Écart négatif ou non numérique refusé ; un seul niveau : éclaté sans effet, message ; modèle sans niveau : mode inactif ; objets de niveaux non chargés : chargés à la demande ; WebGL2 indisponible : mode non offert, message (R20). |
| | **Concurrence, réseau, droits.** Niveau ajouté, supprimé ou modifié par autrui pendant l'éclaté : la vue se resynchronise (`GET /journal?apres=n`), l'écart reste ; lecture seule : `read` suffit, aucune requête d'écriture, donc ni 409 ni 423 ; 404 sans accès ; hors ligne : dernier instantané Dexie. |
