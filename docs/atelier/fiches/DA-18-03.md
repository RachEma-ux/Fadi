# DA-18-03 — Exploded presentations / Présentations éclatées — module M14 → module Fadi Atelier — lot 3b

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : part 3b (L3b.1, D-047) : mode « Éclaté » de la vue 3D (`apps/web/src/modules/atelier/vue3d/scene.ts`, `MODES_3D`), niveaux écartés de `ECART_ECLATE` = 3 m par rang (paramètre d'affichage `ecartEclate`, R10), portée « tous les niveaux » ou « niveau actif », sélection au clic et inspecteur en mode éclaté (`Vue3d.tsx`) ; test `apps/web/src/modules/atelier/vue3d/vue3d.test.ts` « niveaux filtrés ; mode éclaté : écart ajouté par rang ; hauteur de coupe par défaut » ; scénario `14-nouvel-atelier.mjs#vue3d` « niveaux × 3 modes (volume, éclaté, coupe) rendus sans vue vide » ; PR #72. Reste : -b écartement réglable par l'utilisateur et règle du prototype (`explodeLift`, 0,95 × hauteur moyenne) — écart fixe de 3 m retenu (D-047) ; -c portée « hors sol » ; -d localisation des problèmes en éclaté (DA-17-16) ; -e transition animée et `prefers-reduced-motion`.

Sous-exigences : **DA-18-03-a** activer / quitter le mode éclaté ; **-b** écartement des niveaux réglable ; **-c** choix des niveaux montrés (bâtiment entier, niveaux hors sol seulement, niveau actif mis en évidence) ; **-d** sélection, inspection et localisation de problèmes en mode éclaté (DA-17-16) ; **-e** transition animée respectant `prefers-reduced-motion`. | Situation utilisateur | Pour lire l'organisation verticale (noyaux, trémies, escaliers d'un niveau à l'autre) ou la présenter, l'architecte écarte les étages, tourne autour, sélectionne un objet d'un étage intermédiaire, puis revient en volume. |
| Entrées et unités | Mode (`volume` / `eclate` / `coupe`) ; écartement : par défaut, **règle du prototype** (`explodeLift`, `v14-viewer.js`) : décalage du niveau d'indice `i` parmi les niveaux visibles triés par altitude = `i × max(3 m, 0,95 × hauteur moyenne des niveaux visibles)` (hauteur d'un niveau absente → 3 m, comme le prototype) ; facteur d'écartement réglable par l'utilisateur (sans unité, multiplicateur ≥ 1) ; portée : bâtiment entier ou niveaux d'altitude ≥ 0 (case « sous-sol » du prototype). Tous ces réglages sont des **paramètres d'affichage** (R10). |
| Comportement | Bascule de mode (barre de la zone de travail, palette « éclaté / exploded », raccourci conservé) → transition vers les positions écartées (instantanée si `prefers-reduced-motion`) → orbite / pan / zoom, sélection par lancer de rayon sur les objets décalés (la sélection renvoie l'objet du modèle, pas sa position affichée) → l'inspecteur affiche les altitudes **réelles** (le décalage d'éclaté n'est jamais lu comme une donnée) → retour au mode volume. Les objets « référence de plan seulement » (escaliers, DA-07-10) ne sont pas dessinés en 3D. Aucune commande n'est émise ; la révision du modèle ne change pas (R10). |
| Données et dépendances | Lit le modèle typé à la révision affichée (niveaux, objets, représentations `solide-3d` dérivées) ; scène par niveau de DA-18-04 (un groupe three.js par niveau, translaté verticalement) ; état d'affichage local au client (mode, facteur, portée), éventuellement mémorisé par navigateur (préférence, jamais dans le modèle). Dépend de `apps/web/src/modules/atelier/rendu3d/**` ; aucune dépendance de `packages/atelier-model` vers le rendu (R6). |
| Résultats | Vue éclatée interactive, rattachée à la révision affichée (indiquée dans la zone de travail). Aucune image exportée au lot 3 (export d'image et feuilles de présentation : lot 5). |
| Cas limites | Un seul niveau → l'éclaté équivaut au volume (pas d'erreur). Niveaux d'altitude égale ou non triés → ordre par altitude puis par `ordre` du niveau. Hauteur de niveau absente → 3 m pour l'écartement d'affichage seulement, signalé « hauteur non renseignée » dans l'inspecteur du niveau (aucune donnée inventée dans le modèle). Modèle modifié pendant l'éclaté (autre compte) → mise à jour de la scène à la nouvelle révision, mode conservé. Perte de contexte WebGL → repli et message (DA-18-04). |
