Preuve liée (P2-5) : `packages/atelier-model/src/ontologies/mep/mep.test.ts`, `apps/api/src/routes/atelier-reseaux.test.ts`, recette `apps/web/e2e/p2-reseaux.mjs` (en CI) ; compte rendu `lots/p2-lot-5.md`. Preuve prévue : —

| Champ | Contenu |
| --- | --- |
| Identité | DA-12-06 (M08, P2). Le routage suit une polyligne 3D (sommets saisis ou tracé d'une esquisse à une altitude) : un segment par tronçon, un raccord coude par sommet intermédiaire (ports déduits des deux directions, bras de longueur saisie, tronçons raccourcis d'autant), connexions créées, dans la même commande. |
| Situation utilisateur | Tracer un réseau en trois clics et obtenir des tronçons et des coudes déjà connectés. |
| Entrées et unités | `reseau.router { niveauId, systeme, sommets[≥2], section, fluide?, materiau?, sens?, specificationId?, coude?: { longueur }, prefixe? }` ; outil Segment de réseau (sommets « x ; y ; z » ou esquisse sélectionnée). |
| Comportement | Sans `coude`, les tronçons se connectent bout à bout (coude implicite, déclaré) ; avec, `portsCoude` oriente les bras vers l'amont et l'aval, y compris en 3D (montée verticale). Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `mep` activable par projet (registre `ontologies/mep/`, T01) ; classes `segment-reseau`, `raccord-reseau`, `vanne`, `equipement-reseau`, `support-reseau` ; définitions `specification` et `catalogue` ; relation `connecte` ; géométrie 3D partagée `geometrie-3d.ts` ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; contrôle `controlerReseau` après chaque commande (T07). |
| Résultats | Segments, coudes, connexions ; nomenclature. |
| Cas limites | Tronçon trop court pour ses bras : refus nommé ; tronçon nul : refus. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC : chaque objet exporté par sa classe, connexions `IfcRelConnectsPorts`. |
| Validation | Tests : polyligne en L → 2 segments + 1 coude, positions des ports, refus d'un tronçon de 80 mm avec des bras de 100 ; recette : routage depuis l'inspecteur. |
| Règles métier | Aucune valeur de réseau dans le code (test : pas de table de DN, pas de débit ni de pression) : sections saisies ou tirées d'un catalogue CSV sourcé (`tubes-raccords.csv`, D-180), fluides et matériaux déclarés, spécifications du projet ; une grandeur absente est « non évaluée » (R3) ; aucun dimensionnement, aucune vérification hydraulique ou aéraulique. |
| Extensions à spécifier | Routage automatique entre deux points en évitant les obstacles ; pentes ; accrochage aux ports au tracé. |
