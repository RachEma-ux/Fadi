# DA-02-11 — Chamfer / Chanfreiner — module M02 → module Fadi Atelier — lot 3a

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : — (aucune commande de chanfrein dans `atelier-commands/1`, non inventée : D-037 (2)). Reste : -a à -e (aucun code au lot 3a ; ajout au contrat au lot où `atelier-model` est rouvert, puis outil).

Portée : chanfrein en 2D sur des objets d'esquisse et sur les sommets de contours polygonaux. Le chanfrein
d'arêtes de solides (3D) relève du lot optionnel OCCT.

| Champ | Contenu |
| --- | --- |
| Identité | **DA-02-11** « Chamfer » (Exigences V4.1, annexe B.3, module M02, étape cible P1 ; critère de recette commun B.3). Retenue (proposition §5.1, lot 3) ; tâche **L3a.2**. Sous-exigences : **DA-02-11-a** chanfrein entre deux lignes par deux distances ; **-b** chanfrein par une distance et un angle ; **-c** chanfrein d'un sommet de polyligne ou de polygone (insertion d'un sommet) ; **-d** chanfrein d'un sommet de rectangle (le rectangle devient un polygone, perte listée) ; **-e** chanfrein d'un sommet du contour d'un `solide` ou d'une `dalle` (**Recommandation**). Fiches liées : DA-02-10 (congé), DA-02-13 (décomposer), DA-02-14 (points de contrôle), DA-01-02 / 04. |
| Situation utilisateur | L'architecte coupe un angle : pan coupé d'un îlot de mobilier, angle abattu d'une dalle ou d'un contour d'esquisse. Résultat : l'angle remplacé par un segment droit aux distances exactes saisies. |
| Entrées et unités | Mode deux objets : deux objets (`esquisse.ligne`, `esquisse.construction`) et leurs points de désignation `{ x, y, frame: "local", unit: "m" }`. Mode sommet : un objet (`esquisse.polyligne`, `esquisse.polygone`, `esquisse.rectangle`, `solide`, `dalle`) et l'indice `sommet`. Distances : `d1`, `d2` `{ value, unit: "m" }` > 0 (mesurées depuis l'intersection le long de chaque segment) **ou** `d1` et `angle` `{ value, unit: "°" }` ∈ ]0 ; 180[. **Aucune valeur par défaut** de projet (R3). |
| Comportement | Cycle UX3 : outil « Chanfreiner » (synonymes « chamfer », « pan coupé », « angle abattu ») → distances → désignations → **aperçu** du segment de chanfrein et des longueurs restantes → contrôle → validation.<br>Commande émise : **`transformer.chanfreiner`** — *nom proposé, à figer par L1.2* (absent de l'annexe B). `{ type: "transformer.chanfreiner", cibles: [idA, idB] \| [id], params: { designationA, designationB \| sommet, d1, d2 \| angle } }`. Effets : mode deux objets → deux lignes raccourcies + une `esquisse.ligne` créée (calque du premier objet) ; mode sommet → le sommet `i` remplacé par deux sommets (le contour gagne un sommet) ; rectangle → l'objet change de classe en `esquisse.polygone` : la perte des paramètres « largeur / hauteur / angle » est **listée dans l'aperçu et acceptée explicitement** (`pertesAcceptees`, même mécanisme que DA-02-13), jamais silencieuse. `solide` / `dalle` : contour modifié, autres paramètres (hauteur, épaisseur, décalage, `role`, trous) inchangés ; pour un `solide` portant des `vertexOffsets` (hauteurs par sommet, 104 tracés de P.118) → refus au lot 3a (la hauteur du nouveau sommet serait inventée). Inverse : restauration exacte des paramètres et de la classe d'origine. Lot atomique. |
| Données et dépendances | Calcul pur `packages/core-geometry` (intersection, points à distance le long des segments) ; réducteur `transformer.chanfreiner` (`packages/atelier-model`). Écritures `atelier_objects`, journal, événement → vues du niveau « à recalculer » ; pour une `dalle` : quantités (aire de dalle) et bilan Harmonie marqués « à recalculer ». **Références** : un sommet remplacé par deux fait évoluer les indices `dalle:contour[i]` (cahier §5.2) — les références vers l'arête ou le sommet touchés passent **« à réparer »** avec propositions (R12, T05) ; les références vers les autres arêtes sont réindexées de façon déterministe (**Hypothèse**, à valider par L1.3). |
| Résultats | Segment de chanfrein (nouvelle ligne ou nouveau côté de contour) ; aire du contour recalculée (dérivée) dans l'inspecteur ; journal « Chanfreiner » ; révision `n + 1` ; références éventuelles listées dans le panneau des problèmes. |
| Cas limites | Segments parallèles → refus. `d1` ou `d2` plus long que le segment conservé → refus citant la distance maximale. Distance ≤ 0, angle hors ]0 ; 180[, unités autres que `m` / `°` → 400 (T03). Chanfrein qui rend un contour auto-sécant ou d'aire < `aireMin` (1·10⁻⁶ m², proposée) → refus. Sommet de trou (`holes`) d'une dalle ou d'un solide : admis (même règle) — **Recommandation**. Solide avec `vertexOffsets` ou `topOffsets` → refus motivé. Rectangle sans accord de perte → 400 « pertes non acceptées ». Calque verrouillé → refus. Lecteur 403 ; réservation 423 ; conflit 409 ; `requestId` répété → une seule modification ; hors ligne : local, rejoué. |
| Compatibilité | Aucun format spécifique. Une dalle chanfreinée s'exporte comme toute dalle (IFC `IfcSlab` au lot 6). Import P.118 : aucun chanfrein enregistré ; les contours importés sont modifiables par cette commande sous les conditions ci-dessus. Prototype : pas d'outil de chanfrein. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts`) : lignes (0 ; 0)–(4 ; 0) et (4 ; 0)–(4 ; 3), `d1 = d2` = 0,5 m → (0 ; 0)–(3,5 ; 0), (4 ; 0,5)–(4 ; 3) et ligne (3,5 ; 0)–(4 ; 0,5) de longueur √0,5 m ; `d1` 0,5 m + angle 45° → même résultat ; rectangle 4 × 3 chanfreiné 0,5 / 0,5 sur un coin → polygone de 5 sommets, aire 11,875 m², pertes listées ; dalle 10 × 8 chanfreinée 1 / 1 → aire 79,5 m², cotation attachée à l'arête modifiée « à réparer » ; refus sur solide à `vertexOffsets` ; inverse → empreinte identique. Tolérance `tolCoincidence` 1·10⁻⁶ m. **API** : 400 (distance trop longue, pertes non acceptées) ; idempotence. **Scénario** `05-atelier.mjs` : rectangle 4 × 3 tracé au clavier sur la mezzanine, chanfrein 0,50 m, accord de perte affiché puis accepté, aire 11,88 m² affichée (stockée 11,875), annuler / rétablir. |
| Règles métier | Aucune règle réglementaire concernée. R5, T03 ; valeurs jamais arrondies (R7). |
| Extensions à spécifier | Chanfrein d'arêtes 3D (lot optionnel OCCT) ; chanfrein de murs (angle de mur abattu) ; chanfrein multiple de tous les sommets d'un contour en une commande ; sommets à hauteur variable (`vertexOffsets`). **Signalement** : `transformer.chanfreiner` absent de l'annexe B — ajout à valider par le chef de projet. |
