# DA-02-11 — Chamfer / Chanfrein — module M02 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-11 (M02, étape cible P1). Chanfrein entre deux lignes d'esquisse. **Commande absente de l'annexe B** : nom proposé `transformer.chanfreiner`, mêmes conditions que DA-02-10 (validation du nom par le chef de projet, ajout au catalogue ; repli : deux `esquisse.modifier` et une `esquisse.ligne`). Pas de référence dans le prototype. |
| Situation utilisateur | Couper l'angle formé par deux lignes avec un segment (pan coupé) de dimensions exactes. |
| Entrées et unités | `niveauId` ; `cibles` (deux `esquisse.ligne` distinctes) ; `points` (portions conservées) ; `nouveauxIds` (le segment). Mode `distances` : `distance1`, `distance2` (m, au-dessus de la tolérance de longueur, mesurées depuis l'intersection sur chaque ligne). Mode `distance-angle` : `distance` (m, sur la première ligne) et `angle` (°, entre le chanfrein et la première ligne, strictement entre 0° et 180°). |
| Comportement | **Cycle.** Outil Chanfreiner → mode et valeurs (saisie DA-02-16, ou pointeur avec accrochages DA-02-15) → désigner les deux lignes (clic sur chaque portion conservée, sans accrochage) → aperçu du segment et des lignes ajustées → contrôle → validation ; Échap annule sans commande. |
| | **Résultat.** Les deux lignes sont modifiées (même identifiant, extrémités ramenées aux points de chanfrein, raccourcies ou prolongées) ; une `esquisse.ligne` neuve (le chanfrein) sur le calque de la première ligne ; un seul lot atomique. |
| | **Contrôles.** Distance nulle ou angle hors de ]0°, 180°[ refusés ; lignes parallèles ou confondues refusées ; distance supérieure à la portion conservée refusée avec la valeur maximale calculée ; unités (m, °) vérifiées (T03) ; niveaux différents refusés. |
| | **Palette (UX2) et aide (UX4).** « chanfreiner » ; synonymes « chamfer », « pan coupé », « couper un angle » ; actif si deux `esquisse.ligne` du même niveau existent ; exemple court : couper un angle droit avec deux distances de 0,30 m. |
| | **Clavier et toucher (T16).** Au clavier : distances saisies (DA-02-16), lignes désignées par Tab puis Entrée. Au toucher : deux appuis sur les lignes ; deux doigts déplacent ou zooment la vue sans désigner de ligne. |
| | **Portée du lot 3a.** Coin d'une polyligne, d'un polygone ou d'un rectangle : refus, `transformer.decomposer` d'abord. Un `mur` n'est pas admis : un coin coupé de bâtiment relève de DA-07-01. Lot 5 : lignes contraintes (DA-01-07) résolues avec leurs contraintes ou refusées avec la contrainte nommée. |
| | **Références (R12).** Mêmes objets, extrémités déplacées : références conservées ; le chanfrein est un objet neuf. |
| Données et dépendances | Modifie deux `esquisse.ligne`, crée une `esquisse.ligne` ; `core-geometry` : intersection ; événement de commande validée : vues du niveau « à recalculer » (R11, T07). |
| Résultats | Deux lignes ajustées et un segment de chanfrein, effets listés (2 modifiées, 1 créée), inverse = extrémités précédentes restituées et segment supprimé. |
| Cas limites | **Géométrie.** Lignes parallèles ; distance trop grande ; distance ou angle nuls ; angle de 0° ou de 180° ; portions désignées incompatibles ; calque verrouillé ou niveau différent : lot refusé en entier. |
| | **Concurrence.** `baseRevision` dépassée et ligne modifiée ou supprimée depuis → 409 détaillé, résolution explicite côté client ; même `requestId` → une seule révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie rejouée dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : aucune ligne ni tracé ouvert importé (967 tracés fermés) : la commande s'exerce sur les esquisses dessinées dans Fadi. DXF : lignes exportées en `LINE` / `LWPOLYLINE` au lot 5. IFC : omis au rapport d'échange. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts` et `packages/core-geometry`) : deux lignes perpendiculaires, `distance1` = `distance2` = `d` : chanfrein de longueur `d` × √2, à 45° (valeurs vérifiables à la main) ; mode distance-angle équivalent ; lignes parallèles refusées ; distance maximale calculée ; inverse rétablit les extrémités et supprime le segment. |
