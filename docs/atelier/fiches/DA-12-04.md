Preuve prévue : —

| Champ | Contenu |
| --- | --- |
| Identité | DA-12-04 (M08, P2). Un tuyau est un `segment-reseau` de système `tuyau` : section circulaire seulement (diamètre extérieur, épaisseur facultative), fluide déclaré, sens (`a-vers-b`, `b-vers-a`, `indifferent`) qui type ses ports en entrée / sortie. |
| Situation utilisateur | Tracer l'eau froide d'une pompe à un appareil. |
| Entrées et unités | `segmentReseau.creer { systeme: "tuyau", sommets, section: { forme: "circulaire", diametre, epaisseur? } | { catalogueId, designation }, fluide?, materiau?, sens?, specificationId? }` ; outil Segment de réseau. |
| Comportement | Tube creux balayé (couronne) ; `designationReseau` : DN du catalogue sinon Ø × e ; longueur développée de la polyligne. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `mep` activable par projet (registre `ontologies/mep/`, T01) ; classes `segment-reseau`, `raccord-reseau`, `vanne`, `equipement-reseau`, `support-reseau` ; définitions `specification` et `catalogue` ; relation `connecte` ; géométrie 3D partagée `geometrie-3d.ts` ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; contrôle `controlerReseau` après chaque commande (T07). |
| Résultats | Occurrence ; longueur, section, fluide, source dans la nomenclature. |
| Cas limites | Section rectangulaire sur un tuyau : refus ; épaisseur ≥ rayon : refus. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC `IfcPipeSegment` .RIGIDSEGMENT., `Fadi_Reseau` (diamètre, épaisseur, DN, source, fluide, sens, longueur). |
| Validation | Tests : volume d'un tube 60,3 × 2,9 sur 4,5 m à 5 % ; recette : tuyau EF routé. |
| Règles métier | Aucune valeur de réseau dans le code (test : pas de table de DN, pas de débit ni de pression) : sections saisies ou tirées d'un catalogue CSV sourcé (`tubes-raccords.csv`, D-180), fluides et matériaux déclarés, spécifications du projet ; une grandeur absente est « non évaluée » (R3) ; aucun dimensionnement, aucune vérification hydraulique ou aéraulique. |
| Extensions à spécifier | Pentes imposées, isolation, calorifuge, tubes flexibles. |
