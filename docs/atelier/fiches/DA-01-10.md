# DA-01-10 — Centerlines / Lignes d'axe — module M01 → module Fadi Atelier — lot 3a

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `creer.axe` (axe par deux points) et `creer.construction` (droite ou demi-droite avec Alt) → `esquisse.construction` (`apps/web/src/modules/atelier/plan2d/outils/esquisse.ts`) ; test `apps/web/src/modules/atelier/plan2d/outils.test.ts` « axe et ligne de construction (DA-01-10) » ; PR #57. Reste : -b axe de symétrie entre deux segments sélectionnés ; -c repère de centre d'un cercle ou d'un arc ; -e suppression (aucun outil de suppression dans le nouvel Atelier (`plan2d/controleur.ts` ne transmet Retour arrière / Suppr qu'à l'outil actif)) ; étapes « 05-atelier.mjs » du champ Validation (ancien Atelier) non reprises dans `apps/web/e2e/scenarios/14-nouvel-atelier.mjs`.

**Recommandation de correspondance (hypothèse à valider)** : l'annexe B n'a pas de commande « axe ». Les lignes
d'axe et les lignes de construction sont portées par **une seule commande** `esquisse.construction`, avec un
paramètre `nature` ∈ {`axe`, `construction`} : un axe est un segment (ou un repère de centre) **imprimable** en
trait mixte ; une ligne de construction est une droite (infinie ou demi-droite) d'aide au dessin, **non
imprimée**.

| Identité | **DA-01-10** « Centerlines » (Exigences V4.1, annexe B.2, module M01, étape cible P1 ; critère de recette commun B.2). Sous-exigences : **DA-01-10-a** axe libre par deux points ; **-b** axe de symétrie entre deux segments sélectionnés (bissectrice / médiane) ; **-c** repère de centre (croix d'axes) d'un cercle ou d'un arc ; **-d** ligne de construction (droite infinie, demi-droite) non imprimée ; **-e** modification et suppression. Tâche **L3a.2**. Fiches liées : DA-01-02, DA-01-03, DA-02-04 (miroir autour d'un axe), DA-02-15 (accrochage sur axe), DA-07-01 (`mur:axe` est une caractéristique d'objet, pas une esquisse). |
| Situation utilisateur | L'architecte trace les axes d'une composition (axe de symétrie d'une façade, axes d'un local, centre d'un poteau rond), s'y accroche pour dessiner et les retrouve sur les plans imprimés ; il pose aussi des droites de construction provisoires qui n'apparaîtront pas à l'impression. |
| Entrées et unités | `niveauId` ; `nature` ∈ {`axe`, `construction`} ; axe : `a`, `b` `{ x, y, frame: "local", unit: "m" }`, `depassement` `{ value, unit: "m" }` ≥ 0 (prolongement au-delà des extrémités, facultatif, aucune valeur normalisée imposée) ; construction : `point` + `direction` `{ value, unit: "°" }` et `etendue` ∈ {`droite`, `demi-droite`} ; repère de centre : `cibleId` d'un cercle / arc à la création, géométrie **copiée** (sans lien associatif au lot 3a, **hypothèse**) ; `calqueId`. |
| Comportement | Outils « Axe » (synonymes « centerline », « axe de symétrie », « CL ») et « Ligne de construction » (« xline », « construction », « droite infinie ») → mode (2 points / entre deux segments / centre d'un cercle / droite par point et angle) → **aperçu** → validation. Commande (annexe B) : `{ type: "esquisse.construction", params: { niveauId, nature, … , calqueId } }`, labels « Tracer un axe » / « Tracer une ligne de construction ». Préconditions : niveau existant ; calque non verrouillé ; repère `local` ; longueur d'axe ≥ `longueurMin` ; deux segments sélectionnés pour la symétrie (parallèles → médiane ; sécants → bissectrice ; confondus → refus). Inverse : `esquisse.supprimer`. Modification : `esquisse.modifier`. Affichage : trait mixte (axe) ou trait fin pointillé (construction) — style d'affichage du plan de travail ; l'impression est l'affaire des vues (lot 5) : les objets `nature: construction` sont exclus des vues et exports (**exigence de la fiche**, testée au lot 5). |
| Données et dépendances | Classe `esquisse.construction` (ontologie `drawing`) avec `params.nature` (**recommandation**, à figer par L1.1 / L1.2) ; représentation `plan-2d` `parametrique` ; une droite infinie est rendue bornée à la vue (calcul d'affichage, R10). Points d'accrochage fournis à DA-02-15 : points de l'axe, intersection avec d'autres objets, perpendiculaire. Caractéristiques proposées pour le lot 5 : `esquisse:axe`. Événement `atelier.commande.validee` → vues « à recalculer » (axes seulement ; une ligne de construction ne périme aucune vue, **recommandation** à valider avec L2.3). |
| Résultats | Axe ou ligne de construction au plan, navigateur « Esquisse › Axes / Construction » ; inspecteur : nature, longueur ou direction, dépassement ; journal ; révision + 1. |
| Cas limites | Deux points confondus → refus. Segments confondus pour un axe de symétrie → refus « pas d'axe unique ». Cercle cible supprimé entre l'aperçu et l'envoi → 409. Droite infinie : jamais exportée en coordonnées infinies (exclue des exports, ou bornée à l'emprise de la vue au lot 5). Calque verrouillé, droits, hors ligne : comme DA-01-02. |
| Compatibilité | IFC 4.3 : omis et listé (T13). DXF (lot 5) : axe en `LINE` avec type de ligne mixte (à confirmer par DA-22-03) ; construction en `XLINE` ou exclue (à décider dans DA-22-03). Import P.118 : aucun axe ni ligne de construction dans les données. |
