| Champ | Contenu |
| --- | --- |
| Identité | DA-01-10 (M01, étape cible P1). Interprétation : lignes d'axe et de construction = `esquisse.construction` (cahier §2.1, « ligne de construction »). Sous-exigences : -a droite ou segment de construction ; -b axes d'un cercle ou d'un arc. Ce sont des repères d'accrochage persistants ; les repères temporaires de saisie relèvent de DA-02-16. Pas de référence dans le prototype. |
| Situation utilisateur | Poser des axes (symétrie, implantation, centre) qui guident le dessin et l'accrochage sans appartenir à la géométrie du bâtiment ni compter dans les quantités. |
| Entrées et unités | `esquisse.construction` : `a`, `b` (points locaux, m), `etendue` (`segment` ou `droite` illimitée), `niveauId`, `calqueId`. |
| | Modes : deux points ; un point et un angle (°, 0 = axe x local) ; axes d'un cercle ou d'un arc (deux constructions perpendiculaires au centre, `depassement` en m, supérieur ou égal à 0, au-delà du rayon). |
| Comportement | **Cycle.** Outil Axe → points, ou point puis angle saisi (DA-02-16) → aperçu (la droite illimitée est tracée sur toute la vue) → contrôle → validation ; sur un cercle ou un arc, « Axes » = un lot de deux commandes. |
| | **Commandes.** `esquisse.construction` (une par axe) ; `esquisse.modifier`, `esquisse.supprimer` ; transformable comme toute esquisse (`transformer.decaler` donne une parallèle à distance saisie, DA-02-09 ; `transformer.deplacer`, `transformer.tourner`). |
| | **Statut.** Une construction n'est ni extrudée, ni hachurée, ni quantifiée, ni exportée comme géométrie du bâtiment ; elle est source d'accrochage (extrémité, milieu, intersection, perpendiculaire ; « sur la droite » pour une droite illimitée) et visible ou masquable par calque et par réglage d'affichage. |
| | **Style.** Style d'affichage « construction » distinct (tirets) ; le type de trait d'axe normalisé n'est pas introduit sans source fournie (R3) et remplacera le style provisoire quand elle l'est. |
| | **Contrôles.** Points confondus (tolérance de longueur, DA-01-01) refusés ; `depassement` négatif refusé ; angle non fini refusé ; droite illimitée admise sans longueur. |
| | **Palette (UX2) et aide (UX4).** « axe » ; synonymes « ligne de construction », « guide », « centerline » ; exemple court : axe vertical passant par un point accroché. |
| Données et dépendances | Occurrences `esquisse.construction` (`drawing`) ; sources d'accrochage pour DA-02-15 ; aucune relation ; exclues des profils (DA-01-09), des quantités et, par défaut, des documents dérivés (visibilité par calque, lot 5). |
| | Références : aucune caractéristique nommée d'esquisse avant le lot 5 ; pas de cotation rattachée, donc pas de référence à réparer (R12) au lot 3a. Événement de commande validée : vues du niveau « à recalculer ». |
| Résultats | Axes et constructions visibles dans le plan, accrochables, sans effet sur les quantités ; entrée de journal avec inverse. |
| Cas limites | **Géométrie.** Deux points confondus ; direction nulle ; cercle ou arc supprimé après la création de ses axes (les axes restent des objets libres : aucun lien associatif) ; niveau inconnu ; calque verrouillé : lot refusé en entier. |
| | **Concurrence.** `baseRevision` dépassée → 409 détaillé, résolution explicite côté client ; même `requestId` → une seule révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local puis file Dexie rejouée dans l'ordre ; 403 motivé en lecture, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : le prototype n'a pas d'objet de construction ; rien à importer. |
| | DXF : constructions exportées sur leur calque (`XLINE` pour la droite illimitée, `LINE` pour le segment : à fixer au lot 5), tout aplatissement signalé au rapport. IFC : non exportées, listées « omises ». |
| Validation | **Unité** (`packages/atelier-model/src/commandes/esquisse.test.ts`) : points confondus refusés ; droite par point et angle 30° : direction vérifiable à la main ; axes d'un cercle : deux droites perpendiculaires passant par le centre ; une construction n'entre dans aucun profil ni aucune quantité (filtre). |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `esquisse.construction` → 200 ; `etendue` inconnue → 400 avec `chemin` ; même `requestId` → une seule révision ; `baseRevision` périmée → 409. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · axes ») : axe par point et angle saisis sur la mezzanine de la copie de travail P.118 ; curseur près de l'axe : accrochage annoncé « Sur la droite » ; tableau des surfaces régénéré identique (l'axe ne compte pas) ; annuler, second navigateur. |
| Règles métier | Aucune règle réglementaire ; types de trait et symboles d'axe normalisés non fournis sans source (R3). |
