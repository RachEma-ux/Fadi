# DA-02-08 — Extend / Prolonger — module M02 → Atelier — lot 3a

**État : spécifiée (lot 0)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : —.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-08 (M02, étape cible P1). `transformer.prolonger`. Pas de référence dans le prototype. |
| Situation utilisateur | Prolonger l'extrémité d'une ligne, d'un arc ou d'un mur jusqu'à un objet frontière (fermer un angle, atteindre un mur), sans redessiner. |
| Entrées et unités | `niveauId` ; `cible` ; `extremite` (`a` ou `b` pour une ligne, un mur, une construction ; `debut` ou `fin` pour une polyligne ou un arc) ; `limites` (objets frontières, identifiants explicites). |
| | Cibles admises : `esquisse.ligne`, `.polyligne` (dernier segment), `.arc`, `.construction` (segment), `mur`. Frontières : celles de DA-02-07. Refusées : formes fermées, spline, cercle. |
| Comportement | **Cycle.** Outil Prolonger → désigner les frontières → désigner l'extrémité à prolonger (le côté le plus proche du clic ; position non accrochée, elle ne crée aucune géométrie) → aperçu du prolongement et de son point d'arrivée → contrôle → validation ; un lot par cible. |
| | **Règle.** L'extrémité avance dans la direction de son dernier segment (ligne, mur : prolongement de l'axe ; arc : sur son cercle) jusqu'à la première frontière rencontrée. Frontière derrière l'extrémité ou absente : refus (« Prolonger — aucune limite devant cette extrémité. ») ; extrémité déjà sur la frontière (tolérance de longueur, DA-01-01) : refus, aucun effet. |
| | **Mur.** Extrémité amenée sur l'axe de la frontière (même objet) ; ouvertures hébergées : distance depuis l'extrémité restée fixe conservée, aucune glissade ; jonction dérivée recalculée ; aucune ouverture ne peut sortir du mur, qui s'allonge. |
| | **Références (R12).** Même objet, identité conservée : références et caractéristiques nommées conservées (`mur:arete-fin` ou `mur:arete-debut` se déplace avec l'extrémité), cotations recalculées ; aucune référence « à réparer ». |
| | **Contrôles.** Arc dont le prolongement dépasserait 360° : refus ; frontière parallèle à la direction : refus ; intersection hors borne : refus ; cible d'un autre niveau, supprimée ou sur un calque verrouillé : lot refusé en entier. |
| | **Palette (UX2) et aide (UX4).** « prolonger » ; synonymes « extend », « rallonger » ; actif si au moins une frontière et une cible d'une classe admise existent dans le niveau ; exemple court : prolonger un mur jusqu'à un mur frontière ; clavier complet par la saisie de précision (DA-02-16). |
| Données et dépendances | Modifie le paramètre d'extrémité de la cible (`b`, `a`, `sommets`, `angleFin`, `axe`) ; relations `heberge` (position `t` recalculée), `joint-a` recalculée ; `core-geometry` : intersections ; événement de commande validée : vues, quantités et bilan Harmonie « à recalculer ». |
| Résultats | Objet prolongé, effets listés (objets modifiés, jonctions créées), inverse = valeurs précédentes enregistrées. |
| Cas limites | **Géométrie.** Aucune frontière devant l'extrémité ; frontière derrière ; frontière confondue avec la cible (ignorée) ; extrémité déjà posée ; intersection hors borne ; calque verrouillé : lot refusé en entier. |
| | **Concurrence.** `baseRevision` dépassée et cible ou frontière modifiée ou supprimée depuis → 409 détaillé ; même `requestId` → une seule révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie rejouée dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : les 220 murs, avec leurs 210 ouvertures hébergées, sont prolongeables ; les tracés fermés importés (`solide`) ne le sont pas. DXF : aucune sortie propre. IFC : mur prolongé réexporté avec son axe et ses `IfcRelVoidsElement`. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts` et `packages/core-geometry`) : ligne prolongée jusqu'à une frontière : extrémité à l'intersection (valeur vérifiable à la main) ; arc prolongé : `angleFin` recalculé ; mur portant une porte : distance à l'extrémité fixe conservée ; frontière absente refusée ; extrémité déjà posée refusée ; inverse bit à bit. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `transformer.prolonger` → 200 ; sans frontière → 400 avec `chemin` ; frontière modifiée depuis `baseRevision` → 409 ; même `requestId` → une seule révision. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · prolonger ») : sur la copie de travail de P.118, un mur dessiné sur la mezzanine, court, est prolongé jusqu'à `EX118-mezz-W-009` ; la porte du mur prolongé garde sa distance au point fixe ; annuler ; second navigateur. |
| Règles métier | Aucune règle réglementaire. R12 : aucune référence ni ouverture déplacée en silence. |
| Extensions à spécifier | Prolongement jusqu'à une frontière apparente (prolongée) ; prolongement de splines, de polylignes à une extrémité intérieure ; prolongement d'une longueur donnée sans frontière ; jonction de murs forcée (`mur.joindre`, DA-07-01). |
