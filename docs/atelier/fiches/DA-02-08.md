| Champ | Contenu |
| --- | --- |
| Identité | **DA-02-08** « Extend » (Exigences V4.1, annexe B.3, M02, P1). Critère commun B.3. Tâche **L3a.2**. Sous-exigences : **DA-02-08-a** prolonger un segment d'esquisse (ligne, segment extrême de polyligne ouverte, arc) jusqu'à une arête limite ; **-b** prolonger un **mur** jusqu'à la face ou l'axe d'un autre mur, avec jonction proposée ; **-c** prolonger d'une longueur donnée (sans arête limite). Règles communes : fiche **DA-02-01**. Fiches liées : DA-02-07 (ajuster, mêmes conventions), DA-07-01 (`mur.joindre`), DA-02-16 (saisie de longueur). |
| Situation utilisateur | L'architecte prolonge une cloison jusqu'au mur de façade, ou une ligne de construction jusqu'à une limite, sans calculer la longueur ; il voit le point d'arrivée avant de valider. |
| Entrées et unités | `aretesLimites` : références `{ objetId, caracteristique }` (ex. `mur:face-droite`) — ou -c : `longueur` `{ value, unit: "m" }` > 0 ; `cible` `{ objetId, caracteristique }` ; `pointDesigne` `{ x, y, frame: "local", unit: "m" }` (choisit l'extrémité la plus proche) ; -b : `reference` ∈ {`face`, `axe`} explicite (l'outil propose la face rencontrée en premier et l'affiche). |
| Comportement | Cycle UX3 : « Prolonger » (synonymes « extend », « allonger jusqu'à ») → arêtes limites → désigner l'extrémité → **aperçu** (prolongement en pointillé, longueur ajoutée, point d'arrivée) → validation.<br>Commande (annexe B) : `{ type: "transformer.prolonger", cibles: [cible.objetId], params: { aretesLimites?, longueur?, cible, pointDesigne, reference? } }`. Intersection calculée par le réducteur et inscrite dans les effets (valeur exacte). Inverse : `esquisse.modifier` / `mur.modifier` avec les anciennes extrémités.<br>Règles : la direction du prolongement est celle du segment (arc : même centre et rayon) ; première intersection rencontrée **dans la direction** retenue ; **mur** : l'extrémité désignée avance, l'autre est fixe ; ouvertures : `distance` depuis l'extrémité **fixe** conservée (elles ne bougent pas) ; jonction avec le mur limite proposée (`mur.joindre` dans le même lot si l'utilisateur la garde) ; un mur prolongé qui **traverse** d'autres murs avant la limite → aperçu les liste, jonctions non créées silencieusement. Classes admises : `esquisse.ligne`, `.polyligne` (segment extrême d'une polyligne **ouverte**), `.arc`, `.construction`, `mur`. Autres classes → refus. Calque verrouillé (cible) → refus du lot ; arête limite verrouillée → admise (non modifiée). |
| Données et dépendances | Comme DA-02-07 : géométrie d'esquisse, axe des murs, `t` des ouvertures recalculé, `joint-a` ; `core-geometry` (intersection de demi-droite / segment, demi-droite / arc, cercle / segment) ; événement → vues et quantités (longueurs de murs). |
| Résultats | Élément prolongé ; jonction proposée ; journal « Prolonger » ; quantités périmées. |
| Cas limites | Aucune arête rencontrée dans la direction → refus « aucune limite atteinte » (jamais de prolongement « à l'infini » ni d'une longueur arbitraire). Direction parallèle à l'arête (`tolAngle` = 1·10⁻⁶ rad, **proposée**) → refus. Extrémité déjà sur l'arête (< `tolCoincidence` = 1·10⁻⁶ m) → pas de commande. Arc dont le prolongement dépasserait le cercle complet → refus. Polyligne fermée → refus (pas d'extrémité). -c `longueur` ≤ 0 ou unité non `m` → 400 (T03). Arête limite sur un autre niveau → refus. 409 / 403 / 423 ; idempotence ; hors ligne rejoué. |
| Compatibilité | Aucun format concerné. Prototype : pas d'outil « Prolonger » — fonction nouvelle. |
| Validation | **Unité** `transformer.test.ts` : ligne (0 ; 0)→(3 ; 0), limite = ligne x = 7,5 → (0 ; 0)→(7,5 ; 0) exact ; arc de centre (0 ; 0) rayon 2 de 0° à 45° prolongé jusqu'à la droite y = x·tan(60°) → arc 0°→60° à `tolAngle` ; mur (0 ; 0)→(3 ; 0) épaisseur 0,10 m prolongé jusqu'à la `mur:face-gauche` d'un mur dont la face est en x = 5,90 → extrémité (5,90 ; 0), porte à `distance` 1,00 m de (0 ; 0) inchangée ; direction parallèle → refus ; inverse → empreinte identique. **API** : 400 longueur négative. **Scénario** `05-atelier.mjs` : prolonger une cloison de la mezzanine de P.118 jusqu'à un mur, garder la jonction ; révision + 1 ; annuler ; second navigateur. |
