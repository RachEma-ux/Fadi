# DA-04-07 — Push/Pull / Pousser / tirer — module M02 → Atelier — lot 3b

**État : prototype (lot 3b)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs` (partie 3D), tests `packages/atelier-model/src/projection/maillage.test.ts` ; compte rendu `lots/lot-3b.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-04-07 (M02, étape cible P1). Sous-exigences : -a face haute ou basse d'un `solide` (hauteur, décalage de base) ; -b face latérale (arête du contour) ; -c polygone d'esquisse fermé (extrusion directe). Contrôle commun de la section : résultat géométrique valide, erreurs et références ambiguës signalées. Pousser / tirer est un geste, non une opération de géométrie : il se termine par `solide.modifier` ou `solide.extruder` sur les paramètres canoniques (R9, R15). |
| Situation utilisateur | Tirer ou pousser une face d'un volume à la souris, au toucher ou au clavier pour changer sa hauteur, son assise ou son emprise, en voyant le résultat avant de valider. |
| Entrées et unités | `solide.modifier` : `solideId` ; face visée ramenée à un paramètre : `haut` (`hauteur`), `bas` (`decalageBase` et `hauteur`), `lateral` d'indice i (arête i du `contour` ou d'un trou) ; `distance` `{ value, unit: "m" }` signée selon la normale extérieure (positive = tirer). La commande reçoit les valeurs canoniques finales (`hauteur`, `decalageBase`, `contour`, `trous`), jamais une face ni un maillage. Polygone fermé : `solide.extruder` (DA-04-01). |
| Comportement | **Cycle.** Survol d'une face (face visée et paramètre surlignés, affichage R10) → clic ou toucher sur la poignée de face → distance par glisser, flèches ou saisie (DA-02-16) → aperçu fantôme avec distance, hauteur et volume dérivés → contrôle → validation ; Échap annule sans commande. Deux doigts : caméra seulement (T16). |
| | **Effets.** Face haute : `hauteur` change, base fixe. Face basse : `decalageBase` et `hauteur` changent, sommet fixe. Face latérale : l'arête se déplace parallèlement à elle-même ; ses extrémités sont recalculées à l'intersection avec les arêtes voisines prolongées, les autres sommets ne bougent pas. Une face de trou se comporte de même, vers l'intérieur du trou. |
| | **Contrôles.** Hauteur résultante ≤ tolérance de longueur (DA-01-01) refusée (« le solide disparaîtrait : utilisez Supprimer ») ; arêtes voisines parallèles à l'arête déplacée, arête voisine annulée ou inversée, contour auto-sécant ou trou sortant du contour : refusés avec l'arête nommée, aucun sommet fusionné en silence ; contour ouvert (`ferme` faux) : seules les faces haute et basse sont admises ; objet de représentation importée (autorité `importee`) refusé (R16) ; unité ≠ m refusée (T03) ; calque ou niveau verrouillé : lot refusé en entier. |
| | **Classes admises (lot 3b).** `solide` ; polygone `esquisse.polygone` fermé (extrusion). `mur`, `dalle`, `poteau` en sont exclus : leurs hauteurs et épaisseurs dépendent de relations (`niveauHaut`, objets posés, ouvertures) à décider (extension). |
| | **Palette (UX2) et aide (UX4).** « pousser », « tirer » ; synonymes « push », « pull », « pousser / tirer » ; actif si un solide ou un polygone fermé est sélectionné ; exemple court : tirer la face haute de 0,40 m (jamais une valeur par défaut). |
| Données et dépendances | Modifie `hauteur`, `decalageBase`, `contour` ou `trous` du `solide` ; représentation `solide-3d` recalculée (empreinte changée). Aucune caractéristique nommée de solide n'existe en 5.2 : la face visée est transitoire (lue sur le maillage dérivé, jamais enregistrée) et aucune cotation n'y est rattachée, donc aucune référence à réparer. `core-geometry` : décalage d'arête, simplicité, inclusion. Événement de commande validée : vues et quantités « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Solide modifié avec sa représentation dérivée recalculée ; effets (volume avant et après) dans le panneau des modifications ; inverse = valeurs canoniques précédentes, bit à bit. |
| Cas limites | **Géométrie.** Distance nulle : aucun lot ; distance qui annulerait une arête ou ferait se croiser deux côtés : refusée avec les côtés nommés ; solide avec trous : la face tirée ne peut pas rencontrer un trou (refus nommant le trou) ; solide supprimé par autrui pendant le geste : 409 à la validation, rien n'est écrit. |
| | **Concurrence et réseau.** `baseRevision` dépassée et solide modifié depuis → 409 avec `conflits[].objetId` et état serveur, résolution explicite côté client ; même `requestId` → une seule révision (T06). Hors ligne : réducteur local (aperçu et validité identiques), file Dexie, rejeu dans l'ordre, brouillon si le solide a changé. Rôle `write` exigé : 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : les 807 `solide` de rôle `solid` et leurs autres rôles à contour fermé sont modifiables, sans aucun arrondi des valeurs importées ; un solide à contour ouvert (« Ligne » du prototype) n'admet que les faces haute et basse. IFC : une extrusion modifiée s'exporte avec ses nouveaux paramètres (`IfcExtrudedAreaSolid`, annexe C, lot 6) ; objet importé d'IFC en B-rep : non modifiable par ce geste. DXF : sans objet. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/solide.test.ts` ; `packages/core-geometry/src/decalage-arete.test.ts`) : face haute : `hauteur` modifiée, base fixe ; face basse : sommet fixe ; face latérale d'un rectangle : emprise modifiée, sommets recalculés à l'intersection ; hauteur résultante nulle, arête annulée, auto-intersection, trou sortant refusés ; contour ouvert : face latérale refusée ; représentation importée refusée ; inverse restitue les valeurs bit à bit. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `solide.modifier` (gabarit pousser / tirer) → 200, révision +1, `effets` ; hauteur négative → 400 avec `chemin` ; même `requestId` → même réponse ; `baseRevision` périmée et solide modifié → 409 ; rôle lecture → 403 ; réservation d'autrui → 423. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 3D · pousser / tirer ») : copie de travail de P.118 : un solide de la mezzanine, face haute tirée d'une distance saisie : hauteur = ancienne + distance ; face latérale tirée ; annuler : valeurs initiales identiques ; second navigateur à la même révision ; au toucher, un doigt édite, deux doigts déplacent la caméra ; ligne `⏱ pousser / tirer d'une face (aperçu)` imprimée (R14), sans seuil. |
| Règles métier | Aucune règle réglementaire. R3 : aucune dimension complétée ; les valeurs d'exemple de la palette (UX4) ne sont jamais des valeurs par défaut. R9 : le geste se termine par une commande typée sur les paramètres canoniques. R15 : le maillage n'est jamais édité. |
| Extensions à spécifier | Pousser / tirer sur `mur`, `dalle`, `poteau` ; accrochage 3D (DA-02-15 est 2D) ; face enregistrée comme caractéristique nommée (cotations en 3D) ; faces inclinées ou courbes (lot optionnel OCCT) ; pousser / tirer avec déplacement de solides voisins (jamais implicite). |
