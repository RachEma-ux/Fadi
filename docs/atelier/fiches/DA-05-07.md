| Champ | Contenu |
| --- | --- |
| Identité | DA-05-07 (M04, étape cible P1). Sous-exigences : -a parcourir et rechercher ; -b regrouper des définitions en bibliothèques ; -c placer depuis une bibliothèque. Une bibliothèque est un regroupement nommé de définitions du catalogue versionné (blocs, DA-05-06, et composants, DA-05-09) ; elle n'a pas de commande propre à l'annexe B. |
| Situation utilisateur | Retrouver rapidement un bloc ou un composant déjà défini dans le projet, voir sa version et ses usages, et le placer. |
| Entrées et unités | `bibliotheque` (texte libre, attribut de la définition fixé par `bloc.definir`), `nom` et `categorie` (texte libre) ; recherche : texte, bibliothèque, nature (bloc ou composant), version. Aucune grandeur : pas d'unité. |
| Comportement | **Cycle.** Panneau Bibliothèques (liste par bibliothèque, recherche, vignette du symbole, version, nombre d'occurrences) → choix d'une définition → `bloc.placer` (DA-05-06 : même cycle d'aperçu, de contrôle et de validation). Consulter est de l'affichage (R10) ; seule la création ou la redéfinition d'une définition émet `bloc.definir`. |
| | **Regroupement.** L'appartenance à une bibliothèque est un paramètre de la définition (`bibliotheque`) : créer une bibliothèque = en nommer une dans `bloc.definir` ; changer la bibliothèque d'une définition = redéfinition (version n + 1, aperçu des occurrences, DA-05-06). Aucune commande de bibliothèque n'existe à l'annexe B. |
| | **Contenu (R3).** Aucune bibliothèque n'est livrée avec Fadi : la bibliothèque d'un projet neuf est vide (« aucun bloc défini »). Partage entre projets, import et export de bibliothèques : hors lot 5, décision du chef de projet (droits R13, copie ou lien). |
| Données et dépendances | Lecture du catalogue des `definition` (bloc ou composant) du projet ; écriture seulement par `bloc.definir` ; aucune classe de bibliothèque séparée. Index de recherche local, reconstruit depuis l'état, jamais source de vérité. La consultation ne marque aucun document « à recalculer ». |
| Résultats | Liste filtrée de définitions ; occurrence placée par `bloc.placer` ; aucune définition créée par la seule consultation. |
| Cas limites | **Affichage.** Bibliothèque vide : état vide expliqué ; définition sans bibliothèque : rangée sous « Sans bibliothèque » ; nom de bibliothèque vide ou ne différant que par la casse d'un nom existant : refusé à la définition (aucun doublon silencieux). |
| | **Concurrence et réseau.** Définition redéfinie ou supprimée par autrui pendant le placement → 409 avec `conflits[].objetId`, aucune occurrence orpheline ; même `requestId` → une seule occurrence (T06) ; hors ligne : consultation de l'état local, placement mis en file Dexie et rejoué dans l'ordre, brouillon si la définition a changé. 403 / 404 / 423 selon R13. |
| Compatibilité | Import P.118 : aucune bibliothèque de blocs (bibliothèque vide). Formats de bibliothèques tiers (DWG, DXF, catalogues de fabricants) : non couverts ; DA-05-17 et DA-05-18 (P2). IFC : `IfcProjectLibrary` candidat, à confirmer à l'annexe C (lot 6). |
| Validation | **Unité** (`packages/atelier-model/src/bibliotheque.test.ts`) : regroupement par `bibliotheque` à partir de l'état ; recherche par texte, nature et version ; consultation sans commande ni changement de révision ; nom de bibliothèque ne différant que par la casse refusé. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `bloc.definir` avec `bibliotheque` → 200 ; nom de bibliothèque en quasi-doublon → 400 avec `chemin` ; `bloc.placer` d'une définition supprimée → 409. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « Blocs · bibliothèque », lot 5) : copie de travail de P.118 : bibliothèque vide à l'ouverture ; définir deux blocs dans une bibliothèque, rechercher, placer ; recharger : même liste ; second navigateur à la même révision. |
| Règles métier | Aucune règle réglementaire. R3 : aucun contenu de bibliothèque inventé. R10 : filtres et recherche = affichage. R13 : droits relus à chaque requête. |
| Extensions à spécifier | Bibliothèques partagées entre projets, versionnées et publiées (lot 7) ; import et export d'un fichier de bibliothèque ; catégories normalisées ; bibliothèques de composants à règles et connecteurs (DA-05-16, P2). |
