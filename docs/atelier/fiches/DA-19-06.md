# DA-19-06 — Automatic drawing/report generation / Génération automatique de documents et rapports — module M11 → Atelier — lot 5

Preuve liée : `packages/atelier-model/src/documents/documents.test.ts`, recette `apps/web/e2e/atelier-documents.mjs` (18 contrôles), scénario `parcours-scenario.mjs` ; compte rendu `lots/lot-5.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-19-06 (M11, P2, avancée en P1). Vues, feuilles, tableaux et rapports sont produits automatiquement par le serveur à la révision courante ; publication = production de tous les documents d'un jeu. |
| Situation utilisateur | Obtenir le dossier de plans sans génération manuelle. |
| Entrées et unités | Définitions de vues et feuilles ; publication. |
| Comportement | `GET …/documents/atelier/…` produit à la demande ; la publication fige. |
| Données et dépendances | Code pur de `atelier-model/documents` exécuté côté serveur. |
| Résultats | PDF, DXF, SVG, CSV, HTML au catalogue. |
| Cas limites | Objet supprimé après génération : document périmé, régénération sans l'objet ; niveau sans objet : dessin vide déclaré ; même révision et même empreinte → octets identiques (reproductibilité testée) ; `baseRevision` périmée à la création de la vue → 409 ; hors ligne : la définition est mise en file, le dessin attend la reprise. |
| Compatibilité | IFC : non concerné (les vues ne s'exportent pas en IFC) ; export SVG / PDF (vectoriel, sans dépendance, Helvetica WinAnsi) / DXF R12 (calques par nature de trait) au catalogue ; import P.118 : les documents se régénèrent depuis le modèle importé. |
| Validation | Recette documents : PDF au catalogue à jour, périmé après commande, régénéré. |
| Règles métier | Aucune règle réglementaire : un document dérivé porte révision et empreinte (R11), périmé il reste consultable sans être présenté comme actuel (T07) ; les surfaces sont calculées, jamais qualifiées de conformes ; hauteur absente = « non évaluée » (R3). |
| Extensions à spécifier | Plans d'atelier et de production générés par ontologie (P2-7). |
