| Situation utilisateur | Piloter la forme d'une esquisse par des valeurs (longueur, largeur) : modifier la valeur recalcule l'esquisse, et seulement elle. |
| Entrées et unités | Contrainte de distance : `cibles` (deux points, ou un point et un segment), `valeur` `{ value, unit: "m" }` (au-dessus de la tolérance de longueur), `pilotante` (booléen : vrai = pilote la forme ; faux = cote de contrôle qui mesure), `nom` facultatif du paramètre. |
| | Un paramètre nommé est une valeur typée unique `{ nom, valeur, unite }`, provenance `saisie`, statut `declaree` ; aucune expression ni formule (DA-06-02). Rayon, diamètre et angle pilotants : extension. |
| Comportement | **Cycle.** Sélection de deux éléments → « Cote » → saisie de la valeur dans l'inspecteur ou au clavier (DA-02-16 ; unité explicite ou unité d'affichage) → aperçu de l'esquisse résolue avec son état de contrainte → contrôle → validation. Modifier la valeur : même cycle sur la contrainte existante. |
| | **Commandes.** `contrainte.*` (annexe B ; proposition : `contrainte.ajouter` avec `type = distance`, `contrainte.modifier` pour `valeur`) ; le lot contient les `esquisse.modifier` des éléments déplacés par la résolution. Une cote de contrôle (`pilotante = faux`) ne modifie jamais la géométrie : elle lit la valeur courante. |
| | **Contrôles.** Valeur sous la tolérance, non finie ou d'unité incompatible (« 30° » pour une distance, T03) refusée ; cote pilotante qui rend l'esquisse sur-contrainte ou non convergente : refus avec la liste des contraintes (diagnostic de DA-01-07), rien n'est écrit ; deux cotes pilotantes sur la même paire : refus (redondance). |
| | **Recalcul reproductible.** Mêmes valeurs, mêmes coordonnées (solveur déterministe) ; le serveur recalcule et fait autorité ; si l'écart entre l'aperçu local et la réponse dépasse la tolérance de comparaison déclarée, il est affiché. |
| | **Palette (UX2) et aide (UX4).** « cote » ; synonymes « dimension pilotante », « paramètre », « driving dimension » ; exemple court : fixer la longueur d'un côté à une valeur saisie. |
| Données et dépendances | Objets `contrainte` (`type = distance`, `valeur`, `pilotante`, `nom`) référençant des éléments d'esquisse (caractéristiques nommées de DA-01-07) ; R12 identique : cible disparue → « à réparer » avec propositions. Événement de commande validée : vues du niveau « à recalculer ». |

| Résultats | Esquisse redimensionnée par la valeur, paramètres listés dans l'inspecteur (nom, valeur, unité), entrée de journal avec inverse. |
| Cas limites | **Géométrie.** Valeur négative ou nulle ; cote entre éléments confondus ; cote entre niveaux différents ; esquisse déjà extrudée (le solide ne suit pas) ; calque verrouillé : lot refusé en entier. |
| | **Concurrence et réseau.** 409 si un élément ou la contrainte a été modifié depuis `baseRevision` ; même `requestId` → une seule révision ; hors ligne : solveur local, rejeu dans l'ordre, le serveur tranche au retour ; 403 / 404 / 423 selon R13. |
