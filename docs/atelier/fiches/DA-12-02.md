Preuve prévue : —

| Champ | Contenu |
| --- | --- |
| Identité | DA-12-02 (M08, P2). Une gaine est un `segment-reseau` de système `gaine` : section rectangulaire (largeur × hauteur) ou circulaire, fluide déclaré (air soufflé, repris…), polyligne 3D ; raccords, équipements et supports du même système. |
| Situation utilisateur | Tracer le réseau de soufflage d'une centrale jusqu'aux bouches. |
| Entrées et unités | `segmentReseau.creer { niveauId, systeme: "gaine", sommets, section: { forme: "rectangulaire", largeur, hauteur } | { forme: "circulaire", diametre }, fluide?, sens?, specificationId? }`. |
| Comportement | Maillage : boîte ou tube balayé tronçon par tronçon ; rendu plan à la largeur de la section ; ports a et b aux extrémités. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `mep` activable par projet (registre `ontologies/mep/`, T01) ; classes `segment-reseau`, `raccord-reseau`, `vanne`, `equipement-reseau`, `support-reseau` ; définitions `specification` et `catalogue` ; relation `connecte` ; géométrie 3D partagée `geometrie-3d.ts` ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; contrôle `controlerReseau` après chaque commande (T07). |
| Résultats | Occurrence ; nomenclature de réseau (section, longueur, fluide). |
| Cas limites | Tronçon de longueur nulle : refus ; section incompatible : refus. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC `IfcDuctSegment` .RIGIDSEGMENT., `IfcDuctFitting`, `Fadi_Reseau`. |
| Validation | Tests : volume d'une gaine 400 × 250 sur 5 m ; recette : gaine de soufflage avec suspente. |
| Règles métier | Aucune valeur de réseau dans le code (test : pas de table de DN, pas de débit ni de pression) : sections saisies ou tirées d'un catalogue CSV sourcé (`tubes-raccords.csv`, D-180), fluides et matériaux déclarés, spécifications du projet ; une grandeur absente est « non évaluée » (R3) ; aucun dimensionnement, aucune vérification hydraulique ou aéraulique. |
| Extensions à spécifier | Gaines flexibles, pièces de transformation rectangulaire → circulaire, registres et clapets coupe-feu. |
