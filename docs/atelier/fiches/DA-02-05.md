| Identité | **DA-02-05** « Scale » (Exigences V4.1, annexe B.3, M02, P1). Critère commun B.3. Tâche **L3a.2**. Sous-exigences : **DA-02-05-a** échelle **uniforme** d'une sélection autour d'un point de base (facteur ou longueur de référence → longueur cible) ; **-b** échelle **non uniforme** (facteurs sx, sy) limitée aux objets non paramétriques ; **-c** mise à l'échelle d'une référence de plan (calage d'un fond importé sur une cote connue). Règles communes : fiche **DA-02-01**. Fiches liées : DA-04-07 (pousser / tirer, qui change une dimension paramétrique nommée), DA-02-06 (étirer). |
| Situation utilisateur | L'architecte agrandit un îlot de mobilier ou une esquisse d'étude, ou cale un plan de fond scanné sur une cote connue ; il ne veut pas que l'épaisseur d'un mur ou la largeur d'une porte change sans qu'il le sache. |
| Entrées et unités | `cibles` ; `base` `{ x, y, frame: "local", unit: "m" }` ; `facteur` (nombre sans unité, > 0) **ou** `longueurReference` et `longueurCible` `{ value, unit: "m" }` (le facteur est dérivé et affiché) ; -b : `facteurX`, `facteurY` (> 0). Aucun facteur par défaut. |
| Comportement | Cycle UX3 : sélection → « Échelle » (synonymes « scale », « mise à l'échelle », « homothétie ») → base → **aperçu** (facteur, dimensions résultantes des objets touchés, liste des paramètres qui changeraient) → validation.<br>Commande (annexe B) : `{ type: "transformer.echelle", cibles, params: { base, facteur } }` ou `{ base, facteurX, facteurY }`. Inverse : facteur `1/f` (resp. `1/fx`, `1/fy`) autour de la même base.<br>**Règle des objets paramétriques — Recommandation de cette fiche (à figer par L1.2)** : une échelle est une transformation de **position et de forme en plan** ; elle ne modifie **jamais silencieusement** un paramètre dimensionnel nommé. Échelle uniforme : **mur** → axe mis à l'échelle (longueur × f), `epaisseur` et `hauteur` **inchangées** ; **ouverture** → `t` conservé (sa position suit le mur), `largeur`, `hauteur`, `allege` **inchangées** ; si l'ouverture sort de l'emprise du mur raccourci → refus listant les ouvertures (comme DA-07-01) ; **poteau** → `point` déplacé, `largeur` / `profondeur` inchangées ; **escalier** → refus (ses paramètres sont liés : nombre et hauteur de marches, fiche DA-07-10) ; **dalle**, **solide**, **pièce**, **esquisse** → contour mis à l'échelle, `epaisseur`, `hauteur` inchangées ; **cotation** → recalculée par ses références ; **texte** → position seulement. L'aperçu affiche explicitement « épaisseurs, hauteurs et dimensions d'ouvertures conservées ». Pour changer une épaisseur ou une hauteur : inspecteur ou pousser / tirer (DA-04-07). Échelle non uniforme (-b) : admise seulement sur `esquisse.*`, `solide`, `dalle`, `piece`, `espace`, `zone`, `reference-plan` ; une sélection contenant `mur`, ouverture, `poteau`, `escalier` → **refus** nommant les objets (**Recommandation**). Échelle d'un **cercle / arc** non uniforme → refus (pas d'ellipse dans l'ontologie §5.2). Calque verrouillé : tout ou rien. |
| Données et dépendances | Paramètres de position et contours modifiés ; paramètres dimensionnels nommés jamais touchés ; aires dérivées (pièces, dalles) recalculées → quantités et tableau des surfaces « à recalculer » ; `aireDeclaree` (provenance `prototype`) **jamais** modifiée : l'écart aire déclarée / calculée est listé (cahier §6). `core-geometry` (homothétie pure). |
| Résultats | Objets mis à l'échelle ; liste des paramètres conservés ; journal « Échelle × f de n objets » ; aires périmées. |
| Cas limites | `facteur` ≤ 0, nul, non fini → 400 ; `facteur` = 1 (à `1·10⁻¹²` près) → pas de commande ; facteur négatif (symétrie déguisée) → refus, renvoi vers Miroir. Résultat sous `longueurMin` = 0,001 m (**proposée**) pour un segment, un côté ou un mur → refus. Mur raccourci dont une ouverture sort de l'emprise → refus avec liste. Pièce de P.118 mise à l'échelle → aire calculée change, `aireDeclaree` inchangée, écart signalé. Unité de longueur non `m` (-a par longueurs) → 400 (T03). 403 / 409 / 423 ; idempotence ; hors ligne rejoué. |
| Compatibilité | -c : référence de plan (`reference-plan`, `echelle`) — l'import DXF 2D (lot 6) produira des fonds à caler. Prototype : outil « Échelle » — fonction conservée, avec la règle ci-dessus (le prototype mettait-il les épaisseurs à l'échelle ? non vérifié ; sans incidence : la règle de Fadi est explicite). |
| Validation | **Unité** `transformer.test.ts` : mur (0 ; 0)→(4 ; 0), épaisseur 0,20 m, échelle × 1,5 autour de (0 ; 0) → (0 ; 0)→(6 ; 0), épaisseur toujours 0,20 m, porte `t = 0,5` largeur 0,90 m conservée ; rectangle d'esquisse 4 × 3 × 2 → 8 × 6, aire 48 m² ; échelle non uniforme sur un mur → refus ; escalier → refus ; ×2 puis ×0,5 → état initial à `tolCoincidence` ; mur raccourci ×0,1 avec porte de 0,90 m → refus. **API** : 400 facteur négatif. **Scénario** `05-atelier.mjs` : caler une esquisse rectangle de 4,00 m sur 5,00 m par longueurs de référence ; révision + 1 ; annuler. |
| Règles métier | Aucune règle réglementaire. Les épaisseurs et dimensions d'ouvertures ne sont pas des valeurs que l'échelle peut « corriger » ; aucune valeur minimale réglementaire n'est contrôlée (non évaluée, R3). |
| Extensions à spécifier | Échelle 3D (axe z) des solides (lot 3b / optionnel) ; option explicite « mettre aussi à l'échelle les épaisseurs » (si le maître d'ouvrage la demande) ; échelle d'annotations (taille de texte par vue, lot 5). **Question au chef de projet** : valider la règle « paramètres nommés conservés, non uniforme refusé sur objets paramétriques » (L1.2). |
