# DA-02-05 — Scale / Mettre à l'échelle — module M02 → Atelier — lot 3a

**État : spécifiée (lot 0)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : —.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-05 (M02, étape cible P1). `transformer.echelle`. Référence de comportement : prototype, outil « Échelle » (facteur demandé, strictement positif, autour du premier point de l'objet) ; il mettait aussi à l'échelle largeur, profondeur et hauteur des poteaux, ce qui n'est pas repris (R3). |
| Situation utilisateur | Agrandir ou réduire une esquisse, un contour ou un fond de plan, ou caler un fond de plan sur une longueur connue, sans jamais modifier une dimension typée. |
| Entrées et unités | `niveauId` ; `cibles` ; `centre` (point local, m) ; `facteur` (nombre sans dimension, strictement positif, différent de 1 ; un seul facteur : échelle uniforme). Mode « longueur de référence » : longueur actuelle puis longueur voulue (m), seul le facteur résultant est stocké. |
| | Classes admises : `esquisse.*`, `solide` et `dalle` (contour), `mur` (axe seulement), `poteau` (position seulement), `piece`, `espace`, `zone`, `reference-plan`, `cotation` libre, `texte`. Refusées : `escalier` (sa longueur ne correspondrait plus à ses marches : `escalier.modifier`) et `ouverture`. |
| Comportement | **Cycle.** Sélection → centre (accroché, DA-02-15) → facteur au pointeur ou saisi (DA-02-16), ou longueur de référence → aperçu fantôme avec le facteur affiché → contrôle → validation ; Échap annule sans commande. |
| | **Dimensions typées.** Elles ne changent jamais : `epaisseur` et `hauteur` d'un mur, largeur, profondeur et hauteur d'un poteau (section : donnée structurelle), `hauteur` et `epaisseur` d'un solide ou d'une dalle, `largeur`, `hauteur` et `allege` d'une ouverture. Positions et contours sont mis à l'échelle, ainsi que les rayons de cercle et d'arc (dimensions de forme) ; hachure : contour mis à l'échelle, motif et espacement conservés. |
| | **Conséquences.** Mur raccourci : ses ouvertures gardent `t` et leurs dimensions ; une ouverture qui ne tient plus passe « à réparer » (propositions : déplacer, réduire, supprimer). Pièce : `aireDeclaree` inchangée, `aireCalculee` recalculée, écart listé comme problème. Références (R12) : même objet, références et caractéristiques nommées conservées, cotations recalculées. |
| | **Contrôles.** Facteur nul, négatif, égal à 1 ou non fini refusé (« Échelle — facteur positif différent de 1 attendu. ») ; un facteur négatif n'est pas une symétrie : `transformer.miroir` ; résultat hors borne refusé ; grandeur avec unité refusée (T03) ; cible d'un autre niveau, supprimée ou sur un calque verrouillé : lot refusé en entier. |
| | **Palette (UX2) et aide (UX4).** « mettre à l'échelle » ; synonymes « scale », « agrandir », « réduire », « homothétie » ; actif si au moins un objet d'une classe admise est sélectionné ; exemple court : caler un fond de plan en indiquant une longueur connue ; clavier complet par la saisie de précision (DA-02-16). |
| Données et dépendances | Paramètres de position et de contour des cibles ; `heberge` conservé, `delimite` et `joint-a` recalculés ; événement de commande validée : vues, quantités et bilan Harmonie « à recalculer » (R11, T07). |
| Résultats | Objets mis à l'échelle, effets listés (objets modifiés, ouvertures « à réparer », écarts d'aire), inverse = valeurs précédentes enregistrées. |
| Cas limites | **Géométrie.** Facteur 1 ; facteur extrême (borne) ; mur réduit à une longueur sous la tolérance : refusé ; escalier dans la sélection : lot refusé en entier avec l'action « modifier l'escalier » ; fond de plan calé sur une longueur de référence nulle : refusé. |
| | **Concurrence.** `baseRevision` dépassée et cible modifiée ou supprimée depuis → 409 détaillé, résolution explicite côté client ; même `requestId` → réponse enregistrée, aucune seconde révision (T06). |
