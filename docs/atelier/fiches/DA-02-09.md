# DA-02-09 — Offset / Décaler — module M02 → module Fadi Atelier — lot 3a

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : — (à lier au lot 3a).

| Champ | Contenu |
| --- | --- |
| Identité | **DA-02-09** « Offset » (Exigences V4.1, annexe B.3, module M02, étape cible P1 ; critère de recette commun B.3 : « Transformations réversibles ; sélection, copie et dépendances conservées »). Retenue par la proposition (§5.1, DA-02 17 / 17, lot 3) ; tâche **L3a.2** (cahier §7). Sous-exigences : **DA-02-09-a** décaler une ligne, un arc ou une polyligne ouverte d'une distance signée, d'un côté choisi ; **-b** décaler un contour fermé (polyligne fermée, rectangle, polygone, cercle) vers l'extérieur ou l'intérieur ; **-c** décaler un mur (nouveau mur parallèle) ; **-d** décaler par un point de passage (la distance est déduite du point désigné). Fiches liées : DA-01-02 à DA-01-04 (primitives), DA-02-02 (copier), DA-02-15 / 16 (accrochage, saisie de précision), DA-07-01 (murs). |
| Situation utilisateur | L'architecte part d'un tracé (contour de dalle esquissé, ligne de construction, mur) et veut un tracé parallèle à une distance connue : nu intérieur d'une façade, recul, épaisseur d'isolant esquissée, second mur parallèle. Résultat : un **nouvel** objet, parallèle, à la distance exacte saisie, l'original restant inchangé. |
| Entrées et unités | `cibles` : un ou plusieurs objets d'une classe admise (`esquisse.ligne`, `esquisse.polyligne`, `esquisse.arc`, `esquisse.cercle`, `esquisse.rectangle`, `esquisse.polygone`, `esquisse.construction`, `mur`) ; `distance` `{ value, unit: "m" }`, valeur > 0 ; `cote` ∈ {`gauche`, `droite`} pour un objet ouvert (relatif au sens de parcours de l'objet), ∈ {`exterieur`, `interieur`} pour un contour fermé ; ou `pointPassage` `{ x, y, frame: "local", unit: "m" }` qui fixe à la fois le côté et la distance (distance = distance du point à l'objet). `angles` ∈ {`vifs`} au lot 3a (angles prolongés jusqu'à leur intersection) ; `calqueId` du résultat (par défaut : calque de l'original). **Aucune distance par défaut** (le prototype proposait 0,20 m : non repris, R3) : le champ propose la dernière valeur saisie par l'utilisateur dans la session, ou reste vide. Saisie : clavier (DA-02-16), ou pointeur avec accrochage (DA-02-15) pour `pointPassage`. |
| Comportement | Cycle UX3 (cahier §5.8) : outil « Décaler » (palette `Ctrl/⌘ K`, synonymes « offset », « parallèle », « décalage ») → sélection de l'objet → paramètres (distance, côté) dans l'inspecteur → **aperçu** du résultat et de la distance pendant le survol du côté → contrôle → validation (`Entrée`), `Échap` abandonne sans commande. Plusieurs décalages successifs du même objet sont possibles sans quitter l'outil (une commande par validation).<br>Commande émise (annexe B) : `{ type: "transformer.decaler", cibles: [id…], params: { distance, cote \| pointPassage, angles: "vifs", calqueId } }`, `label` « Décaler ». Classes admises déclarées par la commande (annexe B, « chaque commande déclare les classes admises ») : celles listées ci-dessus ; toute autre classe → refus motivé.<br>Effets : un objet créé par cible, de **même classe** que l'original (une ligne donne une ligne, un cercle un cercle de rayon r ± d, un rectangle un rectangle, une polyligne une polyligne de même nombre de sommets, un mur un mur). Pour un mur (**Hypothèse**, à confirmer par la fiche DA-07-01) : nouveau mur dont l'axe est décalé de `distance` (axe à axe), mêmes `epaisseur`, `hauteur` / `niveauHaut`, `typeId`, `alignement`, `calqueId` ; ses ouvertures **ne sont pas copiées** (listées dans l'aperçu) ; jonctions proposées comme pour `mur.tracer`. Inverse : suppression des objets créés. Lot atomique : si une cible échoue, rien n'est créé. **Exigence** (R9) : aucun résultat n'atteint le modèle hors de cette commande. |
| Données et dépendances | Lecture de la géométrie paramétrique de la cible ; calcul pur dans `packages/core-geometry` (décalage de segment, d'arc, de polygone à angles vifs ; orientation d'un contour fermé pour déterminer l'extérieur) ; réducteur dans `packages/atelier-model` (commande `transformer.decaler`). Écriture : nouvelle(s) ligne(s) `atelier_objects` (`ontology`, `class`, `level_id` de l'original, `layer_id`, `params`), journal `atelier_commands`, événement `atelier.commande.validee` → vues du niveau « à recalculer » ; pour un mur : pièces proposées et quantités marquées (comme DA-07-01). Propriété de provenance optionnelle `decaleDe: <id>` (`provenance: calcul`) — **Recommandation**, pas une relation : le résultat n'est pas associatif (modifier l'original ne déplace pas la copie). Microversion `model_revision + 1`. |
| Résultats | Objet(s) parallèle(s) visibles dans le plan 2D du niveau et dans le navigateur du projet ; inspecteur : distance effective à l'original affichée (dérivée) ; entrée de journal « Décaler » ; vues à recalculer. |
| Cas limites | Distance ≤ 0 ou < `longueurMin` (0,001 m, proposée, à confirmer) → 400 `{ chemin: "commands[0].params.distance", message }`. Unité autre que `m`, `pointPassage` dans un autre repère que `local` → 400 (R5, T03). `pointPassage` situé sur l'objet (distance nulle) → refus. **Décalage intérieur qui fait disparaître le contour** (rectangle 4 × 3 décalé de 1,5 m vers l'intérieur, cercle de rayon ≤ distance, arc de rayon ≤ distance du côté du centre) → refus « le contour s'effondre : distance maximale X m » (X calculée). **Décalage qui produit une auto-intersection ou plusieurs morceaux** (polygone concave, polyligne en épingle) → refus motivé au lot 3a, jamais de résultat tronqué silencieusement (**Recommandation** ; découpage en plusieurs contours : extension). Polyligne ayant deux segments consécutifs colinéaires opposés (retour en arrière) → refus. Cible sur un calque verrouillé : le décalage **crée** un objet ; le calque de destination ne doit pas être verrouillé (sinon 400 « calque verrouillé ») — l'original n'est pas modifié, donc son verrou ne bloque pas. Lecteur : 403 ; réservation d'autrui : 423 ; cible supprimée entre-temps : 409 `conflits[0].motif = "objet introuvable"`. Même `requestId` → une seule création (T06). Hors ligne : commande exécutée localement (état « local »), rejouée. |
| Compatibilité | Aucune incidence de format : le résultat est un objet ordinaire de sa classe (IFC / DXF selon la classe, fiches correspondantes). Import P.118 : aucun décalage enregistré dans les données ; rien à importer. Prototype : outil « Décalage » (invite « + extérieur / − intérieur », polygones fermés et objets linéaires) — fonction conservée, défaut 0,20 m abandonné. |
