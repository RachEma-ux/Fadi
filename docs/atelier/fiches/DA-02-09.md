# DA-02-09 — Offset / Décaler — module M02 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-09 (M02, étape cible P1). `transformer.decaler`. Référence de comportement : prototype, outil « Décalage » (distance signée, + extérieur et − intérieur ; polygone strictement convexe seulement ; ligne et mur : translation perpendiculaire ; l'original est conservé). |
| Situation utilisateur | Créer une parallèle ou un contour équidistant d'un objet à une distance exacte (doublage, recul, axe parallèle). |
| Entrées et unités | `niveauId` ; `cibles` ; `distance` `{ value, unit: "m" }` (au-dessus de la tolérance de longueur) ; `cote` (`gauche` ou `droite` du sens de tracé pour un objet ouvert, `interieur` ou `exterieur` pour un contour fermé ; déduit du clic) ; `nouveauxIds`. |
| | Classes admises : `esquisse.ligne`, `.polyligne`, `.arc`, `.cercle`, `.rectangle`, `.polygone`, `.construction`, `mur`. Refusées : spline, hachure, `dalle`, `solide` (leur contour n'est pas une esquisse). |
| Comportement | **Cycle.** Outil Décaler → distance saisie (DA-02-16) ou désignée au pointeur (accrochages DA-02-15) → clic du côté voulu → aperçu de l'objet décalé, distance affichée → contrôle → validation ; mode multiple : un lot par décalage. |
| | **Résultat.** Toujours un objet nouveau, l'original ne change pas. Ligne : parallèle de même longueur. Polyligne et polygone : côtés décalés, angles vifs prolongés. Rectangle : rectangle agrandi ou réduit. Cercle et arc : concentriques, rayon augmenté ou diminué de la distance. Mur : mur parallèle de même type, épaisseur, hauteur et alignement, avec copie de ses ouvertures (comme DA-02-02 ; `repere` et `exterieur` non recopiés). |
| | **Contrôles.** Rayon résultant sous la tolérance (cercle, arc) : refus. **Auto-intersection** : chaque côté doit garder son sens et le contour rester simple, sinon refus (« Décaler — distance trop grande : le contour se recoupe. ») ; contour non convexe admis tant que le résultat reste simple, jamais de découpe automatique en plusieurs boucles. Distance nulle refusée ; unité autre que m refusée (T03). |
| | **Palette (UX2) et aide (UX4).** « décaler » ; synonymes « offset », « parallèle », « équidistance » ; actif si au moins un objet d'une classe admise est sélectionné ; exemple court : décaler une ligne de 0,50 m vers la droite ; clavier complet par la saisie de précision (DA-02-16). |
| | **Géométrie.** `core-geometry` : `inwardOffset` ne traite que les polygones convexes et n'a pas de garde contre l'auto-intersection (comportement documenté par son test) ; le décalage général est une fonction nouvelle, gardée, qui redonne les résultats de `inwardOffset` sur les polygones convexes. |
| Données et dépendances | Crée des occurrences (identifiants déterministes) et, pour un mur, les relations `heberge-par` de ses ouvertures copiées ; aucune référence existante modifiée (R12 sans objet) ; événement de commande validée : vues, quantités et bilan Harmonie « à recalculer » (R11, T07). |
| Résultats | Un objet nouveau par cible (plus les ouvertures copiées d'un mur), sélectionné après validation ; inverse = suppression exacte de ces objets. |
| Cas limites | **Géométrie.** Distance nulle ; rayon résultant nul ; contour qui se recoupe ; décalage vers l'intérieur au-delà de la demi-largeur d'un rectangle ; coordonnée hors borne ; cible d'un autre niveau, supprimée ou sur un calque verrouillé : lot refusé en entier. |
| | **Concurrence.** `baseRevision` dépassée et cible modifiée ou supprimée depuis → 409 détaillé, résolution explicite côté client ; même `requestId` → pas de second décalage (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, rejeu identique grâce à `nouveauxIds`, file Dexie rejouée dans l'ordre ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : murs (220) décalables avec leurs ouvertures ; les contours fermés importés (`solide`, `dalle`) ne le sont pas au lot 3a. Le recul de parcelle (`inwardOffset`, outil Parcelle) est un autre calcul, inchangé (R2). |
| | DXF : objets décalés exportés comme les autres. IFC : un mur décalé est un nouvel `IfcWall`. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts` et `packages/core-geometry`) : ligne décalée de `d` : parallèle à distance `d` (propriété) ; rectangle : côtés ± `d` ; cercle `r + d` et `r − d`, `r − d` ≤ 0 refusé ; polygone convexe : même résultat que `inwardOffset` ; polygone en L, distance excessive vers l'intérieur : refusé ; mur et porte : porte copiée, `repere` vide ; même enveloppe, mêmes identifiants. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `transformer.decaler` → 200 ; `distance` en « ° » ou nulle → 400 avec `chemin` ; contour qui se recoupe → 400 avec motif ; même `requestId` → pas de second décalage ; `baseRevision` périmée → 409. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · décaler ») : sur la copie de travail de P.118, mur « Noyau A » de la mezzanine (`EX118-mezz-W-009`) décalé d'une distance saisie : murs +1, porte copiée ; rectangle d'esquisse décalé vers l'intérieur, puis distance excessive refusée avec son message ; annuler ; second navigateur. |
| Règles métier | Aucune règle réglementaire. Aucun recul ni distance réglementaire n'est proposé par défaut (R3) : la distance est toujours saisie. |
| Extensions à spécifier | Décalage de splines, de dalles et de solides ; décalage multiple (série de distances) ; décalage à angles arrondis ; contour non convexe donnant plusieurs boucles. |
