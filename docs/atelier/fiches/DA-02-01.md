| Champ | Contenu |
| --- | --- |
| Identité | **DA-02-01** « Move » (Exigences V4.1, annexe B.3, module M02, étape cible P1). Critère de recette commun B.3 : « Transformations réversibles ; sélection, copie et dépendances conservées ». Tâche **L3a.2** (cahier §7 : « transformations (DA-02-01…15, 17) comme commandes avec aperçu »). Sous-exigences : **DA-02-01-a** déplacer une sélection dans le plan du niveau par un vecteur (deux points ou saisie Δx, Δy / longueur + angle) ; **-b** déplacer une sélection vers un autre niveau (même x, y) ; **-c** règles communes des transformations (ci-dessous, champ Comportement). Fiches liées : DA-02-15 (accrochages), DA-02-16 (saisie de précision), DA-02-17 (manipulateur), DA-07-01 (murs), DA-07-02/03/04 (ouvertures hébergées), DA-05-01 (calques verrouillés), DA-15-02 (cotations, lot 5). |
| Situation utilisateur | L'architecte sélectionne un ou plusieurs objets (une cloison et ses portes, un îlot de mobilier, une esquisse) et les décale d'une distance exacte ou les pose sur un point accroché ; il voit l'aperçu, ce qui sera touché (ouvertures, cotations, pièces) et obtient une nouvelle révision, annulable, visible des autres membres. |
| Entrées et unités | `cibles` : identifiants d'objets (≥ 1) ; `vecteur` `{ dx, dy, frame: "local", unit: "m" }` (DA-02-01-a) **ou** `niveauCibleId` (DA-02-01-b, `vecteur` facultatif). Saisie : point de base puis point d'arrivée accrochés (DA-02-15), ou longueur (m) et angle (°, sens trigonométrique depuis +x local) au clavier (DA-02-16), ou Δx / Δy dans l'inspecteur. Aucune valeur par défaut (pas de décalage 0,5 m repris du prototype `fdDuplicate`, R3). Aucune hypothèse ni source de projet requise. |
| Comportement | Cycle UX3 (cahier §5.8) : sélection (clic, lasso, filtre par classe) → outil « Déplacer » (palette `Ctrl/⌘ K`, synonymes « move », « déplacer », « translater ») → point de base → **aperçu** (réducteur pur exécuté localement : objets déplacés en fantôme, vecteur, longueur en m et angle en °, liste des objets entraînés et des références touchées) → contrôle → validation (`Entrée` / clic) ; `Échap` abandonne sans commande.<br>Commande émise (annexe B) : `{ type: "transformer.deplacer", cibles: [ids], params: { vecteur } }` ou `params: { niveauCibleId, vecteur? }`, `label` « Déplacer n objets ». Inverse : `transformer.deplacer` avec `−vecteur` (et le niveau d'origine par objet pour -b). Effets : objets modifiés, relations recalculées (`joint-a`, `delimite`), références touchées.<br>**Règles communes des transformations (DA-02-01 à 08) — Exigence** (cahier §5.3, annexe B : « sur une sélection typée ; chaque commande déclare les classes admises ») :<br>1. **Classes admises** : `esquisse.*`, `solide`, `mur`, `poteau`, `dalle`, `escalier`, `piece`, `espace`, `zone`, `cotation`, `texte`, `etiquette`, `reference-plan`. **Exclues** : `niveau`, `calque`, `parcelle`, `emprise` (repère `cadastral` ; se modifient par `site.*`, R5), `hypothese`, `source`, `structureDeclaree`. Une classe exclue dans la sélection → refus 400 nommant l'objet.<br>2. **Ouvertures hébergées** (`porte`, `fenetre`, `ouverture`) : elles **suivent leur mur** (leur `t` et `distance` sont relatifs à l'axe et restent inchangés) ; sélectionnées seules, elles ne sont pas déplaçables par `transformer.*` (refus « utilisez Déplacer le long du mur », qui émet `ouverture.deplacer`) : une ouverture ne quitte jamais son mur par une transformation libre.<br>3. **Murs joints** : déplacer un mur sans ses voisins rompt la jonction ; l'aperçu montre les jonctions rompues ; la jonction n'est jamais rétablie silencieusement vers un autre mur (problème listé).<br>4. **Références (R12, T05)** : une cotation dont *toutes* les caractéristiques référencées sont dans la sélection est déplacée avec elle ; une cotation dont une seule extrémité est déplacée garde sa référence (caractéristique toujours existante) et est recalculée ; une cotation **libre** (import P.118, `dims[]`) n'est déplacée que si elle est sélectionnée. Rien n'est rattaché silencieusement.<br>5. **Pièces** : `delimitee-par` est dérivée ; après déplacement de murs, la pièce n'est pas redessinée d'office : `piece.detecter` propose (jamais imposé, DA-07-15) et l'écart polygone / murs est listé au panneau des problèmes.<br>6. **Calque verrouillé** (DA-05-01) : si un seul objet ciblé est sur un calque verrouillé (P.118 : « Espaces », « Zones noyaux », « Repères exemple »), tout le lot est refusé (« calque verrouillé : <nom> »), **tout ou rien** (lot atomique, §5.3).<br>7. **Sélection mixte multi-niveaux** : admise pour -a (chaque objet reste sur son niveau) ; pour -b, tous les objets doivent partir du même niveau, sinon refus.<br>8. **Repère** : toute grandeur en `local`, `m` ; un vecteur `cadastral` / `geographic` ou en `mm` → 400 (R5, T03).<br>9. **Aperçu ≠ validation** : l'aperçu est le même réducteur ; seul le serveur valide (R9). La sélection, l'accrochage actif et la grille ne sont pas des commandes (R10). |
| Données et dépendances | Paramètres modifiés : `axe` (mur, escalier), `point` (poteau), `contour` / `trous` (dalle, solide), `polygones` (pièce, espace, zone), géométrie (esquisse), `a`, `b`, `position` (cotation, texte) ; `level_id` pour -b. Ouvertures : inchangées (relatives). Représentations dérivées `plan-2d` / `solide-3d` recalculées (empreinte des entrées changée). Modules : `atelier-model` (réducteur `transformer.deplacer`, résolveur de références), `core-geometry` (translation, jonctions), API §5.4 ; événement `atelier.commande.validee` → vues, quantités, bilan Harmonie « à recalculer » (T07). Révision `n + 1`. |
| Résultats | Objets déplacés ; jonctions recalculées ou rompues (listées) ; cotations recalculées ; pièces proposées à la redétection ; entrée de journal « Déplacer n objets » ; vues du ou des niveaux marquées « à recalculer ». |
| Cas limites | Vecteur nul (‖v‖ < `tolCoincidence` = 1·10⁻⁶ m, **proposée, à confirmer**) → aucune commande émise (bouton désactivé), refus 400 si reçu. Coordonnée non finie → 400 `details: [{ chemin: "commands[0].params.vecteur.dx", message }]`. Ouverture seule sélectionnée → refus motivé (règle 2). Objet supprimé par autrui entre aperçu et envoi → 409 `conflits[0].motif = "objet introuvable"`. `baseRevision` dépassée → 409 détaillé ; réservation d'autrui → 423 ; rôle `read` → 403. Niveau cible inexistant ou identique au niveau source (-b) → 400. Déplacement qui place un objet hors de la parcelle : **accepté** (aucune règle de recul évaluée ici), éventuel contrôle laissé à Harmonie / contrôles métier existants. Réseau coupé : commande en file Dexie (« local »), rejouée ; même `requestId` → une seule modification (T06). Sélection de très grande taille (ex. 563 solides « Mobilier ») : un seul lot, borné par l'enveloppe ≤ 1 Mo (cahier §8) ; au-delà, refus explicite, jamais un découpage silencieux. |
| Compatibilité | Aucun format d'échange concerné directement ; IFC (lot 6) exporte la position résultante. Import P.118 : non concerné (aucune donnée de transformation). Prototype : outil « Déplacer » (glisser dans le plan du niveau) — fonction conservée, réécrite en commande. |
