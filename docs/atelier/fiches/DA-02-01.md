# DA-02-01 — Move / Déplacer — module M02 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-01 (M02, étape cible P1). Sous-exigences : -a déplacement de la sélection (`transformer.deplacer`) ; -b déplacement d'une ouverture le long de son mur hôte (`ouverture.deplacer`). Référence de comportement : prototype, outil « Déplacer » (glisser, déplacement accroché à la grille, ouvertures qui glissent sur leur hôte). |
| Situation utilisateur | Déplacer des objets d'un niveau d'un vecteur donné sans changer leur nature, en emmenant ce qui leur est attaché et en voyant ce qui ne suit pas. |
| Entrées et unités | `niveauId` ; `cibles` (objets du niveau) ; `vecteur` `{ x, y, frame: "local", unit: "m" }` (déplacement horizontal non nul), par point de base et point d'arrivée accrochés (DA-02-15) ou valeurs saisies (dx, dy, ou distance et angle, DA-02-16). |
| | Classes admises : toutes les `esquisse.*`, `mur`, `dalle`, `escalier`, `poteau`, `solide`, `piece`, `espace`, `zone`, `reference-plan`, `cotation`, `texte`, `etiquette` (et `toiture` au lot 5). Une `ouverture` seule : `ouverture.deplacer`. |
| Comportement | **Cycle.** Sélection (clic, lasso, filtre par classe : affichage, R10) → point de base, puis arrivée ou saisie → aperçu fantôme avec vecteur (longueur et angle) et liste des objets affectés → contrôle → validation ; Échap annule sans commande. |
| | **Commandes.** `transformer.deplacer` ; une sélection de plusieurs classes est un seul lot (libellé « Déplacer N objets »). Un geste sur une ouverture seule émet `ouverture.deplacer` (composante du vecteur le long de l'axe de l'hôte, contrôle d'emprise dans le mur). |
| | **Attachements (R12).** Un mur emmène ses ouvertures (même `murHoteId`, position `t` et `distance` dérivée inchangées). Une `cotation` rattachée suit ses objets (référence conservée, valeur recalculée) ; une cotation libre suit la sélection ; sélectionnée seule, une cotation rattachée ne déplace que son `decalage`. Une `etiquette` suit l'objet référencé. |
| | **Sans déplacement silencieux.** Aucun objet non sélectionné ne bouge. L'aperçu liste les jonctions de murs rompues (`transformer.etirer`, DA-02-06, les maintient), les pièces dont la délimitation ne correspond plus à leurs murs (problème listé, `piece.detecter` propose) et les autres occurrences d'un escalier de même `groupe` ou sa trémie, avec « ajouter à la sélection » ; sans accord, rien d'autre ne change. |
| | **Contrôles.** Vecteur sous la tolérance de longueur (DA-01-01) refusé ; unité autre que m refusée (T03) ; cible d'un autre niveau, supprimée ou sur un calque verrouillé : lot refusé en entier ; coordonnée résultante hors borne refusée. |
| | **Palette (UX2) et aide (UX4).** « déplacer » ; synonymes « move », « translater » ; actif si au moins un objet d'une classe admise est sélectionné ; exemple court : déplacer un local de 2,50 m vers la droite ; clavier complet par la saisie de précision (DA-02-16). |
| Données et dépendances | Modifie les paramètres de position de chaque cible (`axe`, `contour`, `trous`, `point`, `polygones`, `a`, `b`) sans toucher aux dimensions typées ; relations `heberge` inchangées, `joint-a` et `delimite` recalculées (dérivées) ; références des cotations conservées. |
| | `core-geometry` (polygones de murs, jonctions) ; événement `atelier.commande.validee` : vues, quantités et bilan Harmonie « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Objets déplacés (état « local » puis « synchronisé »), effets listés dans le panneau des modifications (objets modifiés, problèmes créés), inverse = valeurs précédentes enregistrées. |
| Cas limites | **Géométrie.** Vecteur nul ; sélection vide (aucun lot) ; objets de niveaux différents ; calque verrouillé ou masqué ; mur déplacé sans ses voisins : jonctions rompues listées. Une translation conserve l'emprise des ouvertures : aucune ne passe « à réparer ». |
| | **Concurrence.** `baseRevision` dépassée et cible modifiée ou supprimée depuis → 409 avec `conflits[].objetId` et état serveur ; résolution explicite côté client ; un objet supprimé par autrui ne réapparaît pas. Même `requestId` → réponse enregistrée, aucune seconde révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie (une entrée par lot), rejeu dans l'ordre à la reconnexion, brouillon si incompatible. Rôle `write` exigé : 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : cibles admises — 220 `mur` (210 ouvertures hébergées), 120 `poteau`, 32 `escalier` (occurrences), 807 `solide` de rôle `solid`, 6 `dalle`, `zone`, 45 `piece`, 64 `cotation` libres, 95 `texte`. |
| | IFC : un mur déplacé s'exporte avec ses `IfcRelVoidsElement` conservés ; `cotation` et `texte` en `IfcAnnotation` (export seulement) à leur nouvelle position. DXF : aucune sortie propre. Objets « représentation importée » (lot 6) : classes admises à préciser. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts`) : mur et porte déplacés : `t` et `distance` de la porte inchangés ; inverse restitue les coordonnées bit à bit ; vecteur nul refusé ; cible d'un autre niveau refusée ; calque verrouillé refusé ; sélection mixte = un seul lot ; jonctions rompues et pièce désalignée listées ; cotation rattachée : référence conservée, valeur recalculée. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `transformer.deplacer` → 200, révision +1, `effets` (vues à recalculer) ; même `requestId` → même réponse ; `baseRevision` périmée → 409 avec `conflits[].objetId` ; vecteur nul → 400 ; rôle lecture → 403 ; réservation d'autrui → 423. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · déplacer ») : sur la copie de travail de P.118, mur « Noyau A » de la mezzanine (`EX118-mezz-W-009`, porte `EX118-mezz-D-001` à t = 0,5) déplacé d'un vecteur saisi : porte toujours à t = 0,5 ; annuler : coordonnées initiales identiques ; second navigateur à la même révision ; ligne `⏱ déplacement d'un élément` imprimée (L3b.3), sans seuil. |
| Règles métier | Aucune règle réglementaire. R3 : aucune dimension typée (épaisseur, hauteur, section) n'est modifiée par un déplacement ; les valeurs d'exemple de la palette (UX4) ne sont jamais des valeurs par défaut. |
| Extensions à spécifier | Déplacement vers un autre niveau ; déplacement vertical (3D, lot 3b) ; objets « représentation importée » (lot 6) ; déplacement qui maintient les jonctions de murs : `transformer.etirer` (DA-02-06). |
