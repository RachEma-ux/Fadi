# DA-02-10 — Fillet / Raccorder (congé) — module M02 → module Fadi Atelier — lot 3a

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : — (aucune commande de raccord dans `atelier-commands/1`, non inventée : D-037 (2)). Reste : -a à -c (aucun code au lot 3a ; ajout au contrat au lot où `atelier-model` est rouvert, puis outil).

Portée : congé en 2D sur des objets d'esquisse. Le congé d'arêtes de solides (3D) relève du noyau exact (lot
optionnel OCCT) et n'est pas couvert ici.

| Champ | Contenu |
| --- | --- |
| Identité | **DA-02-10** « Fillet » (Exigences V4.1, annexe B.3, module M02, étape cible P1 ; critère de recette commun B.3 : « Transformations réversibles ; sélection, copie et dépendances conservées »). Retenue (proposition §5.1, DA-02 17 / 17, lot 3) ; tâche **L3a.2**. Sous-exigences : **DA-02-10-a** raccorder deux lignes (ou une ligne et un arc) par un arc tangent de rayon donné ; **-b** rayon nul : raccord en coin (les deux segments sont ajustés ou prolongés jusqu'à leur intersection) ; **-c** congé sur un sommet de polyligne, de rectangle ou de polygone (dépend des segments d'arc dans une polyligne, voir Extensions). Fiches liées : DA-01-02 (lignes et polylignes), DA-01-03 (arcs), DA-02-07 / 08 (ajuster, prolonger), DA-02-11 (chanfrein). |
| Situation utilisateur | L'architecte esquisse un angle arrondi (bord de mobilier, contour de banquette, arrondi d'un parvis) ou ferme proprement un coin entre deux traits qui se croisent ou ne se touchent pas. Résultat : les deux traits raccourcis ou prolongés jusqu'aux points de tangence, et un arc tangent de rayon exact. |
| Entrées et unités | Deux objets désignés (`esquisse.ligne`, `esquisse.arc`, `esquisse.construction`) avec le point de désignation de chacun (il indique quelle partie conserver) `{ x, y, frame: "local", unit: "m" }` ; `rayon` `{ value, unit: "m" }`, ≥ 0. Mode sommet (sous-exigence -c) : un objet (`esquisse.polyligne`, `esquisse.rectangle`, `esquisse.polygone`) et l'indice du sommet. `ajuster` booléen (vrai : les objets sont raccourcis / prolongés ; faux : l'arc seul est créé) — **Recommandation**, vrai par défaut d'interface. **Aucun rayon par défaut** de projet (R3) : dernière valeur saisie dans la session ou champ vide. |
| Comportement | Cycle UX3 : outil « Raccorder » (synonymes « fillet », « congé », « arrondi ») → rayon dans l'inspecteur → désignation du premier puis du second objet → **aperçu** de l'arc, des points de tangence et des parties conservées → contrôle → validation.<br>Commande émise : **`transformer.raccorder`** — *nom proposé, à figer par L1.2* : l'annexe B ne contient pas de commande de congé. `{ type: "transformer.raccorder", cibles: [idA, idB], params: { designationA, designationB, rayon, ajuster } }` ou `{ cibles: [id], params: { sommet: i, rayon } }`. Effets (lot atomique) : modification des deux objets (extrémités déplacées aux points de tangence) + création d'un `esquisse.arc` (centre, rayon, angles de début et de fin, sens) sur le calque du premier objet ; rayon nul : modification seule, pas d'arc. Inverse : restauration des paramètres d'origine des deux objets + suppression de l'arc. Classes admises déclarées par la commande ; murs exclus au lot 3a (murs courbes : extension de DA-07-01). |
| Données et dépendances | Calcul pur dans `packages/core-geometry` (centre du cercle tangent aux deux droites / à la droite et au cercle, points de tangence, choix du quadrant d'après les points de désignation) ; réducteur `transformer.raccorder` dans `packages/atelier-model`. Écritures : `atelier_objects` (2 modifiés, 0 ou 1 créé), journal, événement `atelier.commande.validee` → vues du niveau « à recalculer ». Les caractéristiques des objets modifiés (`esquisse:sommet[i]`, `esquisse:segment[i]`, proposées par DA-01-02) restent stables ; une référence vers une extrémité déplacée reste attachée à l'extrémité (pas « à réparer », la topologie ne change pas) — **Hypothèse**, à valider par L1.3. Le congé n'est pas associatif (modifier une ligne ensuite ne recalcule pas l'arc). |
| Résultats | Deux objets ajustés et un arc tangent ; inspecteur de l'arc : rayon, longueur d'arc (dérivée), angle balayé ; entrée de journal « Raccorder » ; révision `n + 1`. |
| Cas limites | Lignes parallèles ou colinéaires (angle < `tolAngle` 1·10⁻⁶ rad, proposée) → refus « pas d'intersection : raccord impossible ». Rayon trop grand : le point de tangence tombe hors du segment conservé → refus citant le rayon maximal admissible (calculé), jamais d'arc partiel. Rayon négatif, unité autre que `m`, point de désignation hors repère `local` → 400 (T03, R5). Objets sur deux niveaux différents → refus. L'un des objets sur un calque verrouillé → refus « calque verrouillé : <nom> » (tout ou rien). Ligne de longueur résultante < `longueurMin` (0,001 m, proposée) → refus. Arc et ligne sans solution tangente → refus. Mode sommet sur une polyligne alors que les segments d'arc ne sont pas pris en charge → refus motivé (voir Extensions). Lecteur 403 ; réservation 423 ; objet modifié par autrui 409 ; `requestId` répété → une seule modification (T06) ; hors ligne : exécution locale, rejeu. |
| Compatibilité | Aucun format spécifique ; l'arc créé suit la fiche DA-01-03 (export DXF `ARC` des vues au lot 5, à confirmer par DA-22-03). Import P.118 : aucun arc ni congé dans les données (tous les tracés sont des polygones fermés) ; rien à importer. Prototype : pas d'outil de congé. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts`) : lignes (0 ; 0)–(4 ; 0) et (4 ; 0)–(4 ; 3), rayon 1 m → lignes (0 ; 0)–(3 ; 0) et (4 ; 1)–(4 ; 3), arc de centre (3 ; 1), rayon 1, de −90° à 0°, longueur π/2 m ; rayon 0 sur deux lignes qui ne se touchent pas → extrémités prolongées jusqu'à l'intersection exacte ; refus : lignes parallèles, rayon 3,5 m (maximal 3 m cité), unité `mm` ; inverse → paramètres identiques bit à bit, empreinte identique. Tolérance `tolCoincidence` 1·10⁻⁶ m. **API** : 400 détaillé ; idempotence ; 409. **Scénario** `05-atelier.mjs` : deux lignes tracées au clavier sur la mezzanine de P.118, raccord de rayon 1,00 m, arc visible, révision + 1, annuler / rétablir. |
| Règles métier | Aucune règle réglementaire concernée. Unités et repère : R5, T03. |
| Extensions à spécifier | Congé sur un sommet de polyligne / rectangle / polygone : exige des **segments d'arc dans une polyligne** (extension déjà notée par DA-01-02) et la conversion d'un rectangle en polyligne (perte de ses paramètres, listée, voir DA-02-13) ; congé de contours de `dalle` et de `solide` (contour polygonal aujourd'hui) ; congé d'arêtes 3D (lot optionnel OCCT) ; murs courbes. **Question au chef de projet (L1.1 / L1.2)** : le modèle de `esquisse.polyligne` inclut-il des segments d'arc (courbure par segment) dès le lot 1 ? Sans cela, la sous-exigence -c reste refusée au lot 3a. **Signalement** : `transformer.raccorder` est absent de l'annexe B (catalogue « initial ») — ajout à valider par le chef de projet. |
