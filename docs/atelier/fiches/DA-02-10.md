| Identité | DA-02-10 (M02, étape cible P1). Congé entre deux lignes d'esquisse. **Commande absente de l'annexe B** (douze `transformer.*` pour les quatorze entrées DA-02-01 à 14) : nom proposé `transformer.raccorder`, à valider par le chef de projet (cahier 10.2, nommage) et à ajouter au catalogue. | Situation utilisateur | Arrondir l'angle formé par deux lignes avec un arc tangent de rayon donné. |
| Entrées et unités | `niveauId` ; `cibles` (deux `esquisse.ligne` distinctes) ; `rayon` `{ value, unit: "m" }` (au-dessus de la tolérance de longueur) ; `points` (deux positions désignées, une par ligne : elles désignent les portions conservées) ; `nouveauxIds` (l'arc). |
| Comportement | **Cycle.** Outil Raccorder → rayon (saisi, DA-02-16, ou désigné au pointeur avec accrochages DA-02-15) → désigner la première puis la seconde ligne (clic sur chaque portion conservée, sans accrochage) → aperçu : arc tangent, lignes raccourcies ou prolongées aux points de tangence → contrôle → validation ; Échap annule sans commande. |
| | **Résultat.** Les deux lignes sont modifiées (même identifiant, extrémité ramenée au point de tangence, raccourcie ou prolongée) ; un `esquisse.arc` neuf (`centre`, `rayon`, `angleDebut`, `angleFin`) sur le calque de la première ligne ; un seul lot atomique. |
| | **Contrôles.** Lignes parallèles ou confondues refusées (« Raccord — les lignes ne se croisent pas, même prolongées. ») ; rayon trop grand pour les portions conservées : refus avec le rayon maximal admissible calculé ; rayon nul refusé (`transformer.prolonger` ou `transformer.ajuster`) ; niveaux différents refusés. |
| | **Palette (UX2) et aide (UX4).** « raccorder » ; synonymes « fillet », « congé », « arrondir un angle » ; actif si deux `esquisse.ligne` du même niveau existent ; exemple court : arrondir un angle droit avec un rayon de 0,50 m. |
