# DA-02-14 — Control-point editing / Édition par points de contrôle — module M02 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-14 (M02, étape cible P1). `transformer.pointsDeControle` : édition d'un objet par ses poignées. Sous-exigences : -a déplacer un point de contrôle ; -b insérer un point ; -c supprimer un point. Référence de comportement : prototype (poignées de dimension L / l / H, sans édition de sommet). |
| Situation utilisateur | Retoucher la forme d'un objet existant en déplaçant, ajoutant ou retirant ses sommets ou points caractéristiques, sans le redessiner ni perdre son identité. |
| Entrées et unités | `niveauId` ; `cible` (un objet) ; `operations` (liste ordonnée, chaque indice relatif à l'état courant du lot) : `{ type: "deplacer", indice, position }`, `{ type: "inserer", apres, position }`, `{ type: "supprimer", indice }` ; positions : points `{ x, y, frame: "local", unit: "m" }`. |
| | Points de contrôle par classe : `esquisse.ligne`, `.construction` (a, b) ; `.polyligne`, `.polygone`, `.spline` (sommets ou points de passage ; insérer, supprimer) ; `.rectangle` (4 coins) ; `.arc` (début, fin, milieu) ; `.cercle` (centre, point de rayon) ; `mur`, `escalier` (a, b de l'axe) ; `dalle`, `solide` (sommets du contour et des trous ; insérer, supprimer) ; `piece`, `espace`, `zone` (sommets) ; `poteau` (centre). |
| Comportement | **Cycle.** Sélection d'un objet → ses poignées s'affichent (affichage seul, R10) → glisser une poignée (accrochages DA-02-15), saisir sa position (DA-02-16), ou « Ajouter un point » / « Supprimer le point » → aperçu de la forme modifiée avec les valeurs affichées → contrôle → validation = une commande par objet et par geste ; Échap annule sans commande. |
| | **Contrôles de forme.** Effectifs minimaux (polyligne et spline 2 points ; polygone, dalle, solide 3) : suppression en dessous refusée ; segments de longueur nulle refusés ; polygone, dalle ou solide auto-sécant refusé (« Poignées — le contour se coupe lui-même. ») ; rectangle : un coin déplacé redimensionne le rectangle, il ne devient jamais un parallélogramme ; arc : trois points alignés refusés ; cercle : rayon sous la tolérance refusé. |
| | **Murs et ouvertures.** Déplacer `a` ou `b` d'un mur est un étirement de cette extrémité (DA-02-06) : ouvertures hébergées à distance conservée depuis l'extrémité fixe, « à réparer » si elles ne tiennent plus, jonctions rompues listées ; aucun mur voisin ne bouge. |
| | **Références (R12).** Déplacer un point sans changer le nombre de points : références conservées, cotations recalculées. **Insérer ou supprimer** un point d'une dalle ou d'un solide décale les indices `dalle:contour[i]` : les références concernées passent « à réparer » avec la correspondance proposée (ancien indice, nouvel indice), jamais ré-indexées en silence. |
| | **Autres classes.** Escalier : déplacer `a` ou `b` modifie son axe ; `largeur`, `marches` et `hauteurAFranchir` restent inchangés, contradictions affichées (DA-07-10), aucune correction silencieuse. Pièce : `aireDeclaree` inchangée, `aireCalculee` recalculée, écart listé. Poteau : déplacer le centre ne modifie que `point`. |
| | **Palette (UX2) et aide (UX4).** « poignées » ; synonymes « points de contrôle », « sommets », « grips » ; actif si un objet d'une classe admise est sélectionné ; exemple court : déplacer un sommet d'une dalle. Clavier : poignées atteintes par Tab, déplacées par saisie de position (T16). |
| Données et dépendances | Modifie les paramètres de géométrie de l'objet (`a`, `b`, `axe`, `sommets`, `points`, `contour`, `trous`, `polygones`, `point`, `centre`, `rayon`, angles) ; relations `heberge`, `joint-a`, `delimite` recalculées ; références indexées (`dalle:contour[i]`) ; événement de commande validée : vues, quantités et bilan Harmonie « à recalculer ». |
| Résultats | Objet remodelé (même identifiant), effets listés (références et ouvertures « à réparer », problèmes), inverse = paramètres précédents enregistrés. |
| Cas limites | **Géométrie.** Suppression sous l'effectif minimal ; indice inexistant (400 avec `chemin`) ; contour auto-sécant ; trou sorti du contour (refusé) ; coordonnée hors borne ; point inséré hors du segment (admis, la forme change). |
| | **Concurrence.** `baseRevision` dépassée et objet modifié ou supprimé depuis → 409 détaillé, résolution explicite côté client ; même `requestId` → une seule révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie rejouée dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : cibles admises — dalles (6, dont `EX118-mezz-SLAB-0` à 19 sommets et sa trémie `EX118-mezz-V815-MC-VOID`), murs (220), poteaux (120), occurrences d'escalier (32), pièces (45). IFC : contour et trous d'une dalle réexportés tels quels. DXF : aucune sortie propre. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts`) : sommet de polygone déplacé, autres inchangés ; insertion et suppression : effectifs et ordre ; suppression sous le minimum refusée ; polygone auto-sécant refusé ; coin de rectangle : rectangle redimensionné ; mur : extrémité déplacée, porte à distance conservée ; dalle : insertion décale `contour[i]`, cotation « à réparer » avec correspondance ; cercle : rayon ; inverse bit à bit. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `transformer.pointsDeControle` → 200 ; indice inexistant → 400 avec `chemin` ; contour auto-sécant → 400 ; même `requestId` → une seule révision ; objet modifié depuis `baseRevision` → 409. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · poignées ») : sur la copie de travail de P.118, sommet de la dalle `EX118-mezz-SLAB-0` déplacé par poignée puis par saisie de position ; point inséré puis supprimé ; annuler ; second navigateur ; clavier seul (Tab, saisie). |
| Règles métier | Aucune règle réglementaire. R3 : `aireDeclaree` et dimensions typées jamais modifiées par une poignée ; R12 : indices jamais ré-attribués en silence. |
| Extensions à spécifier | Poignées de tangente des splines ; poignées 3D (lot 3b) ; édition d'un sommet commun à plusieurs objets ; aimantation d'un sommet avec création de contrainte (lot 5) ; segments en arc dans une polyligne. |
