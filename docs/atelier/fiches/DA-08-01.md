Preuve prévue : —

| Champ | Contenu |
| --- | --- |
| Identité | DA-08-01 (M06, P1). Une poutre est un élément linéaire de structure (`poutre`, rôle `poutre` ou `longrine`) : axe a → b avec altitudes relatives au niveau (za, zb), section (`SectionStructure`), rotation autour de l'axe, matériau déclaré. |
| Situation utilisateur | Poser une poutre entre deux poteaux ou sur un axe tracé. |
| Entrées et unités | `poutre.creer` { niveauId, a, b (m), za, zb (m), section : { forme, largeur, hauteur, epaisseur?, epaisseurAile? } (m) ou { catalogueId, designation }, rotation (°), materiau (acier / beton / bois / autre), materiauNom, prefabrique }. |
| Comportement | Outil Élément de structure : deux poteaux sélectionnés (axe entre leurs têtes), une ligne, ou extrémités saisies ; section en mm ou désignation d'un catalogue sourcé ; géométrie = balayage de la section le long de l'axe (`balayer`), volume = aire × longueur. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'ontologie ajoute ses outils à la palette et ses classes à l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Ontologie `structure` activable par projet (registre `ontologies/structure/`, cahier P2 §4, T01) ; classes `poutre`, `trame`, `plaque`, `assemblage-structurel`, `soudure`, `armature`, `coulage` + `poteau` du socle ; commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9) ; nomenclatures « à recalculer » (T07). |
| Résultats | Occurrence `poutre` ; fiche : rôle, section, source du profil, longueur, volume, masse (si masse linéique sourcée) ; ligne de la nomenclature de structure. |
| Cas limites | Longueur nulle : refus ; forme I / H / T / L / U sans épaisseur d'âme ou d'aile : refus nommé ; désignation absente du catalogue : 409. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC `IfcBeam` (.BEAM.) corps tessellé, `Fadi_Structure` (rôle, section, profil, source, masse linéique, matériau) ; réimport en `objet-importe` ; DXF : vues (bande de section). |
| Validation | Tests : volume du balayage (horizontal, vertical, incliné, tube), refus sans dimension, catalogue → section ; recette : 7 poutres générées + HEA 160 de catalogue sur P.118. |
| Règles métier | Aucune valeur normative dans le code (test « aucune constante normative » de `structure.test.ts`, cahier P2 §8-3) ; sections et masses linéiques viennent du projet (saisie ou catalogue CSV sourcé, D-180) ; masse « non évaluée » sans masse linéique sourcée ; aucune vérification de résistance (R3). |
| Extensions à spécifier | Section variable, cambrure, poutre courbe (P2-6 / P2-7). |
