# DA-01-01 — Precision 2D drawing and drafting / Dessin 2D de précision — module M01 → Atelier — lot 3a

Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-01-01 (M01, étape cible P1). Fiche chapeau de la catégorie B.2 : contrat de précision de l'éditeur de plan, repris par DA-01-02 à 06, 09 à 11 et par les transformations DA-02. Sous-exigences : -a repère et unités ; -b tolérances ; -c niveau, calque et état d'affichage. Référence de comportement : prototype (outils Ligne, Rectangle, Polygone, Cercle ; grille ; accrochage aux sommets). |
| Situation utilisateur | Dessiner et mesurer à l'échelle 1:1 dans le plan d'un niveau, au clavier, à la souris ou au toucher, avec des valeurs exactes saisies ou accrochées ; ce qui est affiché (zoom, décimales, unité) ne change jamais ce qui est stocké. |
| Entrées et unités | Point `{ x, y, frame: "local", unit: "m" }` ; longueur `{ value, unit: "m" }` ; angle `{ value, unit: "°" }` (sens trigonométrique, 0° sur l'axe x local) ; `niveauId` existant et modifiable ; `calqueId` existant, ni verrouillé ni masqué. |
| | Unité d'affichage m (défaut), cm ou mm : réglage d'affichage (R10), valeur stockée inchangée (T03). Pas de grille 0,10 / 0,25 / 0,50 (défaut) / 1,00 m : valeurs du prototype conservées. |
| Comportement | **Cycle (UX3).** Outil → paramètres dans l'inspecteur → aperçu par le réducteur pur du navigateur (état « local ») → contrôle → validation = un lot atomique `POST …/atelier/commands` (`requestId`, `baseRevision`, `atelier-commands/1`) → « synchronisé ». Un aperçu ne vaut pas validation : un refus serveur (400, 409) défait l'application optimiste et affiche le motif. Annuler / rétablir = commandes inverses (nouvelle microversion). |
| | **Commandes.** Aucune commande propre : les outils émettent `esquisse.*` (DA-01-02 à 06, 10, 11) et `transformer.*` (DA-02) du catalogue de l'annexe B. Zoom, panoramique, grille, niveau visible, calque actif, mode et sélection ne sont jamais des commandes (R10). |
| | **Précision.** Accrochages : DA-02-15. Saisie de longueur et d'angle pendant le tracé : DA-02-16. Un point accroché porte la coordonnée exacte du point visé, jamais un arrondi d'écran ; aucun arrondi à l'enregistrement, seul l'affichage arrondit. |
| | **Contrôles du réducteur.** Repère différent de `local` refusé (R5) ; coordonnée non finie ou hors borne (prototype : valeur absolue ≤ 10 000 000 m, à confirmer) ; niveau inconnu ; calque verrouillé ou masqué (« Calque masqué ou verrouillé : modification impossible », message du prototype) ; unité incompatible : 400 (T03). Messages « objet, cause, action ». |
| | **Tolérances (cahier 10.2, à confirmer par le chef de projet).** Longueur nulle : le réducteur refuse sous 0,001 m (seuil minimal du prototype pour épaisseur et décalage) ; le geste ignore en plus les segments de moins de 0,01 m (seuil du prototype), sauf valeur saisie. À consigner dans `decisions.md`. |
| Données et dépendances | Occurrences `esquisse.*` (ontologie `drawing`, table `atelier_objects`) portant `niveauId` et `calqueId`, sans définition (objets libres). Identifiants créés déterministes (dérivés du `requestId` ou fournis par l'enveloppe) : le réducteur reste pur et le rejeu hors ligne reproduit les mêmes objets (T06). |
| | Représentation `plan-2d` dérivée par `core-geometry` (moteur versionné). Événement `atelier.commande.validee` : vues et documents du niveau « à recalculer » (R11, T07) ; bilan Harmonie et aperçu conceptuel selon la projection d'analyse (L1.4). |
| Résultats | Objets `esquisse.*` valides dans le plan du niveau, entrée de journal avec son inverse, coordonnées lisibles dans l'inspecteur avec leurs unités ; tout refus est un message, jamais un résultat silencieux. |
| Cas limites | **Géométrie.** Longueur nulle ou sous tolérance, auto-intersection d'un contour, coordonnée invalide, niveau supprimé, calque verrouillé : lot refusé en entier (atomicité), rien n'est écrit. Hors niveau : un lot ne mélange jamais deux niveaux. |
| | **Concurrence.** `baseRevision` dépassée → 409 détaillé (`conflits[]` : objets cibles modifiés ou supprimés depuis, état serveur) ; le client propose de garder le serveur ou de réappliquer sur l'état courant, jamais de fusion automatique. Même `requestId` → réponse enregistrée, aucune seconde révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie (une entrée par lot), rejeu dans l'ordre à la reconnexion ; lot devenu incompatible = brouillon à traiter, jamais déclaré synchronisé. Rôle `write` exigé : 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : les 967 tracés sont tous fermés (`closed: true`, 3 à 96 sommets, trous éventuels) ; selon le cahier §6 ils deviennent `solide`, `dalle`, `toiture`, `zone`, `reference-plan` ou polygones de `piece` / `espace`, sans arrondi ; l'importeur ne crée aucun `esquisse.*` (un tracé ouvert d'un export du prototype, outil « Ligne », devient un `solide` à contour ouvert, `ferme = false`). |
| | DXF : l'export actuel n'écrit que `LINE` et `TEXT` (AC1015, unités m) ; export des vues au lot 5, import 2D en `reference-plan` au lot 6. IFC : pas de correspondance des esquisses en annexe C ; le rapport d'échange les liste « omises » (R7) tant que le lot 6 n'a pas décidé (`IfcAnnotation` envisagé). |
| Validation | **Unité** (`packages/atelier-model/src/commandes/esquisse.test.ts`) : repère non local refusé ; unité incompatible refusée ; longueur sous tolérance refusée ; calque verrouillé refusé ; même enveloppe → mêmes identifiants ; inverse ∘ commande = état initial identique. |

Tolérances : décision déléguée au chef de projet (cahier 10.2). Les valeurs données en exemple dans les fiches illustrent l'aide située ; elles ne sont jamais des valeurs par défaut (R3). |
| Extensions à spécifier | Plans d'esquisse non horizontaux ; unités non métriques ; loupe de précision au toucher ; coordonnées d'un autre repère (réservées à `site.*`) ; fond de plan DXF (lot 6). |
