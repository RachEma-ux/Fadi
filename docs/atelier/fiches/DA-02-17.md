# DA-02-17 — Gumball manipulation / Manipulateur déplacer, tourner, échelle — module M02 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-17 (M02, étape cible P1). Interprétation de l'inventaire : manipulateur de déplacement, de rotation et d'échelle, équivalent fonctionnel ; pas reprise du produit Gumball. Lot 3a : manipulateur du plan 2D ; manipulateur de la vue 3D : lot 3b (L3b.1). Aucune commande propre. |
| Situation utilisateur | Transformer la sélection en la saisissant directement : glisser pour déplacer (librement ou le long d'un axe), tourner autour d'un pivot, agrandir ou réduire, avec les mêmes contrôles que par menu. |
| Entrées et unités | Sélection typée (classes admises par la transformation visée : DA-02-01, 03, 05). Poignées : flèches X et Y (déplacement contraint à l'axe), carré central (déplacement libre), arc de rotation, poignées d'échelle uniforme aux coins de la boîte englobante. |
| | Pivot (point de rotation et d'échelle) : par défaut le centre de la boîte englobante, déplaçable et accrochable. Orientation des axes : repère `local` ou repère de précision (DA-02-16). Valeurs : dx, dy en m, angle en °, facteur sans dimension. |
| Comportement | **Cycle.** Sélection → le manipulateur apparaît (affichage seul, R10) → glisser une poignée = aperçu fantôme avec valeurs affichées (dx, dy, angle, facteur) → relâcher = **une seule** commande `transformer.deplacer`, `transformer.tourner` ou `transformer.echelle`, mêmes paramètres et mêmes contrôles que par menu → « local » puis « synchronisé » ; Échap pendant le glissement annule sans commande. |
| | **Précision.** Accrochages (DA-02-15) et pas angulaire pendant le glissement ; saisie de la valeur au clavier pendant le glissement (DA-02-16) ; le pivot déplacé devient le `centre` de la commande. |
| | **Tactile.** Poignées d'au moins 44 px de cible (cahier §8) ; `pointer events` unifiés ; un geste à deux doigts déplace ou zoome la vue et ne transforme jamais la sélection. |
| | **Clavier et lecteurs d'écran.** Pas de manipulation directe au clavier : équivalent fonctionnel = dialogue « Déplacer / Tourner / Échelle » de l'inspecteur et saisie de précision, mêmes commandes (T16) ; le manipulateur est une aide visuelle, ses valeurs sont annoncées dans une région `aria-live`. |
| | **Désactivation.** Sélection contenant un objet d'un calque verrouillé, d'un autre niveau, une `ouverture` seule (son déplacement le long du mur reste `ouverture.deplacer`) ou une classe non admise par la transformation : poignées de cette transformation masquées, motif affiché. |
| | **Palette (UX2) et aide (UX4).** « manipulateur » ; synonymes « gizmo », « poignée de transformation », « gumball » ; actif si au moins un objet transformable est sélectionné ; exemple court : glisser la flèche X d'un poteau pour le déplacer le long de l'axe. |
| Données et dépendances | Aucune donnée propre : les effets sont ceux des commandes émises (DA-02-01, 03, 05) ; l'état du manipulateur (pivot, orientation) est de l'affichage, jamais dans le modèle (R10). |
