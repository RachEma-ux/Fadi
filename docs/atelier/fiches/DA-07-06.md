# DA-07-06 — Slabs / Dalles — module M05 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-07-06 (M05, étape cible P1). Une dalle est un objet de classe `dalle` (building.architecture) : contour polygonal, trous, épaisseur, décalage de base, niveau de rattachement. La classe est unique : le plancher d'un niveau (DA-07-05) et la dalle isolée (balcon, plateforme, dalle partielle) sont deux usages du même modèle et des mêmes commandes ; cette fiche porte le modèle, les contrôles et les références communs. Sous-exigences : -a créer (`dalle.creer`) ; -b modifier contour, trous, épaisseur, décalage (`dalle.modifier`) ; -c supprimer (`dalle.supprimer`). Référence de comportement : prototype, tracés `floor-slab` de P.118. |
| Situation utilisateur | Dessiner une dalle de contour quelconque sur un niveau, y percer des trous, lui donner épaisseur et décalage de base, et retrouver par niveau ce qui est posé dessus. |
| Entrées et unités | `niveauId` ; `contour` (polygone fermé, sommets `{ x, y, frame: "local", unit: "m" }`) ; `trous` (polygones locaux) ; `epaisseur` `{ value, unit: "m" }` (> 0) ; `decalageBase` `{ value, unit: "m" }` (signé, relatif à l'élévation du niveau). Contour par points accrochés (DA-02-15), rectangle, polygone, ou copié d'un tracé fermé sélectionné (copie, sans lien caché ni seconde géométrie canonique, R15). |
| | Unité autre que m refusée (T03). Aucune épaisseur ni décalage par défaut (R3) : absents, ils restent « non évalués » (la dalle existe en plan, son volume n'est pas placé en 3D). Sens d'extrusion du décalage : convention du prototype, à vérifier sur les dalles de P.118 avant la 3D (lot 3b), non présumée ici. |
| Comportement | **Cycle.** Outil « Dalle » → paramètres (épaisseur, décalage de base) → contour → trous éventuels → aperçu (contour, trous, aire géométrique, objets posés dessus) → contrôle → validation ; Échap annule sans commande. |
| | **Commandes.** `dalle.creer` ; `dalle.modifier` (contour, trous, épaisseur, décalage de base, niveau) ; `dalle.supprimer`. Déplacer un sommet à la poignée relève de `transformer.pointsDeControle` ; toitures : `toiture.*` (DA-07-07, lot 5), hors de cette fiche. |
| | **Contrôles et palette.** Contour simple (sans auto-intersection), au moins 3 sommets, aire supérieure à la tolérance ; trous contenus dans le contour, sans recouvrement entre eux ; niveau existant ; calque verrouillé : lot refusé en entier. Dalle recouvrant une autre dalle du même niveau : signalée, jamais fusionnée. Palette (UX2) : « dalle » ; synonymes « slab », « dalle isolée » ; exemple court : dessiner une dalle rectangulaire sur le niveau actif (exemple, jamais valeur par défaut) ; aide (UX4). |
| | **Références (R12).** Une cotation s'attache à `dalle:contour[i]` (sommet d'index i). Déplacer un sommet conserve la référence ; ajouter ou retirer un sommet décale les index suivants : ces références passent « à réparer », l'index du même sommet géométrique étant proposé ; `dalle.supprimer` : références à réparer ou détachées. |
| Données et dépendances | Classe `dalle` ; relation `porte` (dérivée : objets du niveau dont l'emprise repose sur la dalle, calculés, jamais saisis) ; `niveauId` vers `niveau` ; caractéristique `dalle:contour[i]` ; trémie d'escalier = `trous` de la dalle (DA-07-10). `core-geometry` (polygones, aires, inclusions) ; événement `atelier.commande.validee` : vues, quantités et bilan Harmonie « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Dalle créée, modifiée ou supprimée (état « local » puis « synchronisé ») ; aire géométrique affichée ; effets dans le panneau des modifications (références à réparer, objets posés, quantités à recalculer) ; inverse = valeurs précédentes. |
| Cas limites | **Géométrie.** Contour non fermé ou auto-intersecté ; sommets confondus ; trou hors du contour ou recouvrant un autre trou ; épaisseur ≤ 0 ; niveau absent ; dalle supprimée avec des objets posés : objets conservés, relation `porte` recalculée. |
| | **Concurrence, réseau, droits.** `baseRevision` dépassée et dalle modifiée ou supprimée depuis → 409 avec `conflits[].objetId` et état serveur ; même `requestId` → aucune seconde révision (T06) ; hors ligne : réducteur local, file Dexie, rejeu dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 (section 6) : tracés `role = floor-slab` → `dalle`, `thickness`, `baseOffset` et `holes` conservés exactement (effectif par niveau donné par le rapport d'import) ; tracés `role = roof-slab` → `toiture` plate (DA-07-07, lot 5). |
| | IFC (annexe C, lot 6) : `IfcSlab` de type `FLOOR` ; trous représentés dans le profil ou en vides, choix à valider par le corpus IFC (R16). DXF : aucune sortie propre, vues de plan au lot 5. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/dalle.test.ts`) : création ; contour auto-intersecté, trou hors contour, épaisseur ≤ 0, unité ≠ m refusés ; aire d'un rectangle de test (4 m sur 5 m) moins un trou de 1 m sur 1 m = 19 m² à la tolérance (entrées de test sans valeur normative) ; ajout d'un sommet : cotation sur un index suivant « à réparer » avec proposition, déplacement d'un sommet : référence conservée ; inverse restitue l'état. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `dalle.creer` → 200, révision +1, `effets` ; contour invalide → 400 avec `chemin` ; même `requestId` → même réponse ; `baseRevision` périmée et dalle modifiée → 409 avec `conflits[].objetId` ; rôle lecture → 403 ; réservation d'autrui → 423. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « 2D · dalles ») : copie de travail de P.118 : dalles issues de `floor-slab` listées par niveau avec épaisseur, décalage de base et trous identiques au rapport d'import ; créer une dalle, y percer un trou, annuler, rétablir ; second navigateur à la même révision. |
| Règles métier | Aucune règle réglementaire (épaisseur minimale, portance, résistance au feu, isolation : non fournies ; règles selon pays, usage et version identifiés, à fournir avec leur source). R3 : aucune valeur par défaut ; l'aire géométrique n'est pas une surface réglementaire. R9 : tout par commande ; R10 : niveau actif et sélection hors révision ; R11. |
| Extensions à spécifier | Dalles inclinées ou à retombées ; composition en couches ; propriété typée d'usage (plancher, dalle isolée) pour filtrer et quantifier par usage (lot 5) ; sens d'extrusion du décalage de base ; copie d'une dalle vers un autre niveau (`transformer.copier`). |
