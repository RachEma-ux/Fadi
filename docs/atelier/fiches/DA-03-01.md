# DA-03-01 — Solid modeling / Modélisation de solides — module M02 → module Fadi Atelier — lot 3b + optionnel

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : — (à lier au lot 3b).

Portée : au lot 3, uniquement le **solide générique paramétrique** (contour fermé avec trous, extrudé
verticalement : classe `solide`). Le solide général B-Rep (faces quelconques, booléens, congés, coques) relève du
lot optionnel OCCT, ouvert seulement après la décision du maître d'ouvrage sur la licence (D-003, R15, cahier §7
« Lot optionnel » : « DA-04 restantes, DA-03-01 / 12 »).

| Champ | Contenu |
| --- | --- |
| Identité | **DA-03-01** « Solid modeling » (Exigences V4.1, annexe B.4, M02, P1 ; critère de recette commun B.4 : « Représentation identifiée ; géométrie valide dans les tolérances du cas »). Retenue « 3 + optionnel » (`docs/atelier-drawall.md` §5.1 : « Solide général et multicorps complets seulement avec le lot OCCT »). Sous-exigences lot 3 : **DA-03-01-a** classe `solide` (prisme droit : `contour`, `trous`, `hauteur`, `decalageBase`) créée par extrusion (DA-04-01) ou import ; **-b** représentation canonique paramétrique unique, représentations `plan-2d` et `solide-3d` dérivées et identifiées (moteur, version, empreinte) ; **-c** validité géométrique contrôlée (contour simple, trous intérieurs, hauteur ≥ 0) ; **-d** grandeurs dérivées (aire, volume). Optionnel : **-e** solide B-Rep (`brep`, `occt@version`). Fiches liées : DA-04-01, DA-04-07, DA-03-12, DA-03-09. |
| Situation utilisateur | L'architecte manipule des volumes simples (mobilier, noyaux, gabarits d'accès, rampes, volumes d'étude) : il les crée, les voit en 3D, connaît leur aire et leur volume, les modifie. Résultat : des solides valides, mesurables, dont l'origine de la géométrie est identifiée. |
| Entrées et unités | Paramètres `solide` du cahier §5.2 : `contour` et `trous` (points `{ x, y, frame: "local", unit: "m" }`), `ferme` (toujours vrai pour un solide), `hauteur` `{ value, unit: "m" }` (≥ 0 ; > 0 exigé à la création, DA-04-01), `decalageBase` (m), `epaisseur` (m, conservée), `role` (texte), `calqueId`, `nom`, `couleur` (`#rrggbb`). Hauteurs par sommet importées (`vertexOffsets`, `topOffsets`) : paramètres de provenance `import` (voir Compatibilité). |
| Comportement | Création : `solide.extruder` (DA-04-01). Modification : `solide.modifier` (paramètres ci-dessus ; DA-04-07, DA-03-10). Suppression : `solide.supprimer` (inverse : recréation à l'identique). Transformations : `transformer.*` sur une sélection contenant des solides (DA-02). Dérivation : à chaque changement de paramètre, `fadi-geometry` recalcule le prisme ; la représentation porte `autorite: "derivee"`, `moteur`, `versionMoteur`, `empreinteEntrees` ; la clé de calcul ne change pas si les entrées sont identiques (recalcul reproductible). Contrôle de validité au réducteur (refus) et à l'import (problème listé, objet conservé). **Exigence** (R15, D1) : un objet n'a jamais deux géométries canoniques ; au lot optionnel, un solide B-Rep aura `brep` pour autorité et ses paramètres d'extrusion d'origine deviendront historiques, sans coexistence de deux autorités. |
| Données et dépendances | `atelier_objects` (`ontology = "drawing"`, `class = "solide"`), `atelier_representations` (`plan-2d`, `solide-3d`), `atelier_properties` (provenance `import` pour les champs P.118 non canoniques). `core-geometry` : prismes aujourd'hui limités aux murs, poteaux, escaliers (`Prism.kind`) — extension requise pour `solide` (L1.5). Rendu three.js (L3b.1, instanciation). Quantités (L1.3) : aire et volume par solide, reproductibles. |
| Résultats | Solides valides, visibles en plan et en 3D, avec aire du contour (m²), volume (m³), représentation identifiée dans l'inspecteur (niveau d'affichage Complet : moteur, version, empreinte). |
| Cas limites | Contour qui se recoupe, trou hors contour ou chevauchant, aire < `aireMin` → refus à la commande ; à l'import → objet créé **et** problème « géométrie invalide » listé (R7 : jamais supprimé). Hauteur 0 importée (`clearance`) → solide plat valide, sans volume, représenté en plan et en 3D comme surface (**hypothèse**). Hauteurs par sommet non reproduites par le moteur → représentation `a-verifier`, jamais aplatie. Version du moteur changée → représentations marquées « à recalculer ». Très grand nombre de solides (807 `solid` dans P.118) → chargement par niveau, mesure `⏱` (T18). |
| Compatibilité | **Import P.118** : 807 tracés `solid`, 35 `clearance`, 28 `ramp-*` (`basement-ramp` 6, `ramp-retaining-wall` 10, `ramp-guard` 9, `ramp-direction` 2, `ramp-drain` 1) → `solide`, `role` conservé (cahier §6) ; tous `cadSolid: true`. **IFC 4.3** (lot 6) : `IfcBuildingElementProxy` + `IfcExtrudedAreaSolid` (`IfcArbitraryProfileDefWithVoids`), jamais reclassé silencieusement (annexe C). **Lot optionnel** : OCCT WASM en Web Worker, licence LGPL non arbitrée (D.3) ; alternative de maillage manifold-3d (Apache-2.0) mesurée au lot 0 (L0.4) — un maillage n'est pas une B-Rep et ne sera jamais présenté comme tel. |
| Validation | **Unité** `packages/atelier-model/src/commandes/solide.test.ts` : prisme 4 × 3 × 2,5 m → aire 12 m², volume 30 m³ ; avec trou 1 × 1 m → 11 m² / 27,5 m³ ; contour invalide refusé ; deux dérivations aux mêmes entrées → même `empreinteEntrees`. `src/ontologie/solide.test.ts` : paramètres et unités obligatoires. **Import** `src/importeur/p118.test.ts` : 870 solides (807 + 35 + 28), rôles et calques conformes, coordonnées bit à bit, problèmes listés nominativement. **Géométrie** `packages/core-geometry/src/geometry.test.ts` : faces du prisme, trous traversants, tolérance `tolCoincidence`. **Scénario** `apps/web/e2e/scenarios/05-atelier.mjs` : chaque niveau de P.118 en 3D sans vue vide ni erreur JavaScript ; sélection d'un mobilier → aire et volume affichés ; `⏱` ouverture de la vue 3D (`12-mesures.mjs`). |
| Règles métier | Aucune. Un solide générique ne porte aucune qualification constructive ou structurelle (R3, R4). |
| Extensions à spécifier | Tout le solide général : B-Rep, faces quelconques, booléens (DA-04-11), congés / chanfreins 3D, coques (DA-04-10), révolution / balayage / lissage (DA-04-02 / 03 / 04) — lot optionnel, **décision du maître d'ouvrage (§10.1-2, licence OCCT)**. Solides à hauteur variable par sommet créés par commande. |
