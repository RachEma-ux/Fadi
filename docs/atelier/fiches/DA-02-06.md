| Champ | Contenu |
| --- | --- |
| Identité | DA-02-06 (M02, étape cible P1). `transformer.etirer`. Pas de référence dans le prototype (il ne déformait pas une sélection : déplacer, copier, tourner, échelle, miroir et décalage seulement). |
| Situation utilisateur | Allonger, raccourcir ou déformer une partie du plan en déplaçant seulement les sommets pris dans une fenêtre de capture, le reste de chaque objet restant en place. |
| Entrées et unités | `niveauId` ; `fenetre` (deux coins `a`, `b` du repère local : seuls les sommets dans la fenêtre bougent) ; `cibles` (objets que la fenêtre traverse ou contient) ; `vecteur` (m, non nul). |
| | Classes admises : `esquisse.ligne`, `.polyligne`, `.polygone`, `.rectangle`, `.construction`, `mur`, `dalle`, `solide` ; objets ponctuels (`poteau`, `texte`, `etiquette`) entièrement dans la fenêtre : déplacés. Refusées : arcs, cercles, splines (poignées : DA-02-14), `escalier`, `piece`, `espace`, `zone`. |
| Comportement | **Cycle.** Fenêtre de capture tracée au pointeur → base, puis arrivée (accrochées, DA-02-15) ou saisie (DA-02-16) → aperçu de la forme déformée, sommets concernés marqués → contrôle → validation ; Échap annule sans commande. |
| | **Règle.** Chaque sommet dans la fenêtre est translaté du vecteur ; un objet entièrement dans la fenêtre est translaté ; un segment qui traverse la fenêtre s'étire. Un `esquisse.rectangle` reste un rectangle : la composante qui le déformerait en parallélogramme est ignorée et signalée à l'aperçu. |
| | **Mur.** Extrémité `a` ou `b` dans la fenêtre : elle bouge ; les deux : translation. Ouvertures hébergées : **distance conservée depuis l'extrémité restée fixe** (la position `t` est recalculée), jamais une glissade proportionnelle ; une ouverture qui ne tient plus dans le mur raccourci passe « à réparer » (propositions : déplacer dans le mur, supprimer ; jamais supprimée en silence). |
| | **Jonctions.** Fenêtre sur l'angle de deux murs : les deux extrémités bougent, la jonction est maintenue. Si seule l'extrémité d'un mur est dans la fenêtre, la jonction avec l'autre est rompue et listée ; aucun mur non sélectionné ne bouge. |
| | **Références (R12).** Même objet, aucune scission : références et caractéristiques nommées conservées (`mur:arete-fin` suit l'extrémité, `dalle:contour[i]` garde ses indices), cotations recalculées ; leur valeur change, pas leur rattachement. |
| | **Contrôles.** Vecteur nul ou fenêtre dégénérée refusés ; aucune cible dans la fenêtre : aucun lot ; mur dont la longueur passe sous la tolérance, polygone ou dalle qui devient auto-sécant : refusés (« Étirer — le contour se coupe lui-même. ») ; cible d'un autre niveau, supprimée ou sur un calque verrouillé : lot refusé en entier. |
| | **Palette (UX2) et aide (UX4).** « étirer » ; synonymes « stretch », « allonger » ; actif si au moins un objet d'une classe admise est sélectionnable dans la fenêtre ; exemple court : allonger un mur de 1,00 m en capturant son extrémité ; clavier complet par la saisie de précision (DA-02-16). |
| Données et dépendances | Paramètres de géométrie des cibles (`a`, `b`, `axe`, `sommets`, `contour`, `point`) ; relations `heberge` (position `t` recalculée), `joint-a` et `delimite` recalculées ; événement de commande validée : vues, quantités et bilan Harmonie « à recalculer » (R11, T07). |
| Résultats | Objets déformés, effets listés (objets modifiés, jonctions rompues, ouvertures « à réparer », problèmes), inverse = valeurs précédentes enregistrées. |
| Cas limites | **Géométrie.** Fenêtre qui ne contient aucun sommet ; objet qui devient dégénéré (longueur nulle, polygone auto-sécant) ; ouvertures qui ne tiennent plus ; pièce dont la délimitation ne correspond plus à ses murs (problème listé). |
| | **Concurrence.** `baseRevision` dépassée et cible modifiée ou supprimée depuis → 409 détaillé, résolution explicite côté client ; même `requestId` → réponse enregistrée, aucune seconde révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie rejouée dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : cibles murs (220, dont 210 ouvertures hébergées), dalles (6, dont `EX118-mezz-SLAB-0` à 19 sommets), solides ; poteaux (120) ponctuels. |
| | IFC : un mur étiré est réexporté avec son axe et ses ouvertures (`IfcRelVoidsElement`). DXF : aucune sortie propre. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts`) : mur de 4 m portant une porte à 1 m de `a`, extrémité `b` étirée à 3 m : porte toujours à 1 m de `a` (`t` de 0,25 à 1/3) ; extrémité `a` étirée : distance à `b` conservée ; fenêtre englobant tout le mur : translation, `t` inchangé ; porte de 1,4 m dans un mur raccourci à 1 m : « à réparer », non supprimée ; rectangle toujours rectangle ; polygone auto-sécant refusé ; inverse bit à bit. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `transformer.etirer` → 200 ; fenêtre dégénérée → 400 avec `chemin` ; cible modifiée par un autre depuis `baseRevision` → 409 ; même `requestId` → une seule révision. |
