| Champ | Contenu |
| --- | --- |
| Identité | DA-03-05 (M02, P2). La subdivision de Loop d'une `surface-libre` : `surfaceLibre.subdiviser { id, niveaux }` change le niveau (0–4) ; la fiche porte un curseur. |
| Situation utilisateur | Lisser progressivement une forme de contrôle grossière. |
| Entrées et unités | `surfaceLibre.subdiviser { id, niveaux: 0..4 }` ; curseur de la fiche Surface libre. |
| Comportement | Chaque niveau quadruple les triangles ; les sommets de contrôle restent la donnée ; le volume lissé est recalculé. Cycle UX : sélection → paramètres → aperçu → contrôle → validation (UX1–UX4) ; l'outil vit dans l'inspecteur, sans ruban ni écran distinct (T01). |
| Données et dépendances | Classe `surface-libre` (`ParamsSurfaceLibre` : sommets 3D relatifs au niveau, faces à 3 ou 4 indices, `niveaux` 0–4, `origine`, `ferme`) ; `geometrie-3d.ts` (`triangulerFaces`, `subdiviserLoop`, `proprietesMasse`) ; `batiment-p2.ts` (`maillageSurfaceLibre`, `controleDepuisMaillage`) ; réducteurs `surfaceLibre.creer / modifier / supprimer / depuisObjet / deplacerSommet / subdiviser`. Commandes du contrat `atelier-commands/3` ; journal, idempotence, inverse exact (R9). |
| Résultats | Niveau courant et nombre de faces subdivisées dans la fiche. |
| Cas limites | Niveau hors 0–4 : 400. `baseRevision` périmée : 409 avec objets en conflit ; même `requestId` : une seule révision (T06) ; objet verrouillé : 423 ; hors ligne : réducteur local puis file Dexie ; unité absente ou incompatible, dimension requise absente : 400 (T03, R3). |
| Compatibilité | IFC : `Fadi_SurfaceLibre.Subdivisions`, `FacesSubdivisees`. |
| Validation | Tests : 0 → 3 niveaux (6 × 64 = 384 faces) ; recette : 0 → 1 depuis le curseur, quatre fois plus de faces. |
| Règles métier | Limite à 4 niveaux déclarée (performance du navigateur et du serveur). Une grandeur absente est « non évaluée » (R3) ; géométrie seulement, aucune vérification réglementaire. |
| Extensions à spécifier | Arêtes vives, poids de sommets, Catmull–Clark. |
