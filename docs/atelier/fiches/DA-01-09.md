# DA-01-09 — Sketcher / Éditeur d'esquisse — module M01 → module Fadi Atelier — lot 3a

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : plan d'esquisse = niveau actif, famille « Créer » de `apps/web/src/modules/atelier/plan2d/outils/esquisse.ts`, sélection clic / lasso / filtre par classe (`plan2d/choix.ts`), analyse de profil (`analyserProfil`, `plan2d/profil.ts`), édition par l'inspecteur générique (`esquisse.modifier`) ; tests `apps/web/src/modules/atelier/plan2d/fondations.test.ts` « lasso de gauche à droite : entièrement inclus ; de droite à gauche : touchés », « filtre par classe : esquisses groupées, bascule, retour à « toutes » », « indicateur de profil : fermé, auto-intersection, fermé avec trou », `apps/web/src/modules/atelier/plan2d/outils.test.ts` « familles Créer et Modifier, raccourcis L/A/C/R, fiches citées, dessinateurs des esquisses et de la référence », « hachure : paramètres exigés, contour et trou copiés par clic intérieur » ; PR #57. Reste : -f suppression (aucun outil de suppression dans le nouvel Atelier (`plan2d/controleur.ts` ne transmet Retour arrière / Suppr qu'à l'outil actif)) ; -g contraintes (lot 5) ; étapes « 05-atelier.mjs » / « 11-accessibilite.mjs » du champ Validation (ancien Atelier) non reprises dans `apps/web/e2e/scenarios/14-nouvel-atelier.mjs`.

Interprétation de l'Exigences : « éditeur d'esquisses paramétriques ; équivalent fonctionnel, pas atelier CATIA
intégré ». Au lot 3a, l'éditeur couvre la création, la sélection, l'édition et la validation de profils ; les
contraintes géométriques et cotes pilotantes (DA-01-07 / DA-01-08) viennent au lot 5.
