| Identité | **DA-02-07** « Trim » (Exigences V4.1, annexe B.3, M02, P1). Critère commun B.3. Tâche **L3a.2**. Sous-exigences : **DA-02-07-a** couper un segment d'esquisse (ligne, segment de polyligne, arc) à ses intersections avec des arêtes de coupe et supprimer la partie désignée ; **-b** ajuster un **mur** sur un autre mur ou une ligne de coupe (raccourcir l'extrémité désignée jusqu'à la face ou l'axe) ; **-c** coupe rapide (sans arêtes de coupe explicites : toutes les entités visibles du niveau coupent). Règles communes : fiche **DA-02-01**. Fiches liées : DA-02-08 (prolonger, symétrique), DA-07-01 (`mur.scinder`, `mur.joindre`), DA-01-02 / 03. |
| Situation utilisateur | L'architecte nettoie un croquis (bouts de lignes qui dépassent) ou raccourcit une cloison qui traverse un mur jusqu'à sa face ; il désigne la partie à enlever et voit l'aperçu avant de valider. |
| Entrées et unités | `aretesCoupe` : références `{ objetId, caracteristique }` (ex. `mur:face-gauche`, `esquisse:segment[2]`) ou vide (-c) ; `cible` : `{ objetId, caracteristique }` de l'élément à couper ; `pointDesigne` `{ x, y, frame: "local", unit: "m" }` (côté à supprimer) ; pour -b : `reference` ∈ {`face`, `axe`} (choix explicite, pas de défaut silencieux — l'outil propose la face la plus proche et l'affiche). |
| Comportement | Cycle UX3 : « Ajuster » (synonymes « trim », « couper », « ajuster ») → arêtes de coupe (ou aucune) → désigner la partie → **aperçu** (partie supprimée en rouge, point d'intersection, longueur restante) → validation.<br>Commande (annexe B) : `{ type: "transformer.ajuster", cibles: [cible.objetId], params: { aretesCoupe, cible, pointDesigne, reference? } }`. Le réducteur calcule l'intersection retenue et l'inscrit dans ses **effets** (valeur exacte, non arrondie). Inverse : `esquisse.modifier` / `mur.modifier` avec les anciens paramètres (et `esquisse.supprimer` des morceaux créés).<br>Règles : **esquisse** : si la partie désignée est intérieure (deux intersections), le segment est **scindé** en deux objets (nouveaux identifiants déterministes) ; ligne entièrement entre deux arêtes → refus « rien à couper ». **Mur** (-b) : seule une **extrémité** peut être ajustée ; couper l'intérieur d'un mur = `mur.scinder` + `mur.supprimer` du tronçon, proposé comme lot explicite (ouvertures du tronçon listées avant accord, cotations « à réparer », R12) ; l'extrémité ajustée produit une jonction `mur.joindre` proposée. **Ouvertures** : `distance` depuis l'extrémité conservée conservée, `t` recalculé ; ouverture coupée → refus listant l'ouverture. Classes admises : `esquisse.ligne`, `.polyligne` (segment), `.arc`, `.construction`, `mur` ; autres classes (dalle, solide, pièce : opérations de contour booléennes, lot optionnel) → refus. Calque verrouillé (cible) → refus ; arête de coupe sur calque verrouillé → **admise** (elle n'est pas modifiée). |
| Données et dépendances | Géométrie d'esquisse, axe des murs, `t` des ouvertures, relations `joint-a` ; caractéristiques nommées (`esquisse:segment[i]` proposée par DA-01-02) ; `core-geometry` (intersections segment / segment, segment / arc, décalage de face de mur `wallPolygon`) ; références à réparer ; événement → vues et quantités. |
| Résultats | Élément raccourci ou scindé ; jonction proposée ; journal « Ajuster » ; longueurs de murs périmées. |
| Cas limites | Aucune intersection entre la cible et les arêtes → refus « aucune arête de coupe rencontrée ». Intersection tangente ou colinéaire (à `tolAngle` = 1·10⁻⁶ rad / `tolCoincidence` = 1·10⁻⁶ m, **proposées**) → refus « coupe ambiguë », jamais un choix silencieux. Plusieurs intersections équidistantes du point désigné → l'aperçu demande de préciser. Reste < `longueurMin` = 0,001 m → refus. Arête de coupe sur un autre niveau → refus (les coupes se font dans le plan du niveau). 409 si la cible a changé ; 403 / 423 ; idempotence ; hors ligne rejoué. |
| Compatibilité | Aucun format concerné. Prototype : pas d'outil d'ajustement (mot « trim » présent dans la palette de synonymes du cahier §5.8) — fonction nouvelle. |
| Validation | **Unité** `transformer.test.ts` : ligne (0 ; 0)→(10 ; 0), arêtes x = 3 et x = 7, point désigné (5 ; 0) → deux lignes (0→3) et (7→10) exactes ; point désigné (9 ; 0) avec arête x = 7 → ligne (0→7) ; cloison traversant un mur de 0,20 m centré sur x = 5, ajustée sur `mur:face-gauche` (x = 4,90) → extrémité en 4,90 exact ; ajustement tangent → refus ; inverse → empreinte identique. **API** : 400 cible non admise (dalle). **Scénario** `05-atelier.mjs` : tracer une ligne d'esquisse traversant deux murs de P.118 et couper la partie centrale ; annuler. `11-accessibilite.mjs` : désignation au clavier (cycle entre intersections). |
