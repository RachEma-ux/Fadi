# DA-02-07 — Trim / Ajuster — module M02 → Atelier — lot 3a

**État : spécifiée (lot 0)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : —.

| Champ | Contenu |
| --- | --- |
| Identité | DA-02-07 (M02, étape cible P1). `transformer.ajuster`. Pas de référence dans le prototype (qui n'avait que l'outil « Effacer »). |
| Situation utilisateur | Raccourcir ou couper un objet à l'endroit où d'autres objets le croisent (angle de murs, tracé qui dépasse), sans le redessiner. |
| Entrées et unités | `niveauId` ; `cible` (objet à raccourcir ou à couper) ; `aretes` (objets coupants, identifiants explicites : en mode « rapide » le client y met tous les objets visibles du niveau, la commande reste déterministe) ; `point` (position désignée, repère local, m : elle choisit le tronçon retiré). |
| | Cibles admises : `esquisse.ligne`, `.polyligne`, `.arc`, `.cercle`, `.construction` (segment), `mur`. Arêtes admises : toute esquisse linéaire ou fermée (côtés), `mur` (axe), construction. Refusées : formes fermées (rectangle, polygone : `transformer.decomposer` d'abord), spline, `dalle`, `solide`. |
| Comportement | **Cycle.** Outil Ajuster → désigner les arêtes (ou « toutes ») → désigner le tronçon à retirer (la position désignée n'est pas accrochée : elle choisit un tronçon, elle ne crée aucune géométrie) → aperçu : tronçon retiré en tirets, objets créés et modifiés listés → contrôle → validation, un lot par cible. |
| | **Résultat par classe.** Ligne : raccourcie, ou coupée en deux si le tronçon retiré est intérieur (l'original garde la première partie, la seconde est un objet nouveau). Polyligne : sommets du tronçon retiré supprimés, une ou deux polylignes. Arc : raccourci ou coupé en deux. Cercle : remplacé par un arc (conversion indiquée à l'aperçu, nouvel identifiant). Mur : extrémité ramenée à l'intersection des axes (même objet), ou scission si le tronçon retiré est intérieur. |
| | **Ouvertures.** Mur raccourci : distance depuis l'extrémité restée fixe conservée. Celles qui tombent dans le tronçon retiré ou ne tiennent plus passent « à réparer » (propositions : déplacer dans le mur, supprimer ; jamais supprimées en silence). Scission : ouvertures réaffectées au tronçon qui les contient (`mur.scinder`). |
| | **Références (R12).** Un ajustement qui scinde un objet référencé (mur coupé en deux, cercle devenu arc) met les cotations et contraintes (lot 5) qui le référencent « à réparer », avec les caractéristiques des nouveaux objets proposées ; l'aperçu annonce le nombre de références concernées et la validation demande un accord explicite. Extrémité ramenée sans scission : références conservées (`mur:arete-fin` suit l'extrémité). |
| | **Contrôles.** Aucune intersection entre la cible et les arêtes : refus (« Ajuster — aucune arête ne coupe cet objet. ») ; contact tangent sans croisement : pas d'intersection ; arêtes colinéaires qui se recouvrent : refus (ambigu) ; `point` trop éloigné de la cible ; arête identique à la cible : ignorée. |
| | **Palette (UX2) et aide (UX4).** « ajuster » ; synonymes « trim », « couper », « recouper » ; actif si au moins une arête et une cible d'une classe admise existent dans le niveau ; exemple court : couper la partie d'un mur qui dépasse d'un autre mur ; clavier complet par la saisie de précision (DA-02-16). |
| Données et dépendances | Modifie ou crée des occurrences (identifiants déterministes) ; relations `heberge` réaffectées ; références à réparer ; `core-geometry` : intersections ; événement de commande validée : vues, quantités et bilan Harmonie « à recalculer » (R11, T07). |
| Résultats | Objets raccourcis ou coupés, effets listés (objets modifiés, créés, remplacés ; ouvertures et références « à réparer »), inverse = objets et valeurs précédents restaurés avec leurs identifiants. |
| Cas limites | **Géométrie.** Aucune intersection ; tangence ; arêtes colinéaires ; cible fermée (refusée, action « décomposer ») ; mur coupé dont une ouverture tombe dans le tronçon retiré ; intersection hors borne ; cible d'un autre niveau, supprimée ou sur un calque verrouillé : lot refusé en entier. |
| | **Concurrence.** `baseRevision` dépassée et cible ou arête modifiée ou supprimée depuis → 409 détaillé ; résolution explicite côté client ; même `requestId` → une seule révision (T06). |
| | **Réseau et droits.** Hors ligne : réducteur local, file Dexie rejouée dans l'ordre, brouillon si incompatible ; 403 motivé, 404 sans accès, 423 pendant une réservation d'autrui (R13). |
| Compatibilité | Import P.118 : les 220 murs sont ajustables entre eux ; les 967 tracés importés sont des contours fermés (`solide`) et ne sont donc pas ajustables. DXF et IFC : aucune sortie propre ; une scission de mur s'exporte en deux `IfcWall`. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/transformer.test.ts` et `packages/core-geometry`) : ligne coupée par deux arêtes, clic au milieu : deux lignes de longueurs vérifiables à la main ; une seule arête : tronçon jusqu'à l'extrémité ; aucune intersection refusée ; cercle → arc aux angles attendus ; mur et porte dans le tronçon retiré : porte « à réparer », non supprimée ; scission : cotation « à réparer » avec deux propositions ; inverse restaure identifiants et valeurs. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `transformer.ajuster` → 200 avec `effets` ; sans intersection → 400 avec `chemin` ; arête modifiée depuis `baseRevision` → 409 ; même `requestId` → une seule révision. |

Cote « à réparer » après scission : contrôle activé au lot 5, quand les cotations rattachées existent. |
