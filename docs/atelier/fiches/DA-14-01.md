# DA-14-01 — Drawing views / Vues de dessin (ici : « Exporter » la vue courante en PNG / SVG) — module M11 → module Fadi Atelier — lots 3a / 3b (export simple, D-018), vues de dessin au lot 5

**État : spécifiée** pour la part « export de la vue courante » (à spécifier → spécifiée → prototype → vérifiée → disponible). **Prototype** pour la part « vues techniques de travail » (lot 3b, L3b.4, D-050) : plan (coupe horizontale), coupes nord–sud, est–ouest et selon un plan quelconque, quatre façades, calculés depuis `core-geometry` (`apps/web/src/modules/atelier/vue3d/vues.ts`), panneau SVG `VuesTechniques.tsx` ouvert depuis la vue 3D, position de coupe réglable, sélection au clic partagée ; tests `apps/web/src/modules/atelier/vue3d/vue3d.test.ts` (coupes N–S, E–O, quelconque, plan, façades) ; scénario `14-nouvel-atelier.mjs#vuesTechniques` (8 vues non vides sur P.118) ; PR #75. Les vues de dessin proprement dites (vues nommées, échelle, fraîcheur par vue, feuilles) restent **à spécifier** pour le lot 5.

| Cas limites | Vue vide (niveau sans objet visible, tous calques masqués) → export refusé avec motif « rien à exporter », pas de fichier blanc. Vue de tranche en 3D → export de ce qui est rendu (pas de refus). Canvas WebGL2 perdu (contexte perdu) → refus motivé, nouvel essai après restauration. PNG au-delà de la limite de taille → résolution réduite et signalée, jamais un fichier tronqué. Fichier > 25 Mo (limite existante de l'API) → 413, téléchargement conservé. Texte contenant `<`, `&`, `"` → échappé dans le SVG. Commande validée pendant la génération → l'export porte la révision rendue et passe « périmé » au catalogue. Navigateur qui bloque le téléchargement → message, rien n'est enregistré au catalogue sans fichier téléchargé. Polices : le SVG utilise une famille générique (`sans-serif`) — rendu du texte variable selon le lecteur, déclaré. |
