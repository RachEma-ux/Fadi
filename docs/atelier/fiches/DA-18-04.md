# DA-18-04 — Digital mock-up visualization and review / Visualisation de la maquette numérique — module M14 → module Fadi Atelier — lot 3b

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : part 3b : rendu three.js chargé à la demande, une géométrie fusionnée par famille de matériau (au lieu de l'instanciation, D-047), murs découpés autour des baies par `core-geometry` (`apps/web/src/modules/atelier/vue3d/scene.ts`, `rendu.ts`) ; modes volume / éclaté / coupe (plan de coupe réglable) ; orbite, panoramique, zoom à la souris, au clavier (L3b.1) et au toucher, un doigt = orbite, deux doigts = pincer + panoramique (L3b.3, D-049) ; sélection par lancer de rayon partagée avec le plan 2D et l'inspecteur ; révision affichée (`data-revision`) ; WebGPU derrière le réglage « Moteur » avec repli WebGL2 et motif ; mesures `⏱` imprimées (`vue3d/mesures.ts`, scénario `14-nouvel-atelier.mjs#mesures3d`) ; tests `vue3d/vue3d.test.ts` ; scénarios `14-nouvel-atelier.mjs#vue3d` (niveaux × modes sans vue vide, clavier, aucune erreur JavaScript) et `#mesures3d` (téléphone tactile, cibles ≥ 44 px) ; PR #72, #74. Reste : -a chargement / déchargement par niveau (la scène est reconstruite pour la portée choisie) ; -e visibilité par classe et calque dans la 3D ; -f fraîcheur visible hors révision ; -g contexte du site (parcelle, recul, emprise) ; hors ligne (`09-hors-ligne.mjs`) ; budget de trame publié au compte rendu du lot 3b, aucun objectif contractuel (R14).
