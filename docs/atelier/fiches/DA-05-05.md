# DA-05-05 — Groups / Groupes — module M04 → Atelier — lot 3a

**État : prototype (lot 3a)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : recette `apps/web/e2e/atelier-nouveau.mjs`, tests `apps/web/src/modules/atelier/nouveau/nouveau.test.ts` et `packages/atelier-model/src/commandes/commandes.test.ts` ; compte rendu `lots/lot-3a.md`.

| Champ | Contenu |
| --- | --- |
| Identité | DA-05-05 (M04, étape cible P1). Sous-exigences : -a créer un groupe (`groupe.creer`) ; -b dissoudre un groupe (`groupe.dissoudre`) ; -c sélectionner et transformer un groupe. Un groupe rassemble des objets distincts d'un même niveau qui se sélectionnent et se transforment ensemble ; il n'a pas de géométrie propre. Distinct du bloc (définition et occurrences réutilisables, DA-05-06) et du paramètre `groupe` des `escalier` (occurrences d'un même escalier sur plusieurs niveaux, conservé tel quel). |
| Situation utilisateur | Réunir plusieurs objets d'un niveau (murs, solides, esquisses, annotations…) pour les sélectionner, déplacer, copier et masquer d'un bloc, sans perdre l'identité de chacun. |
| Entrées et unités | `groupe.creer` : `niveauId`, `membres` (au moins 2 identifiants d'occurrences ou de groupes du niveau, sans doublon), `nom` facultatif. `groupe.dissoudre` : `groupeId`. Aucune grandeur propre : un groupe transformé délègue aux commandes `transformer.*` (vecteurs `{ x, y, frame: "local", unit: "m" }`). |
| Comportement | **Cycle.** Sélection (clic, lasso, filtre par classe : affichage, R10) → Grouper → nom facultatif → aperçu (liste des membres, niveau, calques, membres masqués) → contrôle → validation ; Échap annule sans commande. Clic sur un membre : sélectionne le groupe entier ; double-clic ou « Entrer dans le groupe » : sélectionne un membre seul (affichage, R10). Dissoudre libère les membres sans changer leur position ni leur identité. |
| | **Commandes.** `groupe.creer`, `groupe.dissoudre` (annexe B) ; libellés « Grouper N objets », « Dissoudre le groupe ». Une transformation (`transformer.*`) appliquée à un groupe se développe en ses membres : un seul lot, journal et inverse par objet. Ajouter ou retirer un membre n'existe pas : dissoudre puis recréer donne un nouveau `groupeId` (extension). |
| | **Contrôles.** Membre d'un autre niveau, inconnu ou supprimé : lot refusé ; porte, fenêtre et ouverture ne sont pas membres directs (elles suivent leur mur hôte, relation `heberge`) ; un objet appartient à au plus un groupe direct ; imbrication admise, cycle refusé (un groupe ne contient ni lui-même ni un de ses ancêtres) ; membre d'un calque verrouillé : transformation du groupe refusée en entier ; membres masqués inclus dans une transformation mais listés à l'aperçu (aucun déplacement silencieux). |
| | **Palette (UX2) et aide (UX4).** « grouper », « dissoudre » ; synonymes « group », « ungroup » ; actif si au moins 2 objets groupables sont sélectionnés (ou 1 groupe pour dissoudre) ; exemple court : grouper trois solides et une cotation. |
| Données et dépendances | Entité `groupe` d'organisation (`nom`, `niveauId`, `membres`), relation `membre-de` : absentes du tableau 5.2, à y ajouter avant le code (lot 1) — écart signalé au chef de projet. Le paramètre `groupe` des `escalier` reste un paramètre de l'escalier (DA-02-01 propose d'ajouter à une sélection les occurrences de même `groupe`) et n'est pas converti. |
| | Suppression d'un membre par sa propre commande : retiré du groupe, effet listé ; dernier membre supprimé : groupe supprimé, effet listé. Événement de commande validée : vues « à recalculer » (R11, T07) ; microversion +1. |
| Résultats | Un groupe sélectionnable, transformable et annulable ; membres inchangés (identités, calques, paramètres) ; effets listés dans le panneau des modifications ; inverse = membres et positions avant. |
| Cas limites | **État.** Groupe d'un seul objet refusé ; objet déjà groupé refusé avec le nom de son groupe ; mur groupé sans ses ouvertures : elles le suivent par `heberge` ; groupe dont un membre est sur un calque masqué : voir Contrôles. |
| | **Concurrence et réseau.** `baseRevision` dépassée et membre modifié ou supprimé depuis → 409 avec `conflits[].objetId` ; un objet supprimé par autrui ne réapparaît pas, le groupe survit moins ce membre ; groupe dissous par autrui puis transformé : 409 ; même `requestId` → une seule révision (T06). Hors ligne : réducteur local, file Dexie, rejeu dans l'ordre, brouillon si incompatible. 403 / 404 / 423 selon R13. |
| Compatibilité | Import P.118 : aucun groupe d'organisation ; le paramètre `groupe` des 32 `escalier` est conservé tel quel (R7). IFC : `IfcGroup` avec `IfcRelAssignsToGroup` candidats, correspondance à fixer à l'annexe C (lot 6), sinon omission nominative au rapport d'échange. DXF : aucune sortie propre. |
| Validation | **Unité** (`packages/atelier-model/src/commandes/groupe.test.ts`) : création avec 2 membres ; membre d'un autre niveau, ouverture, objet déjà groupé, cycle : refusés ; dissolution : membres identiques bit à bit ; `transformer.deplacer` sur un groupe : tous les membres déplacés en un lot, inverse restitue ; calque verrouillé : lot entier refusé ; suppression d'un membre : effet listé. |
| | **API** (`apps/api/src/routes/atelier-commands.test.ts`) : `groupe.creer` → 200 et `effets` ; un seul membre → 400 avec `chemin` ; même `requestId` → même réponse ; `baseRevision` périmée et membre supprimé → 409 ; rôle lecture → 403. |
| | **e2e** (`apps/web/e2e/scenarios/05-atelier.mjs`, bloc « Organisation · groupes ») : copie de travail de P.118 : grouper le mur `EX118-mezz-W-009` et un autre mur de la mezzanine, déplacer le groupe : porte `EX118-mezz-D-001` toujours à t = 0,5 ; annuler ; dissoudre ; second navigateur à la même révision. |
| Règles métier | Aucune règle réglementaire. R9 : toute création ou dissolution passe par une commande. R12 : les références (cotations rattachées) aux membres sont conservées ; un groupe n'est jamais la cible d'une référence. |
| Extensions à spécifier | Ajouter ou retirer un membre (`groupe.modifier`, absent de l'annexe B) ; groupes sur plusieurs niveaux ; nom et propriétés d'un groupe (DA-06-07) ; verrou de groupe ; conversion d'un groupe en bloc (lot 5). |
