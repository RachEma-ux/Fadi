# DA-01-04 — Rectangles / Rectangles — module M01 → module Fadi Atelier — lot 3a

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `creer.rectangle` (R, deux coins, largeur et profondeur saisies) et `creer.polygone` (centre, sommet, nombre de côtés, inscrit) (`apps/web/src/modules/atelier/plan2d/outils/esquisse.ts`) ; modification par l'inspecteur générique (`esquisse.modifier`) ; tests `apps/web/src/modules/atelier/plan2d/outils.test.ts` « rectangle : coins dans n'importe quel ordre normalisés ; largeur et profondeur saisies », « polygone : nombre de côtés en paramètre (contrôlé), centre et sommet » ; PR #57. Reste : -b angle de rotation à la création ; -c rectangle par trois points ; -d mode « circonscrit » non proposé par l'outil ; -e suppression (aucun outil de suppression dans le nouvel Atelier (`plan2d/controleur.ts` ne transmet Retour arrière / Suppr qu'à l'outil actif)) ; étapes « 05-atelier.mjs » du champ Validation (ancien Atelier) non reprises dans `apps/web/e2e/scenarios/14-nouvel-atelier.mjs`.
