# Contexte — Studio

## Objectif

Préparer et livrer Studio natif autonome dans Fadi selon les sources officielles, avec deux planches et un dossier de conception durable et publiable, sans modifier implicitement les 21 étapes.

## Périmètre

Les 630 cases de STUDIO-TASKS-001 sont affectées aux missions M11–M30 du programme #156. Les lots I/A/B/X/C/D/E/F/R, G0–G4, J0–J8, TEST/NAV/DEC et qualifications TR gardent leurs sens d'origine. Les options F restent conditionnelles.

## Sources canoniques

Studio/Fadi_Studio_Checklist_Execution_V1_0.md ; Studio/Fadi_Studio_Plan_Implementation_V1_0.md ; Définition officielle V2.1 et Référentiel technique détaillé V1.0 DOCX dans Studio/. AGENTS.md et continuité existante. Routage des missions dans docs/ai-team/missions.json ; les textes normatifs restent dans leurs sources, pas dans les résumés du catalogue.

## Contraintes

Entrée verticale Studio, accès sans étape Parcours, services Fadi partagés, pas d'iframe ni seconde base métier. Conserver Atelier pendant coexistence décidée, capacités industrielles et normes. Codes/POC/portes et production selon autorisations ; aucune source privée dans GitHub public.

## Hypothèses et questions ouvertes

Placement précis, routes, composants/paquets, modèles physiques, budgets et DEC restent à instruire selon le sous-lot. Les capacités existantes et les preuves doivent être qualifiées avant de cocher les tâches. Une fiche TR complète ne vaut pas conformité du produit.
