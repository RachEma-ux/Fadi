| Champ | Contenu |
| --- | --- |
| Identité | PL-12-02 ; machine `packages/planche-model/src/outils/profiles-aretes.ts` ; catalogue `profiles-aretes` (statut `fadi`, famille Dessin) ; pictogramme ⫴ ; raccourci Fadi **Alt+Maj+Q** ; barres « Arêtes » et « Volumes » ① Créer ; bouton « Poser » du panneau Profilés. |
| Situation utilisateur | Habiller d'un coup un dessin d'arêtes (cadre, ossature, garde-corps) de pièces de la même section. |
| Entrées | Arêtes présélectionnées, une ou plusieurs chaînes. Section du panneau. Mesures : décalage signé des extrémités libres. Options : **Position** centre / extérieur / intérieur, que **Ctrl** frappé seul fait défiler ; **Rotation 90°**, basculée par **Alt** frappé seul ; **Onglets** (oui par défaut) ; **Fusion des colinéaires**. |
| Comportement | Au survol, l'aperçu est calculé par le noyau sur un modèle candidat, sans rien écrire. Un clic, Entrée au champ vide ou « Poser » pose une pièce par arête (ou par tronçon fusionné), toutes chaînes comprises, en **un seul pas**. Les pièces posées sur une seule arête à la racine sont liées à leur arête (L11). |
| Résultats | Rectangle de 4 arêtes : 4 pièces à onglet, liées, en un pas. Deux chaînes séparées : posées ensemble, en un pas. |
| Cas limites | Pas d'arête ; pas de section ; chaîne qui se ramifie ; boucle non plane en extérieur ou intérieur ; onglet singulier. Chacun est refusé avec un message. |
| Compatibilité | Nouveau. La coupe après pose est réservée à L13. |
| Validation | Voir les preuves. Une dimension manquante bloque « Poser » et le panneau le dit. |
| Règles métier | Aucune donnée de profilé dans le code. La pièce fusionnée couvre plusieurs arêtes et n'est pas liée (déclaré). |
| Extensions à spécifier | Coupe par profil et onglets réglables (L13) ; liste de débit et repères (L14). |
