| Situation utilisateur | Ajuster la longueur d'une pièce à une extrémité, d'une valeur ou d'une demi-section (bout contre bout). |
| Entrées | Clic près d'une extrémité. Longueur signée tapée au champ Mesures. Option **Valeur** : saisie, ½ largeur ou ½ hauteur (le clic applique alors aussitôt). Option **Sens** : + allonger, − raccourcir (ce n'est pas Maj). |
| Comportement | Le décalage de l'extrémité est modifié dans les métadonnées et la pièce est régénérée. La transformation est inchangée. Le lien à l'arête source est gardé, son instantané mis à jour. |
| Résultats | +0,3 puis −0,1 à la fin d'une pièce de 2 m : 2,3 puis 2,2 m. Demi-largeur au début : −0,05. Un pas par allongement. |
| Cas limites | Extrémité coupée en onglet ; pièce recoupée par un profil ; allongement nul ; longueur qui deviendrait nulle. Chacun est refusé avec un message. |
| Compatibilité | Nouveau, sans effet sur les autres outils. Les raccourcis étaient libres. |
| Règles métier | Aucune donnée de profilé dans le code. Les angles sont dérivés et les volumes vérifiés. |
| Extensions à spécifier | Liste de débit avec les angles de coupe (L14) ; édition et régénération d'une pièce recoupée (L17). |
