| Entrées et unités | Survol d'une face = aperçu du plan (couleur de l'axe) ; Maj = verrou ; flèches = orientation ; clic = pose. Barre du plan sélectionné : Inverser, Coupe active, Effacer le plan. |
| Comportement | État `EtatPlanDeCoupe` { `apercu`, `fleche`, `verrouMaj`, `inference` }. La pose crée `PlanDeCoupe` { origine, normale, u, w, demiU, demiW, actif, inverse, nom } (un pas), sélectionne le plan et rend Sélection ; `modifierPlanDeCoupe` applique Inverser / Coupe active (un pas chacun) ; Suppr ou Effacer retire le plan. |
| Données et dépendances | `annotations.ts`, `geometrie-libre.ts`, `inference.ts` ; vue : `majCoupe` (dernier plan actif). |
| Résultats | Un plan de coupe (rectangle à l'étendue de la face), coupe rendue, outil Sélection. |
| Cas limites | Aucune face survolée : plan de 1 m autour du point, normale du plan du sol ; plusieurs plans actifs : seul le **dernier** (ordre de création) coupe, les autres restent visibles sans couper. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
