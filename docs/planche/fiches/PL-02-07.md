| Identité | PL-02-07, mode de travail « planche » de l'Atelier (`ModeTravail`, `etat-ui.ts`) : composant `Planche.tsx`, vue three.js `vue-planche.ts`, barre et clavier `outils-planche.ts`, historique local `historique.ts`, brouillon local `brouillon.ts` (dossier `apps/web/src/modules/atelier/nouveau/planche/`) ; bouton « Planche » dans `AtelierNouveau.tsx` ; textes dans `messages.ts`. Sous-exigences : -a entrée dans le mode ; -b rendu ; -c barre d'outils, grille, recherche, Instructeur ; -d barre d'état et champ Mesures ; -e clavier ; -f navigation (Orbite, Panoramique, Zoom) ; -g toucher ; -h annuler / rétablir et brouillon local. Référence : `cahier-planche.md` §3, §4.34, §4.35, §5.3, §5.5, §5.7, §5.9, §8 (lot 2) ; C1, C6, C11, C18, C19, C20, C23, C25, C26. |
| Situation utilisateur | Depuis l'Atelier d'un projet, ouvrir la Planche, choisir un outil (barre, grille, raccourci, recherche), dessiner en tapant des valeurs exactes sans cliquer dans le champ Mesures, naviguer, annuler ; au téléphone, disposer des touches modificatrices à l'écran ; retrouver son dessin au retour, en sachant qu'il n'est pas enregistré dans le projet. |
| Entrées et unités | Pointeur (souris, trackpad, toucher), clavier (`keydown` / `keyup` sur la fenêtre), réglages de navigation D-157 (préférence locale) ; coordonnées en m, repère `local` ; champ de vision en degrés. |
| Comportement | **-a Entrée.** Bouton « Planche » dans le groupe Plan / 3D / Documents (`data-mode-planche`, `aria-pressed`) ; le composant est chargé à la demande avec three.js (`lazy`). En mode Planche, la barre de l'Atelier masque ce qui porte sur le modèle de l'Atelier (niveau, annuler / rétablir du journal, palette Ctrl K, affichage, accrochages, Cadrer, exports, imports) ; la colonne de panneaux du Canevas et les outils étendus de l'Atelier ne sont pas affichés ; le clavier de l'Atelier est désactivé sauf Ctrl + S. Plan / 3D / Documents inchangés. |
| | **-b Rendu** (`VuePlanche`, WebGL2, R14) : faces recto gris clair / verso bleu-gris, arêtes noires, sélection bleue, aperçu de l'outil (noir, couleur de l'axe sur une inférence linéaire), marqueur d'inférence par forme **et** infobulle (C20), axes pleins côté positif / pointillés côté négatif, sol neutre ; rendu à la demande ; triangulation des faces trouées (`trianglesFace`). Couleurs : **choix Fadi** d'après SketchUp. Caméra initiale : position (9 ; −12 ; 7), cible l'origine ; champ de vision 35° (relevé). Sans WebGL2 : message « Vue 3D indisponible » (`role="alert"`). |
| | **-c Barre d'outils** verticale flottante : Rechercher, outils « barre » du catalogue dans l'ordre relevé (§3.2), emplacement « récent » pour le dernier outil pris dans la grille (obs §5.9), « ⋯ » ouvre la grille par sections (§3.3 ; fermée au clic extérieur et à Échap). **Un outil sans machine d'états n'est jamais actif** (R20, C11) : grisé, `aria-disabled`, motif « prévu au lot N » ; Texte 3D : « 2 ou 5 (décision P-7) ». Lecteur (C25) : Sélection, Lasso et caméras seulement. **Recherche** (`Maj + -`, lue sur `code = Minus` pour l'AZERTY, et bouton) : boîte modale, noms français et de référence anglais, insensible aux accents, 12 résultats, ↑ ↓ Entrée, Échap ferme. **Colonne de droite** : Instructeur seul (outil actif : étapes, touches et leur nature, suite, statut du relevé) ; les autres panneaux (§3.4, §6) ne sont pas livrés (lot 5). Pictogrammes : dessins Fadi. |
| | **-d Barre du bas** : aide, langue « Français » (C1), choix du périphérique (D-157), **barre d'état** `aria-live="polite"` (contexte d'édition, consigne de l'étape, message ou erreur), **champ Mesures** (`input` étiqueté par le libellé de l'étape, `inputMode="decimal"`, bouton OK) ; locale française : virgule décimale, point-virgule de liste (proposition P-3) ; unités anglo-saxonnes refusées (P-4 non tranchée). Le champ garde le texte tapé après validation, jusqu'au prochain mouvement. |
| | **-e Clavier** : frappe captée quand le focus est sur le dessin ou le champ Mesures, **jamais** dans un autre champ ni pendant la recherche (C19) ; un chiffre, `.`, `,`, `;`, `:`, `+`, `-`, `[`, `<`, `*`, `/`, `x` commence une saisie, puis tout caractère s'y ajoute ; Entrée valide (champ vide : Entrée transmise à l'outil) ; Retour arrière corrige la frappe, sinon Suppr / Retour arrière = Suppr de l'outil ; raccourcis du catalogue lus sur le caractère (§5.10, L-29) ; Maj, Ctrl, Alt, flèches suivis à l'enfoncement et au relâchement (§5.5), relâchés à la perte du focus (choix Fadi) ; Ctrl + Z / Ctrl + Maj + Z / Ctrl + Y ; Ctrl + / Ctrl −. **Échap** : ferme la grille ; sinon annule l'opération en cours de l'outil ; **sans opération en cours, revient à l'outil précédent** (sinon Sélection, sinon vide la sélection) — comportement **D-156**, alors que le cahier propose le comportement relevé (C23 : outil gardé à l'étape 1 ; caméra → outil précédent) : **écart à trancher (P-5)**. |
| | **-f Navigation** (D-157, P-11 : échelle 0,25…4 gardée) : molette = zoom autour du curseur, trackpad deux doigts / pincement, bouton du milieu = orbite, Maj + milieu = panoramique, deux doigts au toucher = pincement + orbite ou panoramique selon le réglage. Outils Orbite, Panoramique, Zoom (bouton gauche) sans machine d'états, gérés par l'interface ; Zoom : glisser vers le haut = avant, champ Mesures « Champ de vision » (`60` → 60°, CA-CAM-2). Tolérance d'accrochage : **10 px** convertis en mètres à la profondeur visée (choix Fadi ; PL-01-03 proposait 12 px) ; glisser au-delà de 4 px ; double-clic : 400 ms et 6 px (choix Fadi). Aucune caméra ne touche le modèle (R10). |
| | **-g Toucher** (C18, P-12) : **barre de modificateurs** (Maj, Ctrl, Alt, ← ↑ → ↓) affichée dès le premier pointeur tactile ou sur écran sans survol (`hover: none` et `pointer: coarse`) ; boutons de 44 px au moins ; Maj **maintenue** tant que le bouton est enfoncé, appui long (≥ 500 ms) = verrouillée jusqu'au prochain appui, au clavier Entrée / Espace bascule ; Ctrl, Alt et flèches = un appui (enfoncée puis relâchée), conforme à leur nature de bascule. Au toucher, le point touché est d'abord survolé (inférence) puis appuyé ; sans survol, la direction d'une longueur tapée n'existe pas : au doigt, les coordonnées relatives `<dx;dy;dz>` sont la saisie exacte. Téléphone (≤ 760 px) : libellés masqués, panneau en surcouche, barre du bas sur deux lignes. |
| | **-h Annuler / rétablir et brouillon** (C6) : historique **local** de modèles immuables, une opération = un pas, `remplaceDernier` remplace le dernier pas (correction au champ Mesures), 200 pas au plus (choix Fadi) ; boutons ↶ ↷ de la Planche, opération nommée dans le titre et annoncée (« Annulé : Rectangle. »). **Brouillon local** par projet dans IndexedDB (`localStore`, clé `planche-brouillon:<projet>`, format `planche-brouillon/1`), enregistré 300 ms après chaque pas, relu à l'ouverture s'il n'y a encore rien de dessiné ; un brouillon illisible ou d'un autre format est ignoré. Affiché en permanence « Brouillon local — non enregistré dans le projet (lot 7) » ; **aucune commande, aucune requête au serveur** ; ni partagé, ni présent sur un autre appareil. |
| Données et dépendances | `@parcours/planche-model` (catalogue, machines `machineParId`, `analyserSaisie`, `geometrieVisible`), `three`, `etat-ui.ts` (mode, navigation), `navigation.ts` (D-157), `lib/local-store`. Instrumentation de recette en lecture seule : `window.fadiPlanche` { `modele`, `outil`, `etatOutil`, `pas`, `versEcran` }. Aucune révision, aucun `POST /commands`. |
| Résultats | Dessin à l'écran ; brouillon dans le navigateur ; aucune sortie (exports Planche au lot 7). |
| Cas limites | Exception d'une machine : message « Erreur de l'outil : … » dans la barre d'état, état gardé ; stockage local indisponible : le brouillon ne vit que dans la page (dit dans l'infobulle) ; lecture seule : rien n'est enregistré au brouillon ; un brouillon déjà dessiné n'est jamais écrasé par la lecture tardive du stockage. |
