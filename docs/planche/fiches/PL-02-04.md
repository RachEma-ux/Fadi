| Comportement | **Rectangle** — état `EtatRectangle` { `etape` 1 \| 2, `centre` (bascule Ctrl persistante), `verrouFleche`, `verrouMaj`, `normaleSurvol`, `premier`, `normale`, `u`, `w`, `a`, `b`, `contraint`, `inference`, `texte`, `erreur`, `derniere` }. **Étape 1** (« Cliquez pour placer le premier coin… » ; mode centre : « … le centre ») : plan inféré = face survolée, sinon sol ; flèches avant le 1ᵉʳ clic (bascules) : → plan ⟂ rouge, ← ⟂ vert, ↑ ⟂ bleu, ↓ plan inféré courant ; Maj maintenue : plan inféré verrouillé (instr) ; saisie refusée avant le 1ᵉʳ clic. **Étape 2** : aperçu fermé et face provisoire ; Mesures `1,93 m ; 0,59 m` (`~` si approché) ; clic ou `4;3` → rectangle et **face** (`ajouterRectangle`), **sens donné par le quadrant du curseur** ; inférence « Carré » (relevée) ; mode centre : dimensions totales. Retour à l'étape 1, **outil gardé**, Mesures garde le texte tapé. **Correction après coup** : une saisie juste après la création remplace le dernier rectangle (`remplaceDernier`, un pas) ; après une autre action : refusée. Échap : annule l'opération en cours. « Section dorée » : doc seule → non livrée. |
| | **Rectangle tourné** — état `EtatRectanglePivote` { `etape` 1 \| 2 \| 3, `verrouFleche`, `normaleSurvol`, `p1`, `normale`, `base`, `longueur`, `angle1`, `cote1`, `largeur`, `angle2`, `inference`, `texte`, `erreur`, `dimensions` }. Étape 1 (« Sélectionnez le premier coin. » ; Mesures vide) : plan inféré, flèches = axe du rapporteur. Étape 2 (« Longueur, angle » `1,27 m ; 0,0`) : 1ᵉʳ côté, angle depuis la ligne de base (axe rouge projeté) ; `3` seul accepté. Étape 3 (« Largeur, angle ») : angle du 2ᵉ côté **mesuré depuis la normale du plan de départ, autour du 1ᵉʳ côté** ; 90° = dans le plan de départ, à gauche du 1ᵉʳ côté (CA-RTO-1 : `2;90` → posé au sol) ; largeur seule : angle du curseur. Face créée ; « Dimensions » `3,00 m ; 2,00 m` après. **Écart à trancher** : le relevé affiche `0,0` au survol de l'étape 3, ce qui suggère une autre référence d'angle (dans le plan) que celle retenue — référence non établie. Alt (plan / ligne de base du rapporteur), Maj, cliquer-glisser : textes relevés, effets nv → **non livrés**. |
