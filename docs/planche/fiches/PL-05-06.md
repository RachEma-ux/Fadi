| Champ | Contenu |
| --- | --- |
| Identité | PL-05-06, `PanneauInfoEntite`, `PanneauComposants`, `NavigateurPlanche` (`panneaux-objets.tsx`), actions dans `Planche.tsx` (`actionsInfo`). Référence : §6.1, §6.2, §6.12, D-171. |
| Situation utilisateur | Lire et corriger les propriétés de ce qui est sélectionné ; parcourir les objets de la Planche. |
| Entrées et unités | Sélection courante ; champs nom d'occurrence / de définition, matériau recto / verso / objet, balise, Verrouillé, Masqué ; Composants : nom, description, options, « Sélectionner les occurrences » ; Navigateur : recherche, ouvrir, cibler, masquer, supprimer. |
| Comportement | Info entité : face → aire, recto / verso, balise héritée ; arête → longueur ; courbe → rayon, segments ; objet → « Groupe / Composant (solide) (N dans le modèle) », motif de non-solidité nommé, volume, occurrence, définition, matériau, balise, Ombres (fixe, non réglable), Verrouillé, Masqué ; cote / texte / plan / scène / guide → nom. Chaque modification = une opération du noyau = un pas. Composants : liste des définitions « composant » avec le nombre d'occurrences. Navigateur : arbre racine → objets (groupes et composants imbriqués), l'objet du contexte d'édition et la sélection marqués, objets masqués grisés. |
| Données et dépendances | `aire`, `volume`, `estSolide`, `motifNonSolide`, `nombreOccurrences`, `peindreFacesCote`, `renommerOccurrence`, `modifierDefinition`, `baliserOccurrences`, `verrouillerOccurrences`, `masquerEntites`, `boiteOccurrence`. |
| Résultats | Propriétés affichées en unités SI, virgule décimale ; modifications enregistrées dans la Planche. |
| Cas limites | Sélection vide → « Aucune sélection » ; sélection mixte → « N entités » ; lecture seule → champs désactivés. |
| Compatibilité | Préférence de précision (Info modèle) appliquée. |
| Validation | e2e : composant solide 4,00 m³, renommage « Copie de fenêtre », Verrouillé coché → Suppr refusé, Navigateur 2 objets, masquer depuis le Navigateur, « Bloc 1 occurrence(s) ». |
| Règles métier | « Non évalué » plutôt qu'une valeur inventée (volume absent si non solide, motif nommé). |
| Extensions à spécifier | Ombres par objet (relevé fixe), Solid Inspector (absent de l'offre gratuite). |
