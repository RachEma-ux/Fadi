# PL-04-03 — Axes / Axes — mode Planche → Atelier — lot Planche 4

**État : disponible — acceptée le 8 octobre 2026 (D-174)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `outils/mesure.test.ts` (CA-AXE-1, -2, double-clic) ; recette `planche-lots-4-6.mjs` (axes).

| Champ | Contenu |
| --- | --- |
| Identité | PL-04-03, machine pure `outils/axes.ts` ; repère lu par `saisie-vcb.ts` (`ContexteSaisie.repere`) et `inference.ts` (axes d'inférence). Référence : §4.30, R5 (C12). |
| Situation utilisateur | Changer le repère de saisie (origine et orientation) pour dessiner dans une direction oblique sans changer les coordonnées stockées. |
| Entrées et unités | Trois clics (origine, axe rouge, axe vert) ; double-clic = axes tels qu'orientés à l'origine cliquée ; Alt = orientation alternative ; Échap annule. |
| Comportement | État `EtatAxes` { `etape` 1 \| 2 \| 3, `origine`, `x`, `alternatif`, `inference` }. `repereDepuis` orthonormalise (vert projeté hors du rouge, bleu = rouge × vert). Le repère est posé dans `annotations.repere` (un pas, annulable) ; `Transition.outilPrecedent` rend l'outil précédent. Toutes les saisies `[x;y;z]` / `<dx;dy;dz>` et les inférences d'axes (couleurs, verrous) suivent le repère. |
| Données et dépendances | `annotations.ts` (`Repere`), `geometrie-libre.ts` (`modifierAnnotations`), `saisie-vcb.ts` (`dansLeRepere`), `inference.ts`. |
| Résultats | Un repère de saisie (donnée de la Planche) ; les coordonnées stockées ne changent jamais (R5). |
| Cas limites | Axe rouge nul ou vert colinéaire : « Orientation impossible », rien n'est modifié. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-AXE-1 → « origine (1;2;0), rouge vers +y → « [1;0;0] » lu dans le repère donne (1;3;0) » ; CA-AXE-2 → « Annuler rétablit les axes précédents » ; double-clic. **e2e** : trois clics → repère (4;3;0), rouge −y ; outil précédent (Ligne) rendu ; « [0;0;0] » dans le repère ; Ctrl + Z retire le repère. |
| Règles métier | R5 : repère de saisie seulement, jamais le repère des données. |
| Extensions à spécifier | Menu contextuel des axes (Aligner, Déplacer, Réinitialiser, Masquer) ; Réinitialiser = Ctrl + Z pour l'instant. |
