| Champ | Contenu |
| --- | --- |
| Identité | PL-02-03, machines d'états pures `machineLigne` (`packages/planche-model/src/outils/ligne.ts`) et `machineMainLevee` (`main-levee.ts`). Sous-exigences : -a Ligne (chaîne, saisie, fermeture, verrous, cycle Alt, correction après coup) ; -b Main levée (courbe, plan de dessin, segments). Référence : `cahier-planche.md` §4.4, §4.5, §5.1–5.3 ; relevés [OD §4, §13], [CM §7]. Raccourci Ligne : `L` ; Main levée : grille, sans raccourci. |
| Situation utilisateur | Tracer des arêtes exactes (longueur tapée, coordonnées), fermer une boucle pour obtenir une face, couper une face d'un milieu à l'autre ; esquisser une courbe à main levée. |
| Entrées et unités | Rayon et tolérance (m, repère `local`) ; champ Mesures (attente `longueur-ou-point`, locale `fr` : virgule décimale, point-virgule de liste, P-3) : longueur (m ; négative = sens inverse), `[x;y;z]` absolu, `<dx;dy;dz>` relatif ; flèches, Maj, Alt ; Ctrl + / Ctrl − (main levée). |
| Comportement | **Machine Ligne** — état `EtatLigne` { `etape` 1 \| 2, `depart`, `debutChaine`, `inference`, `fleche`, `verrouMaj`, `modeAlt`, `areteReference`, `texte`, `erreur`, `dernier` (correction), `rayon` }. **Étape 1** (« Cliquez pour placer la première extrémité ») : clic → `depart` = point inféré → étape 2 ; `[x;y;z]` tapé → départ ; une longueur tapée **corrige le dernier segment** (`remplaceDernier`, un seul pas). **Étape 2** (segment élastique, Mesures « Longueur » `2,64 m`, `~` si verrouillée ou arrondie) : clic ou longueur (direction du curseur : point inféré − départ) ou `<dx;dy;dz>` → segment créé (`ajouterSegment`, collage et faces automatiques du lot 1) et **la chaîne continue** depuis l'extrémité ; elle **se termine** (retour à l'étape 1, outil gardé) quand le segment revient au départ de la chaîne ou crée une face. Longueur sans direction (curseur sur le départ) : erreur « Orientez le curseur… », rien n'est créé. **Flèches (bascules)** : → ← ↑ verrou rouge / vert / bleu, 2ᵉ appui = déverrouillé ; ↓ parallèle / perpendiculaire à la dernière arête survolée — sans référence, longueur bloquée à 0 (obs) ; choix parallèle ou perpendiculaire selon la direction courante du curseur (**choix Fadi**). **Maj maintenue** : verrou de l'inférence courante, le segment « Alt = … » disparaît de la consigne. **Alt** : cycle toutes actives → toutes coupées → parallèle / perpendiculaire → toutes actives, appliqué **au relâchement** (obs [CM §7]). **Échap** : annule le segment en cours, vide Mesures, outil gardé à l'étape 1. Clic au point de départ : ignoré (pas de segment nul). Contexte d'édition : points monde ramenés dans le repère du groupe. |
| | **Machine Main levée** — état `EtatMainLevee` { `points` (null au repos), `plan`, `pas`, `verrou`, `faceSurvolee`, `derniere`, `ignorerClic` }. **Repos** → appui : plan de dessin = plan de la face visée, sinon sol z = 0, sinon plan verrouillé par une flèche avant le tracé (→ ← ↑ : plan ⟂ rouge / vert / bleu ; ↓ : plan de la face survolée ; bascules) → **tracé** : points échantillonnés à une distance minimale égale à la tolérance d'accrochage reçue, au moins 1 mm (**choix Fadi déclaré**, non relevé) → relâché : **une courbe** (une entité, au moins 2 arêtes ; `ajouterCourbeLibre`) ; boucle fermée plane → face (doc [S12], nv — livré, déclaré). Juste après : Ctrl − / Ctrl + = ±1 segment (ré-échantillonnage du trajet, bornes 2 à 999, remplace le dernier pas ; instr). Mesures inactif. Échap pendant le tracé : rien ; appui + relâché sur place : rien. Outil gardé. |
| Données et dépendances | `geometrie-libre.ts` (`ajouterSegment`, `ajouterCourbeLibre` — la courbe à main levée est enregistrée avec le genre `arc`, centre = 1er point, rayon 0, faute de genre dédié : **écart à PL-01-01**, qui prévoyait `main-levee`) ; `inference.ts` (`inferer`, `modeAltSuivant`) ; `saisie-vcb.ts`. |
| Résultats | Arêtes, faces automatiques, courbes ; un pas d'annulation par segment ou par courbe. |
| Cas limites | Saisie refusée : erreur annoncée (barre d'état `aria-live`), rien n'est modifié, le champ garde le texte ; longueur nulle : refusée ; correction après une autre action : refusée ; état reçu jamais modifié (immuable). |
| Compatibilité | Formes relevées `3`, `3m` ; formes documentées non confirmées `[x;y;z]`, `<x;y;z>` (L-3) livrées et déclarées. |
| Validation | **Unité** — CA-LIG-1 → `ligne.test.ts` « CA-LIG-1 : clic (0;0;0), curseur vers +x, « 3 » Entrée → arête exacte … » ; CA-LIG-2 → « CA-LIG-2 : quatre segments fermant un carré plan (clics) → 4 arêtes, 1 face, retour à l'étape 1 » et « Ligne, puis « 4 » Entrée ×4 en tournant → une face de 16 m² » ; CA-LIG-3 → « ligne d'un milieu à l'autre d'une face rectangulaire → 2 faces » ; CA-LIG-4 → « → puis curseur hors axe → point projeté sur l'axe rouge, Mesures « ~ » … » ; CA-LIG-5 → « Alt au relâchement, cycle de 3 … » ; CA-LIG-6 → « Échap à l'étape 2 → aucune entité créée … » ; compléments : ← ↑, Maj, ↓, coordonnées, longueur négative, saisie refusée, correction, vue, contexte d'édition. CA-MLV-1 → `main-levee.test.ts` « CA-MLV-1 : glisser de A à B → une courbe d'au moins 2 arêtes, sélectionnée en entier par un clic » ; **CA-MLV-2 adapté** → « CA-MLV-2 (adapté) : flèche → avant le tracé → … plan vertical x = constante » (le cahier écrit ↑ ; le catalogue et la machine donnent ↑ = plan ⟂ bleu = horizontal : **écart à trancher**, `lots/lot-2.md`). **e2e** — `planche.mjs` : L au clavier, `4` Entrée × 4 → 4 arêtes, 1 face de 16 m², étape 1 ; au toucher, `<4;0;0>`… → 1 face. |
| Règles métier | Aucune. R5 : toute coordonnée stockée est `local` ; R7 : aucune valeur arrondie au stockage. |
