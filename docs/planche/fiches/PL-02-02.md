| Champ | Contenu |
| --- | --- |
| Identité | PL-02-02, machine d'états pure `machineGomme` (`packages/planche-model/src/outils/gomme.ts`). Sous-exigences : -a effacement au clic ; -b gommage glissé ; -c adoucir, masquer, réafficher (Ctrl, Maj, Alt maintenus). Référence : `cahier-planche.md` §4.3 ; relevés [OD §3], [CM §4, §9]. Raccourci `E`. |
| Situation utilisateur | Effacer des arêtes (et les faces qui en dépendent), une courbe entière, un groupe ; adoucir ou masquer des arêtes sans les effacer, puis les réafficher. |
| Entrées et unités | Rayon caméra et tolérance (m) ; touches Ctrl, Maj, Alt (enfoncée / relâchée) ; appui, glisser, relâché ; Échap. |
| Comportement | État `EtatGomme` { `maj`, `ctrl`, `alt`, `appui`, `glisse`, `marques` (ids), `ignorerClic` }. **Repos** : clic sur une arête → l'arête est effacée **avec les faces qui en dépendent** ; sur un segment de courbe → **la courbe entière** ; sur une occurrence (groupe / composant) → l'occurrence entière, retirée de la sélection ; dans le vide ou sur une face → rien (la gomme n'efface jamais une face seule, doc [S23]). **Appui → glisser** : les arêtes survolées sont **marquées** (aucune suppression), puis traitées **au relâchement** en **un seul pas** (`effacerAretes`) ; appui + relâchement sans glisser : c'est le clic qui efface (une fois). **Modificateurs maintenus** (malgré « Toggle » du texte relevé, obs) : Ctrl = adoucir (attribut `adoucie`, l'arête reste, entités inchangées) ; Maj = masquer (`masquee`, courbe entière) ; Alt = réafficher / annuler le lissage au même endroit, sur une arête invisible ; Ctrl + Maj pendant un glisser = retirer de la liste en cours (instr, nv — livré comme choix Fadi déclaré). Masquer et réafficher sont **chacun un pas d'annulation** (obs [CM §9]). La première phrase de la consigne suit le modificateur maintenu (catalogue). **Échap** pendant un glisser : rien n'est effacé. |
| Données et dépendances | `geometrie-libre.ts` : `effacerAretes` (plusieurs arêtes et leurs courbes en une opération), `modifierAretes` (attributs de visibilité), `aretesDeLaCourbe`. Chaque opération = un pas de l'historique local (brouillon, PL-02-07). |
| Résultats | Nouveau modèle ; libellé d'opération pour l'historique. |
| Cas limites | Arête déjà masquée : invisible au clic simple, atteinte avec Alt ; courbe partiellement survolée au glisser : toute la courbe ; glisser interrompu par Échap : rien ; lecteur : outil indisponible (motif affiché). |
| Compatibilité | Sans objet. |
