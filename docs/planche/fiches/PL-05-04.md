| Entrées et unités | `G` ou menu « Créer un composant… » : boîte (nom prérempli « Composant N » sélectionné, croix d'effacement, chevron : description, coller à, découper l'ouverture, toujours face à la caméra, ombres face au soleil grisé), Annuler / Créer. Menu : Rendre unique, Éclater, Intersection des faces ▸ Avec le modèle. Ctrl + C / X / V. |
| Comportement | Créer : `grouper(m, sel, { genre: "composant", nom, description, collerA, decouperOuverture, faceCamera, dans })`, occurrence sélectionnée, un pas. Occurrences liées : même `Definition` (le contenu est partagé, éditer l'une modifie toutes). Rendre unique : nouvelle définition « Nom#k » pour l'occurrence seule. Éclater : le contenu revient dans le contexte courant, sélectionné ; un objet verrouillé refuse. Intersection : les faces et objets de la sélection sont coupés par le reste du modèle (segments d'intersection insérés), nombre d'arêtes annoncé. Ctrl + V : copie à 1 m sur l'axe rouge dans le même contexte, sélectionnée. |
| Données et dépendances | `Definition extends MetadonneesDefinition`, `Occurrence.nom`, `Rapport.crees`. |
| Résultats | Composant nommé et décrit ; copies liées ; définitions séparées ; géométrie libre ; arêtes d'intersection. |
| Cas limites | Sélection vide → message ; Rendre unique à 1 occurrence → grisé / message ; Éclater une géométrie libre → grisé ; collage dans un autre contexte → refusé ; objet verrouillé → refus nommé. |
| Compatibilité | Boîte en français, traduite dans `en.json` ; nom par défaut « Composant N » (fadi). |
| Validation | `objets.test.ts` ; e2e : « Fenêtre » créée avec description et « coller à vertical », 2 occurrences liées après Ctrl + V, « Fenêtre#1 » après Rendre unique, Éclater → 6 faces libres, Intersection → arêtes ajoutées. |
| Règles métier | R5 (nommage), R10 (métadonnées = données de la Planche, pas d'état d'interface). |
| Extensions à spécifier | Effets géométriques de « Coller à » / « Découper l'ouverture » / « Toujours face à la caméra » (nv, §9) ; collage par glisser ; Mettre la définition à l'échelle. |
