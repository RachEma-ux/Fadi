# PL-01-01 — Free geometry, sticky edges and faces / Géométrie libre (arêtes et faces collantes) — mode Planche → Atelier — lot Planche 1

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : —.

| Champ | Contenu |
| --- | --- |
| Identité | PL-01-01, noyau de géométrie libre de la Planche (`packages/planche-model/src/geometrie-libre.ts`, s'appuie sur `vecteur.ts`). Sous-exigences : -a structure (sommets, arêtes, faces planes trouées, courbes, contextes) ; -b ajout d'arêtes avec collage et faces automatiques ; -c effacement ; -d différences exactes et inverse ; -e invariants et contrôle ; -f sérialisation canonique ; -g mesures (aire, volume, solidité). Référence de comportement : `docs/planche/cahier-planche.md` §5.4, §4.3, §4.4 ; relevés [OD §4, §15.5], [CM §5], [DOC §8]. |
| Situation utilisateur | (Servie à partir du lot 2.) Dessiner des arêtes qui se soudent à la géométrie touchée, voir les faces apparaître dès qu'une boucle plane se ferme, couper une face par une ligne, effacer une arête et ses faces dépendantes, isoler une géométrie dans un groupe pour qu'elle ne colle pas. |
| Entrées et unités | Coordonnées en **mètres**, repère **`local`** du projet (R5), nombres double précision, jamais arrondis (R7). Tolérance de fusion `TOL` (m) et tolérance angulaire de coplanarité : **choix Fadi** (cahier Atelier §10.2 ; valeur de SketchUp non relevée, lacune L-31) — `TOL = 1e-6 m` de `vecteur.ts`, à documenter comme choix Fadi (le commentaire actuel cite une valeur de SketchUp non sourcée). Générateur d'identifiants déterministe passé en argument (préfixe + compteur), de sorte que la même suite d'opérations donne les mêmes identifiants dans le navigateur et sur le serveur (même principe que l'Atelier). |
| Comportement | **-a Structure.** `Contexte` = { `sommets` (id → position), `aretes` (id → sommets a, b ; attributs facultatifs `adoucie`, `lissee`, `masquee`, `courbeId`), `faces` (id → contour : suite ordonnée de sommets ; `trous` : suites de sommets ; `normale` unitaire ; attributs facultatifs `materiauRecto`, `materiauVerso`, `masquee`), `courbes` (id → suite ordonnée et contiguë d'arêtes ; `nature` ∈ { `libre`, `arc`, `cercle`, `polygone`, `main-levee` } ; métadonnées facultatives `centre`, `rayon`, `normale`, `angleDepart`, `angle`, `segments`, `inscrit`) }. `Planche` = { `racine` : Contexte ; `groupes` : id → { `contexte`, `transformation` (affine 4 × 4), `nom`, `verrouille` } } ; composants : type réservé, opérations au lot 5. **Une seule géométrie canonique** : les sommets ; les métadonnées de courbe ne servent qu'à régénérer les sommets sur commande explicite et sont retirées (la courbe devient `libre`) dès qu'un sommet de la courbe n'est plus sur le cercle porteur à `TOL` près (R15, cahier C8 ; comportement de SketchUp dans ce cas : non relevé). |
| | **-b Ajout** (`ajouterSegment`, `ajouterChaine`, `ajouterBoucle`). (1) Chaque extrémité à moins de `TOL` d'un sommet existant **est** ce sommet ; (2) une extrémité sur une arête existante (à `TOL`) **coupe** cette arête en deux (les faces bordantes gagnent ce sommet, les courbes gardent leurs arêtes) ; (3) les intersections avec les arêtes coplanaires du même contexte coupent les deux arêtes ; (4) un segment colinéaire et superposé à une arête existante est fusionné avec elle (pas de doublon) ; (5) **faces automatiques** : pour chaque nouvelle arête et chaque plan qui la contient avec au moins une arête voisine, parcours du sous-graphe des arêtes de ce plan (virage minimal) ; chaque cycle simple fermé, d'au moins 3 arêtes, qui n'est pas déjà une face et qui ne contient pas d'autre arête du plan à l'intérieur, devient une face (cahier §5.4, obs) ; (6) **une arête qui relie deux points du bord d'une face, à l'intérieur de cette face, la divise en deux** (obs [OD §4]) ; une boucle fermée strictement intérieure à une face devient un **trou** de cette face et une face intérieure (obs indirect : rectangle dessiné sur une face puis percé [OM §1]) ; une arête intérieure qui ne ferme rien reste « sur la face » sans la couper ; (7) le collage n'agit **que dans le contexte** de l'ajout : un groupe ne colle à rien (obs [CM §5]) ; (8) une arête non coplanaire qui traverse une face ne la coupe pas (seule « Intersection des faces » le fait, lot 5 ; comportement non relevé). **Normale** d'une face créée : choix Fadi — +z pour une face horizontale (convention de SketchUp pour les faces au sol non relevée, cahier §9) ; sinon orientation cohérente avec les faces voisines de la même coque, vers l'extérieur si elle est fermée. |
| | **-c Effacement** (`effacerAretes`). Une arête effacée emporte **toute face qui en dépend** (obs [OD §3]) ; une arête d'une courbe emporte **toute la courbe** (obs) ; les sommets orphelins sont retirés ; l'arête commune de deux faces coplanaires effacée : les deux faces **fusionnent** en une — comportement documenté non vérifié (cahier L-25), livré comme choix Fadi déclaré. `effacerFaces` (menu contextuel « Effacer » sur une face) retire la face seule, ses arêtes restent (doc [S23]). |
| | **-d Différences.** Toute opération est une fonction pure `(Planche, arguments, generateur) → { planche, difference }` ; `difference` = { `crees`, `modifies` (avant, après), `supprimes` } par entité ; `appliquer(difference)` et `inverser(difference)` sont exacts (instantané différentiel, comme `interne.restaurer`, D-014). Au lot 7, une opération = une commande ; d'ici là, base de l'annulation locale. |
| | **-e Invariants** (`verifierContexte` → liste nominative d'erreurs, vide si correct) : sommets distincts deux à deux au-delà de `TOL` ; arête = deux sommets distincts existants, pas de doublon ; face : contour et trous fermés sur des arêtes existantes, plans à `TOL` près, trous intérieurs au contour et disjoints, normale unitaire perpendiculaire ; courbe : arêtes existantes, contiguës, dans l'ordre ; deux faces n'ont jamais le même contour. Chaque opération vérifie ses résultats ; une opération qui produirait un état invalide est **refusée** (erreur nommée, état inchangé), jamais corrigée en silence. |
| | **-f Sérialisation canonique** (`serialiser` / `relire`) : JSON à ordre de clés fixe, entités triées par identifiant, nombres tels quels ; `relire` revalide (invariants) et refuse un document invalide ou d'une version inconnue (`planche-geometrie/1`). |
| | **-g Mesures** : `aireFace` (contour moins trous, m²), `estSolide(contexte)` (chaque arête borde exactement 2 faces, définition [DOC §3.8, S21]) et motifs de refus nommés (arêtes bordant 0, 1 ou ≥ 3 faces), `volume` (théorème de la divergence sur une coque fermée orientée, m³), `composantesConnexes`. |
| Données et dépendances | Aucune dépendance (manifest `allowedDependencies: []`, R6) ; aucune écriture au modèle de l'Atelier au lot 1 ; pas de révision. Lot 7 : la Planche devient une classe du modèle de l'Atelier (décision P-1), ses opérations des commandes. |
| Résultats | Un nouvel état de Planche et sa différence ; des listes d'erreurs nommées ; des mesures. |
| Cas limites | Segment de longueur < `TOL` : refusé (« segment nul ») ; trois points alignés fermant une « boucle » : pas de face ; boucle non plane : pas de face (les arêtes restent) ; sommets à `TOL` + ε : distincts (pas de fusion approximative en cascade) ; boucle qui touche le bord d'une face en un seul point : trou refusé, choix Fadi (face non créée, arêtes gardées), déclaré ; effacement d'une arête inexistante : erreur nommée ; coordonnées non finies (NaN, ∞) : refusées. |
| Compatibilité | Interne (`planche-geometrie/1`). IFC (lot 7) : `IfcBuildingElementProxy` en tessellation depuis ces faces (cahier C14). manifold-3d (lot 6) : conversion vers et depuis `MeshGL` à spécifier dans la fiche du lot 6. |
| Validation | **Unité** (`geometrie-libre.test.ts`), valeurs vérifiables à la main : (1) quatre segments (0;0;0)→(4;0;0)→(4;3;0)→(0;3;0)→(0;0;0) → 4 sommets, 4 arêtes, **1 face** d'aire 12, normale (0;0;1) ; (2) segment (2;0;0)→(2;3;0) sur cette face → **2 faces** d'aire 6 chacune, arêtes du bas et du haut coupées (6 sommets, 7 arêtes) ; (3) les 12 arêtes d'une boîte 4 × 3 × 2 ajoutées une à une → 6 faces, `estSolide` vrai, `volume` = 24 ; (4) deux boîtes 4 × 3 × 2 identiques posées face contre face (la seconde décalée de 4 sur x) → **11 faces et 20 arêtes (31 entités)**, la face x = 4 unique et bordant les deux volumes (relevé [CM §5] : 31 entités) ; (5) effacer une arête du rectangle de (1) → 3 arêtes, 0 face ; (6) polygone de 6 côtés enregistré comme courbe : effacer un côté → 0 arête, 0 face ; (7) carré 1 × 1 au centre de la face de (1) → la grande face a un trou, aire 11, nouvelle face d'aire 1 ; (8) segment de (0;0;0) à (0;0;1e-7) → refusé ; (9) pour chaque cas, `inverser(difference)` appliqué rend une sérialisation identique à l'état initial, et deux sérialisations du même état sont identiques octet pour octet ; (10) un groupe contenant une boîte et une boîte libre qui le chevauche : aucune arête de la racine n'est coupée ; (11) même suite d'opérations avec le même générateur → mêmes identifiants. **API, e2e** : sans objet au lot 1. |
| Règles métier | Aucune règle réglementaire. Repère : toute coordonnée est `local` (R5). Aucune donnée de projet supposée (R3) : une Planche vide n'a ni personnage d'échelle ni matériau prédéfini. |
| Extensions à spécifier | Transformations avec collage (Déplacer, Rotation, Échelle, copies : lot 3) et découpe des faces coplanaires qui se recouvrent (relevé [CM §5] : un chevauchement découpe les faces ; le décompte de 75 entités du relevé n'est pas reconstituable sans l'état exact de départ et n'est pas utilisé comme cas de test) ; pliage automatique ; Pousser / tirer (lot 3) ; composants et occurrences (lot 5) ; matériaux d'apparence (lot 5, cahier C15) ; booléens (lot 6) ; arêtes adoucies groupées en surfaces. |
