| --- | --- |
| Identité | PL-04-04, machine pure `outils/texte.ts` ; saisie par l'interface (`Transition.editerTexte`, zone de texte flottante). Référence : §4.31, relevé [MCP §1.5]. |
| Situation utilisateur | Annoter une face, une arête ou un point avec un repère (texte proposé : aire, longueur ou coordonnées), ou poser un texte libre à l'écran. |
| Entrées et unités | Clic sur une entité (épingle) puis clic de placement → saisie ; clic dans le vide → texte écran, saisie ; Entrée valide, Maj + Entrée = retour à la ligne, Échap garde le texte proposé. |
| Comportement | État `EtatTexte` { `etape` 1 \| 2 \| 3, `ancre`, `entite`, `defaut`, `enEdition`, `inference` }. Étape 2 : aperçu de la ligne de repère et de l'étiquette ; placement = annotation créée (un pas) + `editerTexte` ; `saisie` remplace le texte **dans le même pas** (`remplaceDernier`) ; clic ailleurs ou Échap termine. |
| Données et dépendances | `annotations.ts` (`TexteAnnotation` repère / écran), `formaterAire`, `formaterLongueur`, `inference.ts`. |
| Résultats | Un texte avec repère (monde) ou un texte écran (pixels), affiché par la vue, sélectionnable et effaçable par Suppr. |
| Cas limites | Saisie identique au texte proposé : rien n'est ajouté à l'historique ; saisie sans texte posé : message. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-TXT-1 → « face de 10,8 m² → « 10,8 m² » proposé, remplacé par la saisie » ; texte écran. **e2e** : « 12,0 m² » proposé, « Salon », texte écran « Saisissez le texte » gardé après Échap, deux étiquettes. |
| Règles métier | Aucune. L'aire proposée est figée à la création (choix déclaré, relevé nv). |
| Extensions à spécifier | Info entité (police, extrémités, alignement) ; texte lié qui suit l'aire modifiée. |
