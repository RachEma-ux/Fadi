| Champ | Contenu |
| --- | --- |
| Identité | PL-05-01, machines pures `outils/peinture.ts` (`machinePeinture`, `machineEchantillon`) ; panneau Matériaux dans `Planche.tsx`. Référence : §4.24, §4.25, P-8 (D-170). Raccourci : B. |
| Situation utilisateur | Peindre des faces ou des objets avec une matière de la Planche (couleur unie) ; prélever la matière d'une face pour la réutiliser. |
| Entrées et unités | Matière courante choisie au panneau Matériaux (créer : nom + couleur) ; clic = face ; Ctrl = faces connectées de même matière ; Maj = toutes les faces de cette matière ; Maj + Ctrl = même objet ; Alt = prélever ; clic sur un objet = matière de l'occurrence. Prélever : clic sur une face → matière courante, Pot de peinture activé. |
| Comportement | `EtatPeinture` { maj, ctrl, alt, survol }. Une face garde sa matière propre (`materiauRecto`) ; un objet peint de l'extérieur porte la matière sur l'occurrence et ses faces sans matière la montrent (`FaceVisible.materiau` héritée). Chaque clic = un pas (`peindreFaces`, `peindreOccurrences`, `peindreFacesPartout`). `materiauVise` remonte la chaîne d'occurrences. |
| Données et dépendances | `annotations.ts` (`Materiau`), `geometrie-libre.ts`, `inference.ts` ; rendu par couleurs de sommets (`majModele`). |
| Résultats | Faces et objets colorés ; matière courante affichée au panneau. |
| Cas limites | Matière supprimée : « La matière choisie n'existe plus » ; clic hors face / objet : message ; lecteur : outil refusé. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-PEI-1 à -6 → `materiau.test.ts` (une face ; Ctrl = 5 faces, l'avant brun inchangé ; Maj = partout ; Maj + Ctrl = l'objet ; groupe vert : occurrence seulement ; un pas par clic) ; CA-PRE-1 → Prélever bascule. **e2e** : panneau, « Brique », clic sur une face, Maj + clic, matière par défaut, Prélever puis peindre. |
| Règles métier | P-8 : couleur unie, sans bibliothèque ni texture. |
| Extensions à spécifier | Peindre une arête, le verso ; bibliothèque de matières de l'Atelier (C15) ; Info entité. |
