| Champ | Contenu |
| --- | --- |
| Identité | PL-02-01, machines d'états pures `machineSelection` (`packages/planche-model/src/outils/selection.ts`) et `machineLasso` (`lasso.ts`). Sous-exigences : -a Sélection (clic, double, triple, cadre, modificateurs, Échap, Suppr, contexte d'édition) ; -b Lasso (contour polygonal et libre, sens horaire / anti-horaire). Référence : `cahier-planche.md` §4.1, §4.2, §5.6 ; relevés [OD §1, §2], [OM §0.7], [CM §3.2]. |
| Situation utilisateur | Choisir des faces, arêtes, courbes, groupes ou composants pour les effacer, puis (lots suivants) les transformer ; entrer dans un groupe pour l'éditer et en sortir. |
| Entrées et unités | Événements `EvenementOutil` (`machine.ts`) : rayon caméra → curseur (repère `local`, m) et tolérance d'accrochage en mètres ; position écran (px) pour les cadres et contours ; touches Maj, Ctrl (maintenues), Suppr, Échap. Le rendu fournit `entitesDansCadre` / `entitesDansContour` (projection écran) ; la sélection est tenue par l'interface (`ContexteOutil.selection`). |
| Comportement | **Machine Sélection** — état `EtatSelection` { `maj`, `ctrl`, `appui` (px), `cadre` (de, a), `ignorerClic` } ; un seul état de repos, un état « cadre » pendant un glisser. **Repos** : clic → remplace la sélection par l'entité visée (face seule ; arête ; **courbe entière** ; occurrence de groupe / composant entière) ; clic dans le vide sans modificateur → tout désélectionner ; double-clic → face + arêtes bordantes, arête + faces qui la partagent (instr), groupe → **contexte d'édition** (`Transition.dans`) ; triple-clic → tout le connecté. **Appui puis glisser** au-delà de `SEUIL_GLISSER` = 3 px (choix Fadi) → état cadre ; relâcher : de gauche à droite = **fenêtre** (entièrement contenu), de droite à gauche = **croisée** (touché) ; le clic qui suit le relâchement est ignoré. **Modificateurs maintenus** : Maj = basculer, Ctrl = ajouter, Maj + Ctrl = retirer (obs). **Échap** : pendant un cadre, l'annule ; en contexte d'édition, en sort ; sinon vide la sélection. **Suppr** : efface la sélection en un pas (`effacerEntites` : face seule → ses arêtes restent ; arête → courbe et faces dépendantes ; occurrence retirée). Visée : une face devant une arête la masque. Aucune pré-surbrillance au survol (obs). |
| | **Machine Lasso** — état `EtatLasso` { `maj`, `ctrl`, `points` (px), `curseur`, `appui`, `libre`, `ignorerClic` }. Étape 1 (repos) → clic = 1er sommet → étape 2 (« Double-cliquez pour fermer le contour de sélection ») : clics = sommets, élastique jusqu'au curseur, carré rouge au départ ; double-clic → fermeture et application. **Contour libre** (instr) : appuyer, glisser, relâcher → appliqué. **Sens** : aire écran > 0 (horaire, y vers le bas) = fenêtre, anti-horaire = croisée — le relevé fait foi contre [DOC §1.2]. Moins de 3 sommets distincts (clic puis double-clic sur place) = clic de Sélection sur l'objet visé (obs « comme Sélection »). Modificateurs comme la Sélection (relevé : Ctrl = ajouter ; Alt de [DOC §1.2] écarté). Échap avant fermeture : aucun changement. |
| Données et dépendances | Lit le modèle (`geometrie-libre.ts` : `aretesDeLaCourbe`, `aretesDeFace`, `facesDeLArete`, `entitesConnectees`, `matriceMonde`) ; la sélection et le contexte d'édition sont de l'**état d'interface** (R10) ; seule Suppr produit un nouveau modèle (un pas d'annulation local). |
| Résultats | Nouvelle sélection (`Transition.selection`), contexte d'édition (`Transition.dans`), modèle effacé (Suppr). |
| Cas limites | Clic dans le vide avec Ctrl : sélection inchangée ; courbe au cadre : prise en fenêtre seulement si toutes ses arêtes sont dedans, en croisée dès qu'une est touchée ; contour du Lasso dégénéré (< 3 sommets distincts) : traité comme un clic ; lecteur (C25) : Sélection et Lasso restent permis, Suppr n'écrit rien (`readOnly`). |
| Compatibilité | Sans objet (aucun format). |
| Validation | **Unité** — CA-SEL-1 → `selection.test.ts` « CA-SEL-1 : clic sur une face → la face seule, aucune arête » ; CA-SEL-2 → « CA-SEL-2 : double-clic sur une face → la face et ses 4 arêtes » ; CA-SEL-3 → « triple-clic sur une boîte libre → 6 faces et 12 arêtes » ; CA-SEL-4 → « clic sur un segment d'un polygone à 6 côtés → les 6 arêtes » ; CA-SEL-5 → « fenêtre gauche → droite … croisée droite → gauche » ; CA-SEL-6 → « Maj + clic ×2 → absente ; Ctrl + clic ×2 → présente ; Maj + Ctrl + clic → absente » ; CA-SEL-7 → « la sélection ne change jamais le modèle » ; compléments : double-clic sur une arête, clic dans le vide, Échap, Suppr, groupe (clic, double-clic, Échap), visée. CA-LAS-1 → `lasso.test.ts` « CA-LAS-1 : contour horaire autour du cercle entier … » ; CA-LAS-2 → « Échap avant fermeture → aucun changement de sélection » ; compléments : sens, fenêtre partielle, Ctrl / Maj + Ctrl, clic simple, contour libre. **e2e** : `planche.mjs` (Échap, clic dans le vide au toucher). |
| Règles métier | Aucune. R10 : la sélection ne touche jamais la révision ni le modèle. |
