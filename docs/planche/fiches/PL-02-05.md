| Situation utilisateur | Poser un cercle ou un polygone régulier exact (rayon, nombre de côtés), au sol, sur une face ou dans un plan verrouillé, puis corriger le dernier tracé. |
| Entrées et unités | Rayon, tolérance (m) ; Mesures : étape 1 « Côtés » (nombre ou `Ns`, bornes 3 à 999), étape 2 « Rayon » (m) / « Rayon inscrit » / « Rayon circonscrit » ; Ctrl + / Ctrl − ; Ctrl (polygone) ; flèches ; Maj. Valeurs par défaut **relevées** portées par le catalogue (24, 6 ; C2). |
| Comportement | État `EtatCirculaire` { `etape` 1 \| 2, `cotes`, `mode` (inscrit \| circonscrit), `verrouFleche`, `verrouMaj`, `normaleSurvol`, `centre`, `normale`, `contraint`, `direction`, `valeur`, `inference`, `texte`, `erreur`, `derniere` }. **Étape 1** (« Choisissez le centre. Ctrl « + » ou Ctrl « − »… » ; Mesures « Côtés · 24 ») : `12` ou `12s` → côtés ; Ctrl ± → ±1 ; flèches avant le clic (bascules) : normale sur l'axe → rouge, ← vert, ↑ bleu, ↓ normale inférée ; Maj maintenue : normale inférée verrouillée (instr) ; clic → centre → **étape 2** (« Choisissez un point du bord… » ; Mesures « Rayon · 1,29 m ») : `Ns` et Ctrl ± modifient l'aperçu ; clic ou rayon tapé → courbe fermée (**une seule courbe**, genre `cercle` / `polygone`) et **face** ; **le 1ᵉʳ sommet est dans la direction du curseur** (cercle, polygone inscrit ; circonscrit : milieu d'un côté vers le curseur). Retour à l'étape 1, outil gardé ; le nombre de côtés est **mémorisé** pour la forme suivante. **Correction après coup** : un rayon ou `Ns` juste après la création reconstruit la dernière forme (`remplaceDernier`, un pas) ; après une autre action : refusée. **Polygone** : Ctrl (bascule) = rayon inscrit (centre → sommet, défaut) / circonscrit (centre → milieu d'un côté, apothème). Échap : annule, garde le nombre de côtés. |
| Données et dépendances | `geometrie-libre.ts` (courbe fermée avec métadonnées centre, rayon, normale — attributs subordonnés, jamais une seconde géométrie, C8) ; `commun-formes.ts` (visée du plan, formatage, catalogue, correction). |
| Résultats | Une courbe fermée de n arêtes et sa face ; un pas d'annulation. |
| Cas limites | `1000` ou `2` côtés : erreur relevée « Le nombre de segments d'une courbe doit être compris entre 3 et 999 », état inchangé (annoncée dans la barre d'état ; **écart** : le relevé montre une alerte modale [OK], l'interface l'annonce sans boîte modale) ; rayon nul, négatif ou texte : erreur nommée ; Ctrl − à 3 : reste à 3. |
