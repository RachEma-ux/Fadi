| Identité | PL-04-06, outils de caméra **sans machine** (état de vue, R10) : `vue-planche.ts` (`cadrer`, `zoomFenetre`, `positionnerCamera`, `regarder`, `marcher`, `hauteurOeil`, `emprise`), `outils-planche.ts` (`OUTILS_CAMERA`, temporaires), `Planche.tsx` (Mesures Hauteur / Hauteur d'œil, `finOutilCamera`). Référence : §4.34, relevé [MCP §2]. |
| Situation utilisateur | Cadrer tout le modèle, agrandir une zone, se placer à hauteur d'œil et regarder ou marcher dans la Planche. |
| Entrées et unités | Zoom étendu : immédiat (Ctrl + Maj + E). Zoom fenêtre : glisser (Maj + W). Positionner la caméra : clic au sol (glisser = direction), Mesures « Décalage de hauteur » 1,68 m. Regarder autour : glisser ; Marcher : glisser (haut / bas avance, gauche / droite tourne), Maj = vertical / latéral, Ctrl = courir ; Mesures « Hauteur d'œil ». Échap rend l'outil précédent. |
| Comportement | Zoom étendu cadre l'emprise de la géométrie visible dans la zone non couverte (marges mesurées : barre d'outils, colonne, panneau, haut, pied) sans changer l'outil. Zoom fenêtre et Positionner la caméra sont **temporaires** : fin du geste → outil précédent, ou Regarder autour après Positionner. La hauteur d'œil est un état de vue réglable au champ Mesures (longueur > 0). |
| Données et dépendances | `vue-planche.ts` (three.js), catalogue (consignes et libellés Mesures). |
| Résultats | Une vue cadrée, agrandie, placée ou orientée ; aucun pas d'historique, aucune donnée. |
| Cas limites | Planche vide : Zoom étendu annonce « Rien à cadrer » ; fenêtre trop petite (< seuil de glisser) : rien ; hauteur ≤ 0 : refusée. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-CAM-3 → e2e « Zoom étendu : la caméra bouge, l'outil reste Sélection, le rectangle entier est dans le canevas » ; CA-CAM-4 → e2e « clic au sol en P → œil en P + (0;0;1,68), Regarder autour actif » ; « 2 » → hauteur d'œil 2 m ; Regarder autour pivote sur place ; Marcher avance à hauteur constante ; Zoom fenêtre agrandit (échelle > ×1,5) puis rend Sélection. |
| Règles métier | R10 : la révision ne change jamais ; R13 : permis au lecteur. |
| Extensions à spécifier | Détection de collision de Marcher (Alt) ; vitesse de marche réglable. |
