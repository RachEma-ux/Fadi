# PL-17-01 — Édition des pièces de profilé — lot Planche L17

| Champ | Contenu |
| --- | --- |
| Identité | PL-17-01 ; noyau `changerSectionPiece`, `tournerPieceAxe`, `alignerFacePiece`, `axesDesPieces`, échelle axiale dans `mettreAEchelle` (`geometrie-libre.ts`) ; `placement.rotationAxe` (`profiles.ts`) ; outil `aligner-face` (`outils/assemblages-pieces.ts`) ; commandes `COMMANDES_PIECE` (famille `piece`) ; bloc `data-planche-piece-edition` de `Planche.tsx`. |
| Situation utilisateur | Corriger une pièce posée sans la reposer : changer sa section, la tourner sur son axe, l'aligner sur une face, l'allonger à l'échelle. |
| Entrées | Une seule pièce sélectionnée ; section du panneau Profilés (catalogue sourcé, saisie, face) ; angle en degrés ; face de la pièce et face cible ; facteur d'échelle. |
| Comportement | Section : géométrie régénérée depuis les métadonnées (même axe, même longueur, onglets rejoués, liens gardés, nouvelle source enregistrée), un pas. Rotation : angle cumulé autour de l'axe. Aligner : translation le long de la normale de la face cible. Échelle : le long de l'axe seulement. |
| Commandes (règle d'or) | Appliquer la section ⇆ **Alt+Maj+S** ; Rotation axiale ⥁ **Alt+Maj+H** (barre du bloc d'édition, registre) ; Aligner une face ⫠ **Alt+Maj+F** (barre Volumes · Modifier). |
| Cas limites | Pièce recoupée par un profil : section et rotation refusées avec motif. Faces non parallèles : refus. Échelle transversale ou pièce coupée : refus nommé. Aucune section choisie : Appliquer grisé. Lecture seule : grisé. Angle nul ou invalide : message. |
| Compatibilité | `rotationAxe` est facultatif : les fichiers anciens sont inchangés. |
| Règles métier | Une section vient d'une source ou d'une saisie déclarée, jamais d'une déformation (R3). |
| Extensions à spécifier | Rejouer une coupe par profil après changement de section ; édition de plusieurs pièces à la fois. |
