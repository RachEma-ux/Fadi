# PL-07-01 — Planche commands and delta persistence / Commandes de Planche et persistance par différence — mode Planche → Atelier — lot Planche 7

**État : disponible — acceptée le 8 octobre 2026 (D-174)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `delta.test.ts`, `planches.test.ts`, `atelier-planches.test.ts` (API).

| Champ | Contenu |
| --- | --- |
| Identité | PL-07-01, `packages/planche-model/src/delta.ts` (`differencePlanche`, `appliquerDeltaPlanche`, `empreintePlanche`, `lireModelePlanche`, `estDeltaPlanche`), `packages/atelier-model/src/commandes/planches.ts` (`planche.creer / renommer / copier / supprimer / operation`, `planches()`, `lireParamsPlanche`), contrat `atelier-commands/2`. Référence : cahier-planche §8 lot 7, §5.7, P-1 (D-167), D-172. |
| Situation utilisateur | Que chaque geste de la Planche soit enregistré dans le projet comme n'importe quelle commande de l'Atelier : journalisé, annulable, rejouable, validé par le serveur. |
| Entrées et unités | `planche.creer { id?, nom, niveauId?, modele? }`, `planche.renommer { id, nom?, niveauId? }`, `planche.copier { id?, source, nom }`, `planche.supprimer { id }`, `planche.operation { id, libelle, delta, empreinteApres }` ; coordonnées du modèle en mètres, repère `local` de la Planche. |
| Comportement | La Planche est une `Definition` de classe `planche` (`params`: nom, niveauId, modele, empreinte). `planche.operation` : `appliquerDeltaPlanche(modele, delta)` puis `empreintePlanche` comparée à `empreinteApres` ; différente → `ErreurCommande("precondition")` (409). Inverse = instantané différentiel (définition d'avant). Noms uniques (accents ignorés), 120 caractères ; niveau connu ou `null`. |
| Données et dépendances | `@parcours/planche-model` (dépendance déclarée dans `manifest.json`), `atelier_definitions` (jsonb) via le différentiel existant. |
| Résultats | Une entrée de journal par pas ; empreinte stable d'un poste à l'autre (clés triées, forme canonique des annotations). |
| Cas limites | Delta mal formé → `invalide` ; modèle de brouillon mal formé → `invalide` ; rejouer un delta à l'identique ne change rien (idempotent au niveau du modèle ; l'idempotence du lot est celle du `requestId`) ; Planche modifiée entre-temps → `precondition`. |
| Compatibilité | Lots `atelier-commands/1` acceptés ; archive : paramètres revalidés (`lireParamsPlanche`, empreinte recalculée). |
| Validation | `delta.test.ts` (3), `planches.test.ts` (2), `atelier-planches.test.ts` (1 scénario complet contre PostgreSQL). |
| Règles métier | R9 (mêmes réducteurs purs, inversible), MO-2 (file, annuler / rétablir, réservations existants). |
| Extensions à spécifier | Compactage des inverses pour les grandes Planches ; fusion de deltas concurrents (CRDT) non prévue. |
