| Comportement | **Arc par le centre / Secteur** — état `EtatArcCentre` { `etape` 1 \| 2 \| 3, `cotes`, `verrouFleche`, `verrouMaj`, `normaleSurvol`, `centre`, `normale`, `contraint`, `rayon`, `depart`, `balayage`, `angleBrut`, `inference`, `texte`, `erreur`, `derniere` }. Étape 1 « Côtés · 12 » → clic = centre ; étape 2 « Longueur » → clic ou rayon tapé = départ ; étape 3 « Angle » → clic ou angle tapé. L'angle balayé suit le curseur **en continu** (au-delà de 180°) ; un angle tapé prend le sens du balayage courant (direct par défaut), négatif = sens inverse (choix Fadi déclaré). Arc : **courbe seule**, sans face ni rayons (obs). Secteur : arc + 2 rayons, **face** (`ajouterSecteur`). `Ns` juste après la création reconstruit (un pas). Erreurs : angle 0 ou 360, rayon nul, côtés hors bornes. Échap annule. |
| | **Arc 2 points** — état `EtatArc2Points` { `etape` 1 \| 2 \| 3, `cotes`, `verrouTangence`, `normaleSurvol`, `debut`, `normale`, `tangente`, `fin`, `perp`, `fleche`, `apercu`, `inference`, `texte`, `erreur`, `derniereFleche`, `derniere` }. Étape 1 (départ) → étape 2 (fin ; « Longueur » = corde) → étape 3 (« Flèche » = distance corde → milieu de l'arc, du côté du curseur ; `Nr` = rayon, arc mineur — doc, nv, livré et déclaré). **Arc tangent** depuis l'extrémité d'un arc : aperçu tangent (« Tangente au sommet ») ; **double-clic** au point final → arc tangent sans étape de flèche, retour à l'étape 1 (obs [CM §8]) ; le rendu peut émettre clic puis clic double au même point : traité de même ; clic simple → étape de flèche. **Alt (bascule « Verrouiller la tangence »)** : 2 clics suffisent, l'outil **enchaîne** depuis la dernière extrémité ; Échap termine la chaîne. Après une création, l'étape 1 affiche la dernière flèche ; une longueur tapée n'y est pas une correction. Inférence « Demi-cercle », congé par double-clic sur un coin : doc seule → non livrés. |
| | **Arc 3 points** — état `EtatArc3Points` { `etape` 1 \| 2 \| 3, `cotes`, `normaleSurvol`, `debut`, `normale`, `second`, `curseur`, `apercu`, `inference`, `texte`, `erreur`, `derniere` }. Départ ; 2ᵉ point (« Longueur » : distance départ → 2ᵉ point dans la direction du curseur) ; fin (« Angle » = angle balayé). L'arc **passe toujours** par le 2ᵉ point, même au-delà de 180°. **Angle tapé (choix Fadi, non relevé)** : sur le cercle de l'aperçu courant (départ, 2ᵉ point, curseur) s'il existe, sinon sur le cercle dont le 2ᵉ point est le milieu de l'arc ; l'angle doit dépasser celui du 2ᵉ point. Alt (tangence) : Instructor seul → non livré. |
