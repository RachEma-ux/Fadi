# PL-05-05 — Context menu and selection shortcuts / Menu contextuel et raccourcis de sélection — mode Planche → Atelier — lot Planche 5

**État : disponible — acceptée le 8 octobre 2026 (D-174)**. Preuve liée : `objets.test.ts` (`etendreSelection`, masquer, verrouiller, inverser / orienter les faces, adoucir, aire) ; recette `planche-lot-5.mjs` (menu, selectionner, verrou, aire, aligner-vue, aligner-axes, zoom-selection).

| Champ | Contenu |
| --- | --- |
| Identité | PL-05-05, `MenuContextuel` (`panneaux-objets.tsx`), rappel `menuContextuel` de `vue-planche.ts`, construction des entrées dans `Planche.tsx` (`ouvrirMenuContextuel`) ; noyau `etendreSelection`, `masquerEntites`, `afficherTout`, `verrouillerOccurrences`, `inverserFaces`, `orienterFaces`, `adoucirAretes`, `diviser`, `aire`, `opererSolides`. Référence : §5.8, §5.10, D-171. |
| Situation utilisateur | Agir sur ce qui est sous le curseur sans changer d'outil. |
| Entrées et unités | Clic droit dans le dessin (souris) ; Échap ou clic hors du menu ferme ; `Ctrl + A`, `Ctrl + Maj + I`, `K`. |
| Comportement | L'entité visée (annotation, arête, face, objet — masqués et adoucis exclus) rejoint la sélection si elle n'y est pas ; les entrées dépendent de la cible : face (Info, Effacer, Masquer, Sélectionner ▸, Aire ▸, Créer un composant…, Créer un groupe, Intersection ▸, Aligner la vue, Aligner les axes, Inverser / Orienter les faces, Texture unique grisé, Zoom), arête (+ Adoucir / Durcir, Diviser en 2), objet (+ Verrouiller, Modifier le groupe / composant, Éclater, Rendre unique, Coque extérieure à deux solides, Adoucir / lisser, grisés relevés), vide (Coller, Réafficher). Chaque entrée = une opération du noyau = un pas. Sélectionner ▸ : arêtes bordantes, faces connectées, tout le connecté, même balise, même matériau, désélectionner les faces, inverser. Aire ▸ : somme des faces de la sélection / de même balise / de même matériau (m², précision d'affichage). |
| Données et dépendances | `ElementScene` (`viser`, `cibleDans`, `viserAnnotation`), `OptionsAffichage`. |
| Résultats | Sélection étendue ; entités masquées / verrouillées ; faces inversées ; repère posé ; caméra alignée ; message d'aire. |
| Cas limites | Clic droit dans le vide → menu réduit ; menu trop long → défilement interne ; clic droit tactile (appui long) : non livré (nv). |
| Compatibilité | Libellés français du relevé, traduits dans `en.json`. |
| Validation | e2e : 18 entrées sur un composant, Rendre unique grisé / actif, Suppr refusé sur un objet verrouillé, Sélectionner ▸ Tout le connecté → 25 entités, Ctrl + Maj + I, Ctrl + A, Aire 12,000 m², repère z = normale, caméra à l'aplomb, face dans le canevas après Zoom. |
| Règles métier | Approche menu = raccourci des mêmes commandes (C6), jamais une autre voie d'écriture. |
| Extensions à spécifier | Appui long tactile ; Souder, Trouver le centre, Convertir en polygone, Éclater la courbe (nv). |
