# PL-01-03 — Inference engine / Inférences (accrochages, verrous, couleurs) — mode Planche → Atelier — lot Planche 1

**État : spécifiée** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : —.

| Champ | Contenu |
| --- | --- |
| Identité | PL-01-03, moteur d'inférence 3D de la Planche (`packages/planche-model/src/inference.ts`). Sous-exigences : -a inférences de point ; -b inférences linéaires ; -c inférences de surface ; -d verrous (flèches, Maj, cycle Alt) ; -e priorité déterministe ; -f libellés et jetons de couleur ; -g accrochage de longueur et d'angle. Référence : `cahier-planche.md` §5.1, §5.2 ; relevés [OD §4, §15.3–15.4], [OM §0.6], [CM §7–8], [MCP §0, §7.2], [DOC §7]. Distincte de l'accrochage 2D de l'Atelier (DA-02-15), dont elle reprend les principes (point exact calculé sur la géométrie, libellé textuel, ordre déterministe). |
| Situation utilisateur | (Servie à partir du lot 2.) Pendant un geste, voir le point remarquable visé (« Extrémité », « Milieu », « Sur l'axe rouge »…) avant de cliquer, le verrouiller sur un axe ou un plan, et poser un point **exact**. |
| Entrées et unités | `planche` (PL-01-01 : contextes, groupes avec leur transformation) ; `vue` = { `matrice` : 16 nombres (vue × projection, colonne par colonne), `largeur`, `hauteur` en pixels } — **jamais un objet three.js** (R6) ; `curseur` { x, y } (px) ; `rayonPx` (rayon de capture en pixels ; valeur de SketchUp non relevée → choix Fadi, défaut 12 px comme l'Atelier, D-012) ; `reference` (point précédent du geste, facultatif ; m, repère local) ; `memoire` = { `derniereAreteSurvolee`, `pointsMemorises` (derniers points survolés, pour « Depuis un point ») } ; `verrous` = { `fleche` ∈ { aucune, rouge, verte, bleue, parallele }, `mode` ∈ { direction, plan } (fourni par le catalogue selon l'outil et l'étape, cahier §5.2), `maj` (inférence verrouillée ou aucune), `lineaires` ∈ { toutes, aucune, parallele-perpendiculaire } } ; `axes` (repère de saisie : origine + 3 directions unitaires, défaut = repère local) ; `accrochages` { longueur (m, défaut **0,01**, actif), angle (degrés, défaut **15**, actif) } — défauts relevés dans Info modèle [CP]. |
| Comportement | **-a Points** (distance écran ≤ `rayonPx`) : Extrémité (sommet), Milieu (milieu d'arête), Centre (centre porté par les métadonnées d'un arc, d'un cercle, d'un polygone), Intersection (deux arêtes qui se coupent en 3D à `TOL` près), Origine (origine des axes), Point de guide (lot 4). Point calculé sur la géométrie en double précision, jamais déduit des pixels ; candidat `exact: true`. |
| | **-b Linéaires** (seulement si `reference` est fournie et `lineaires` ≠ aucune) : Sur l'axe rouge / vert / bleu (droite passant par `reference` selon une direction des `axes`) ; Parallèle à l'arête et Perpendiculaire à l'arête (direction de `derniereAreteSurvolee` ou sa perpendiculaire dans le plan courant) ; Depuis un point (le point est aligné, selon un axe, sur un point de `pointsMemorises` ; rendu en pointillés de la couleur de l'axe depuis ce point) ; Tangent au sommet (si `reference` est l'extrémité d'un arc : direction de sa tangente). Le point est le point de la droite le plus proche du rayon du curseur ; il est `exact` pour la direction, et sa distance à `reference` est **accrochée** au pas de longueur s'il est actif (interprétation des relevés : valeur sans « ~ » en tracé libre, `~` en tracé contraint — à confirmer, cahier §9). En `parallele-perpendiculaire`, seules ces deux inférences linéaires restent (obs [CM §7]) ; en `aucune`, aucune inférence linéaire ; l'effet sur les inférences de point n'est pas relevé → elles restent actives (choix Fadi). |
| | **-c Surfaces** : Sur l'arête (point le plus proche sur l'arête), Sur la face (intersection du rayon avec la face visible la plus proche, losange) ; candidats les moins prioritaires avant le point libre. |
| | **-d Verrous.** `fleche` en mode **direction** : le point est contraint sur la droite `reference` + t · axe (ou la direction parallèle) — libellé « Contraint sur une ligne », candidat `exact: false` pour la longueur (Mesures en « ~ ») ; `parallele` sans `derniereAreteSurvolee` : longueur bloquée à 0 (obs [OD §4]). En mode **plan** (formes, avant le 1ᵉʳ clic) : la normale du plan de dessin est l'axe choisi — libellé « Contraint sur un plan ». `maj` : l'inférence verrouillée (droite ou plan) contraint le point tant que le verrou est fourni (le maintien de la touche est géré par l'interface). La fonction ne connaît pas le clavier : elle reçoit l'état des verrous (cahier §5.5). |
| | **-e Priorité** (choix Fadi déclaré, l'ordre de SketchUp n'étant ni documenté ni relevé) : verrou actif d'abord (il contraint tous les autres) ; puis points (Extrémité, Intersection, Milieu, Centre, Origine, Point de guide) ; puis linéaires (axes, parallèle, perpendiculaire, tangente, depuis un point) ; puis Sur l'arête, Sur la face ; sinon point libre (sur le plan de dessin courant, défaut : plan du sol z = 0 du repère de saisie). À égalité : distance écran, puis identifiant d'entité (ordre déterministe). `inferer(...)` rend le meilleur candidat et la liste ordonnée (pour un futur cycle au clavier). |
| | **-f Libellés et couleurs** (jetons, valeurs par défaut relevées dans Settings > Accessibility [MCP §7.2]) : `axe-rouge` rgb(255,0,0), `axe-vert` rgb(0,255,0), `axe-bleu` rgb(0,0,255), `parallele` rgb(255,0,255) (magenta), `tangente` rgb(0,255,255) (cyan) ; marqueurs : Extrémité point vert, Milieu point cyan, Sur l'arête carré rouge, Sur la face losange bleu, Origine cercle noir, Intersection X rouge (doc, nv). Libellés français : « Extrémité », « Milieu », « Centre », « Intersection », « Origine », « Sur l'arête », « Sur la face », « Sur l'axe rouge / vert / bleu », « Parallèle à l'arête », « Perpendiculaire à l'arête », « Depuis un point », « Tangent au sommet », « Contraint sur une ligne », « Contraint sur un plan », « Plan libre ». Un candidat dans un groupe est suffixé « dans *nom* » (relevé : « Endpoint in Ty … » avec coordonnées [MCP §0]). |
| | **-g Accrochage d'angle** (`accrocherAngle(angle, pas, tolerance)`) pour le rapporteur (Rotation, Rapporteur, Rectangle tourné, arcs) : un angle à moins de `tolerance` d'un multiple de `pas` (15° relevé) est ramené à ce multiple et rendu exact (relevé : `90.0` sans « ~ » quand accroché [OM §3]) ; tolérance de SketchUp non relevée → choix Fadi (fiche du lot 2). |
| Données et dépendances | Fonction pure (R6) ; lit la Planche, n'écrit rien, aucune révision (R10). Entités masquées (attribut `masquee`) non inférables (choix Fadi, non relevé). Groupes : leurs sommets et arêtes sont inférables après application de leur transformation (lecture seule, collage inchangé). |
| Résultats | Candidat { `type`, `point` (Vec3 local), `exact`, `libelle`, `jeton` (couleur), `entite` (identifiant et caractéristique visée, ex. sommet, milieu d'arête), `droite` ou `plan` éventuels (pour le rendu des pointillés), `ecartPx` } et la liste ordonnée des candidats. |
| Cas limites | Aucune géométrie et aucune référence : point libre sur le plan du sol ; rayon du curseur parallèle au plan de dessin : point libre refusé (aucun candidat, l'interface garde le dernier point valide) ; plusieurs candidats à égale distance : ordre déterministe ; arête dégénérée vue de bout (projection d'un point) : Extrémité prioritaire ; caméra dont la matrice n'est pas inversible : erreur nommée ; sommets derrière la caméra : ignorés. |
| Compatibilité | Sans objet (aucun format). Couleurs réglables (préférence locale, R10, cahier C20). |
| Validation | **Unité** (`inference.test.ts`), boîte 4 × 3 × 2 à l'origine, caméra de face fixée par une matrice écrite en clair dans le test : (1) curseur à 3 px du sommet (4;0;0) projeté → Extrémité, point (4;0;0) exact ; (2) curseur au milieu projeté de l'arête (0;0;0)–(4;0;0) → Milieu (2;0;0) ; (3) curseur sur l'arête loin des extrémités et du milieu → Sur l'arête, point sur l'arête à 1e-9 près ; (4) curseur au centre de la face avant → Sur la face, point dans le plan de la face ; (5) `reference` (0;0;0), curseur près de la projection de l'axe x, à 2,64 m → Sur l'axe rouge, point (2,64;0;0) avec accrochage 0,01 m ; (6) même cas, `fleche` = rouge, curseur loin de l'axe → point sur l'axe x le plus proche du rayon, libellé « Contraint sur une ligne », `exact: false` ; (7) `lineaires` = aucune → aucun candidat d'axe ; `parallele-perpendiculaire` → seuls parallèle et perpendiculaire ; (8) `derniereAreteSurvolee` de direction (1;1;0), `fleche` = parallele, `reference` (0;0;0) → point sur la droite t · (1;1;0)/√2 ; sans arête survolée → point = `reference` (longueur 0) ; (9) deux sommets à égale distance écran → le plus petit identifiant ; (10) `accrocherAngle(89,7, 15, 1)` → 90 exact, `accrocherAngle(80, 15, 1)` → 80 non exact ; (11) sommet d'un groupe translaté de (10;0;0) → Extrémité « dans *nom* » au point transformé ; (12) arête masquée → non proposée. **API, e2e** : sans objet au lot 1. |
| Règles métier | Aucune. Repère : tout point rendu est `local` ; une saisie dans le repère de saisie (outil Axes) est convertie explicitement (R5). |
| Extensions à spécifier | Inférences de forme (Carré, Section dorée, Demi-cercle — cahier L-20) au lot 2 avec les outils qui les portent ; Prolongement d'arête, « Par un point », inférence encouragée par pause du curseur (doc) ; points et lignes de guide (lot 4) ; inférences dans un contexte d'édition (magenta selon la doc, L-20) ; plan d'une face verrouillé par Maj + Alt (doc) ; cycle des candidats au clavier ; capture au toucher (loupe, rayon adapté), comme DA-02-15. |
