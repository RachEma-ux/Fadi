| Champ | Contenu |
| --- | --- |
| Identité | PL-05-02, machine pure `outils/balise.ts` ; panneau Balises dans `Planche.tsx` ; Ctrl + G (créer un groupe). Référence : §4.33, P-9 (D-170). |
| Situation utilisateur | Ranger les objets (groupes, composants) sous des balises visibles ou masquées, comme des calques. |
| Entrées et unités | Balise courante choisie au panneau (créer : nom + couleur ; case Visible) ; clic sur un objet ; Maj = remplacer l'identique ; Ctrl = toutes les occurrences du composant ; Alt = prélever. |
| Comportement | `EtatBalise` { maj, ctrl, alt, survol }. `baliserOccurrences` / `baliserDefinition` (un pas). Une balise masquée retire l'objet de la géométrie visible (`geometrieVisible`), de la scène de sélection (`scene`) et du rendu ; la case Visible est un pas d'historique. |
| Données et dépendances | `annotations.ts` (`Balise`), `geometrie-libre.ts`, `inference.ts`, `outils/selection.ts`. |
| Résultats | Objets balisés, visibilité par balise. |
| Cas limites | Aucune balise choisie : message « Choisissez d'abord une balise… » ; clic sur une face libre : message ; balise supprimée : message. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-BAL-1 → « balise choisie, clic sur un groupe → le groupe porte la balise ; masquer la balise masque le groupe » ; Ctrl = toutes les occurrences. **e2e** : création « Murs », clic → occurrence balisée, Visible décoché → non sélectionnable, Ctrl + Z → sélectionnable. |
| Règles métier | P-9 : une balise = un calque (correspondance avec D-012 au lot 7). |
| Extensions à spécifier | Balises imbriquées, verrouillage, renommage ; panneau de l'Atelier. |
