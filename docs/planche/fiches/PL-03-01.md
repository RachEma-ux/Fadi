| Situation utilisateur | Pousser ou tirer une face selon sa normale d'une distance exacte ou visée, jusqu'à fermer un solide ou le percer. |
| Entrées et unités | Face cliquée (étape 1) puis curseur ou valeur ; Mesures « Distance » (`longueur`) ; signe : > 0 sens de la normale (tirer), < 0 sens inverse (pousser) ; Ctrl, Alt. Mètres et degrés ; rayon et tolérance (m) reçus de la vue. |
| Comportement | État `EtatPousserTirer` { `etape` 1 \| 2, `nouvelleFace`, `etirement`, `face`, `normale`, `origine`, `contour`, `survol`, `distance`, `inference`, `texte`, `erreur`, `derniere` }. **Étape 1** : survol surligne la face ; clic sur une face de l'espace d'édition → étape 2 (face sélectionnée) ; clic sur un groupe : message (entrer dans le groupe). **Étape 2** : la distance est la projection du rayon sur la droite (point cliqué, normale) avec l'inférence « Extrémité » sur un sommet existant ; 2ᵉ clic ou saisie applique `pousserTirer` (une opération). **Après** : étape 1, outil gardé ; une longueur tapée **corrige** l'extrusion (`remplaceDernier`) tant que le modèle n'a pas changé ; double-clic sur une autre face = répéter la dernière distance. Ctrl : nouvelle face de départ (arête conservée à l'ancien niveau) ; Alt : bascule sans effet distinct. Échap : étape 1, sélection vidée. Distance nulle : message. |
| Données et dépendances | `geometrie-libre.ts` (opérations du noyau), `inference.ts`, `saisie-vcb.ts`, catalogue (consignes et libellés Mesures repris tels quels). |
| Résultats | Une boîte fermée, un trou traversant (face opposée parallèle atteinte exactement) ou un déplacement ; un pas d'annulation. |
| Cas limites | Saisie invalide, valeur nulle, élément hors du contexte d'édition, entrée avant la première étape : message nommé dans la barre d'état, rien n'est modifié. Géométrie impossible : le noyau lève une erreur, annoncée sans changer le modèle. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes du relevé anglais acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-PPT-1 → « CA-PPT-1 : rectangle 4 × 3, 2,7 → boîte fermée de 6 faces, 12 arêtes, volume 32,4 m³ » ; CA-PPT-2 → « −3 sur une face de normale +y » ; CA-PPT-3 → « … trou traversant » (la face arrière porte un trou) ; CA-PPT-4 → « Ctrl puis 1 sur le dessus » (4 arêtes à 2,7 m) ; CA-PPT-5 → « double-clic sur une face latérale après un tirage de 0,5 » ; CA-PPT-6 → « tirage au curseur puis 2,7 → une seule opération ». **e2e** — `planche.mjs` : `P`, clic, `2,7` → 5 faces et 8 arêtes de plus, un pas. |
| Règles métier | Aucune : outil de modélisation libre, brouillon local (aucune commande, rien n'est écrit dans le projet avant le lot 7). |
