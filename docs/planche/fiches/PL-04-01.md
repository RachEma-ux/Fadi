# PL-04-01 — Tape Measure / Mètre — mode Planche → Atelier — lot Planche 4

**État : disponible — acceptée le 8 octobre 2026 (D-174)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `packages/planche-model/src/outils/mesure.test.ts` (cas CA-MET-1 à -4, redimensionnement) ; recette `apps/web/e2e/planche-lots-4-6.mjs` (mètre).

| Champ | Contenu |
| --- | --- |
| Identité | PL-04-01, machine pure `outils/metre.ts`. Référence : `cahier-planche.md` §4.27, relevé [MCP §1.1]. Raccourci : T. |
| Situation utilisateur | Mesurer une distance ou une aire, poser des guides (lignes infinies, segments, points) et, au besoin, redimensionner toute la Planche d'après une mesure connue. |
| Entrées et unités | Clic de départ (arête = direction du guide, point accroché = mesure seule, point libre = guide fini) puis clic d'arrivée ou longueur au champ Mesures ; Ctrl = mode Lignes → Points → Mesure ; Maj = verrou de direction ; flèches = axes ; Entrée = confirmation du redimensionnement. Mètres ; survol d'une face : aire (m²). |
| Comportement | État `EtatMetre` { `etape` 1 \| 2 \| 3, `mode`, `depart`, `directionArete`, `mesure`, `confirmation`, `aire`, `texte`, `inference`, `erreur` }. Étape 1 : survol = aire d'une face ou point ; clic = départ. Étape 2 : Mesures = distance au curseur ; clic ou saisie → guide (ligne infinie parallèle à l'arête de départ, segment entre deux points libres, point de guide en mode Points) ou mesure seule (mode Mesure, lecteur, deux points accrochés). Étape 3 (mesure seule) : une longueur saisie demande confirmation ; Entrée redimensionne toute la Planche (`redimensionner`, un pas) ; Échap annule. |
| Données et dépendances | `annotations.ts` (guides), `geometrie-libre.ts` (`modifierAnnotations`, `redimensionner`), `inference.ts`, `saisie-vcb.ts`. |
| Résultats | Un guide (donnée de la Planche, annulable, effaçable par Suppr) ou une mesure affichée ; un redimensionnement de toute la Planche (géométrie, occurrences, annotations) en un pas. |
| Cas limites | Point d'arrivée confondu avec le départ : mesure nulle, rien créé ; lecteur (`ctx.lecture`) : jamais de guide ni de redimensionnement (message) ; saisie invalide : message. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-MET-1 → « survol d'une face 4 × 2,7 → Mesures « Aire · 10,8 m² » » ; CA-MET-2 → « depuis une arête, « 1 » → ligne de guide infinie parallèle à 1 m » ; CA-MET-3 → « mode Mesure, rien n'est créé » ; CA-MET-4 → « un lecteur mesure sans créer de guide » ; redimensionnement « 8 » + Entrée → × 2. **e2e** : guide infini, guide fini, point de guide, mesure seule, confirmation, Planche 8 × 6, Ctrl + Z. |
| Règles métier | Aucune (brouillon local). Le redimensionnement n'écrit rien dans le projet avant le lot 7. |
| Extensions à spécifier | Redimensionner un objet seul (doc) ; Maj = verrou (instr) partiellement couvert par les flèches. |
