| Situation utilisateur | Poser un texte en volume (enseigne, repère) comme un composant solide. |
| Entrées et unités | Boîte : texte, hauteur (m), plein, extrusion (m) ; OK puis clic de placement ; Annuler / Échap rend l'outil précédent. |
| Comportement | `EtatTexte3D` { boite, texte, hauteur, plein, extrusion, inference }. `configurerTexte3D` valide (texte non vide, hauteur > 0, extrusion ≥ 0) ; `facesDuTexte3D` : dessous (inversé), dessus, flancs ; `creerGroupeDepuisFaces` crée un **composant** nommé « Texte 3D « … » », sélectionné, outil Déplacer. Police 5 × 7 à angles droits ; contacts diagonaux supprimés (`sansPinces`) pour que chaque arête borde deux faces ; trous (« O », « A »…) gérés. |
| Données et dépendances | `police-geometrique.ts`, `geometrie-libre.ts`, `inference.ts`. |
| Résultats | Un composant solide posé au sol au point cliqué. |
| Cas limites | Texte vide / hauteur nulle / extrusion négative : refus dans la boîte ; caractère inconnu : ignoré et nommé dans le message ; extrusion 0 : faces plates (non solide, déclaré). |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-T3D-1 → « OK refusé avec un texte vide » ; CA-T3D-2 → « « Fadi » 0,30 / 0,15 → composant solide de 0,15 m, outil Déplacer, sélectionné ». **e2e** : boîte, OK vide refusé, « AB 12 » / 0,5 → composant de 84 faces, z 0 → 0,15, Annuler → outil précédent. |
| Règles métier | P-7 : police géométrique propre à Fadi, aucune police tierce. |
| Extensions à spécifier | Choix de police, alignement, texte sur une face verticale. |
