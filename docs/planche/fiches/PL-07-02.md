# PL-07-02 — Named Planches, main menu, project binding / Planches nommées, menu principal, Planche reliée au projet — mode Planche → Atelier — lot Planche 7

**État : prototype**. Preuve liée : recette `planche-lot-7.mjs` (brouillon → Planche, journal, Ctrl + Z / Y, hors ligne, renommer, niveau, enregistrer sous, ouvrir, supprimer, 3D, téléphone, axe-core).

| Champ | Contenu |
| --- | --- |
| Identité | PL-07-02, `Planche.tsx` (`poserHistorique` → `planche.operation`, adoption du modèle du projet par empreinte, `actionsMenu`), `menu-planche.tsx` (`MenuPlanche`), `etat-ui.ts` (`plancheId`), `AtelierNouveau.tsx` (props `etat`, `plancheId`, `onCommandes`), `vue3d/scene3d.ts` (`majPlanches`). Référence : §7.1, P-1, D-172. |
| Situation utilisateur | Tenir plusieurs Planches dans un projet, les nommer, les rattacher à un niveau, les retrouver d'un appareil à l'autre, les voir en 3D. |
| Entrées et unités | Menu ☰ : Ouvrir, Nouvelle Planche… (nom, reprise du brouillon), Renommer / niveau de référence…, Enregistrer sous…, Supprimer (confirmation), Exporter la Planche en IFC, Télécharger la vue (PNG). |
| Comportement | Sans Planche : brouillon local (IndexedDB) comme au lot 2, reprise proposée. Avec Planches : la première s'ouvre ; chaque pas local envoie une commande par le bus (optimiste, file hors ligne) ; le modèle du projet est adopté quand son empreinte diffère de la locale (changement d'un autre poste, lot refusé) avec le message « Planche mise à jour depuis le projet » ; rien n'est plus écrit dans le brouillon. Créer / copier ouvrent la nouvelle Planche ; supprimer ouvre la suivante. 3D : un `Mesh` gris par objet de Planche, dans le groupe du niveau de référence, non sélectionnable. |
| Données et dépendances | `planches(etat)`, `differencePlanche`, `empreintePlanche`, `maillagesPlanche`, `api.getPlancheIfc`. |
| Résultats | Planches du projet synchronisées entre appareils par le bus de l'Atelier ; journal partagé. |
| Cas limites | Lecture seule : menu désactivé sauf Ouvrir / exports ; projet protégé (exemple) : copie de travail créée par le bus comme pour tout lot ; nom en double refusé par le serveur (message dans la barre d'état). |
| Compatibilité | Téléphone : menu plein largeur sous la barre du haut ; axe-core sans violation sérieuse. |
| Validation | e2e : 31 vérifications vertes ici (ordinateur et téléphone). |
| Règles métier | R10 (Planche ouverte = état d'interface, données dans le modèle), MO-2. |
| Extensions à spécifier | Synchronisation temps réel (canal serveur) ; glisser-déposer entre Planches ; Planche de référence en Plan 2D. |
