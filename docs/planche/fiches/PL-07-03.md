# PL-07-03 — IFC export of Planches / Export IFC des Planches — mode Planche → Atelier — lot Planche 7

**État : prototype**. Preuve liée : `atelier-planches.test.ts` (IFC relu par web-ifc : proxys, volume, altitude), corpus `petit.ifc` (IfcOpenShell en CI), recette `planche-lot-7.mjs` (IFC d'une Planche seule, IFC du projet).

| Champ | Contenu |
| --- | --- |
| Identité | PL-07-03, `echanges/ifc.ts` (section Planches), `representation.ts` (`maillagesPlanche`), route `GET /projects/:id/atelier/planches/:plancheId/export.ifc`. Référence : C14, P-6, D-172. |
| Situation utilisateur | Transmettre la géométrie libre d'une Planche dans l'IFC du projet, ou seule. |
| Entrées et unités | Modèle de la Planche (m) ; niveau de référence → `IfcBuildingStorey` parent ; sinon `IfcBuilding`. |
| Comportement | Un `IfcBuildingElementProxy` (ObjectType « Planche », PredefinedType NOTDEFINED) par objet de la racine, représentation `Body / Tessellation` (`IfcTriangulatedFaceSet`, `Closed` = .T. pour les solides), un proxy « Géométrie libre » pour les faces de la racine ; `Fadi_Planche` : Planche, Identifiant (`planche|objet`), Genre, Solide, Volume (solides seulement, m³). GlobalId dérivé du projet, de la Planche et de l'objet (reproductible). |
| Données et dépendances | `maillageDuSolide` (lot 6) pour les solides, triangulation face par face sinon ; objets masqués exclus. |
| Résultats | Nombre de proxys et volumes égaux à ceux de la Planche à la relecture (web-ifc) ; fichier identique d'une production à l'autre. |
| Cas limites | Planche vide : aucun proxy, remarque dans le rapport ; objet non solide : sans volume (« non évalué ») ; niveau de référence supprimé : sous le bâtiment. |
| Compatibilité | IFC4X3_ADD2 ; validé par IfcOpenShell (schéma, règles EXPRESS) sur le corpus `petit.ifc`. |
| Validation | API : 2 proxys, volume 4 m³ (10⁻⁶), z min 0,5 m ; e2e : 1 proxy pour une Planche seule, 2 « Planche » dans l'IFC du projet avec les murs. |
| Règles métier | C14 (classe proxy, jamais un reclassement), MO-4 (rien de promis avant mesure). |
| OBJ / STL (D-173) | `exporterObj` : `o` par maillage, `v` en mètres, `f` triangulaires indexées à partir de 1 ; `exporterStl` : STL ASCII, un `solid`, normale unitaire par facet ; écrits dans la page depuis le menu ☰ ; recette : 2 `f` / 2 facets pour une face libre. |
| Extensions à spécifier | Matières IFC (`IfcSurfaceStyle`) des faces peintes ; STL binaire si des Planches volumineuses l'exigent. |
