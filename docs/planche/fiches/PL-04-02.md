# PL-04-02 — Dimensions / Cotes · Protractor / Rapporteur — mode Planche → Atelier — lot Planche 4

**État : prototype** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : `outils/mesure.test.ts` (CA-COT-1, -2, CA-RAP-1, pente) ; recette `planche-lots-4-6.mjs` (cotes, rapporteur).

| Champ | Contenu |
| --- | --- |
| Identité | PL-04-02, machines pures `outils/cotation.ts` et `outils/rapporteur.ts`. Référence : §4.28, §4.29, relevé [MCP §1.2, §1.3]. Sans raccourci (grille). |
| Situation utilisateur | Coter une arête, deux points ou le diamètre d'un cercle ; mesurer un angle et poser un guide angulaire. |
| Entrées et unités | Cotes : clic sur une arête (ou un cercle : diamètre) puis placement ; ou deux points puis placement. Rapporteur : centre, début, angle au curseur ou `30` / `4:12` ; Ctrl = bascule de création des guides ; Maj = verrou du plan. |
| Comportement | Cotes : `EtatCotation` { `etape` 1 \| 2 \| 3, `a`, `b`, `sommets`, `diametre`, `inference` } ; la cote linéaire est **associée** aux sommets quand les points sont accrochés (la valeur suit un déplacement) ; la cote de diamètre à la courbe. Rapporteur : `EtatRapporteur` { `etape`, `centre`, `normale`, `depart`, `guides`, `texte` } ; angle accroché à 15° à ±1,5° ; le guide est une ligne infinie passant par le centre dans la direction de l'angle. |
| Données et dépendances | `annotations.ts` (`Cote`, `Guide`), `geometrie-libre.ts`, `inference.ts`, `saisie-vcb.ts` (angles, pentes). |
| Résultats | Une cote (étiquette « 4,00 m » ou « ⌀ 1,20 m » posée par la vue, lignes d'attache) ; un guide angulaire ; un pas chacun. |
| Cas limites | Second point confondu : message ; angle nul : message ; cercle visé par une arête de courbe fermée : diamètre, sinon cote d'arête. |
| Compatibilité | Forme française du champ Mesures (virgule décimale, point-virgule de liste) ; formes anglaises acceptées lorsqu'elles ne sont pas ambiguës (D-167, P-3). |
| Validation | CA-COT-1 → « deux sommets à 4 m → cote « 4,00 m » associée ; la valeur suit le déplacement d'un sommet » ; CA-COT-2 → « cercle de rayon 0,6 → « ⌀ 1,20 m » » ; CA-RAP-1 → « centre (0;0;0), début +x, « 30 » → direction (cos 30° ; sin 30° ; 0) ; aucun guide quand Ctrl désactive la création » ; pente « 4:12 ». **e2e** : cote d'arête, cote entre deux points, deux étiquettes « 4,00 m », sélection et Suppr d'une cote ; guide à 30°, pente. |
| Règles métier | Aucune. |
| Extensions à spécifier | Info entité des cotes (police, extrémités, alignement) : panneau du lot 5 ; texte de cote libre. |
