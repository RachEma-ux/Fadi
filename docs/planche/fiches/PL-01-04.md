# PL-01-04 — Tool catalogue / Catalogue déclaratif des outils — mode Planche → Atelier — lot Planche 1

**État : disponible — acceptée le 8 octobre 2026 (D-174)** (à spécifier → spécifiée → prototype → vérifiée → disponible). Preuve liée : tests vitest de `packages/planche-model` (lot 1, puis audit du 7 octobre : 407 tests), recette `apps/web/e2e/planche-outils.mjs` ; comptes rendus `docs/planche/lots/lot-1.md` à `lot-7.md`.

| Champ | Contenu |
| --- | --- |
| Identité | PL-01-04, catalogue déclaratif des outils de la Planche (`packages/planche-model/src/catalogue-outils.ts`). Sous-exigences : -a descripteur d'outil ; -b contenu (45 outils du cahier §4) ; -c contrôle du catalogue ; -d recherche et raccourcis. Référence : `cahier-planche.md` §3.2–3.3, §4, §5.5, §5.9, §5.10. Données pures (aucune machine d'états au lot 1 : elles viennent au lot 2 et lisent ce catalogue). |
| Situation utilisateur | (Servie à partir du lot 2.) Trouver un outil par son nom français, son nom anglais ou son raccourci ; lire, pour l'étape en cours, la consigne de la barre d'état, le libellé du champ Mesures et les touches de modification ; ouvrir l'Instructeur sur la bonne fiche. |
| Entrées et unités | Aucune entrée utilisateur au lot 1 ; contenu rédigé à partir du cahier §4. Unités des bornes : mètres, degrés, nombres sans dimension. |
| Comportement | **-a Descripteur** `DescripteurOutil` = { `id` (ex. `ligne`, `arc-2-points`, `pousser-tirer`), `nom` (français), `nomReference` (anglais relevé, ex. `Line`, utilisé comme synonyme de recherche seulement, cahier C1), `synonymes` (français), `raccourci` (ex. `L`, `Maj+Espace`, `Ctrl+Maj+E` ; absent si aucun), `acces` ∈ { barre, grille, menu-contextuel }, `section` (sélection, dessin, modification, construction, caméra), `lot` (1 à 7), `etapes` : liste de { `id`, `consigne` (français), `consigneReference` (texte relevé, anglais), `libelleMesures` (français), `libelleReference`, `attente` (formes de saisie admises et bornes, PL-01-02), `modeVerrou` ∈ { direction, plan, aucun } (PL-01-03), `statut` }, `modificateurs` : liste de { `touche` (Ctrl, Alt, Maj, Maj+Ctrl, flèches, Ctrl+plus, Ctrl+moins), `effet`, `nature` ∈ { bascule, maintenu, cycle }, `etapes` concernées, `statut` }, `inferences` (types proposés, PL-01-03), `apresCreation` ∈ { reste-actif, etape-1, enchaine, outil-precedent, autre-outil (id) }, `echap` ∈ { etape-1, outil-precedent, sortir-contexte, vider-selection }, `astuces` (français, rédigées par Fadi), `ecarts` (écarts Fadi déclarés, renvoi au cahier §2), `statut` global ∈ { obs, instr, doc, nv, fadi }, `renvois` (ex. `OD §4`, `CM §7`) }. |
| | **-b Contenu.** Les 45 outils : Sélection, Lasso, Gomme, Ligne, Main levée, Rectangle, Rectangle tourné, Cercle, Polygone, Arc, Arc 2 points, Arc 3 points, Secteur, Texte 3D, Pousser / tirer, Déplacer, Rotation, Échelle, Décalage, Suivez-moi, Retourner, Coque extérieure, Intersection, Union, Soustraction, Découpe, Scission, Peinture, Prélever le matériau, Mètre, Cotes, Rapporteur, Axes, Texte, Plan de coupe, Balise, Orbite, Panoramique, Zoom, Zoom étendu, Zoom fenêtre, Positionner la caméra, Regarder autour, Marcher, Diviser. Valeurs par défaut relevées portées par les attentes (côtés : 24 cercle, 6 polygone, 12 arcs et secteur ; segments de Diviser : 5 ; champ de vision : 35° ; bornes de segments 3 à 999) ; une valeur non relevée n'est pas inscrite (R3). Ordre de la barre et de la grille : celui du relevé (cahier §3.2–3.3). |
| | **-c Contrôle** (`verifierCatalogue()` → liste nominative d'erreurs, vide si correct) : identifiants uniques ; raccourcis uniques (aucune touche ne désigne deux outils) ; chaque outil a au moins une étape, chaque étape une consigne française non vide et un libellé Mesures ; chaque statut dans l'énumération ; chaque renvoi désigne l'un des six fichiers de `docs/planche/reference/` (OD, OM, CM, MCP, CP, DOC) ; chaque outil dont le `statut` est `nv` déclare un écart ou une astuce disant ce qui n'est pas vérifié ; aucune consigne en anglais dans `consigne` (contrôle : la consigne n'est pas égale à `consigneReference`) ; les 45 identifiants attendus sont présents. |
| | **-d Recherche et raccourcis** : `rechercherOutils(texte)` — insensible à la casse et aux accents, sur `nom`, `synonymes` et `nomReference` ; ordre : correspondance exacte du nom, début de nom, synonyme, nom de référence, puis ordre du catalogue ; `outilParRaccourci(touche, modificateurs)` sur le caractère de la touche (`KeyboardEvent.key` fourni par l'interface ; comportement de SketchUp sur AZERTY non relevé, cahier L-29). Les raccourcis attribués par l'utilisateur sont une préférence locale (lot 2), pas une donnée du catalogue. |
| Données et dépendances | Données et fonctions pures (R6), aucune dépendance ; consommé au lot 2 par les machines d'états (`packages/planche-model/outils/`), la barre d'outils, la grille, la barre d'état, le champ Mesures, l'Instructeur et la palette de l'Atelier. |
| Résultats | Le catalogue figé (`CATALOGUE_OUTILS`, lecture seule) ; une liste d'erreurs de contrôle ; des résultats de recherche. |
| Cas limites | Outil hors interface livrée (ex. Intersection avant le lot 6) : présent au catalogue avec son `lot`, affiché désactivé avec motif (« Disponible au lot 6 »), jamais actif sans effet (R20) ; deux synonymes communs à deux outils : les deux sont rendus, ordre du catalogue ; recherche vide : aucun résultat. |
| Compatibilité | Textes de référence anglais conservés pour la traçabilité avec les relevés ; aucun texte de l'Instructor de SketchUp n'est recopié (les astuces sont rédigées par Fadi). |
| Validation | **Unité** (`catalogue-outils.test.ts`) : `verifierCatalogue()` vide ; 45 outils ; `outilParRaccourci("l")` → `ligne`, `("Espace", Maj)` → `lasso`, `("e", Ctrl+Maj)` → `zoom-etendu`, `("w", Maj)` → `zoom-fenetre` ; `rechercherOutils("pousser")` et `("push")` → `pousser-tirer` en tête ; `("cote")` → `cotes` ; Ligne : 2 étapes, libellé Mesures « Longueur », modificateurs Maj (maintenu), Alt (cycle), flèches (bascule), `apresCreation` = enchaine ; Rectangle : Ctrl (bascule), libellé « Dimensions », attente liste de 2 longueurs ; Cercle : étape 1 « Côtés » défaut 24 bornes 3–999, étape 2 « Rayon » ; Polygone : défaut 6 ; Peinture : Ctrl, Maj, Alt **maintenus** ; Mètre : Ctrl `cycle` de 3 modes ; Texte 3D : `apresCreation` = autre-outil `deplacer` ; Plan de coupe : autre-outil `selection` ; Prélever : autre-outil `peinture` ; Positionner la caméra : autre-outil `regarder-autour` ; Orbite, Panoramique, Zoom fenêtre : `echap` = outil-precedent ; Sélection : `echap` comprend sortir-contexte ; chaque outil `nv` a un écart déclaré ; un catalogue modifié en test avec un raccourci en double → erreur nommée. **API, e2e** : sans objet au lot 1. |
| Règles métier | Aucune. R1 : tout texte destiné à l'affichage est français ; R3 : aucune valeur par défaut non relevée. |
| Extensions à spécifier | Machines d'états des outils (lot 2 et suivants) ; textes de l'Instructeur (illustrations, exemples) ; personnalisation de la grille (« Edit », cahier L-30) ; commandes du menu contextuel (cahier §5.8) en descripteurs de même forme ; raccourcis attribuables. |
