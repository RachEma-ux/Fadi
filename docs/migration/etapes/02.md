## Événements, validations, calculs

- Saisie d'un champ → sauvegarde immédiate (`change` dans le prototype ; `blur` dans Fadi, PATCH validé par type côté serveur).
- Harmonie : « Retenir » remplace toute autre variante retenue (« Variante remplacée par … ») ; « Adapter / motiver » et « Écarter avec motif » exigent 8 caractères ; traduire / dessiner / vérifier exigent responsable + preuve ; « Dessinée » seulement dès l'étape 10 ; une intention retenue remet à faire les étapes cibles et rétrograde un GO pris à l'étape 19.
- Péremption : l'empreinte de l'étape couvre le site et le formulaire de l'étape et les règles d'implantation (`setback`) de la parcelle, plus les intentions reçues (version d'arbitrage, péremption de l'origine) ; si elle change après la génération, l'étape est « à réexaminer » (choix conservés, vérification refusée jusqu'à « Actualiser les propositions ») et chaque choix retenu sur une autre empreinte affiche « À réexaminer · choix conservé » jusqu'à « Confirmer ce choix ».
- « Marquer terminée » bascule l'état ; la progression (n / 21) ne compte que les étapes marquées terminées.

## Harmonie

Périmètre « Site constructible ». Propositions (texte intégral dans `parcours-steps.json`) :

- **A · Préserver l’intention, déplacer le dispositif** — Déplacer parvis, filtre paysager ou desserte dans les espaces dont l’usage est admissible ; garder une transition extérieure lisible.
- **B · Concentrer l’aménagement dans une zone moins contrainte** — Regrouper les aménagements permanents dans le secteur admissible et réserver les secteurs incertains à des usages réversibles sous réserve.
- **C · Comparer un autre site ou un programme adapté** — Lorsque l’intention principale est incompatible, comparer un autre site ou réduire le programme plutôt que forcer une implantation.

Exemple P.118 : choix **A** retenu — « Préserver l’intention dans l’enveloppe admissible ».
