## Harmonie

Périmètre « Comparaison argumentée ». Propositions (texte intégral dans `parcours-steps.json`) :

- **A · Retenir le scénario le mieux étayé** — Privilégier la solution répondant aux besoins documentés avec les réserves les plus explicitement traitées.
- **B · Combiner les solutions compatibles** — Assembler les qualités de variantes distinctes seulement si leur compatibilité est démontrée.
- **C · Demander un essai ciblé avant arbitrage** — Identifier la donnée ou l’essai qui départagera les variantes.
