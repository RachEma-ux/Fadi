    REPÈRES ET MESURES

    Une géométrie traçable

    Exemple Lot 118

    Les quatre bornes sont reprises du fichier P118_Site_Interactif_V12_16-1.html, qui les rattache au document cadastral S01 « Calcul contenance_T61833-25 cl_Signed_GLOBAL (1).pdf ». Ce document original n’a pas été relu pour cette page.

    Ordre conservé : B.266 → B.267 → B.268 → B.265. Aire brute des coordonnées : 1 345,54755 m². Contenance cadastrale retenue dans le dossier : 1 346 m². Ces deux valeurs ont des fonctions différentes.

    Référentiel et position

    Le fichier source ne certifie pas le code EPSG. Merchich / Nord Maroc (EPSG:26191) est proposé comme hypothèse de localisation. La transformation vers WGS84 utilise la translation 31 / 146 / 47 m ; sa précision publiée est de l’ordre de 7 m. La position doit être vérifiée avant tout usage nécessitant une précision cadastrale.

    Les longueurs et la surface sont calculées dans le plan Lambert, sans correction de projection ni réduction au terrain. Le nord de la carte est géographique. Une image satellite peut présenter un décalage : les bornes source restent la référence.

    Utilisation

    Modifiez le tableau pour recalculer le contour. Sélectionnez une ligne puis utilisez ↑ ou ↓ pour changer l’ordre. Le déplacement des bornes sur la carte est désactivé par défaut. Utilisez Mes parcelles pour passer d’un fichier à l’autre. Nouvelle parcelle crée un fichier indépendant. Les modifications de cette copie sont conservées sur cet appareil lorsque le navigateur le permet. Elles ne sont pas synchronisées avec le site ; Télécharger ce fichier produit une copie JSON réimportable, même incomplète.
